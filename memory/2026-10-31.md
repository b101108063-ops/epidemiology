## Hugo 站台兩個部署級 bug（2026-10-31 修正）

### Bug 1：`ignoreFiles` 規則吃掉首頁
`hugo.toml` 裡的 `ignoreFiles = ["content/_[^/]*$"]` 會匹配 `_index.md`，導致首頁被排除在 build 之外，線上 `<main class=main></main>` **完全空白**（但 HTTP 仍是 200，所以只看 status code 會漏掉）。

修正：**直接刪掉這條規則**。Hugo 本身預設就忽略底線開頭的 content 檔案，`_index.md` 自動例外，規則本來就多餘。
- 想用 regex 排除 `_index.md` 的話，Hugo 用 RE2，**不支援 lookahead `(?!`**，會報 `invalid or unsupported Perl syntax`。
- `oku14_hugo/hugo.toml` 有同款規則（`content/oku14/_[^/]*$`），一併刪除。
- 站台 repo commit `a5cbab9`、root repo `3f7b0d7`。

### Bug 2：圖片在子路徑站台全部 404
站台部署在 `/oku14/` 子路徑，但 markdown 寫的是根相對路徑 `/images/oku14/x.jpg` → 解析到網域根 → 404。PaperMod 的 `render-image.html` 對非 page resource 的路徑原樣保留，不會改寫。

修正：新增站台自有 render hook `oku14_site/layouts/_markup/render-image.html`，用 `strings.TrimPrefix "/"` 後走 `relURL`，把根路徑轉成 `/oku14/images/...`。
- **注意：`relURL("/images/x.jpg")` 不會加 baseURL 前綴**（它只處理相對路徑），必須先去掉開頭斜線：`relURL(strings.TrimPrefix "/" $u.Path)`。
- 站台 repo commit `92cb519`。

### 驗收教訓
- **HTTP 200 不等於頁面有內容**。必須解析 HTML 抓 `<main>` 的實際長度。線上首頁空殼回 200 但 main 只有 6 bytes。
- Hugo `--minify` 會去掉 HTML 屬性引號（`src=/oku14/...` 而非 `src="/oku14/..."`），驗證 regex 要兩種都吃，否則會誤判「圖片缺失」。
- 驗證站台圖片時要把 baseURL 前綴剝掉再比對本機 `public/`，因為 `public/` 內容部署到 gh-pages 根。
