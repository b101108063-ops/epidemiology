# Chapter 5: Health Policy — 醫療政策

## 章節導讀

醫療政策不是骨科醫師的行政雜務，而是決定醫院能否收支平衡、術式能否執行、病人能否取得照護的系統性框架。本章從美國聯邦資助的 Medicare 與 Medicaid 談起，進入 DRG 給付、醫院取得條件扣款、ACA 與替代支付模式，最後整理星等評分、門診關節置換、ASC 與價格透明化對臨床與經營的衝擊。

---

## 1. 政策框架與醫療可近性 (Policy Frameworks & Access)

本章的關鍵結構是**支付方（payer）—提供者（provider）—病人（patient）三方的權利義務關係**。

### 1.1 聯邦資助醫療的起源

美國二戰後因缺乏資金而未建立普及性健保。1965 年國會通過 <span style="color:#60a5fa">Social Security Amendments of 1965</span>，同時設立 Medicare 與 Medicaid，成為美國政府資助醫療的主要形式。監理機構多次改組：1976 年成立 <span style="color:#e2e8f0">Health Care Financing Administration</span>，2001 年更名為 <span style="color:#60a5fa">CMS</span>，沿用至今。

### 1.2 Medicare

Medicare 提供年滿 65 歲美國成人的醫療保險。制度建立前估計僅 <span style="color:#f87171">60%</span> 的 65 歲以上成人可取得照護。現行涵蓋三大族群：(1) 65 歲以上人口；(2) 65 歲以下但具特定障礙者；(3) 所有末期腎病患者。

| 項目 | 內容 |
|------|------|
| <span style="color:#e2e8f0">Part A</span> | 住院就醫、技術護理機構、部分居家健康服務與 hospice care；由強制薪資扣繳籌資 |
| <span style="color:#e2e8f0">Part B</span> | 補充保險：醫師與門診服務、部分居家健康服務、耐久醫療設備（手杖、助行器、輪椅、義肢）；由保費與聯邦預算籌資 |
| <span style="color:#e2e8f0">Part C</span> | Medicare Advantage plan，由核准私人保險機構提供 A、B（通常另含 D）給付之組合，可選 HMO 或 PPO |
| <span style="color:#e2e8f0">Part D</span> | 2003 年《Medicare Prescription Drug, Improvement, and Modernization Act》設立，涵蓋處方藥，由 Medicare 監管的私人贊助者承辦 |
| 成本分擔 | 年度 deductible 達成後自付 20% coinsurance；A/B 級預防篩檢由 Part B 支付 100% |

- **99% 的受益人**不需支付任何 deductible；僅 **1%** 承保工作年資未滿 10 年者需繳年度調整的住院 deductible（2021 年為 <span style="color:#f87171">$1,484</span>）。
- **Part C 的取捨**：Advantage 計劃收到聯邦 rebates，須部分用於降低保費、增加額外給付或降低 cost sharing。2019 年約 **1/3** 参保人加入 Advantage，其中逾 **60%** 選較便宜的 HMO——但可能產生<span style="color:#f87171">取得專科照護障礙</span>。
- **人口與支出趨勢**：成立時 1,900 萬人；2020 年估計 <span style="color:#60a5fa">6,120 萬</span>人，2030 年預估 8,000 萬人；支出由 2018 年 <span style="color:#34d399">$7,502 億</span>增至 2028 年逾 <span style="color:#f87171">$1.5 兆</span>。近可能政策為合格年齡降至 60 歲、納入牙科與視力。
- 1997 年《Balanced Budget Act》為平衡預算而**擴大** Medicare，允許私人保險提供替代方案，將更多成本轉由個人負擔。

### 1.3 Medicaid

Medicaid 依 1965 年 Social Security Amendments 第 XIX 條設立，為聯邦與州政府合作方案，聯邦以 matching 補助州支出；州可自行設定預算與合格人口。

| 聯邦要求必須覆蓋的四類強制人口 | 說明 |
|---------------------------|------|
| 低收入家庭兒童、低收入孕婦 | 所得低於 <span style="color:#60a5fa">138%</span> 聯邦貧窮線（FPL） |
| 低收入家長與照顧者 | 特定族群 |
| 領取 SSI 現金援助的高齡者與障礙者 | SSI 受助者 |

- 聯邦 matching 依各州人均所得介於 <span style="color:#34d399">50%–75%</span>；ACA 規定 2014–2016 年至多 100%、2020 年後 90%，以支持州層級擴大。
- **逆週期特性（countercyclical）**：經濟衰退時許多人失去工作與雇主保險，参保人數隨之上升——2008 年金融危機後增加逾 <span style="color:#60a5fa">1,000 萬人</span>，紓解無保險者需求並降低州政府財務壓力。
- 現況：涵蓋約 <span style="color:#60a5fa">1/5</span> 美國人、占醫療支出 <span style="color:#60a5fa">16%</span>；2019 財年支出約 <span style="color:#34d399">$6,040 億</span>。
- **State CHIP**：依 1997 年《Balanced Budget Act》設立，服務所得高於 Medicaid 門檻但無力負擔私人健保家庭之兒童；聯邦 matching 較優，多數與 Medicaid 合併。


### 1.4 私人健康保險

私人健保是 2018 年最大單一保險來源，占健保支出 <span style="color:#60a5fa">34%</span>；2019 年涵蓋 <span style="color:#60a5fa">67.3%</span> 美國人口。

| 計劃類型 | 特性與臨床注意 |
|---------|-----------------|
| <span style="color:#e2e8f0">HMO</span> | 管理式醫療，體系內整合團隊，支付採固定費率；保費與自付成本低但**不涵蓋網外醫療**。PCP 為 gatekeeper，專科轉介須符合指引「醫療必要性」 |
| <span style="color:#e2e8f0">PPO</span> | 網內就醫費用較低，可自付較高費用尋求網外照護；**不需 PCP 轉介**；保費略高 |
| <span style="color:#e2e8f0">POS</span> | HMO／PPO 混合，鼓勵網內就診但**仍須 PCP 授權** |
| <span style="color:#e2e8f0">EPO</span> | 排除網外照護但**不需 PCP 授權**；網外費用全自付 |
| <span style="color:#60a5fa">Catastrophic</span> | 極低月費換極高年度 deductible；2020 年為 <span style="color:#f87171">$8,150</span>；限 30 歲以下或獲豁免 |
| <span style="color:#e2e8f0">HSA</span> / FSA | 雇主／員工稅前提撥；HSA 須搭配高 deductible 計劃，餘額可**rollover**；FSA 年末未用即作廢 |

> **Danger zone**：HMO 的 gatekeeping 與 PPO 的 cost sharing 都會直接影響骨科專科的可近性；政策分析不能只看「有無保險」，必須區分保險**類型**。

## 2. 給付機制與品質扣款 (Reimbursement & Payment Mechanics)

### 2.1 DRG 給付與收入循環管理 (DRG & Revenue Cycle Management)

<span style="color:#e2e8f0">DRG</span> 最初由耶魯大學多學科團隊構思，用以分類病人於一次照護過程中所接受的產品。美國政府於 <span style="color:#60a5fa">1983 年 10 月</span>建立 Medicare Inpatient Prospective Payment System，以 DRG 給付控制成本。

| DRG 機制 | 內容 |
|----------|------|
| 分類依據 | 主要診斷碼、最多 24 個其他診斷、最多 25 項處置 |
| MS-DRG | Medicare Severity Diagnosis-Related Groups；多數群組再細分「有／無併發症或共病」 |
| 給付方式 | 依**同一 MS-DRG 內所有病人的平均成本**給付 |
| 數量 | 2021 年 CMS 認可 <span style="color:#60a5fa">767</span> 個 MS-DRG，其中 <span style="color:#60a5fa">75</span> 個為骨科 |

MS-DRG 470（下肢大關節置換或再接合，無重大併發症或共病）是**所有 DRG 中第四常見的主要診斷**。MS-DRG 數量每年調整以納入新診斷與技術，設計目的是使同群病人具有臨床一致性。

### 2.2 醫師費用表 (Physician Fee Schedule)

CMS 以 Medicare 醫師費用表給付醫療服務，以 <span style="color:#e2e8f0">relative value units (RVUs)</span> 衡量：依服務複雜度與資源使用量決定，並做地理校正。

- <span style="color:#f87171;font-weight:600">CMS 近期提案對所有骨外科 RVU 調降 5%，另對髖、膝關節置換術額外調降 5.4%</span>。高 deductible 計劃年度支出變動不得超過 $2,000 萬；某領域加薪必然伴隨其他領域減薪。
- 聯邦政府因骨科學會壓力及 COVID-19 疫情影響而**暫緩調降**；若實施，未來數年骨科照護可近性將受威脅。

> **Pearl**：每一項骨科服務在 RVU 體系中都有對應的「價格標籤」；了解 RVU 與 MS-DRG 的關係，是理解醫院與醫師團隊收入結構的最低門檻。

### 2.3 醫院取得條件扣款 (HAC Reduction Program)

2008 年 CMS 推行 <span style="color:#e2e8f0">Hospital-Acquired Conditions (HACs) Initiative</span> 以強化 value-based care。HAC 定義為**入院時不存在、住院期間新發生的疾病或併發症**。


| HAC 類別 | 內容 |
|---------|------|
| 8 項嚴重可報告事件 | 手術後遺留異物、氣體栓塞、ABO 血型不相容、Stage III/IV 壓瘡、跌倒與創傷、導管相關泌尿道感染、導管相關血管感染、SSI |
| 2009 財年擴充 | 特定骨科處置後的 SSI、減重手術後的 SSI、心臟電子裝置後的 SSI |
| 第 11、12 項 | 新發生的糖尿病嚴重併發症；特定骨科處置後的 DVT 或肺栓塞 |

- HAC Reduction Program 自 **2014 年 10 月**生效，HAC 分數位於**後 25 百分位**的醫院支付被 <span style="color:#f87171">扣減 1%</span>。全美住院樣本 3.51 億人次的 HAC 率為 <span style="color:#f87171">4%（每 25 次住院 1 次）</span>。

| 手術 | HAC 發生率 | 主要 HAC 類別 |
|------|-----------|--------------|
| 頸椎 fusion | <span style="color:#f87171">4.6%</span> | 跌倒創傷 95.2%、SSI 3.7% |
| 胸腰段 fusion | <span style="color:#f87171">5.2%</span> | 跌倒創傷 87%、SSI 11% |
| 畸形相關 fusion（2019） | <span style="color:#f87171">5.4%</span> | CAUTI 2.1%、SSI 1.8%、VTE 1.8% |
| TKA／THA | <span style="color:#f87171">1.3%</span> | TKA：血栓栓塞 0.8%、跌倒創傷 0.4%、SSI 0.2%；THA：跌倒創傷 0.9%、DVT/PE 0.3% |

- **經濟衝擊**：laminectomy 與 fusion 的 HAC 造成逾 <span style="color:#f87171">$20 億</span>額外成本，每件約 <span style="color:#f87171">$40,000</span>、延長住院 <span style="color:#f87171">8.17 天</span>，並占用床位、延誤復工。
> **Pearl**：HAC 扣款把「品質」直接轉譯為金錢，支付方因此可在手術**前**依 HAC 風險因子做 risk stratification；高風險病人轉診低風險中心對雙方都有利。

美國四大骨科住院術式年執行量：TKA <span style="color:#60a5fa">752,900</span>、THA <span style="color:#60a5fa">522,800</span>、spinal fusion <span style="color:#60a5fa">463,200</span>、laminectomy <span style="color:#60a5fa">438,200</span> 例。選擇性 fusion 由 2004 年 122,679 例增至 2015 年 199,140 例（<span style="color:#60a5fa">62.3%</span>），以 65 歲以上病人為主；增幅最大為脊椎滑脫（<span style="color:#f87171">111%</span>）與脊柱側彎（<span style="color:#f87171">186.6%</span>）；2015 年椎間盤退化、突出與狹窄共占 <span style="color:#60a5fa">42.3%</span>。

## 3. ACA 與替代支付模式 (ACA & Alternative Payment Models)

### 3.1 病人保護與可負擔醫療法案 (PPACA/ACA)

2010 年，在 Barack Obama 總統領導下推動的 <span style="color:#60a5fa">Patient Protection and Affordable Care Act (PPACA/ACA)</span>，目標是擴大全民保險覆蓋、提供病人保護，並建立 <span style="color:#e2e8f0">individual mandate</span>（須投保最低保險額度，否則繳罰金）。

**ACA 授權的四個 value-based 計畫**：Hospital Readmissions Reduction Program、Hospital Value-Based Purchasing Program、HAC Reduction Program 與 Physician Value-Based Modifier；目的為更好照護與更低成本。品質量測方案包括 Physician Quality Reporting System 與 Hospital Outpatient／Inpatient Reporting。

- **ACA 同時設立 health insurance exchange**：供消費者比較並直接購買私人保險的 marketplace，由聯邦或州規管；並**大幅擴大 Medicaid**，統一合格所得線至 <span style="color:#60a5fa">133%</span> FPL，以 100% 聯邦補助支持州。
- 強制投保使更多年輕健康人加入保險池，有助分攤風險；**2017 年《Tax Cuts and Jobs Act》廢除 individual mandate**。


### 3.2 ACA 的憲法攻防

| 時點 | 事件 | 結果 |
|------|------|------|
| 2011 年 11 月 | 對 Medicaid 強制擴大與 individual mandate 提起挑戰 | 2012 年 7 月 28 日最高法院裁定**反對**聯邦強制州 Medicaid 擴大，認為扣留聯邦經費具**脅迫性（coercive）**；各州可自行決定 |
| 2014 年 | <span style="color:#e2e8f0">Halbig v. Burwell</span> 與 <span style="color:#e2e8f0">King v. Burwell</span> | 主張 ACA 中「由州建立的 exchange」條文使聯邦 exchange 保費補助違憲；Roberts 大法官多數意見支持歐巴馬政府，採「contextual definition」，確保數百萬人在聯邦 exchange 投保的合法性 |
| 2018 年 2 月 | <span style="color:#e2e8f0">Texas v. Azar</span> | 裁定 individual mandate 為 ACA 核心條款，刪除罰金後牴觸課稅權；**但未處理 mandate 本身合憲性** |

**對骨科照護的影響**：ACA 允許各州將 Medicaid 合格年齡下修至 65 歲以下、所得至多 138% FPL；截至 2017 年 1 月，<span style="color:#34d399">31 州與華盛頓特區</span>採納擴大，19 州未採納。


- 紐約州 2020 年研究評估 10 種最常見選擇性骨科手術可近性，發現 ACA 支持的 Medicaid 擴大與參保人數增加、<span style="color:#60a5fa">骨科照護使用率同步上升</span>。
- 路易斯安那州 2016 年擴大 Medicaid，參保人數增加逾 400,000，占居民比例由約 20% 升至 <span style="color:#60a5fa">30%</span>；但研究仍顯示**門診骨科可近性明顯受限**。

> **Danger zone**：ACA 雖擴大「投保率」，卻未必等同擴大「專科門診可近性」；不應僅以参保數字推論市場需求。

### 3.3 替代支付模式 (APMs) 與打包支付

2011 年 ACA 制定 <span style="color:#e2e8f0">National Quality Strategy</span>，提出「**triple aim**」：改善照護品質、考量人口需求與社會決定因素、藉由降低成本提供可負擔的照護。美國醫療體系歷來採 <span style="color:#e2e8f0">fee-for-service (FFS)</span>：依個別服務逐項計費，醫院與醫師因服務「數量」而受激勵，對低品質幾乎沒有懲罰。

HHS 設定目標：至 2016 年底至少 **30%**、2018 年底 **50%** 的 Medicare FFS 支付連結品質或價值（APM）；另設定 2016 年底 **85%**、2018 年底 **90%**。2014–2018 年連結 APM 的 FFS 支付比例近乎倍增（22% → 41%），但自 2017 年起未達標。

| 模式 | 內容 |
|------|------|
| <span style="color:#60a5fa">BPCI (2013/1 啟動)</span> | 首種 APM；對預先定義的照護過程（episode）給予單一打包支付，總值與長度由 CMS 決定 |
| <span style="color:#60a5fa">CJR (2016/4/1 啟動)</span> | Comprehensive Care for Joint Replacement；episode 自下肢大關節置換住院起至**出院後 90 天**；與 BPCI 不同，**風險主要由醫院承擔**（BPCI 由管理公司、醫院、醫師團體共同評量）。最初強制參與 67 個都會統計區，2 年後改為 67 區中 33 區的所有提供者及低量／鄉村提供者**自願參加** |
| <span style="color:#60a5fa">BPCI Advanced (2018/10 啟動)</span> | 自願 episode 支付模型；對指定 DRG 的照護過程給予單一打包支付，涵蓋出院後最多 90 天；成本低於目標價可獲支付，且最多 <span style="color:#60a5fa">10%</span> 的支付依品質調整 |


- BPCI 涵蓋 49 種照護 episode（DRG），許多包含 TKA、THA、上肢關節置換與脊柱融合；早期結果顯示成本降低、併發症減少。
- **風險轉移的負面效應**：BPCI 缺乏針對高齡、衰弱（fraility）、社經地位與共病的有效 risk stratification，醫師可能為降低成本而<span style="color:#f87171">迴避為高風險病人手術</span>；早期研究亦提示可能**加劇健康不平等**。
- CJR 的 benchmark pricing 初期採機構自身歷史價格與區域價格，參與數年後改採**區域**成本基準。

### 3.4 MACRA 與醫師支付路徑

2015 年通過的 <span style="color:#60a5fa">MACRA</span>（Medicare Access and CHIP Reauthorization Act）根本改造傳統醫師支付制度：廢除 sustainable growth rate model，改採兩條路徑，將健康照護從「volume-based」轉向「value-based」。

| 路徑 | 內容 |
|------|------|
| <span style="color:#60a5fa">MIPS</span> | Merit-based Incentive Payment System；將 FFS 調整為依品質調整的支付，另依品質、成本、互操作性與改善活動調整。**強制適用**，例外：(1) 接受 Medicare 病人的**第一年新成立**診所；(2) 服務 Medicare 病人 < 100 人或年申報 < $30,000；(3) 已核准 APM 的參與者 |
| <span style="color:#60a5fa">Advanced APM track</span> | 將全部或大部分 Part B 支付移至 23 個核准的高階 APM 之一；除正常支付外，達成門檻可另獲 <span style="color:#34d399">5%</span> 誘因支付。**CJR 與 BPCI Advanced 屬高階 APM，原始 BPCI 不符合資格** |

> **Pearl**：MIPS 給「**支付調整**」，Advanced APM 給「**支付調整＋誘因支付**」，兩者並用以激勵品質資訊申報。

## 4. 品質評量、政策陷阱與價格透明化 (Quality Ratings, Pitfalls & Price Transparency)

### 4.1 CMS 醫院品質星等評分

2003 年 CMS 推行 Hospital Inpatient Quality Reporting Program，民眾可透過 <span style="color:#e2e8f0">Hospital Compare</span> 比較各機構品質指標。2016 年推出 Overall Hospital Quality Star Ratings，將 64 項指標彙整為 measure groups：mortality、safety of care、readmission、patient experience、effectiveness of care、timeliness of care 與 medical imaging 使用效率；CMS 提供 **0.4%** 的通膨調整減免鼓勵申報。

**2021 年 4 月的三項改變**：

1. **measure groups 改為各 component 的簡單平均**，使個別項目等權重。
2. **醫院至少須申報 3 個 measure groups 才能獲得星等**；新版 5 個為 mortality、safety of care、readmission、patient experience、timely and effective care；更多醫院因此未取得星等，但比較更準確。
3. **依申報的 measure group 數（3、4 或 5）分層比較**，避免申報較多資料的醫院受懲罰；2021 年 931 家醫院分層比較。

**背景**：初版方法將小型醫院與大型 tertiary 中心比較，但小醫院被要求申報較少 measure groups，致社區醫院獲四／五星比例是大型教學醫院的兩倍；計分採不透明的隱變數加權（Safety of Care 單一 measure 占近 90%），爭議後 CMS 暫停至 2020 年。

> **Danger zone**：星等評分**並未**包含多數選擇性處置的指標——骨折、充血性心臟衰竭、腦中風、急性心肌梗塞與肺炎多屬急症，各醫院未必具備全部資料；大型轉介中心即使提供卓越專科照護，也可能僅得一至二星。**其預測外科照護結果的準確性仍有爭議，甚至不明。**

### 4.2 平衡計分卡與機構自我管理

骨科診所最困難的任務之一是績效量測與改善——不只是資料收集，而是改善營運效率的流程。現代做法為 <span style="color:#60a5fa">balanced scorecard (BSC)</span>：1990 年代發展、結合財務與非財務指標的管理工具。

| BSC 四大類別 | 骨科實務對應 |
|-----------|------------|
| <span style="color:#e2e8f0">Finance</span> | 籌款總額、每病例與每次住院成本變化、住院天數、服務支出對收入之比 |
| <span style="color:#e2e8f0">Internal business processes</span> | 決策模式、訓練時間、投入品質發展的預算比例、新品質 protocols |
| <span style="color:#e2e8f0">Learning and growth</span> | 訓練／教學相關之組織能力 |
| <span style="color:#e2e8f0">Customer</span> | 重大事件、每位醫師門診／年病人數、員工流失率與滿意度、病人滿意度、申訴數、出院時效 |

| <span style="color:#e2e8f0">Customer</span> | 重大事件、每位醫師門診／年病人數、員工流失率與滿意度、病人滿意度、申訴數、出院時效 |

骨科診所還須因 BSC 要求重新設計組織結構；**設置內部稽核與風險管理單位以進行日常評估**至關重要。

### 4.3 門診與 ASC 的轉移

<!-- FIG: 圖 4 — Diagram shows the balanced scorecard for better performance measuremen -->
![圖 4 — Diagram shows the balanced scorecard for better performance measuremen](/images/oku14/ch05_p0064_fig4.jpg)
*圖 4 — Diagram shows the balanced scorecard for better performance measuremen*
**門診總關節置換**：技術進步使門診 TKA／THA 安全可行。CMS 的 CY2020 Hospital Outpatient Prospective Payment System 包含關節置換支付更新；**2018 年**將 TKA、**2020 年**將 THA 移出 inpatient-only 清單，Medicare 得以不論住院與否給予支付。

2017 年平均價格：TKA 住院 <span style="color:#f87171">$30,249</span> vs 門診 <span style="color:#34d399">$19,002</span>；髖置換住院 <span style="color:#f87171">$30,685</span> vs 門診 <span style="color:#34d399">$22,078</span>。

**ASC（ambulatory surgical centers）**：美國 ASC 自 1980 年代初期起持續增加；當時 Medicare 將 ASC 照護納入給付並採 DRG 前瞻支付，使醫院有強烈動機將較複雜手術轉往門診。CMS 另建 <span style="color:#e2e8f0">ASC Quality Reporting Program</span>；**未符合要求的 ASC，支付可能被扣減 2%**。

ASC 化趨勢：旋轉肌帶修補於 ASC 比例 1996→2006 成長 <span style="color:#60a5fa">272%</span>；腕隧道鬆解 (CTR) 由 16% 升至 <span style="color:#60a5fa">49%</span>；膝關節鏡檢由 15.3% 升至 <span style="color:#60a5fa">50.7%</span>；ASC 使用量近數年增加約 <span style="color:#60a5fa">14.3%</span>。

ASC 因團隊固定、熟悉術式與手術室流程及 protocols，手術時間更快、效率更高，促使部分保險公司採用鼓勵病人選擇 ASC 的支付模式，每年可省 <span style="color:#34d399">17%–17.6%</span>。

### 4.4 價格透明化 (Price Transparency)

<!-- FIG: 圖 5 — Diagram shows four balanced scorecard categories of main Centers for M -->
![圖 5 — Diagram shows four balanced scorecard categories of main Centers for M](/images/oku14/ch05_p0065_fig5.jpg)
*圖 5 — Diagram shows four balanced scorecard categories of main Centers for M*
Trump 行政支持下，兩黨議員通過立法，要求全美醫院線上公開服務價格，並揭露**折扣後現金價格、支付方特定議定價格，以及議定費率下的去識別化最高與最低收費**。

- **城內價差極大**：德州 Dallas 市內髖關節置換最高收費可達同市最低價的 <span style="color:#f87171">4 倍</span>；支持方認為讓消費者比較「購物」可藉競爭壓低價格。
- **反對方**：醫療是**需求缺乏彈性（inelastic）的商品**，透明化可能反而推升議定費率；消費者也可能被 chargemaster 灌水總額混淆。
- 截至 2021 年 6 月，**ASC 與私人診所尚未被要求公開價格**；小型診所能否在被壓低的 reimbursement 下維持競爭力仍不明朗。

> **Pearl**：同一城市同類置換術價差可達四倍，是醫師向病人解釋「價格透明不等於價格一致」的事實。
> **陷阱**：投保率上升不等於可近性上升；BPCI／CJR 缺乏穩健風險分層，可能誘發迴避高風險病人；星等評分不含多數選擇性骨科處置。

## 5. 實證更新與 OKU 14 重點 (Recent Evidence & Take-Home Points)

### 5.1 骨科專科考試核心總結（Take-Home Points）

1. **政策是臨床決策的一部分**：Medicare／Medicaid／ACA 決定誰能取得骨科照護，MS-DRG 與 RVU 決定收入結構。
2. **Medicare 三大部分**：Part A（住院／機構照護）、Part B（醫師與門診服務，20% coinsurance）、Part C/D（Advantage 與處方藥）；2020 年 6,120 萬人，2030 年 8,000 萬人。
3. **Medicaid 為聯邦—州夥伴**：matching 50%–75%，涵蓋約 1/5 美國人與 16% 醫療支出。
5. **HAC 就是錢**：HAC 率 4%、TKA/THA 1.3%、每件約 $40,000；後 25 百分位醫院支付扣減 1%。
6. **打包支付的雙面性**：BPCI／CJR／BPCI Advanced 降低成本，但缺乏風險分層可能造成迴避高風險病人。
7. **MACRA 兩條路**：MIPS（強制，例外三類）與 Advanced APM（5% 誘因）；僅 CJR 與 BPCI Advanced 合格。
8. **星等評分要打折看**：不含多數選擇性骨科指標，對外科結果的預測力仍有爭議。
9. **趨勢是門診化**：TKA 2018 年、THA 2020 年移出 inpatient-only；病人適任評估不可省略。

## Summary

- <span style="color:#60a5fa;font-weight:600">政策框架</span>：1965 年 Social Security Amendments 設立 Medicare 與 Medicaid；私人保險為最大單一來源（2018 年占 34% 支出，2019 年覆蓋 67.3% 人口）。
- <span style="color:#f87171;font-weight:600">ACA 的落差</span>：投保率上升不等於專科可近性上升；路易斯安那州 Medicaid 占比升至 30%，但門診骨科可近性仍受限。
- <span style="color:#60a5fa;font-weight:600">Medicare</span>：Part A（住院／機構照護）、Part B（醫師與門診服務，自付 20% coinsurance，預防篩檢 100%）、Part C（Advantage，2019 年約 1/3 参保）、Part D（處方藥）；2020 年 6,120 萬人，2030 年預估 8,000 萬人。
- <span style="color:#60a5fa;font-weight:600">Medicaid</span>：聯邦—州夥伴，matching 50%–75%（ACA 期最高 100%），強制基準 138% FPL；涵蓋約 1/5 美國人、16% 醫療支出，具逆週期性；State CHIP 服務門檻略高之兒童。
- <span style="color:#f87171;font-weight:600">私人保險型態</span>：HMO 以 PCP 為 gatekeeper 且無網外給付；PPO 可網外就醫但免轉介；POS 仍須 PCP 授權；EPO 無網外但免轉介；catastrophic deductible $8,150；HSA 可 rollover，FSA 年末作廢。
- <span style="color:#60a5fa;font-weight:600">給付機制</span>：MS-DRG 470 為第四常見主要診斷；RVU 提案調降全骨科 5%、髖膝置換額外 5.4%，因疫情暫緩。
- <span style="color:#f87171;font-weight:600">HAC</span>：全美住院 HAC 率 4%；TKA／THA 1.3%；融合手術 4.6%–5.4%；每件約 $40,000、延長住院 8.17 天；後 25 百分位醫院扣減 1%。
- <span style="color:#60a5fa;font-weight:600">ACA</span>：四個 value-based 計畫；Medicaid 擴大至 133% FPL；health insurance exchange；individual mandate 2017 年廢除；最高法院確立州自主擴大與聯邦 exchange 補助合憲。
- <span style="color:#60a5fa;font-weight:600">打包支付</span>：BPCI（2013）、CJR（2016/4，episode 至出院後 90 天、風險由醫院承擔）、BPCI Advanced（2018/10，最多 10% 依品質調整）；缺乏風險分層可能誘發迴避高風險病人。
- <span style="color:#f87171;font-weight:600">ACA 的落差</span>：投保率上升不等於專科可近性上升；路易斯安那州 Medicaid 占比升至 30%，但門診骨科可近性仍受限。
- <span style="color:#60a5fa;font-weight:600">MACRA</span>：MIPS 強制（三類例外）；Advanced APM 給 5% 誘因，僅 CJR 與 BPCI Advanced 合格。
- <span style="color:#f87171;font-weight:600">星等評分</span>：2021 年改為 component 簡單平均、至少 3 個 measure groups、依 3／4／5 組分層；不含多數選擇性骨科指標，對外科結果預測力仍有爭議。
- <span style="color:#60a5fa;font-weight:600">門診化趨勢</span>：TKA 2018 年、THA 2020 年移出 inpatient-only；2017 年 TKA 住院 $30,249 vs 門診 $19,002、髖置換 $30,685 vs $22,078。
- <span style="color:#fbbf24;font-weight:600">價格透明化</span>：Dallas 同城髖置換最高價可為最低價 4 倍；ASC 與私人診所尚未強制公開價格；醫療需求缺乏彈性，透明化未必降價。
