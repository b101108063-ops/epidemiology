# Chapter 30: Anatomy, Biomechanics, Physical Examination, and Imaging of the Elbow — 肘部解剖、生物力學、理學檢查與影像

## 章節導讀

肘部是上肢最關節化、受力最複雜的關節之一，骨性、韌帶、關節囊與肌腱任一層次的異常都可能造成相似的疼痛。本章先從骨性約束與韌帶、關節囊的穩定機轉談起，再依序整理理學檢查的視診、觸診、活動度、力量與不穩定評估，最後比較X光、動態透視、CT、MRI 與超音波的臨床定位與限制。

---

## 1. 肘部關鍵解剖與生物力學 (Anatomy & Biomechanics)

肘為<span style="color:#22d3ee">constrained synovial hinge joint</span>（受限制的滑膜鉸鏈關節）：尺骨滑車與肱骨滑車、橈骨頭與肱骨小頭構成主要骨性接合，其餘穩定性來自韌帶、關節囊與跨越關節的肌腱。任何「看似單純」的疼痛，都可能來自骨性、韌帶性、關節囊性或肌腱性的不同層次。

### 1.1 骨性約束與其穩定角色 (Osseous Constraints)

- <span style="color:#22d3ee">Humeroulnar joint</span>（肱尺關節）與 <span style="color:#22d3ee">radiocapitellar joint</span>（橈骨小頭關節）共同構成主要骨性穩定來源；當關節面完整時，骨性吻合本身即提供顯著的固有穩定性（inherent stability）。
- 尺骨 <span style="color:#22d3ee">greater sigmoid notch</span>（大乙狀切跡）與 <span style="color:#22d3ee">lesser sigmoid notch / radial notch</span>（小乙狀切跡，即橈骨切跡）分別承接肱骨滑車與橈骨頭；近端尺骨與橈骨頭的幾何關係以 CT 量測可見冠狀突尖端（coronoid tip）至橈骨頭前緣約 **4.5 mm**。
- 肱尺關節的幾何形態（humeroulnar joint geometry）與滑車深度、橈骨切跡深度共同決定肘關節的「鉸鏈」特性，也決定了脫位方向（多為後外側）與復發風險。

### 1.2 韌帶與關節囊的動態穩定機轉

| 穩定結構 | 主要功能 | 傷害後的生物力學後果 |
|---|---|---|
| <span style="color:#22d3ee">LUCL</span>（外側尺骨副韌帶，lateral ulnar collateral ligament） | 抵抗 <span style="color:#60a5fa">varus</span>（內翻）應力 | 單獨切斷後 varus 應力下角度增加 4.3°–7.0° |
| <span style="color:#22d3ee">MUCL</span>（內側尺骨副韌帶複合體，medial ulnar collateral ligament） | 抵抗 <span style="color:#60a5fa">valgus</span>（外翻）應力 | 前束單獨切斷後 valgus 下角度增加 4.9°–8.8° |
| <span style="color:#22d3ee">LCL complex</span>（外側副韌帶複合體，含 radial band） | 後外側旋轉穩定 | 整體切斷後 varus 下角度增加 7.9°–13.4° |
| <span style="color:#22d3ee">Posterolateral capsule</span>（後外側關節囊） | 阻止橈骨頭後向位移 | 稱為 Osborne-Cotterill 韌帶；切斷後橈骨頭位移更明顯 |
| <span style="color:#22d3ee">Anterior capsule</span>（前方關節囊） | 前側穩定 | 與內或外側韌帶損傷合併時，角度增加可超過 20° |

**六具屍體序列穩定結構破壞實驗**顯示：僅有外側副韌帶（lateral collateral ligament, LCL）破壞合併前內側冠狀突骨折（anteromedial coronoid fracture）時，肘在 varus 力下仍保持關節對線（congruent）；其後再切斷 <span style="color:#60a5fa">posterior bundle</span>（後束）後，肘才在重力負荷下發生半脫位（subluxation）。值得注意的是，在切斷後束之前，尺肱關節與橈骨小頭關節已出現**接觸壓力升高**但並未半脫位——此點提示「尚未失位」不等於「未受傷害」。

> **Pearl**：橈骨外側副韌帶複合體（radial lateral collateral complex）雖然作用較小，仍確實藉抵抗 varus 應力貢獻肘穩定；不能因其「次要」角色而忽略。

> **Danger zone**：序列切斷實驗中，**韌帶損傷合併前方關節囊損傷**是最危險的組合——在完全伸直位不論施加 varus 或 valgus，角度增加都可超過 20°，此時單一韌帶的重建往往不足以重建穩定性。

### 1.3 肌腱與附著點解剖 (Insertional Anatomy)

| 結構 | 解剖要點 | 臨床意義 |
|---|---|---|
| <span style="color:#22d3ee">MUCL</span>（尺側副韌帶） | 附著於冠狀突尖端的距離變異極大：**1.4–13.9 mm**（84 具防腐標本） | 重建時須以實際附著點而非平均值決定固定位置 |
| <span style="color:#22d3ee">MUCL</span> 血供 | 有一條沿韌帶走行的一致動脈，為近端韌帶的主要供應 | 近端修復之癒合潛力優於遠端 |
| <span style="color:#22d3ee">ECRB</span>（橈側腕短伸肌） | 起點比過去描述更廣，延伸覆蓋橈骨小頭關節上方關節囊 | 肘外側手術需考慮伸肌群起點切離範圍 |
| <span style="color:#22d3ee">Triceps brachii</span>（肱三頭肌） | 附著足跡比既往報告更小 | 對 triceps-sparing 手術入路之意義 |
| <span style="color:#22d3ee">Distal biceps</span>（遠端肱二頭肌） | 分為 long head 與 short head 兩部分，兩者生物力學角色不同 | 短頭單獨斷裂也可造成明顯功能缺損 |
| <span style="color:#22d3ee">Bicipitoradial bursa</span> | 遠端肱二頭肌腱內鏡評估的重要landmark | 內鏡手術需先建立清楚的解剖標記 |

### 1.4 旋轉中心與功能性活動範圍

- <span style="color:#22d3ee">Center of elbow rotation</span>（肘旋轉中心）位於滑車（trochlea）附近，理解其位置是 MUCL 重建手術的重要前提。
- <span style="color:#60a5fa">功能性活動範圍已因現代生活而重新定義</span>：為完成「把電話放在耳邊」與「在鍵盤上打字」等任務，肘需要 **高達 150° 的屈曲**與 **65° 的旋前**。
- 傳統定義與現代任務的差距，意味著復健與手術後的目標不應只設定在「能屈到 90°」。

## 2. 理學檢查體徵與影像選擇 (Physical Examination & Imaging)

對每一位以肘部症狀就診的病人，都應執行完整的肘部檢查，用以區分可能的病理、釐清功能受限，並指導後續影像與治療。

### 2.1 視診 (Inspection)

- **瘀斑（ecchymosis）的定位**：雖然骨折可造成廣泛瘀斑，但**後方肘部的特徵性瘀斑**提示 <span style="color:#60a5fa">triceps</span>（肱三頭肌）損傷，**肘前窩（antecubital fossa）瘀斑**提示 <span style="color:#60a5fa">biceps brachii</span>（肱二頭肌）損傷；此情形下**肌腱回縮可肉眼可見**。
- **攜帶角（carrying angle）**：與對側比較可提示既存疾病或明顯不穩定。
- **局部腫脹**：合併或不合併周圍紅斑，可提示無菌性或化膿性尺骨鷹嘴滑囊炎（olecranon bursitis），或關節內病變。

### 2.2 觸診 (Palpation)

| 觸診位置 | 陽性表現 | 需鑑別的病變 |
|---|---|---|
| 內、外上髁（epicondyle）**上及其遠端** | 疼痛可被**抗阻腕伸**（外側）或**抗阻腕屈**（內側）加劇 | 橈骨頭病變、早期關節炎、<span style="color:#22d3ee">osteochondral lesion</span>（骨軟骨病灶）可模仿外上髁炎 |
| 內側上髁 | 抗阻腕屈加劇之壓痛 | 內側副韌帶損傷 |
| 肘前窩 | 抗阻前臂旋後（resisted forearm supination）加劇 | 遠端肱二頭肌病變 |
| 尺骨鷹嘴 | 抗阻肘伸直加劇 | 肱三頭肌病變 |
| 側副韌帶解剖位置 | 壓痛範圍可界定損傷程度 | 有肘半脫位病史者尤須逐點檢查 |

> **Pearl**：例行肘檢查中執行 <span style="color:#60a5fa">hook test</span>（勾拉試驗）可快速篩檢遠端肱二頭肌病變，並辨識出可能需要手術治療的損傷。

### 2.3 神經學檢查

跨越肘部的所有神經都可能受壓，但最常見者為**肘管（cubital tunnel）內的尺神經**。當病人主訴內側肘痛或尺神經支配區域的神經痛性病變時，必須執行尺神經評估：

- <span style="color:#60a5fa">Tinel sign</span>（提內爾徵）叩擊測試。
- 在被動屈肘由伸展位至屈曲位的過程中，評估 <span style="color:#60a5fa">ulnar nerve subluxation</span>（尺神經半脫位）。
- <span style="color:#22d3ee">Radial tunnel syndrome</span>（橈隧道症候群）較難評估，但可在**外上髁遠端約 3–5 cm** 處引出 Tinel sign 與壓痛，並可因抗阻腕伸而加劇。

### 2.4 活動度 (Motion)

正常肘部通常可達完全伸直、屈曲至 **140°**、旋前 **75°**、旋後 **85°**。檢查時必須同時評估**主動與被動**活動。

| 檢查發現 | 最可能的意義 | 處理方向 |
|---|---|---|
| 主動活動喪失、被動活動保留 | 神經性或肌腱性**無力**（尤其抗重力時） | 進一步肌力與影像檢查 |
| 被動活動喪失 | 外傷性損傷或**關節炎**性病變 | 影像優先 |
| 疼痛只出現在活動弧末端 | 例如骨關節炎；**具有預後意義**並可能改變治療 | 保守治療預後較佳 |
| 疼痛遍及整個活動弧 | 關節內病變較可能 | 需進一步影像 |
| 無關節炎卻有全程 crepitus（捻髮感） | <span style="color:#22d3ee">radiocapitellar plica</span>（橈骨小頭滑膜褶皺） | 影像或關節鏡評估 |
| 疑似非手術之創傷（如橈骨頭骨折） | 須確認可達**近全範圍活動，尤其旋前與旋後無阻擋** | 決定是否需要手術 |

> **Danger zone**：單憑「患者說痛」無法區分無力與僵硬。**主動喪失而被動保留**與**被動喪失**是兩條完全不同的臨床路徑，混淆兩者會導致後續影像與治療方向錯誤。

### 2.5 力量 (Strength)

| 情境 | 測試方式 | 目的 |
|---|---|---|
| 疑似**遠端肱三頭肌**損傷（急性） | 仰臥、前臂置於胸前，或坐姿將手臂上舉過頭，測試**抗重力伸肘** | 決定是否需進一步影像並輔助處置 |
| 疑似**遠端肱二頭肌**病變（亞急性／慢性） | 自**旋後位起始**執行**抗阻前臂旋後** | 量化無力程度與伴隨疼痛 |

> **Pearl**：遠端肱二頭肌與肱三頭肌病變是肘部無力的最常見原因；兩者的測試起始姿勢不同，不可混用。

### 2.6 不穩定 (Instability)

創傷後的肘部檢查常因疼痛與腫脹而受限，此時須依靠病史與影像；但若患者能放鬆，瘀斑、壓痛與鬆弛度仍可指引後續檢查。

| 不穩定型態 | 臨床檢查 | 檢查特性與陷阱 |
|---|---|---|
| 明顯（gross）不穩定 | 臨床與早期 X 光即可察覺 | 骨性對線完整時即提供強大穩定 |
| <span style="color:#22d3ee">PLRI</span>（後外側旋轉不穩定） | <span style="color:#60a5fa">lateral pivot shift test</span> | **鎮靜病人**下診斷準確度高；清醒病人因合理抵抗而**敏感度差**；清醒者改用 prone 或 chair push-up test 敏感度較佳 |
| 投擲時之 valgus 不穩定 | <span style="color:#60a5fa">milking maneuver</span>（擠乳試驗）、<span style="color:#60a5fa">moving valgus stress test</span>（動態外翻應力試驗） | 陽性即應進一步高階影像 |
| <span style="color:#22d3ee">VPMRI</span>（varus posteromedial rotatory instability，內翻後內側旋轉不穩定） | 外展肩部、以重力給予 varus，前臂平行地面屈伸 | 症狀再現應懷疑外側副韌帶與前內側冠狀突有重大病變 |

> **Pearl**：<span style="color:#60a5fa">milking maneuver</span> 為前臂旋後、肘屈曲超過 90°，拉動病人拇指；<span style="color:#60a5fa">moving valgus stress test</span> 為肘最大屈曲、肩外展並最大外旋，經肘施加外翻應力後快速伸肘。兩者陽性皆以症狀再現為判準。

### 2.7 影像檢查之比較與選擇

| 檢查 | 最佳適應症 | 效能與數據 | 主要限制 |
|---|---|---|---|
| **Plain radiograph / fluoroscopy（X 光與透視）** | 所有肘部症狀之初步評估；近端尺骨骨折 | 2020 年研究：自滑車中央嵴（central trochlear ridge）起，尺骨關節面在**側位片上平均向背側延伸 6.2–9.7 mm** | 需理解**sigmoid notch** 複雜影像解剖；四名資深骨科創傷醫師在屍體模擬近端尺骨骨折中，**平均僅 73% 正確辨識 malreduction**，且觀察者內／間信度皆差 |
| **Dynamic fluoroscopy（動態透視）** | 不穩定程度量化 | LUCL 切斷 varus 下角度增加 4.3°–7.0%；MUCL 前束切斷 valgus 下 4.9°–8.8°；整個 LCL complex 切斷 varus 下 7.9°–13.4°；韌帶合併前方關節囊損傷於完全伸直位 **>20°** | 需特殊設備與判讀經驗 |
| **CT（電腦斷層）** | 複雜近端尺骨骨折、可能 malreduction、術後複雜骨折、關節鏡前規劃 | 36 例肘關節炎關節鏡病人：骨贅偵測之觀察者間信度 95%（vs 純 X 光 80%）、游離體 91%（vs 81%）；敏感度骨贅 98%（X 光 46%）、游離體 98%（X 光 49%） | **特異度下降**；3D 列印著色模型加入術前規劃與單獨規劃相比未見結果差異（可能檢定力不足） |
| **MRI（磁振）** | 肌腱損傷之黃金標準；單純肘脫位後損傷型態；MUCL 病變；X 光正常之持續疼痛 | 17 例單純脫位：LCL complex 除 1 例外**全部至少有部分破壞**，MCL 僅 2 例完整；完全前方關節囊撕裂 12 例；完全 MCL 斷裂 10 例、完全 LCL 斷裂 9 例 | 另一項 30 例單純脫位 MRI 研究中，側副韌帶損傷之**審閱者間一致率僅 60%**，且觀察者內信度變異極大 |
| **Ultrasonography（超音波）** | 動態評估、費用低且無侵入；遠端肱二頭肌與肱三頭肌腱；MUCL | 應力超音波：屈曲 30° 時關節張開 **>0.5 mm** 或屈曲 90° 時 **>1.0 mm**，可準確預測 MRI 上的完全 MUCL 撕裂；39 例非手術案例中僅 1 例與 MRI 有重大不一致（超音波為低階部分撕裂，MRI 為完全撕裂） | **準確度依賴操作者經驗**；推廣需具備相關技術與解剖經驗的醫療人員 |

> **Danger zone**：MRI 在**單純肘脫位後的韌帶損傷判讀並不可靠**——同一批資料中，一項研究的觀察者間一致率極高，另一項 30 例研究的側副韌帶一致率卻只有 60%。不可將「MRI 報告」等同於「韌帶一定完好」。

## 3. 臨床處置：檢查與影像的整合 (Clinical Application)

### 3.1 標準化的檢查順序

面對肘部症狀病人，建議依固定順序執行，以避免遺漏：

1. **視診**：瘀斑分布、攜帶角、局部腫脹與紅斑。
2. **觸診**：內外上髁、肘前窩、鷹嘴、側副韌帶解剖位置，並執行 hook test。
3. **神經**：尺神經 Tinel sign 與屈肘半脫位評估；必要時橈隧道測試。
4. **活動度**：主動與被動屈伸、旋前旋後，並記錄疼痛出現在活動弧的哪一段。
5. **力量**：抗重力伸肘（疑肱三頭肌）、自旋後位起始之抗阻旋後（疑遠端肱二頭肌）。
6. **不穩定**：milking maneuver、moving valgus stress test、lateral pivot shift（鎮靜或 push-up 變體）、varus posteromedial 旋轉測試。
7. **影像**：依上述結果決定 X 光、動態透視、CT、MRI 或超音波。

### 3.2 影像閾值與檢查升級

| 臨床情境 | 建議影像 | 理由 |
|---|---|---|
| 所有肘部症狀 | **Plain radiographs**（AP、lateral、必要時斜位） | 初步評估不可省略 |
| 近端尺骨複雜骨折、術後懷疑 malreduction | **CT** | 資深外科醫師以 X 光辨識 malreduction 僅約 73%，信度差，應採**低門檻**使用 CT |
| 不穩定、韌帶損傷範圍不明 | **Dynamic fluoroscopy** | 可量化 varus/valgus 角度增加，並辨識是否合併前方關節囊損傷 |
| 肌腱損傷 | **MRI**（若無法取得則超音波） | MRI 為主流方法；超音波對部分與完全撕裂具高敏感度 |
| 投擲者 MUCL 損傷 | **Stress ultrasonography** 或 MRI（含分類系統） | 可偵測關節張開、預測未來傷病風險 |
| X 光正常之持續肘痛 | **MRI** | 可診斷 radiocapitellar plica、慢性內外上髁炎、**osteonecrosis**（骨壞死）、骨軟骨病灶 |

### 3.3 MUCL 的 MRI 分類與臨床應用

| 分類軸 | 類別 |
|---|---|
| **受傷位置（location）** | 近端（proximal）／中段（midsubstance）／遠端（distal） |
| **受傷程度（degree）** | 完全（complete）／部分（partial） |

此分類系統在 MRI 上展現**優異的觀察者間與觀察者內信度**，並可協助引導後續**保守或手術治療的選擇**，尤其在辨識**遠端病變**時更具管理價值。

**無症狀投擲者的預後 MRI 研究**：追蹤發現，之後進入 disabled list（傷停名單）的投手，在檢查當下較可能已有 **MUCL 異質性（heterogeneity）**、**肱骨端的 MUCL 部分撕裂**，以及**後內側撞擊（posteromedial impingement）**的 MRI 徵象。雖然將此類研究結果直接轉譯為臨床決策仍具挑戰，但已指出高風險結構與頂尖投手的主要病變型態。

> **Pearl**：影像的終極目的是**指導處置**，不是堆疊診斷。MUCL 的 MRI 分類、CT 的骨贅與游離體定位，目的都在於決定保守或手術、規劃關節鏡清除範圍。

## 4. 陷阱與爭議 (Pitfalls & Controversies)

> **陷阱 1：把「不穩」當成明顯脫位**。PLRI、投擲時的 valgus 不穩定與 varus posteromedial 旋轉不穩定，屬於**細微不穩定**，需要更高的臨床警覺與更仔細的檢查，而非等待明顯徵象出現。

> **陷阱 2：忽略檢查之間的一致性落差**。同一批「單純肘脫位」MRI 資料，一項研究报告高觀察者間信度，另一項 30 例研究的側副韌帶一致率僅 60%，且觀察者內信度範圍極廣——這使「MRI 診斷的再現性」在本情境受到質疑。

> **陷阱 3：低估 LCL 與關節囊的貢獻**。即使被稱為「次要」的橈骨外側副韌帶複合體，也確實抵抗 varus 應力；而後外側關節囊（Osborne-Cotterill 韌帶）在 LCL 複合體切斷後，橈骨頭後移幅度更大。

> **陷阱 4：只看到「仍對線」就判定無傷害**。序列實驗顯示在尚未半脫位之前，尺肱與橈骨小頭關節的接觸壓力已明顯升高。

> **陷阱 5：過度依賴 X 光判讀近端尺骨骨折复位品質**。資深創傷醫師的正確率僅約 73%，且信度差；近端尺骨複雜骨折應採低門檻 CT。

> **陷阱 6：忽略 CT 的特異度代價**。CT 在骨贅與游離體的**敏感度顯著優於 X 光**（98% vs 46%／49%），但代價是**特異度下降**，且 3D 列印著色模型的加成效益尚未證實（分析可能檢定力不足）。

> **陷阱 7：把超音波當成可廣泛推廣的檢查**。超音波的準確度高度依賴操作者經驗；其價值集中於**可做動態測試**的軟組織穩定結構（尤其 MUCL）。

> **陷阱 8：功能角度的目標設定過時**。若以 90° 屈曲為復健目標，將無法滿足現代日常任務（打電話、敲鍵盤）所需的 150° 屈曲與 65° 旋前。

## 5. 實證更新與 OKU 14 重點 (Recent Evidence & Take-Home Points)

### 5.1 本章關鍵研究與證據要點

| 主題 | 關鍵發現 | 臨床意涵 |
|---|---|---|
| 序列穩定結構破壞（6 具屍體） | LCL 破壞＋前內側冠狀突骨折時仍保持對線；切斷後束後在重力下半脫位；半脫位前已有接觸壓力升高 | 「未半脫位」不等於「無傷害」，需追蹤接觸壓力與症狀 |
| 動態透視韌帶切斷實驗 | LUCL→4.3°–7.0°；MUCL 前束→4.9°–8.8°；整個 LCL complex→7.9°–13.4°；合併前方關節囊→**>20°** | 提供量化不穩定程度的可行工具，可指導手術範圍 |
| 近端尺骨影像解剖（2020） | 尺骨關節面自滑車中央嵴於側位片平均向背側延伸 6.2–9.7 mm | 該區域偏心置入的螺絲有**關節內侵入風險** |
| 近端尺骨复位判讀 | 資深創傷醫師辨識 malreduction 正確率僅 73%，信度差 | 對複雜近端尺骨骨折與術後疑慮應**低門檻 CT** |
| CT 於肘關節炎（36 例） | 骨贅信度 95% vs 80%；游離體 91% vs 81%；敏感度 98% vs 46%／49%，但特異度下降 | 術前規劃首選，但須接受特異度代價 |
| 3D 列印著色模型 | 與單獨術前規劃相比結果無差異 | 仍屬新穎嘗試，需更充分證據（可能檢定力不足） |
| MRI 於單純肘脫位（17 例） | LCL complex 除 1 例外皆部分破壞；MCL 僅 2 例完整；完全前方關節囊撕裂 12 例 | 脫位後軟組織損傷型態普遍且廣泛 |
| MRI 判讀一致性（30 例） | 側副韌帶一致率 60%；對關節對線、積液、游離體一致度高 | 韌帶判讀再現性存疑，勿過度信賴 |
| 無症狀投手 MRI 預後 | 之後進入傷停名單者已有 MUCL 異質性、肱骨端部分撕裂、後內側撞擊 | 可標示高風險結構，臨床轉譯仍待驗證 |
| MUCL MRI 分類系統 | 位置（近／中／遠）×程度（完全／部分）；信度優異 | 指導保守或手術處置，遠端病變辨識價值高 |
| 應力超音波診斷完全 MUCL 撕裂 | 屈曲 30° 張開 >0.5 mm、屈曲 90° 張開 >1.0 mm | 提供即時、動態、 低成本的評估方式 |
| 超音波 vs MRI（39 例） | 僅 1 例重大不一致（超音波低階部分撕裂 vs MRI 完全撕裂） | 對部分與完全撕裂具高敏感度，可作替代方案 |

### 5.2 骨科專科考試核心總結（Take-Home Points）

1. **解剖是前提**：肘部骨性、韌帶與肌腱解剖複雜，必須充分理解才能給予適當治療。
2. **檢查是分流的起點**：每位肘部症狀病人都應接受包含視診、觸診、活動度、力量與穩定性的完整常規檢查，檢查結果決定後續影像。
3. **主動 vs 被動**是活動度評估的核心區分：主動喪失＋被動保留＝無力（神經或肌腱）；被動喪失＝外傷或關節炎。
4. **功能性活動角度已更新**：完成含「電話貼耳」與「鍵盤打字」在內的所有任務，需要最高 **150° 屈曲**與 **65° 旋前**。
5. **不穩定的臨床測試各有脾性**：lateral pivot shift 在鎮靜病人準確、在清醒病人敏感度差；清醒病人應改用 prone 或 chair push-up test；milking maneuver 與 moving valgus stress test 陽性即應進一步影像。
6. **影像策略分層**：X 光為所有病人的必備初篩；近端尺骨複雜骨折用 CT；韌帶／不穩定可用動態透視量化；肌腱與韌帶病變以 MRI 為主；超音波是具潛力的動態、低成本工具，但依賴操作者經驗。
7. **勿把單一數字當定論**：CT 提升敏感度但降低特異度；MRI 在單純脫位後的韌帶判讀一致率僅 60%；3D 列印模型尚無實證效益。

## Summary

- **解剖與生物力學是分流的起點**：骨性約束、LCL/MUCL、關節囊與肌腱共同決定穩定性；LCL 破壞＋前內側冠狀突骨折仍可保持對線，但切斷後束後即在重力下半脫位，且半脫位前已有接觸壓力升高。
- **不穩定的量化基準**：LUCL 切斷 varus 下 4.3°–7.0°；MUCL 前束切斷 valgus 下 4.9°–8.8°；整個 LCL complex 切斷 varus 下 7.9°–13.4°；若合併前方關節囊損傷，完全伸直位可超過 20°。
- **完整理學檢查是必要動作**：視診（瘀斑分布、攜帶角、腫脹）、觸診（內外上髁、肘前窩、鷹嘴、hook test）、神經（Tinel、尺神經半脫位）、主動與被動活動度、抗重力伸肘與抗阻旋後、以及不穩定試驗（milking、moving valgus、lateral pivot shift、prone/chair push-up、varus posteromedial）。
- **活動度的兩條路徑**：主動喪失而被動保留＝無力；被動喪失＝外傷或關節炎；疼痛位於活動弧末端預後較佳。現代日常任務需要最高 150° 屈曲與 65° 旋前。
- **影像分層**：X 光為必備初篩；近端尺骨複雜骨折用 CT（資深醫師辨識 malreduction 僅約 73%）；動態透視量化不穩定；MRI 為肌腱與韌帶損傷主軸但單純脫位後韌帶判讀一致率僅 60%；應力超音波可預測完全 MUCL 撕裂（30° 屈曲 >0.5 mm、90° 屈曲 >1.0 mm），惟準確度依賴操作者經驗。
- **主要陷阱**：細微不穩定易被忽略、MRI 與 X 光各有限制（特異度下降／一致性不足）、X 光單獨不足以判定近端尺骨复位品質、超音波難以廣泛推廣、功能角度目標若設定過時將直接影響復健成效。
