# Chapter 50: Foot and Ankle Reconstruction — 足踝重建

## 章節導讀

足踝重建的難處在於同一個疼痛可能來自完全不同的構造：骨性結構、韌帶、肌腱或關節排列。本章依解剖、分型決策、治療指引、手術入路與實證更新五個層次，整理各病變的分型、手術適應症與陷阱。

---

## 1. 臨床評估與關鍵解剖 (Clinical Evaluation & Key Anatomy)

足踝重建的核心觀念是：**足部結構與生物力學的改變會造成疼痛與功能喪失**；**韌帶與肌腱損傷**同樣可造成嚴重功能喪失與慢性疼痛，因此必須理解**軟組織平衡（soft-tissue balancing）**與正確診斷，才能讓病人回到正常功能水準。

### 1.1 前足：拇外翻、Morton 神經瘤與小趾畸形

**拇外翻（hallux valgus）**：本章正文在此處自前頁接續。[原文缺漏：拇外翻的定義、病理力學與保守治療段落位於前頁，未包含於本章文字檔] 原文強調**以拇外翻矯正為目標的外科治療演算法**是本章主軸，並指出**影像學上評估蹼骨（sesamoid）**有助於判斷矯正的程度。

**Morton 神經瘤（Morton neuroma）**

| 項目 | 內容 |
|------|------|
| 定義 | <span style="color:#e2e8f0">Entrapment neuropathy（卡壓性神經病變）</span>，涉及**橫跖骨韌帶** |
| 最常見部位 | **第三趾蹼（third web space）**，即**內側與外側足底神經匯合處** |
| 症狀 | 灼痛感的足底疼痛，放射至趾端，活動時加重；趾端可能有感覺異常 |
| 影像 | **不需影像**；2019 年研究顯示**超音波**可 visualize 神經瘤，**MRI 與 X 光**用來**排除其他病變** |
| 注射 | <span style="color:#fb923c">Ethanol（乙醇）</span>或 <span style="color:#fb923c">lidocaine（利多卡因）</span> 可作診斷或治療用途 |
| 保守治療 | 寬趾頭鞋、跖骨墊（metatarsal bars）、<span style="color:#fb923c">NSAIDs</span>、小腿伸展 |
| 手術 | 非手術治療失敗時可手術切除，可改善症狀 |
| 最常見術後併發症 | **切除不足（inadequate resection）** 或 **殘端神經瘤（stump neuroma）** |

> **Pearl**：Morton 神經瘤是**臨床診斷**；影像主要用於排除其他病因，而非確診。

**小趾畸形（Lesser Toe Conditions）**：小趾功能建立在**內在肌**與**伸、屈肌腱的微妙平衡**上，平衡一旦被破壞即產生畸形。

| 畸形 | 定義（原文描述） | 治療（可活動型） | 治療（僵硬型） |
|------|------------------|------------------|------------------|
| **Hammer toe（鎚狀趾）** | PIP 攣縮，MTP 與 DIP 呈伸直位 | **FDL-to-EDL transfer** | PIP 切除、EDL 延長、MTP 關節囊切開、側副韌帶鬆解 |
| **Claw toe（爪狀趾）** | 內在肌凌駕屈伸肌腱，PIP 與 DIP 屈曲 | **FDL tenotomy** | PIP 切除、DIP 切除、FDL tenotomy |
| **Mallet toe（槌狀趾）** | DIP 固定 | **FDL tenotomy** | DIP 切除 |

- 爪狀趾的成因由**足部內在肌驅動**，因此常見於**創傷性與神經性病因**。
> 縮寫：**DIP** = distal interphalangeal（遠端指間關節）、**EDL** = extensor digitorum longus（趾長伸肌）、**FDL** = flexor digitorum longus（趾長屈肌）、**MTP** = metatarsophalangeal（跖趾關節）、**PIP** = proximal interphalangeal（近端指間關節）。

**Bunionette deformity（小趾外翻畸形）**

| 分型 | 原文描述 | 治療 |
|------|----------|------|
| **Type I** | 跖骨頭**外側髁狀隆起** | 非手術為主；手術為**跖骨頭截骨術** |
| **Type II** | **彎曲的跖骨** | 需**跖骨截骨**矯正排列 |
| **Type III** | **第四與第五跖骨間角（IMA）變寬** | 需**跖骨截骨** |

> **Pearl**：bunionette 的手術層級完全由**分型決定**：Type I 是骨頭本身的問題（切骨頭），Type II 與 Type III 則是**跖骨形狀與 IMA 的問題**（整段跖骨截骨）。

### 1.2 Turf toe 與趾板（Plantar Plate）損傷

**Turf toe**

| 項目 | 內容 |
|------|------|
| 定義 | <span style="color:#22d3ee">馬蹄足（equinus）下的軸向負荷</span>造成**拇趾 MTP 的足底關節囊韌帶複合體（plantar capsuloligamentous complex）**破壞，導致**第一 MTP 過度伸展** |
| 分級 | **Grade 1**：複合體拉傷；**Grade 3**：完全撕裂 |
| 表現 | MTP 關節疼痛與腫脹、拇趾伸展時疼痛 |
| 影像 | **雙足負重 X 光**評估**蹼骨近端移位**，提示複合體撕裂；臨床懷疑時用 **MRI** 判定韌帶與關節面損傷程度 |

**小趾趾板損傷（Lesser Toe Plantar Plate Injury）**

| 項目 | 內容 |
|------|------|
| 病因 | **急性或慢性創傷**；亦見於**發炎性關節炎、神經肌肉疾病**，或**多次類固醇注射** |
| 機轉 | 趾板本應穩定 MTP；一旦破壞，因**趾長伸肌力量凌駕內在肌**，趾在 MTP 處**背屈** |
| 關聯 | 常與 **hammer toe** 合併 |
| 保守治療 | 含跖骨墊足墊、**cross-over toe taping**、凝膠趾套、**Budin 夾板** |
| 手術 | **MTP 關節與關節囊鬆解並修復**；常合併**遠端跖骨截骨**以利關節正確復位並維持前足平衡 |

> **Danger zone**：**Turf toe 的保守治療不可使用類固醇**——原文明言 *cortisone should not be used because it can weaken the capsule*。手術適應症為**創傷性 bunion、游離體、Grade 3 損傷合併明顯蹼骨後縮或大範圍關節囊撕裂**。

### 1.3 後足與中足：PCFD 與 Cavovarus 的解剖關鍵

**Progressive collapsing foot deformity（PCFD，進行性塌陷足畸形）**

- 舊稱 **adult acquired flatfoot deformity** 或 **posterior tibial tendon dysfunction**，是**足部架構一系列改變**所形成的症候群。
- 病理演變：**脛後肌腱功能障礙** ＋ **跟舟韌帶（spring ligament）變薄拉長** → **中足塌陷** ＋ **跟骨外翻傾**。
- 距骨旋轉 → **距骨頭未被覆蓋** ＋ **舟骨外側移位**。
- 臨床：初期為**脛後肌腱炎引起的內側疼痛**，畸形惡化後疼痛**轉移至外側踝**，原因是**腓骨下撞擊**。
- 體檢：**後足外翻**、**足弓消失**、**"too many toes" sign**、**提踵時無法內翻**。

**Cavus / Cavovarus（高弓足／高弓外翻足）**

| 項目 | 內容 |
|------|------|
| 定義 | **第一蹠骨蹠側下沉（plantarflexed first ray）**，造成**高的內側縱弓**；常伴**足跟 varus** |
| 流行病學 | 常為**雙側**，多數病人**無症狀** |
| 病因 | 常與**神經性疾患**相關：**腦中風、創傷性神經損傷、腦麻痺**；也可能是**距骨或跟骨骨折後變形** |
| 最常見神經病因 | **Charcot-Marie-Tooth disease（CMT）**，**體染色體顯性運動感覺神經病變**，分兩型：**Type 1** 為**髓鞘（myelin）病變**；**Type 2** 為**軸突功能異常**，故**表現較 Type 1 晚** |
| 病程 | 神經病變**由遠端向近端進展** → 足部**內在肌**早期失能 → **脛前肌** → **腓骨短肌**；**脛後肌與腓骨長肌過度作用**把後足拉入 varus，造成**第一蹠骨蹠側下沉與高弓外觀** |
| 伴隨表現 | **爪狀趾、跖痛、細微足下垂**；常敘述**反覆踝扭傷**、**第五跖骨骨折**病史、**腓骨肌腱病** |
| 體檢 | **Achilles 或腓腸肌攣縮**、**外側胼胝**、**varus 後足**（**peek-a-boo heel sign**：由正面可見內側足跟墊）；**必須用 Coleman block test 判定病因** |

> **Pearl**：**Coleman block test** —— 將木塊置於**足跟與足的外側半**下方，若 **varus 被矯正**，表示此 varus 為**可活動型、由前足驅動（forefoot driven）**；否則屬後足驅動的固定型變形。

**影像與其他檢查**

| 檢查 | 用途與所見 |
|------|-----------|
| 負重足／踝 X 光（Cavovarus） | **Meary angle 增加**、**跖骨堆疊**、**跟骨 pitch 增加**；varus 足跟產生 **drive-through sign**（距下關節可見間隙） |
| Hindfoot alignment view | 評估 varus 角度；亦可協助 PCFD 手術規劃 |
| 負重 CT | 評估關節炎 |
| MRI | 評估肌腱功能障礙（PCFD 看脛後肌腱完整性；Cavovarus 看肌腱功能） |
| 肌電圖／神經傳導／基因檢測／肌肉切片 | 若無已知神經學診斷，用來判定 cavovarus 的**基礎病因** |

### 2.1 PCFD 新分類：Stage I（可活動）vs. Stage II（僵硬）＋ A–E 五個解剖位置

| Stage | Class | 解剖位置 | 臨床表現 | 影像表現 |
|-------|-------|----------|----------|----------|
| **I — Flexible（可活動）** | **A** | **Hindfoot（後足）** | 後足外翻（**"too many toes" sign**） | 後足外翻 |
| | **B** | **Midfoot（中足）** | 前足外展 | **距骨頭覆蓋減少**、**距舟關節覆蓋角增加** |
| | **C** | **Forefoot（前足）** | **第一跖骨－內側楔骨柱不穩** | 前足 varus、**距骨－第一 TMT 角增加**、**楔骨／舟楔關節足底開展** |
| **II — Rigid（僵硬）** | **D** | **Peritalar region（距骨周區）** | **腓骨下撞擊** | **明顯距下關節半脫位** |
| | **E** | **Ankle（踝）** | **踝不穩** | **踝外翻傾** |

- 每個畸形位置另外標示**可活動（flexible）或固定（fixed）**。
- 分類範例：**可活動的後足外翻＋前足 varus 而無其他畸形 → 1AC**；**固定的後足外翻＋可活動的前足 varus → 2A1C**。
- 此新分類**較能代表疾病光譜並涵蓋整體變形範圍**。

> **Pearl**：新分類的價值在於**同時記錄「位置（A–E）」與「活動度（I 對 II）」**，直接對應後續手術策略：**可活動畸形以截骨矯正，僵硬畸形以融合處理**。

### 2.2 PCFD 手術決策矩陣

| 畸形情形 | 手術方向 | 原文要點 |
|----------|----------|----------|
| 孤立性後足外翻、**距骨頭覆蓋足夠**、**無前足 varus** | **單獨骨性手術**，如**內側化跟骨截骨術（medializing calcaneal osteotomy）** | 常合併**彈簧韌帶重建**、**趾長屈肌轉位**、**腓腸肌鬆解** |
| **距骨頭未被覆蓋 > 50%** | 考慮**外側柱延長術（lateral column lengthening）** | **65 歲以上**與較年輕病人接受相同手術者**結果無明顯差異** |
| 僵硬畸形 | **雙關節或三關節融合**：距下、距舟、跟骰關節 | 完成後足與中足手術後，須**再評估殘餘前足 varus** |
| 殘餘前足 varus，**無 TMT 關節炎** | **內側楔骨背側開口楔形截骨（Cotton osteotomy）** | 目的為**避免足外側過度負荷**；此 varus 可隨時間發展作為後足外翻的代償 |
| 殘餘前足 varus，**有 TMT 關節炎** | **第一 TMT 關節蹠側屈曲融合**，取代 Cotton 截骨 | 依影像而非單一術式決定 |
| 畸形延伸至踝，**外側關節軟骨流失 < 50%** 且畸形**可活動** | **韌帶重建平衡**，如**三角韌帶重建（deltoid reconstruction）** | 前提是尚無踝關節炎 |
| 畸形延伸至踝，**有踝關節炎** | **踝融合或踝關節置換** | 可與足部手術一併進行 |

> **Danger zone**：PCFD 手術有兩個不可省略的步驟——**先處理後足／中足，再重新評估前足是否殘留 varus**；若未重新評估而直接做 Cotton 截骨，可能掩蓋後足矯正不足的問題。

### 2.3 Cavovarus 決策矩陣

| 畸形狀態 | 手術方向 | 原文要點 |
|----------|----------|----------|
| **可活動型、前足驅動** | 初始處理針對**僵硬的前足**：**第一跖骨背屈截骨**或**背屈 TMT 融合** | 常合併**腓骨短肌轉位**以減少第一跖骨頭牽拉；並可做**足底筋膜鬆解**，因上述手術會增加足底腱膜牽拉 |
| **爪狀拇趾** | **拇長伸肌鬆解與轉位至跖骨頸（Jones procedure）** ＋ **趾間關節融合** | — |
| **固定型或後足驅動** | **跟骨外側化或閉合楔形截骨**矯正後足 varus | — |
| **背屈無力**（如 CMT） | **脛後肌腱轉位至外側楔骨**，經**脛骨骨間膜** | 利用過強的脛後肌作為**背屈肌與外翻肌** |
| **固定型或伴隨關節炎** | **距下融合或三關節融合** | 與 PCFD 處理邏輯相同 |

### 2.4 慢性踝不穩：易感因素與評估工具

| 面向 | 內容 |
|------|------|
| 盛行情形 | **2021 年研究估計美國每日發生多達 23,000 次內翻損傷** |
| 受損構造 | **ATFL（前下脛腓韌帶）、CFL（跟腓韌帶）、PTFL、後距腓韌帶**；約 **90%** 有 **ATFL 受損**，**CFL 受損約 20%–40%** |
| 演變 | 多數病人以物理治療改善，但**最多 20% 會進展為慢性踝不穩** |
| 易感因素 | **結締組織疾病、全身韌帶鬆弛、cavus foot 排列、跗骨融合（tarsal coalitions）** |
| 症狀 | **giving way（塌陷感）**、反覆扭傷、間斷疼痛與腫脹 |
| 體檢 | **關節積液**、**外側韌帶複合體壓痛**；因**腓骨肌為次要穩定構造**而**腓骨後方疼痛** |
| 檢查 | **Anterior drawer test** 與 **talar tilt test** 評估 ATFL 與 CFL，**須與對側比較**並考慮**鬆弛度** |
| 影像 | **負重踝 X 光（AP、mortise、lateral）**，可加**壓力測試**；**MRI 非診斷必需**，但可評估**腓骨肌腱撕裂**或**距骨骨軟骨病變**，會影響手術決策 |

### 2.5 下脛腓聯合與腓骨肌腱病

**下脛腓聯合（Syndesmosis）損傷**

| 項目 | 內容 |
|------|------|
| 組成 | **前下脛腓韌帶、後下脛腓韌帶、骨間膜、骨間韌帶、下橫韌帶** |
| 功能 | 抵抗脛骨與腓骨之間的**旋轉、軸向與平移力** |
| 發生率 | 常在**外旋損傷**中受傷，約見於 **13% 的踝骨折**；也可見於**無骨折的踝扭傷** |
| 臨床 | 疼痛位於**聯合處**，即 **ATFL 的前方與近端** |
| 影像 | 負重 X 光可見**脛腓骨重疊減少**與**內側間隙增加**；**對側負重 X 光有助比較**；懷疑但 X 光正常時用 **MRI** |

**腓骨肌腱病（Peroneal Tendinopathy）**

| 面向 | 內容 |
|------|------|
| 背景 | **腓骨肌為踝關節的次要穩定構造**；有**踝不穩病史**者可沿**腱鞘**疼痛 |
| 需排查的外在因素 | **慢性踝不穩、cavus foot、韌帶鬆弛、突出的腓骨結節、位置過低的腓骨短肌肌腹、副腓骨肌** |
| 體徵 | **腓骨遠端與腱鞘沿線疼痛**、**抗阻外翻時疼痛** |
| 影像 | 負重踝 X 光評估慢性踝不穩與後足畸形；**MRI** 評估**肌腱撕裂**、低位肌腹或副肌腱 |
| 手術分級 | 撕裂 **< 50%** → **清創**；變性 **> 50%** → **肌腱管狀化**或**肌腱固定（tenodesis）** |

## 3. 治療指引：保守治療與手術適應症 (Treatment Algorithm)

### 3.1 前足病變的治療路徑

| 病變 | 保守治療 | 手術適應症與術式 |
|------|----------|------------------|
| **拇外翻** | [原文缺漏：保守治療段落位於前頁] | **依畸形程度與體檢所見決定**；常包含**外側 MTP 關節囊鬆解、內側關節囊摺疊（imbrication）**、以及在**無 MTP 關節炎或 TMT 關節不穩**時行**跖骨截骨** |
| **Morton 神經瘤** | 寬趾頭鞋、跖骨墊、<span style="color:#fb923c">NSAIDs</span>、小腿伸展 | 非手術失敗後**切除**；併發症為**切除不足**與**殘端神經瘤** |
| **Bunionette** | **鞋具修改＋足墊**（主要處置） | Type I：跖骨頭截骨；Type II／III：跖骨截骨 |
| **Turf toe** | **Grade 1–2**：**硬墊（stiff insoles）**或 **Morton extension foot plate**；或以**可控制踝活動的靴**、**輕度蹠屈位 toe spica** 短暫固定 | **創傷性 bunion、游離體、Grade 3 合併明顯蹼骨後縮或大範圍關節囊撕裂**；術式為**足底關節囊韌帶複合體修復**，Grade 3 可有良好結果 |
| **趾板損傷** | 含跖骨墊足墊、cross-over toe taping、凝膠趾套、Budin 夾板 | **MTP 鬆解＋關節囊鬆解與修復**；常合併**遠端跖骨截骨** |

> **Danger zone**：**Turf toe 不可使用類固醇注射**——會弱化關節囊；且 Grade 1–2 的固定應為「輕度蹺屈位」而非完全中立或背屈位。

### 3.2 PCFD 與 Cavovarus 的治療路徑

| 病變 | 初始保守治療 | 手術升階 |
|------|--------------|----------|
| **PCFD** | **<span style="color:#fb923c">NSAIDs</span>、冰敷、內側足跟墊足墊、<span style="color:#60a5fa;font-weight:600">以脛後肌腱肌力強化為主的物理治療</span>** | 保守失敗後依**畸形程度與位置**手術（見 2.2）；若畸形延伸至踝，可加用 **Arizona 支架** |
| **Cavovarus** | **外側足跟墊＋內側足弓支撐＋凹陷式第一蹠骨足墊**；**以腓骨肌腱強化為主的物理治療** | 保守失敗後手術；畸形較嚴重者可先以 **AFO** 或 **Arizona 支架**同時穩定踝關節 |

> **Pearl**：PCFD 與 cavovarus 雖然後足方向相反，但**治療邏輯完全對稱**：兩者都是「**先保守（物理治療＋支架）→ 失敗後以肌腱轉位＋截骨矯正排列**」。

### 3.3 踝與肌腱病變的治療路徑

| 病變 | 保守治療 | 手術適應症與術式 |
|------|----------|------------------|
| **急性踝扭傷** | **RICE（休息、冰敷、壓迫、抬高）**；**早期**介入**以本體感覺與神經肌肉訓練為主的物理治療** | **首次損傷後的急性外側韌帶修復很少需要** |
| **慢性踝不穩** | 物理治療、**護具**；若存在**後足畸形**則加用足墊 | 保守失敗後：**解剖性修復或重建 ATFL 與 CFL 至腓骨附著點**；**Brostrém 修復＋Gould 修飾**最常用最有效（側側韌帶複合體**摺疊** ＋ **伸肌支持帶加強修復**）；或**非解剖性重建**，以**腓骨短肌腱**穩定踝關節 |
| **下脛腓聯合扭傷（X 光無 diastasis）** | **一段時間的固定**後接**物理治療** | 非手術結果**變異極大**，癒合**可能長於一般踝扭傷**；手術為**聯合復位＋螺釘或可撓性縫線鈕固定**，亦可採**螺釘＋縫線鈕混合結構** |
| **腓骨肌腱炎** | **物理治療＋抗發炎藥物**；若疼痛為限制因素，可在**超音波引導下注射腱鞘抗發炎藥**如 <span style="color:#fb923c">ketorolac（酮咯酸）</span>；另可用**短暫固定、護具、足墊**（尤其有 varus 後足時） | 保守失敗後手術：評估**腓骨長肌與腓骨短肌**、**鬆解腱鞘炎性組織或粘連**；撕裂 < 50% 清創，> 50% 管狀化或 tenodesis；**若存在足部變形，須於同次手術矯正以防復發** |

> **Danger zone**：**下脛腓聯合的手術固定若採螺釘，高度依賴解剖復位的準確度**——研究顯示**畸形復位（malreduction）可高達 40%**，且**螺釘常需手術移除**；較新的研究顯示**可撓性固定**可較快回活動並改善復位率。

### 3.4 阿基里斯腱斷裂與腱病

**阿基里斯腱斷裂（Achilles Tendon Rupture）**

| 面向 | 內容 |
|------|------|
| 生物力學 | <span style="color:#e2e8f0">Achilles tendon</span> 為**全身最大最粗的肌腱**，可承受**高達 12 倍體重**；在**距跟骨插入處近端約 4 cm** 開始變扁，此處亦為**血流量的分水嶺（watershed region）** |
| 發生位置 | **75% 的斷裂發生於距跟骨插入處近端 2–6 cm**，常為**偏心負荷（eccentric loading）**所致 |
| 族群 | 主要年齡 **30–40 歲**；主訴**「像被從後方踢到」**，伴疼痛與腫脹 |
| 前驅症狀 | **最多 30%** 的病人於斷裂前有**阿基里斯腱病**前驅症狀 |
| 診斷 | 主要為**臨床診斷**：疼痛、腫脹、瘀青、**肌腱缺損**、俯臥屈膝時**靜息背屈角度增加**；**Thompson test（擠壓小腿無跖屈反應）高度敏感且特異**；**超音波或 MRI** 可評估**斷裂高度與術前規劃** |
| 傳統非手術 | **石膏或夾板固定 6–8 週**，**再斷裂率較手術組高** |
| 加速復健非手術 | **2 週起保護性負重**並由物理治療協助活動進展，**再斷裂率與手術治療相似**，多數病人回到原有運動水準；**納入標準**為**48 小時內置入蹺屈位夾板或石膏**且為**肌腱中段斷裂**，**排除標準**為**糖尿病史或類固醇使用** |
| 手術優勢 | 可**較短時間回到工作與運動**；何者最佳仍需更多研究 |
| 慢性斷裂 | **超過 8 週**者多需手術，常因**初始誤診**；未修復可導致**患肢慢性無力或蹬離力量喪失**，需 **AFO** 助行；缺損大小決定是否需**補強** |
| 手術方式 | **Open**（端對端 Krakow 或 locking Bunnell，可加**近端肌腱縫線穿入跟骨**）、**Mini-open**、**Percutaneous**（專用 jig 置入腱鞘內以**不可吸收縫線**做鎖定式縫合，或配合**跟骨縫線錨**補強） |

> **Pearl**：**加速復健方案**是近年最大的改變；其成功前提是**嚴格的納入／排除標準**（48 小時內蹺屈位固定＋中段斷裂；排除糖尿病與類固醇使用者）。

**阿基里斯腱病（Achilles Tendinopathy）**

| 面向 | 內容 |
|------|------|
| 分類 | **Insertional（插入端）** 與 **Noninsertional（非插入端）**，依疼痛位置區分；常伴**腫脹與隆起** |
| 病理 | 退化過程稱為**血管纖維母細胞增生（angiofibroplastic hyperplasia）**：**密集成纖維母細胞族群、血管增生、膠原排列紊亂**，導致**強度與彈性下降** |
| 非插入端表現 | 疼痛與腫脹位於**距跟骨插入處 4–6 cm** |
| 插入端表現 | 疼痛在**插入處**；常見於**肥胖、高血壓、糖尿病、發炎性關節病**及**年齡較大**者 |
| 評估 | 應著重評估**馬蹄足攣縮**；**負重踝 X 光**判斷是否有 **Haglund 畸形（跟骨後外上方隆起）**或**腱內鈣化**；超音波與 MRI **診斷非必需**，但可評估**肌腱品質** |
| 保守治療 | **短暫休息、固定、矽膠足跟杯、以馬蹄足攣縮為焦點的小腿伸展**；**物理治療（離心肌力強化）** 對**插入端**成功率**高**，對**非插入端**較低；**體外震波（ESWT）加上離心物理治療**較單純物理治療**改善結果**；**PRP** 在數篇研究中**未顯示明確效益** |
| 手術時機 | **保守治療 6 個月無效後**方可考慮手術 |
| 插入端手術 | **肌腱清創＋Haglund 畸形切除**；**清創超過橫截面 50%** 者須以**拇長屈肌腱轉位**補強；**肌腱完全自跟骨剝離**者以**縫線錨雙排修復**；**內視鏡 Haglund 切除＋清創＋縫線加強重建**結果優良，但**仍需較大型與對照研究**；使用**後內側與後外側 portal**，有**腓腸神經（sural nerve）損傷**風險 |
| 非插入端手術 | **經皮肌腱切開、肌腱剝離、內視鏡肌腱清創**；若**嚴重變性**可能需**開放修復**，牽涉 **> 50%** 肌腱時需**補強** |

### 3.5 足底筋膜炎與 Lisfranc 損傷

**足底筋膜炎（Plantar Fasciitis）**

| 面向 | 內容 |
|------|------|
| 流行病學 | 運動員與非運動員皆常見；為**慢性過度使用**造成**足底筋膜在跟骨結節內側起點處的微小撕裂** |
| 蔓延構造 | 反覆創傷造成**反覆發炎**，並可波及共用同一跟骨插入處的**拇展肌、趾短屈肌、足底方肌** |
| 症狀 | **起步痛（start-up pain）**：晨起第一步或休息後第一步疼痛，**行走後改善**，日內再逐漸惡化 |
| 體檢 | **足底筋膜內側插入點壓痛**，常伴 **Achilles 肌腱緊繃** |
| 影像 | 負重 X 光常正常；慢性者可見**跟骨骨刺**；除非懷疑其他合併病變，**不需額外影像** |
| 保守治療 | **足底筋膜伸展與小腿伸展＋<span style="color:#fb923c">NSAIDs</span>**；**夜間夾板與鞋墊**效果**並非一致**；嚴重者可**短暫固定**，但**必須配合持續伸展運動** |
| 禁用 | **不建議類固醇注射**——可能造成**足底脂肪墊萎縮或足底筋膜破裂** |
| ESWT | **保守治療 6 個月失敗**後可使用**體外震波治療**並可能有效 |
| 手術 | 症狀持續者可考慮**足底筋膜鬆解**，且**應同時鬆解拇展肌** |

**Lisfranc 複合體解剖與損傷分型**

| 項目 | 內容 |
|------|------|
| 三個關節 | **跖楔關節（第二跖骨－內側楔骨）**、**跖骨間關節（第一－第二跖骨）**、**楔骨間關節（內側－中間楔骨）** |
| 力學要點 | **跖骨基底在冠狀面形成拱**，**第二跖骨基底為拱頂石（keystone）**且**向近端內凹**，是維持中足穩定的重要骨性結構 |
| 韌帶 | 由**內側楔骨與第二跖骨基底**發出的**背側與足底斜韌帶**與 **Lisfranc 韌帶**（**最強者**） |
| **直接損傷** | 常為**高能量（壓碎傷、汽車撞擊）**，伴隨**軟組織創傷**與**血管受損風險** |
| **間接損傷** | **運動傷害或高處跌落**，造成**軸向負荷或旋轉力通過過度蹺屈的足部** |
| **Type A（total incongruity）** | **所有 TMT 關節均不對稱（homolateral）** |
| **Type B（partial incongruity）** | **一個或多個關節面仍保持完整** |
| **Type C（divergent）** | **內側 TMT 向內側移位**，**外側 TMT 向外側移位** |

**臨床、影像與治療**

| 項目 | 內容 |
|------|------|
| 高警覺指標 | **負重困難、明顯中足腫脹、足底弓狀瘀青**；**最多 40% 的損傷在初始 X 光被漏診** |
| 症狀 | **第一與第二 TMT 關節明顯壓痛**、**被動旋前與外展時疼痛** |
| 高能量 | 可能合併**腓深神經或動脈損傷**，應評估**骨筋膜室症候群** |
| 初始影像 | **雙足負重 AP**：**第二跖骨內側緣應與中間楔骨內側緣對位**，第一與第二跖骨基底間**間距 < 2 mm** 為正常；**斜位**：**第四跖骨內側緣應與骰骨內側緣對位**；**側位**：**第一跖骨與內側楔骨的背側皮質應對位** |
| Fleck sign | **第二跖骨基底撕脫骨折** |
| CT／MRI | CT 用於高能量損傷懷疑其他骨折；MRI 用於懷疑**韌帶損傷**（X 光表現可能不確定） |
| 非手術適應症 | 手術風險高，或**檢查與影像均無不穩證據**者：**6 週部分負重**並逐步恢復 |
| 手術為主 | **多數 Lisfranc 損傷需手術**；**不穩定情形下採非手術管理**可造成顯著疼痛與**高達 30% 的創傷後關節炎**；**最重要臨床因素為準確的復位**；**ORIF 與初期融合何者較優仍有爭議** |
| 初期融合適應症 | **延遲就醫**、**韌帶損傷**、或病人有**肥胖、糖尿病**等可能影響癒合的狀況；若行初期融合，**第四與第五 TMT 關節只做暫時性固定** |
| ORIF | 可保留關節但**需要第二次手術移除植入物**；**2020 年研究**發展出**可撓性固定技術**可免去第二次手術，但**仍需更多研究**比較其與螺釘－鋼板 ORIF 或關節融合的結果 |

> **Danger zone**：**初始 X 光正常不代表沒有 Lisfranc 損傷**——**40% 被漏診**；凡有**負重困難＋中足腫脹＋足底瘀青**者應高度懷疑並加做 CT 或 MRI。

## 4. 手術入路與危險地雷 (Surgical Approach & Pearls)

### 4.1 前足與中足手術的珍珠

> **Pearl 1**：**Morton 神經瘤切除**最常見的術後問題不是復發神經瘤，而是**殘端神經瘤**與**切除不足**，故切除範圍與神經處理需一併考量。

> **Pearl 4**：**bunionette** 若只做 Type I 的**跖骨頭截骨**而未處理 Type II／III 的**IMA 寬度與跖骨彎曲**，症狀容易復發。

### 4.2 後足截骨與融合的陷阱

> **Danger zone 1**：**PCFD 手術後必須重新評估前足**；**殘餘前足 varus** 會隨時間發展作為後足外翻的代償，若此時才以 **Cotton 截骨**處理而未確認後足已充分矯正，手術將無法成功。

> **Danger zone 2**：**Cotton 截骨與第一 TMT 融合不可互換**——**若存在 TMT 關節炎**，應做**第一 TMT 蹠側屈曲融合**；Cotton 截骨是為了**避免足外側過度負荷**。

> **Danger zone 3**：**外側柱延長術**應在**距骨頭未被覆蓋 > 50%** 時考慮；原文指出 **65 歲以上與較年輕病人接受相同手術的結果無明顯差異**，故年齡本身不應成為排除外側柱延長的理由。

> **Danger zone 4**：**Cavovarus 術前一定要做 Coleman block test**——**前足驅動**與**後足驅動**的手術路徑完全不同：前者做第一跖骨背屈截骨或背屈 TMT 融合（加**腓骨短肌轉位**），後者做**跟骨截骨**。

> **Danger zone 5**：**CMT 病患的背屈無力**不應只靠軟組織手術處理；**經脛骨骨間膜將脛後肌轉位至外側楔骨**可將過強的內翻／蹠屈力量轉為**背屈與外翻**。

> **Danger zone 6**：**足底筋膜鬆解後應同時鬆解拇展肌**；Cavovarus 術中做第一跖骨背屈截骨會**增加足底腱膜的牽拉**，因此原文建議**合併足底筋膜鬆解**。

### 4.3 踝與下脛腓聯合的陷阱

> **Danger zone 7**：**下脛腓聯合螺釘固定的復位誤差可高達 40%**，且螺釘常需手術移除；**可撓性固定（縫線鈕）** 可較快回活動——RCT（103 例）顯示**螺釘組畸形復位 39%、可撓性固定組 15%**（Level I）。

> **Danger zone 8**：**Brostrém 修復並非萬能**——當**韌帶品質差、翻修病例、或合併韌帶鬆弛**時，解剖性修復失敗率升高，此時應考慮**以腓骨短肌腱做非解剖性重建**。

> **Pearl**：Brostrém ＋ Gould 修飾長期結果優異：**22 例系列 26 年追蹤滿意度 91%**；**150 例、平均追蹤 11 年**的**病人滿意度 93%**。

> **Pearl**：**慢性踝不穩的病人應仔細尋找潛在的足部變形**——**cavus foot** 與**跗骨融合**都是易感因素，且合併足部變形會使**手術結果較不理想**。

> **Danger zone 9**：**腓骨肌腱手術若不處理既存的足部變形（尤其 varus 後足），復發率會升高**；原文明確要求**變形須於同次手術矯正**。

### 4.4 阿基里斯腱與足底筋膜炎的陷阱

> **Danger zone 10**：**加速復健方案並非人人適用**——納入標準為**48 小時內蹺屈位固定＋中段斷裂**；**糖尿病史或類固醇使用者為排除標準**。

> **Danger zone 11**：**阿基里斯腱病的保守治療必須持續至少 6 個月**才考慮手術；**PRP 並未顯示明確效益**，不應作為主要治療。

> **Danger zone 12**：**阿基里斯腱清創超過橫截面 50%**（插入端）或**牽涉 > 50% 肌腱**（非插入端）者**必須補強**——插入端以**拇長屈肌腱轉位**。

> **Danger zone 13**：**阿基里斯內視鏡手術使用後內側與後外側 portal，有腓腸神經損傷風險**；**percutaneous 技術**在某些研究中**腓腸神經損傷與可觸及縫線結節**比例較高（非一致發現）。

> **Danger zone 14**：**足底筋膜炎禁用類固醇注射**——會造成**足底脂肪墊萎縮**或**足底筋膜破裂**；手術時**足底筋膜鬆解須同時鬆解拇展肌**。

### 4.5 開放與微創技術的結果比較

| 技術 | 原文描述的優勢 | 原文描述的風險／代價 |
|------|----------------|-------------------|
| **Achilles open repair** | 端對端 Krakow 或 locking Bunnell；可將**近端肌腱縫線穿入跟骨**加強 | 切口與疤痕相關問題較多 |
| **Achilles mini-open / percutaneous** | **傷口併發症與疤痕較少、手術時間較短**；percutaneous 用專用 jig 與不可吸收縫線，可直接修復或**配合跟骨縫線錨** | 某些研究**腓腸神經損傷**與**可觸及縫線結節**比例較高（非一致發現）；meta-analysis（25 篇研究、2,223 例）顯示**併發症較少但結果相近** |

### 5.2 OKU 14 Key Study Points（本章重點整理）

- **拇外翻的外科治療依畸形程度與體檢所見決定**；常包含**外側 MTP 關節囊鬆解、內側關節囊摺疊**，並在**無 MTP 關節炎或 TMT 關節不穩**的情況下行**跖骨截骨**。
- **PCFD 常發生於脛後肌腱功能障礙的背景下**；相對地，**cavovarus 變形常有神經性病因**。若**物理治療與支架的初始管理失敗**，外科管理涉及**肌腱轉位與截骨術的組合**以改善排列。
- **Lisfranc 損傷常在初始檢查被漏診**，但可導致**中足塌陷與不穩**。手術選項包括**初期融合或 ORIF**，依**影像所見與損傷型態**決定。

### 5.3 骨科專科考試核心總結（Take-Home Points）

1. **前足**：Morton 神經瘤多在**第三趾蹼**，為**臨床診斷**；**切除不足與殘端神經瘤**是最常見術後問題。**Turf toe 禁用類固醇**；Grade 1–2 以硬墊或 Morton extension foot plate 治療，Grade 3 合併蹼骨後縮或大範圍關節囊撕裂者手術修復。**趾板損傷**鬆解修復並常合併**遠端跖骨截骨**。**bunionette** Type I 切骨頭，Type II／III 需跖骨截骨。
2. **分型**：**PCFD 新分類 = Stage I／II × Class A–E**（例：**1AC**、**2A1C**）。**bunionette** 分 Type I（外側髁隆起）、II（彎曲跖骨）、III（IMA 變寬）。
3. **PCFD 手術邏輯**：可活動 → 截骨；僵硬 → 融合。**距骨頭未覆蓋 > 50% → 外側柱延長**（65 歲以上結果無差異）；殘餘前足 varus → 無 TMT 關節炎用 **Cotton 截骨**，有則用**第一 TMT 蹠側屈曲融合**；踝外側軟骨流失 < 50% 且可活動 → **三角韌帶重建**；有踝關節炎 → 融合或置換。
4. **Cavovarus**：**Coleman block test** 決定前足驅動或後足驅動；前足驅動 → 第一跖骨背屈截骨或背屈 TMT 融合（＋**腓骨短肌轉位**、足底筋膜鬆解）；後足驅動 → **跟骨截骨**；**CMT 背屈無力 → 脛後肌經脛骨骨間膜轉位至外側楔骨**。
5. **踝不穩**：**ATFL 受損約 90%、CFL 約 20%–40%**，**最多 20% 進展為慢性不穩**；**Brostrém ＋ Gould** 最常用最有效（**22 例 26 年追蹤滿意度 91%**；**150 例平均 11 年滿意度 93%**）；韌帶品質差／翻修／韌帶鬆弛 → **非解剖性（腓骨短肌）重建**。
6. **下脛腓聯合**：約見於 **13% 踝骨折**；**螺釘固定畸形復位可達 40%**，RCT 顯示**螺釘 39% vs. 可撓性固定 15%**，且螺釘常需移除。
7. **阿基里斯腱**：可承受 **12 倍體重**；**75% 斷裂位於插入處近端 2–6 cm**；**Thompson test** 敏感且特異；**加速復健**再斷裂率與手術相似（排除糖尿病、類固醇使用者）；**慢性（> 8 週）**依缺損：**< 2 cm** 直接修復、**2–5 cm** 加腓腸肌筋膜延長／V-Y／FHL 轉位、**> 5 cm** 需同種異體移植物等。**腱病手術須保守 6 個月後**，**PRP 無明確效益**，**清創 > 50% 須以 FHL 轉位補強**。
8. **足底筋膜炎**：**起步痛**、跟骨結節內側壓痛、禁類固醇注射；**保守 6 個月失敗**後可 **ESWT**；手術為**足底筋膜鬆解＋拇展肌鬆解**。
9. **Lisfranc**：**最多 40% 初始 X 光被漏診**；**fleck sign**；**Type A／B／C**；不穩定者多需手術，不穩定下非手術可致**創傷後關節炎高達 30%**；**初期融合**用於延遲就醫、韌帶損傷、肥胖或糖尿病（第四、五 TMT 僅暫時固定）；ORIF 需第二次取物，**可撓性固定**為 2020 年新技術、待更多研究。
