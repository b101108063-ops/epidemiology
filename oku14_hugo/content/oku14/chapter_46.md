# Chapter 46: Knee Arthritis and Reconstruction — 膝關節炎與重建

## 章節導讀

膝關節骨關節炎（<span style="color:#e2e8f0">Knee Osteoarthritis, KOA</span>）是全球最常見且造成個人與社會重大醫療負擔的肌肉骨骼疾病。隨著人口老化與肥胖盛行率上升，膝關節炎的治療已從傳統「症狀控制等待置換」的思維，轉向精準醫學時代。本章系統性梳理膝關節炎的病理生理學機制與異質性表現型（<span style="color:#e2e8f0">Osteoarthritis Phenotypes</span>），比對各大國際學會（AAOS、ACR、OARSI）的非手術治療指引，並剖析前沿修飾病程藥物（<span style="color:#e2e8f0">DMOADs</span>）與骨生物學（<span style="color:#e2e8f0">Orthobiologics</span>）的最新臨床實證。在手術重建方面，詳細探討單髁關節置換（<span style="color:#e2e8f0">UKA</span>）的精確適應症與禁忌症、非骨水泥全膝關節置換（<span style="color:#e2e8f0">Cementless TKA</span>）的固定進展，以及機器人輔助、客製化手術模具（<span style="color:#e2e8f0">PSI</span>）與智慧感測器植體在優化關節置換精準度中的角色。

---

## 1. 臨床評估、風險因子與病理生理學 (Clinical Evaluation, Risk Factors & Pathophysiology)

膝關節作為下肢動力鏈的核心樞紐，承載著來自上方與下方關節的力學應力。膝關節由四個骨性結構關節組成，並由軟骨、韌帶、肌腱、滑膜、脂肪與皮膚等多元組織包覆。

### 1.1 流行病學與疾病負擔

- **盛行率與人口學**：全球 40 歲以上人口中，膝骨關節炎的盛行率估計達 <span style="color:#60a5fa">22%</span>，全球患者人數超過 <span style="color:#60a5fa">6.54 億人</span>。膝關節是骨關節炎最常發生的部位，佔整體骨關節炎疾病負擔的 <span style="color:#60a5fa">4/5（80%）</span>。
- **終生風險與嚴重度**：個人終生發生症狀性膝骨關節炎的風險估計高於 <span style="color:#f87171">45%</span>。其所導致的失能率、發病率、醫療費用與死亡率，已可與類風濕性關節炎（<span style="color:#e2e8f0">Rheumatoid Arthritis, RA</span>）相提並論。

> **Pearl**：傳統觀念常誤以為骨關節炎的嚴重度低於發炎性關節炎，但長達 40 年的追蹤數據顯示，膝骨關節炎在失能與生活品質上的破壞力與類風濕性關節炎不相上下。

### 1.2 危險因子與多因子病因

膝骨關節炎的發理機制為多因子共同作用的結果：

| 危險因子類別 | 具體機制與臨床特徵 |
|--------------|--------------------|
| **年齡與磨損** | 年齡增長累積的關節磨損與軟骨修復能力下降 |
| **關節過載與創傷** | 軟骨與骨下骨過載、重複過度使用；<span style="color:#f87171">急性創傷使未來發生膝 OA 的風險增加近 4 倍</span> |
| **下肢排列不佳** | 先天性或後天性下肢軸線不正（varus/valgus malalignment） |
| **代謝與全身因子** | <span style="color:#f87171">肥胖（Obesity）</span>、慢性低度發炎、第二型糖尿病（Type 2 DM） |
| **性別與內分泌** | 女性基因易感性；圍絕經期與絕絕期<span style="color:#fb923c">雌激素（Estrogen）</span>流失會破壞軟骨完整性 |
| **組織與分子變化** | 骨密度下降、瘦肌肉量減少（sarcopenia）及衰老細胞累積 |

### 1.3 軟骨退化與分子病理生理學

在滑液關節（diarthrodial joint）中，<span style="color:#22d3ee">chondrocytes（軟骨細胞）</span> 包埋於細胞外基質中，對力學微環境與發炎細胞激素極為敏感：

- **基質分解酶上調**：受力過載或發炎刺激時，軟骨細胞會大幅上調基質金屬蛋白酶（MMP），包括破壞 II 型膠原蛋白的 <span style="color:#e2e8f0">MMP-1</span> 與 <span style="color:#e2e8f0">MMP-13</span>，以及強效的蛋白聚醣酶（aggrecanase）<span style="color:#e2e8f0">MMP-3</span>，導致蛋白聚醣分解與膠原蛋白結構破壞。
- **髁下骨重塑與惡性循環**：軟骨退化伴隨軟骨細胞表現型改變，進而觸發 <span style="color:#22d3ee">subchondral bone（骨下骨）</span> 重塑，以旁分泌（paracrine）方式釋放細胞激素，形成持續破壞軟骨的惡性循環。
- **髁下脂肪墊發炎**：<span style="color:#22d3ee">infrapatellar fat pad（髁下脂肪墊 / Hoffa fat pad）</span> 在骨關節炎環境下會發炎，分泌高濃度的脂肪細胞因子（adipocytokines）、<span style="color:#e2e8f0">IL-6</span> 及 <span style="color:#e2e8f0">VEGF</span>，刺激相鄰滑膜引發發炎與疼痛。
- **細胞衰老（Cellular Senescence）**：隨著年齡增長，關節內累積的衰老細胞過度表現 <span style="color:#e2e8f0">p16</span>，分泌衰老相關分泌表現型（<span style="color:#e2e8f0">SASP</span>），導致細胞週期停滯並持續破壞關節組織。

## 2. 異質性表現型與影像評估 (Phenotypes & Radiographic Evaluation)

### 2.1 膝骨關節炎的異質性表現型 (OA Phenotypes)

由於膝骨關節炎致病機制的異質性，現代醫學將其劃分為不同的臨床表現型，以實施精準醫療：

| 表現型 (Phenotype) | 核心病理機制 | 潛在治療標靶 |
|--------------------|--------------|--------------|
| **滑膜發炎型** (Synovial Inflammatory) | 關節內低度慢性無菌性發炎、滑膜增生 | 促發炎細胞激素抑制劑 (IL-1, TNF-α) |
| **細胞衰老型** (Cell Senescence) | p16 表現衰老細胞累積、SASP 分泌 | 衰老細胞清除劑 (Senolytics) |
| **軟骨退化型** (Cartilage Degradation) | 軟骨細胞分化異常、MMP/aggrecanase 高表現 | Wnt 抑制劑、MMP 抑制劑、Sprifermin |
| **全身代謝型** (Systemic Metabolic) | 肥胖、糖尿病、脂肪因子引發全身發炎 | 體重控制、Metformin、代謝調節劑 |
| **骨質疏鬆過載型** (Osteoporotic Overload) | 骨下骨重塑異常、骨微結構破壞 | 雙磷酸鹽、Teriparatide、降鈣素 |

### 2.2 影像學診斷與評估分級

膝骨關節炎的傳統影像學評估以標準站立位 X 光（plain radiographs）為核心：

- **四大典型 X 光特徵**：
  1. <span style="color:#22d3ee">Joint-space narrowing（關節間隙狹窄）</span>
  2. <span style="color:#22d3ee">Subchondral sclerosis（骨下骨硬化）</span>
  3. <span style="color:#22d3ee">Osteophyte formation（骨贅/骨刺形成）</span>
  4. <span style="color:#22d3ee">Subchondral cysts（骨下囊腫）</span>
- **常用分級系統**：包含 <span style="color:#e2e8f0">ACR criteria</span>、<span style="color:#e2e8f0">Kellgren-Lawrence (K-L) classification</span>、<span style="color:#e2e8f0">Ahlbäck classification</span> 以及 <span style="color:#e2e8f0">Knee Osteoarthritis Grading System</span>。

> **Danger zone**：影像表現與臨床症狀存在高度解離（Discordance）。嚴重 X 光關節破壞的患者可能僅有輕微疼痛，而臨床症狀劇烈的患者 X 光可能無明顯異常。因此，診斷與手術決策切勿單憑 X 光，必須結合病患的實際功能障礙與疼痛程度。

## 3. 非手術治療指引與新型藥物 (Nonsurgical Guidelines & Emerging Pharmacotherapy)

### 3.1 國際三大學會處置指引對比

AAOS、ACR 與 OARSI 針對膝骨關節炎的非手術處置提出了實證指引：

| 治療項目 | AAOS 指引 | ACR 指引 | OARSI 指引 | 臨床建議與定位 |
|----------|-----------|----------|------------|----------------|
| **運動處方 (Exercise)** | ++ | ++ | ++ | 核心基礎治療，強烈推薦 |
| **減重 (Weight Loss)** | + | ++ | + | 減輕關節負載，顯著延緩進展 |
| **助行器/手杖 (Cane)** | NA | ++ | + | 提供關節卸力保護 |
| **口服 NSAIDs** | ++ | ++ | + | 第一線止痛與抗發炎藥物 |
| **外用 NSAIDs (Topical)** | + | ++ | + | 局部使用，胃腸道副作用少 |
| **關節內類固醇 (IA Steroids)** | ++ | ++ | + | 短期快速緩解急性發炎 |
| **關節內玻尿酸 (IA HA)** | - | - | +/- | 學會間存在爭議，實證未一致 |
| **乙醯胺酚 (Acetaminophen)** | - | - | - | 止痛療效有限，不再推薦 |
| **硫酸軟骨素 (Chondroitin)** | - | - | - | 無明確臨床改善實證 |
| **鴉片類藥物 (Opioids)** | - | - | +/- | 僅 Tramadol 具條件式考慮，儘量避免 |
| **經皮電刺激 (TENS)** | - | - | - | 臨床療效不足，不推薦 |

*(符號說明：++ 強烈推薦；+ 推薦；- 不推薦；+/- 結果未定/條件式推薦；NA 未提供處置建議)*

### 3.2 疾病修飾骨關節炎藥物（DMOADs）前沿進展

現行處置多為症狀控制，FDA 已呼籲開發能真正阻止結構破壞與病程進展的 <span style="color:#e2e8f0">DMOADs</span>：

- **抗發炎與抗衰老標靶**：
  - <span style="color:#fb923c">IL-1 抑制劑</span> 與 <span style="color:#fb923c">TNF-α 抑制劑</span>：阻斷促發炎細胞激素引起的骨吸收與軟骨破壞。
  - <span style="color:#fb923c">Senolytics（衰老細胞清除劑）</span>：在小鼠模型中，特異性清除表現 <span style="color:#e2e8f0">p16</span> 的衰老細胞可預防創傷後骨關節炎、降低疼痛並改善軟骨細胞功能。
- **軟骨修復與保護標靶**：
  - <span style="color:#fb923c">Lorecivivint</span>：透過抑制 CLK2 和 DYRK1A 調控 Wnt 通路，防止軟骨細胞轉化為骨細胞及基質分解。
  - <span style="color:#fb923c">M6495</span>（Anti-ADAMTS-5 Nanobody）：抑制蛋白聚醣酶，保護 aggrecan 及 II 型膠原蛋白。
  - <span style="color:#fb923c">Sprifermin</span>（FGF-18 類似物）：刺激軟骨細胞增生與基質合成修復。
  - <span style="color:#fb923c">Metformin（二甲雙胍）</span>：降血糖藥物，實驗顯示能下調 <span style="color:#e2e8f0">MMP-13</span> 並促進膠原蛋白生成。回溯性研究發現，使用 Metformin 的糖尿病合併 OA 患者，接受全關節置換術的比例顯著降低。
- **骨下骨代謝調節劑**：雙磷酸鹽（bisphosphonates）、降鈣素（calcitonin）、鍶鹽（strontium ranelate）、<span style="color:#fb923c">Teriparatide</span>（重組人類副甲狀腺素）及維生素 D。

### 3.3 再生醫學與骨生物學（Orthobiologics）實證

- **高濃度血小板血漿（<span style="color:#e2e8f0">PRP</span>）**：
  - 包含 18 項 Level I 研究（> 800 名患者）的 Meta-analysis 顯示，PRP 在改善疼痛與功能的療效顯著優於玻尿酸（<span style="color:#34d399">改善率 44% vs. 12.6%</span>）。
  - 分子次分型實證指出，<span style="color:#60a5fa">Leukocyte-poor PRP (LP-PRP)</span> 的臨床效果優於包含白血球的 Leukocyte-rich PRP (LR-PRP)。
- **骨髓/脂肪幹細胞（<span style="color:#e2e8f0">MSCs</span>）**：
  - 涵蓋 25 項研究（439 名患者）的 Meta-analysis 顯示，與對照組相比，**注射 MSCs 在疼痛減輕上未達統計顯著差異**。
  - 雖然相較於對照組，MSCs 能帶來關節功能與軟骨體積的改善（效應量較小），但**未見軟骨品質（cartilage quality）的顯著提升**。

## 4. 手術重建、植體固定與前沿科技 (Surgical Reconstruction & Advanced Technologies)

當保守治療無效且患者生活品質嚴重受損時，應考量手術重建。

### 4.1 截骨術與單髁膝關節置換 (UKA)

- **截骨術 (Osteotomy)**：用於矯正早期至中期單腔室膝關節炎的下肢軸線，但近年使用率逐漸被 UKA 取代。
- **單髁關節置換術 (UKA)**：適用於侷限於單一腔室（內側或外側）或髕股關節的骨關節炎。
  - **UKA 的優點**：保留原生骨量與交叉韌帶、術後恢復較快、醫學併發症發生率較低。
  - **適應症選擇與限制**：

| 手術選擇 | 適應症與關節狀態 | 臨床備註與限制 |
|----------|------------------|----------------|
| **UKA 適應症** | 單腔室關節間隙狹窄、韌帶結構完整 | 骨量保留良好、恢復迅速 |
| **禁忌症 (應改採 TKA)** | <span style="color:#f87171">屈曲合約 (Flexion contracture) > 10°</span> | 需廣泛鬆解與骨裁切重建 |
| | <span style="color:#f87171">無法手動校正的內翻/外翻畸形</span> | 單腔室置換無法恢復正確軸線 |
| | <span style="color:#f87171">前十字韌帶缺損 (ACL deficiency)</span> | 關節前後不穩定導致 UKA 早期失敗 |

> **Danger zone**：在年齡小於 65 歲的年輕活躍患者中，UKA 的再置換率（revision rate）顯著高於 TKA。手術決策時需審慎評估患者年齡與活動量需求。

### 4.2 全膝關節置換術 (TKA) 與圍手術期處置

全膝關節置換術（<span style="color:#e2e8f0">TKA</span>）是終末期全關節破壞的最可靠手術。

- **滿意度挑戰**：儘管現代 TKA 植體 10-15 年存活率極高，仍有高達 <span style="color:#f87171">20% 的患者對術後功能或疼痛感受表示不滿意</span>。
- **圍手術期優化**：
  - **多模式止痛 (Multimodal Analgesia)**：結合神經阻斷與關節周圍注射，大幅降低術後鴉片類藥物使用量，實現同日出院（same-day discharge）。
  - **傳明酸 (<span style="color:#fb923c">TXA</span>)**：靜脈或局部使用 TXA 已成為 TKA 標配，顯著減少手術失血量與輸血需求。

### 4.3 骨水泥固定 vs. 非骨水泥固定 (Cemented vs. Cementless TKA)

- **骨水泥固定 (Cemented TKA)**：長期以來被視為金標準。
- **非骨水泥固定 (Cementless TKA)**：
  - 早期的非骨水泥植體在脛骨側失敗率高（特別是體型較大的男性患者）。
  - **現代設計突破**：採用高多孔性金屬（如多孔鉬/鈦或鉭金屬 <span style="color:#e2e8f0">porous tantalum</span>）促進骨長入。
  - 臨床實證：在 BMI ≥ 35 kg/m² 的肥胖患者中，採用具備大型龍骨（keel）與 4 支柱（4-peg）設計的非骨水泥脛骨植體（812 名患者研究），早中期存活率與骨水泥固定相當。

### 4.4 電腦導航、機器人輔助與智慧感測技術

為降低人為誤差與植體偏離（outliers），前沿手術技術快速發展：

| 技術類別 | 代表性系統/產品 | 工作原理與臨床特徵 | 臨床實證與現狀 |
|----------|-----------------|--------------------|----------------|
| **電腦導航** | <span style="color:#e2e8f0">OrthAlign, Intellijoint</span> | 利用加速度計 (accelerometers) 輔助對齊裁切導板 | 避免進入骨髓腔，降低栓塞風險 |
| **機器人輔助** | <span style="color:#e2e8f0">Mako, Rosa, Velys</span> | 結合術前 2D/3D 影像與術中應力測試，動態評估軟組織張力 | <span style="color:#34d399">顯著提高 UKA 脛骨裁切精準度，降低 5 年再置換率</span>；但在 TKA 中尚未證實能改善 PROMs |
| **客製化手術工具** | <span style="color:#e2e8f0">PSI (Patient-Specific Instrumentation)</span> | 術前 3D 模擬製作客製化裁切模具 | Meta-analysis 顯示未顯著減少軸線偏離，效益仍存爭議 |
| **術中感測器** | <span style="color:#e2e8f0">VERASENSE</span> 等試置感測器 | 試置時即時量測關節內壓力與韌帶張力 | 提供客觀張力數據，尚需長期功能實證 |
| **智慧植入物** | <span style="color:#fb923c">Persona IQ</span> (FDA 核准) | 植體內建感測器，長期監測步態與膝關節活動數據 | 收集實時運動學數據，有助釐清不滿意原因 |

> **Pearl**：機器人輔助在 UKA 中能顯著減少植體對齊偏離並降低 5 年再干預率；但在 TKA 中，機器人輔助與 PSI 尚未能明確轉化為患者自述功能結果（PROMs）的顯著優勢。

## 5. 實證更新與 OKU 14 重點 (Recent Evidence & Take-Home Points)

### 5.1 近年重大實證更新

- **流行病學與疾病定位**：膝骨關節炎影響全球逾 6.54 億人，其造成的失能與生活品質下降不亞於類風濕性關節炎（Level V 實證）。
- **髁下脂肪墊發炎與病理**：髁下脂肪墊發炎釋放 adipocytokines、IL-6 與 VEGF，直接參與骨關節炎的致病過程（Level I 實證）。
- **再生醫學 PRP vs. 玻尿酸**：包含 18 項 Level I 研究的 Meta-analysis 證實，PRP 在減痛與功能改善上優於玻尿酸，且 Leukocyte-poor PRP 效益最佳（Level V 實證彙整）。
- **幹細胞治療限制**：Meta-analysis 顯示 MSCs 在減痛上與對照組無顯著差異，雖能微幅增加軟骨體積與功能，但未改善軟骨品質（Level I 實證）。
- **機器人 UKA 5 年追蹤**：隨機對照試驗（RCT）5 年追蹤顯示，機器人輔助 UKA 相較於傳統手動手術，能顯著降低 5 年內的再干預率（Level I 實證）。
- **肥胖患者非骨水泥 TKA**：現代 4-peg 脛骨基板設計的非骨水泥 TKA，在 BMI ≥ 35 kg/m² 患者中的存活率與骨水泥固定相當（Level III 實證）。

### 5.2 骨科專科考試核心總結（Take-Home Points）

- **病因與風險**：急性膝關節創傷使未來發生骨關節炎的風險升高近 4 倍；肥胖是促使 TKA 手術量快速成長的主要驅動力。
- **表現型導向治療**：膝骨關節炎屬異質性疾病，未來治療將依滑膜發炎、衰老細胞、軟骨退化等不同表現型實施精準給藥。
- **保守治療指引**：AAOS、ACR、OARSI 一致強烈推薦運動與減重；不推薦使用乙醯胺酚、硫酸軟骨素與 TENS；鴉片類藥物應避免。
- **UKA 關鍵禁忌症**：屈曲合約 > 10°、不可校正的內外翻畸形、前十字韌帶（ACL）功能缺損均為 UKA 的禁忌症，此類患者應選擇 TKA。
- **植體固定與前沿科技**：非骨水泥 TKA 在現代設計下已取得與骨水泥型相當的早中期結果；機器人輔助能精確優化 UKA 植體擺放與存活率，智慧植體（Persona IQ）則開啟了術後長期運動學監測的新紀元。

## Summary

本章完整歸納了膝關節骨關節炎從致病生理、表現型分類、非手術處置指引到前沿手術重建技術的最新進展。從全球盛行率與流行病學數據可見，膝骨關節炎造成的失能與社會負擔已與類風濕性關節炎相當。針對個體化表現型的處置（如標靶 IL-1/TNF-α、衰老細胞清除劑、Wnt 抑制劑 Lorecivivint、Metformin 以及 LP-PRP）為未來的精準醫療奠定了基礎。在手術領域，嚴格掌控 UKA 的適應症與禁忌症（排除屈曲合約 > 10°、不可校正畸形與 ACL 缺損）是提升預後的關鍵。隨著非骨水泥固定設計的改良、機器人輔助技術降低 UKA 5 年再干預率，以及智慧感測植體（Persona IQ）的臨床應用，膝關節重建手術將邁向更加客準化與個體化的全新階段。
