# Chapter 59: Pediatric Forearm, Wrist, and Hand Trauma — 小兒前臂、腕部與手部創傷

## 章節導讀

小兒前臂、腕部與手部骨折常見，多數可藉閉合復位與石膏固定成功治療。本章依「臨床評估與損傷模式、分型與決策矩陣、保守與手術治療指引、手術入路與陷阱、實證重點」五個層次整理，核心訊息是：**多數骨折可以保守治療，但必須精準辨識會失敗的族群**——近端橈骨幹骨折、體重過重兒童、開放性骨折、<span style="color:#fbbf24">radiocapitellar joint（橈骨頭關節）</span> 不對齊、舟狀骨隱匿骨折與 Seymour 骨折。

## 1. 臨床評估與關鍵解剖 (Clinical Evaluation & Injury Patterns)

### 1.1 整體流行病學與治療原則

- 橈骨與尺骨幹骨折（diaphyseal radial and ulnar shaft fractures）占所有小兒骨折**最高 30%**。
- 手部與指骨骨折（hand and finger fractures）常見，**僅次於前臂骨折**。
- 舟狀骨骨折（scaphoid fractures）占小兒手部與腕骨損傷 **3%–4%**，為**腕骨中最常見的骨折**。
- 整體原則：**閉合復位與石膏固定（closed reduction and casting）為標準治療**；手術介入僅針對復位無法維持、特殊型態或特定併發症。

### 1.2 橈骨與尺骨幹的生物學與功能需求

橈尺骨幹骨折通常由**手伸直著地（fall onto an outstretched hand）**並帶旋轉（旋前或旋後）所致。尺骨相對平直，橈骨具有 **apex anterolateral radial bow（橈骨前外側弓形凸起）**以容許旋轉；判斷「可接受復位」須考量兒童的**重塑潛力（remodeling potential）**。

| 族群 | 屈伸弧度 | 旋前（pronation） | 旋後（supination） |
|------|----------|------------------|------------------|
| 成人肘關節功能活動 | **30°–130°** | **50°** | **50°** |
| 兒童與青少年（現代打字與使用手機等功能性任務之平均弧度） | **28°–146°** | **65°** | **54°** |

> **Pearl**：兒童對**屈曲與旋前**的需求高於成人，復位標準應審慎；但少一些角度的旋轉喪失也可能被功能需求掩蓋，不可放寬復位要求。

### 1.3 骨骺與生長相關的解剖考量

- 遠端橈骨**骨骺（physis）**與幹骺端骨折常見，**關節內骨折則少見**。
- 遠端橈骨具有**高度的矢狀面重塑能力**，冠状面重塑能力**較低但仍存在**：36 例研究顯示損傷後**前 6 個月的重塑速率為每月 2° 至 2.59°**。
- 遠端橈骨骺板骨折可導致**過早骨骺阻滯（physeal arrest）**與隨後的 **ulnar positivity（尺骨側過長）**。

## 2. 分型系統與決策矩陣 (Classification & Decision Making)

### 2.1 可接受復位標準（Table 2）

閉合復位的目標是**解剖對位（anatomic alignment）**；但考量重塑潛力，臨床有一套「可接受復位」的通則。

| 病人年齡 | 橈骨成角（angulation） | 旋轉（rotation） | 縮短（shortening） |
|----------|----------------------|------------------|------------------|
| 8 歲以下女童／10 歲以下男童 | **<15°** | **<45°** | **<1 cm** |
| 8 歲以上女童／10 歲以上男童 | **<10°** | **<30°** | **<1 cm** |
| 橈骨近端（proximal） | **<10°**（原文表格殘缺） | **<30°** | **<1 cm** |
| 橈骨遠端（distal） | **<15°**（原文表格殘缺） | **<30°** | **<1 cm** |

> **原文缺漏**：Table 2 在 OCR 中列序殘缺，「近端／遠端」兩列係依殘存字串與正文「近端橈骨需更接近解剖對位（<10°）」整理，完整欄位對應請回查紙本。

> **Danger zone**：**近端橈骨幹骨折的閉合復位石膏治療較容易失敗**，移位至不可接受排列的比例達 **70%–80%**，可能原因包括骨痂形成時間較長、軟組織包覆較顯著，以及**需要更接近解剖對位（<10°）**；因此此類骨折**應有較低的手術門檻**。

### 2.2 骨折型態與治療反應的分型

| 骨折型態 | 臨床特徵與原文處置方向 |
|----------|----------------------|
| **Greenstick（青枝骨折）** | 不完全骨折；通常可**單次閉合復位成功**，注意**旋轉** |
| **Complete（完全骨折）** | 多數仍可閉合復位＋石膏；**復位不良造成畸形與旋轉喪失** |
| **Torus / buckle（隆凸／扣板）** | 不完全、本質穩定、移位風險低，常見於**遠端橈骨幹骺端**的壓縮性負荷；用軟石膏、腕托、軟繃帶 |
| **移位型完全遠端橈骨骨折** | 閉合復位石膏 vs. 立即鋼針固定個別評估 |
| **Salter-Harris I–IV** | 早期輕柔閉合復位；**反覆復位與傷後逾 10 天**增加骺板阻滯 |
| **Phalangeal neck type I/II/III** | 見 Table 3；近期文獻支持 type I、II 可保守 |
| **Seymour fracture** | 開放性 Salter-Harris I/II 或鄰近骺板的遠端指骨骨折，常**甲床嵌入**；依急診 protocol |

### 2.3 Salter-Harris 分型（遠端橈骨骺板損傷）

| 分型 | 骨折經過的解剖層次 |
|------|-------------------|
| **Type I** | 經過骺板的**肥大層（hypertrophic zone）** |
| **Type II** | 經過肥大層，**另經過幹骺端（metaphysis）** |
| **Type III** | 經過**肥大層與骨骺（epiphysis）** |
| **Type IV** | 經過**骨骺、骺板與幹骺端** |

### 2.4 掌骨頸骨折分型（Table 3）

| 分型 | 描述 |
|------|------|
| **Type I** | **無移位骨折** |
| **Type II** | **有移位但仍有皮質接觸**（cortical contact） |
| **Type II A** | **橫行（transverse）骨折線** |
| **Type II B** | **斜行（oblique）骨折線，遠端骨片帶背側骨唇（dorsal bony lip）** |
| **Type II C／D** | 遠端骨片較小（原文此二小項 OCR 標示殘缺） |
| **Type III** | **有移位且皮質接觸喪失** |

> **Pearl**：掌骨頸骨折傳統上被視為**不穩定、需手術固定**，但近期文獻指出 type I 與 type II 的**非手術治療並不會造成進一步移位**，且最終排列反而改善。

## 3. 治療指引：保守治療與手術適應症 (Treatment Algorithm)

### 3.1 橈尺骨幹骨折的閉合復位與石膏技術

| 技術環節 | 原文要點 |
|----------|----------|
| 麻醉／減痛 | **區域阻斷（regional block）或意識鎮靜（conscious sedation）**下，於急診或手術室以**牽引加手法操作**復位 |
| 固定角度 | 夾板或石膏須於**肘關節屈曲 90°**、**前臂中立旋轉或穩定位置（position of stability）**下施行 |
| 石膏塑形 | **骨間成形（interosseous mold）為維持復位的關鍵**；尺骨緣相對平直，並**塑形過遠端肱骨髁**以防滑移 |
| **Cast index** | 定義為石膏**矢狀徑對冠狀徑的比值**，應**低於 0.80**，以降低復位喪失的風險 |
| 隨訪 X 光 | 復位後建議於 **1、2、4、6 週**拍攝；**可考慮省略第 4 週**，因多數需要再次處置的病例在**第 2 週內**即被發現 |

> **Pearl**：**Cast index < 0.80** 是少數可直接操作的復位喪失預測指標。

> **Danger zone**：**Greenstick 骨折需注意復位其旋轉成分**；一項研究中 **109 例 greenstick 骨折有 94% 僅需單次復位即成功**，作者建議安排**兩次臨床追蹤門診與三次間隔 X 光**，以降低成本與輻射暴露。

### 3.2 體重過重兒童的特殊考量

| 事實 | 數值／結論 |
|------|-----------|
| 流行病學 | 估計**三分之一**的兒童與青少年**體重過重**，**每五人就有一位肥胖** |
| 研究規模 | 565 例小兒前臂骨折，其中 **28.7% 為體重過重或肥胖** |
| 開放性骨折 | **體重正常**的兒童發生開放性骨折的機率為 **4.1 倍** |
| 骨折部位 | 體重過重或肥胖者較易發生**遠端前臂骨折**與**孤立性橈骨幹骨折**；**肥胖兒童較易復位喪失需手術** |

> **Danger zone**：**肥胖**是前臂骨折治療失敗的獨立風險因子——應預期更高的復位喪失率，並**降低轉為手術介入的門檻**。

### 3.3 開放性骨折

- 開放性橈尺骨骨折占橈尺骨骨折病例最高 **9%**，占**所有小兒開放性骨折最高 80%**。
- 歷史標準做法：手術執行 **I&D（沖洗與清創）**，並行**閉合復位或手術固定**。
- 新趨勢：對 **Gustilo-Anderson type I** 開放性骨折，可採**床邊清創（bedside débridement）＋閉合穩定固定＋抗生素**的非手術處理；2020 年比較分析：**非手術處理感染率為 0**，**手術處理者為 1.9%**。
- 共識：**所有 Gustilo-Anderson type II 與 type III 骨折應以手術清創與沖洗並做骨折穩定固定處理**。

### 3.4 手術介入的門檻與固定方式比較

在**排列不可接受**或**發生復位喪失（占病例 >30%）**時，應考慮手術介入。最常用的固定方式為 **ESIN（elastic stable intramedullary nailing，彈性穩定髓內釘）** 與 **板螺絲構造**。

| 比較項目 | ESIN | 板螺絲 ORIF |
|----------|------|------------|
| 骨癒合時間 | **3 至 6 個月**（兩者無差異） | **3 至 6 個月**（兩者無差異） |
| 前臂旋轉／骨折成角／併發症率 | 兩者**無差異** | 兩者**無差異** |
| 外觀／手術時間 | **較佳**／**較短** | — |
| 特殊風險 | **radial bow 明顯偏離，但不影響前臂旋轉** | — |

- **只固定單一骨**（視骨折型態與相對穩定性）：系統性回顧顯示與雙骨固定的**結果相當**。
- **板螺絲 ORIF** 是**成人雙骨前臂骨折的標準治療**，應考慮用於：**青少年**、**長度不穩定骨折**、或位於**較不利於 ESIN 的位置（如幹骺接合處）**。
- **混合式構造（hybrid construct）**：橈骨用板螺絲、尺骨用 ESIN 或 Steinmann pin；雙骨皆板固定時應考慮**早期活動**。
- 留在皮膚外的 **Steinmann pin**，其**感染、再骨折與整體併發症率與其他方式相近**。

> **Pearl**：ESIN 與板螺絲在**癒合時間、旋轉、成角與併發症**四項上無差異，選擇應依**外觀需求、部位是否適合髓內固定**決定，而非依癒合結果。

### 3.5 前臂骨筋膜室症候群（Compartment Syndrome）

前臂急性骨筋膜室症候群是小兒骨科的**外科急症**。最早由 **Volkmann** 描述，為**動脈血供喪失造成的前臂缺血性攣縮**，可造成**永久性肌肉與神經損傷**，導致顯著發病率甚至死亡。

| 面向 | 2020 年系統性回顧與統合分析（12 篇研究、233 名兒童）之結果 |
|------|------------------------------------------------------|
| 最常見原因 | **創傷（trauma）** |
| 發病部位 | **腿部 60%**；**前臂 27%** |
| 骨折位置 | **多數患者在骨筋膜室症候群部位附近有骨折（75%）** |
| 切開時機 | 平均在**傷後 25.4 小時**執行切開減壓 |
| 主訴 | **疼痛（88%）**；**感覺異常 32%** |
| 結果 | **85% 良好結果**；**活動度喪失（10%）為最常見併發症** |
| 預後因子 | **切開減壓時間、是否合併骨折、年齡、性別、解剖部位均非預測因子** |

> **Danger zone**：兒童的表現與成人不同，**可能出現延遲診斷**；**即使就診或診斷已超過 24 小時，仍應執行切開減壓**，因小兒組織具有**良好的恢復潛力**。

### 3.6 Galeazzi 骨折

| 面向 | 原文要點 |
|------|----------|
| 定義 | **1822 年首次描述**；**任何層級的橈骨骨折合併遠端橈尺關節（DRUJ）破壞** |
| 創傷機轉 | 通常為**手伸直著地並處於過度旋前（hyperpronation）** |
| 族群特性 | 在**兒童比成人少見**，通常見於**年長的兒童**；常被**漏診或低估**（低估率不明） |
| 第一線治療 | **閉合復位＋長臂石膏固定，前臂置於旋後（supination）** |
| 治療成功 | **85% 病人以閉合復位與長臂石膏治療成功**；非手術在兒童結果良好，**成人則常失敗** |
| 解剖型態 | 回顧中多數為**尺骨背側脫位**，其中**一半同時有橈骨與尺骨骨折**；**尺骨掌側脫位**的 **7 名兒童為孤立性橈骨骨折** |
| 手術考量 | 雖然易被漏診，但**其併發症嚴重程度不如漏診的 Monteggia 骨折**；**年長兒童與青少年應評估手術介入** |

> **Pearl**：Galeazzi 骨折的**第一線是閉合復位＋前臂旋後位長臂石膏**——與成人不同，兒童非手術成功率很高（85%），但仍須仔細評估**遠端橈尺關節的排列**。

### 3.7 遠端橈骨與尺骨骨折

**Torus / buckle（隆凸／扣板）骨折**：**不完全、本質穩定、移位風險低**，常因**壓縮性負荷**發生於**遠端橈骨幹骺端**。

| 比較研究 | 結果 |
|----------|------|
| **兩項隨機對照試驗**：石膏 vs. 可拆除腕部支具（固定 **3 週**） | 併發症、癒合與疼痛**無差異**；**腕部支具組較早恢復腕部功能** |
| **隨機對照試驗**：石膏 vs. **軟繃帶** | 疼痛與癒合**無差異**；**軟繃帶組腕部活動較早** |
| **兩項隨機試驗**：醫院追蹤 vs. **居家自行拆除支具／軟石膏** | 臨床結果**無差異**；**家屬偏好居家拆除** |

**完全骨折**：通常可由閉合復位與石膏固定獲益。

| 兩項隨機對照試驗（閉合復位石膏 vs. 立即鋼針固定） | 結果 |
|-----------------------------------------------|------|
| **復位喪失率** | 閉合復位石膏組 **20%–39%**；**立即鋼針固定組 0** |
| **鋼針部位併發症** | **6%–38%** |
| **臨床結果與治療成本** | **兩組相似**；短臂 vs. 長臂石膏**無差異** |

2020 年統合分析建議：應考慮**初始移位程度、病人年齡**，以及**閉合復位石膏與立即鋼針固定之間的風險與利益**。

**骨骺骨折（Salter-Harris）處置原則**：對**移位性骨折建議早期、輕柔的閉合復位**；**反覆的復位嘗試**與**傷後超過 10 天**才復位，**可能增加骺板阻滯的風險**。系統性回顧顯示**年輕病人重塑潛力較大**，骺板阻滯發生於**最高 4.3%**；若發生於**年輕病人**，伴隨尺骨側過長的發病率**更高**。需**長期追蹤並拍攝對側 X 光**。

> **Danger zone**：**傷後超過 10 天才復位**與**反覆復位嘗試**是骺板阻滯的兩個可避免因子——應嚴格控制復位次數並安排長期追蹤。

### 3.8 舟狀骨（Scaphoid）骨折

舟狀骨骨折占小兒手部與腕骨損傷的 **3%–4%**，是**腕骨中最常見的骨折**；最常因**跌倒**或**運動中發生**。症狀為疼痛與**解剖鼻煙窩（anatomic snuffbox）**腫脹，可能**徵象輕微而延遲就醫**；檢查須觸診**鼻煙窩**與**舟狀骨結節**，並拍攝 **PA、側位與 scaphoid view**。

| 面向 | 原文要點 |
|------|----------|
| 初次 X 光可見率 | **89%** 的**傷後 30 天內**就醫病例在**第一次 X 光就可見** |
| 幼童可見率 | **93%** 的**傷後 7 天內**、**11 歲以下**急性骨折在**至少一個 view** 上可見；**21% 在所有 view** 上可見；**沒有骨折僅在 PA scaphoid view 上可見** |
| 年齡與部位 | **年幼兒童**多為**遠端（distal corner／distal body）**；**年長兒童**多為**中段與近端體部**；年幼病人**較可能肥胖**，但骨折總數在**年長兒童較多**；**骨折方向、位移、間隙與合併骨折在不同年齡間無顯著差異** |
| 合併傷 | **遠端橈骨骨折、經舟狀骨的月骨周脫位、尺骨莖突骨折、舟骨頭骨折與雙側損傷**，可見於**最高 10%** 的兒童 |

| 情境 | 處理 |
|------|------|
| 初次 X 光**不確定（equivocal）** | **固定 2 週後重拍 X 光**；**癒合反應在傷後 2 至 5 週之間最清楚** |
| 2 週後仍疼痛但未見骨折 | 可執行 **CT 或 MRI**，**而非持續延長固定** |
| **無移位急性骨折** | **短臂拇指人字石膏（thumb spica）固定 6 至 12 週**；**癒合率 90%** |
| 影像陰性但高度懷疑 | **早期進階影像**可**降低隱匿骨折長期固定的成本與發病率** |

| 手術與不癒合 | 原文要點 |
|------------|----------|
| 手術適應症 | **有移位骨折、近端極骨折、不癒合，或合併骨壞死**；手術固定後**癒合率最高 96.5%**；不癒合**罕見**，但**接近三分之一**的兒童病人以**慢性不癒合**就診 |
| 治療選項 | 長期固定、**植骨＋Kirschner wire**、**植骨但無骨接合**、**無頭壓縮螺絲固定**（可合併植骨） |
| 血管化骨膜瓣 | 2019 年 12 例研究：取自**拇指掌骨背側、由第一掌背動脈供應**的骨膜瓣帶血管蒂轉移；**技術需求較低、供區病變較少**；**全部骨癒合完全**，**79% 在 12 週時見橫斷骨小樑橋接**；最終追蹤的**活動度、肌力與平均 radiolunate、scapholunate 角度**與非手術側相似 |

> **Pearl**：**11 歲以下**、**傷後 7 天內**的舟狀骨骨折，**93% 在至少一個 X 光 view 上可見**——「幼童舟狀骨骨折一定要 MRI」的迷思並不成立。

### 3.9 手部與指骨骨折

手部與指骨骨折常見，**僅次於前臂骨折**；最常因**壓挫傷（crush injuries）**或**運動事件**，最常見部位是**小指近端指骨**。大多可**閉合復位、適當固定與早期活動**。檢查須評估**開放傷與手指的成角或旋轉錯位**，並拍攝**正交（orthogonal）X 光**；旋轉對位以**屈曲手指確認所有手指皆指向舟狀骨結節**判定。

**2019 年 buddy taping 與夾板固定之隨機對照試驗（99 例小兒關節外指骨骨折，排除掌骨頸骨折）**

| 項目 | 結果 |
|------|------|
| 分組 | **buddy taping 52 例** vs. **volar-based intrinsic plus splint 47 例** |
| 不穩定骨折 | **39 例**；其中 **31 例需先復位**（18 例 taping、13 例 splinting） |
| 次發移位 | 第一次追蹤時，taping 組 **1 例（2%）**、splinting 組 **3 例（6%）**；**全部**發生於**需先行復位的小指近端指骨**且未再進一步移位；**無移位骨折無任何次發移位** |
| 治療失敗 | 整體僅 **1 例**（splinting 組之**近端指骨幹骨折**）非手術治療失敗 |
| 固定時間與成本 | **5 分鐘 vs. 15 分鐘**（buddy taping 較短）；**成本顯著較低、病人舒適度較高** |

> **Pearl**：**buddy taping 是指骨骨折安全且便利的替代方案，即使需要復位也適用**。

**追蹤 X 光的必要性（2019 年回顧，365 例單一關節外骺板骨折；排除多發、掌骨頸、開放與關節內骨折）**

| 項目 | 結果 |
|------|------|
| 需手法復位者 | **122 例（33.4%）**；全部以 buddy taping 或 volar intrinsic plus splint 固定 **3 週** |
| 次發成角畸形 | 占**全部**指骨骨折 **2.2%（8/365）**；占**需復位者 6.6%**（原文分母均標示 8/365） |
| 危險特徵 | 所有次發移位者初次呈現**成角 >10°**，且**常合併旋轉錯位（87.5%）**，**全部需要內固定**；**初次成角 >10% 者的幹骺端與幹骨折需於 1 週時密集 X 光追蹤**，微小移位或無移位骨折則穩定，不需後續影像 |

### 3.10 掌骨頸骨折（Phalangeal Neck Fractures）

傳統上**移位性掌骨頸骨折建議手術固定**（被視為**不穩定**，且位置**遠離骺板而重塑潛力較差**）；但**近期文獻指出非手術治療可進行且不會造成進一步移位，最終追蹤時排列反而改善**。

| 研究 | 對象與結果 |
|------|-----------|
| **2020 年研究** | 移位性（type II）近端或中節指骨骨折，**成角不超過 30°、移位不超過 25%、且無旋轉錯位**；**12 例**接受復位後以石膏或矯具固定；可**成功以非手術方式處理而未增加移位**，且**最終 X 光在冠狀面與矢狀面的成角與移位皆改善**（不論是否需要復位） |
| **2021 年研究** | type I 與 type II 的**石膏固定 vs. 可拆除夾板**：**19 例**前臂式 intrinsic plus cast，**28 例**客製熱塑**手部夾板（小兒 2 例）或手指式夾板（較大兒童 26 例）**；固定 **3 至 4 週**後開始治療與 buddy taping 輔助的漸進活動；**17 例**曾復位；最終**所有兒童皆可握拳、無疼痛並回到傷前活動水準**；**type I 與 type II 在石膏或夾板之間無臨床或影像差異** |

> **Pearl**：**手指式可拆除夾板對 type I 與 type II 掌骨頸骨折皆安全**，並帶來**衛生、舒適與減少皮膚問題**的好處；作者建議**依病人與家屬的舒適度與遵從度個別化**。

> **Danger zone**：**成角 >30°、移位 >25% 或存在旋轉錯位**者不符合上述非手術條件，仍應**手術介入**。

### 3.11 Seymour 骨折

**Seymour 骨折**是小兒特有的指骨骨折：**遠端指骨的開放性 Salter-Harris I/II 或鄰近骺板骨折**，經常有**甲床（nail bed）嵌入骨折端**；此類骨折**常被漏診**，導致**高比例併發症，包括感染與甲或骺板生長障礙**。影像常顯示遠端指骨移位，但**辨識甲板／甲床的破壞對診斷至關重要**——這表示為**有嵌入組織的開放性骨折**。

**治療**：**移除甲板並清創骨折端 → 取出嵌入的甲床 → 復位**；若不穩定，可能需**額外以 Kirschner wire 固定**並以夾板／石膏固定。

**2019 年急診處理回顧（65 例 <18 歲病人的 Seymour 骨折）**

| 項目 | 結果 |
|------|------|
| 急診初次處理 | **58 例（89%）**在急診初次處理；其中 **37 例（64%）**在局部麻醉或意識鎮靜下**徹底沖洗**後復位與夾板固定 |
| 非計畫手術 | **4 例**需要：**3 例**因第一次追蹤時骨折移位，**1 例**因急診未執行 I&D |
| 手術室處置 | **7 例**以 I&D、開放復位與 Kirschner wire 固定治療；**6 例**因復位失敗或不穩定（**4 例**嵌入組織、**2 例**嚴重壓挫傷），**1 例**合併伸肌腱斷裂 |
| 併發症 | **感染 8%**、**骺板障礙 4%**、**指甲變形 4%**、**非計畫手術 6%**；感染通常**淺表、以口服抗生素處理**；**1 例**未接受初次 I&D 者發生**晚期膿腫與骨髓炎** |
| 抗生素 | **46/58** 急診病人接受口服抗生素；最常用 **cephalexin（中位 7 天）**，其次 **Augmentin（中位 10 天）** |

**Seymour 骨折急診治療 protocol（Table 4）**

| 步驟 | 內容 |
|------|------|
| 1 | **靜脈抗生素** |
| 2 | **移除甲板** |
| 3 | **取出嵌入組織** |
| 4 | **沖洗與清創** |
| 5 | **閉合復位（不穩定者於手術室行 Kirschner wire 固定）** |
| 6 | **以可吸收縫線修復甲床** |
| 7 | **以指甲或鋁箔固定甲上皮** |
| 8 | **夾板或石膏固定** |
| 9 | **口服抗生素** |

> **Danger zone**：Seymour 骨折**漏診的代價高**——未接受初次 I&D 者可能發生**晚期膿腫與骨髓炎**；**甲板／甲床的破壞**是開放性骨折的證據，不可因「看起來只是指尖骨折」而輕忽。

> **Pearl**：急性 Seymour 骨折**若依明確治療 protocol 達到穩定復位，可在急診成功處理**；但**失敗或不穩定的復位（尤其因嵌入組織）仍須轉手術室**。

## 4. 手術入路與危險地雷 (Surgical Approach & Pearls)

### 4.1 ESIN 的入路選擇與併發症

橈骨 ESIN 的**起始點**可選**第一與第二背側骨間間隙之間**，或**更靠背側、第二與第三背側間隙之間的 Lister 結節（Lister tubercle）**。

| 入路 | 具體併發症 | 發生率 |
|------|------------|--------|
| **背側入路（dorsal approach）** | **伸拇長肌（extensor pollicis longus）斷裂** | **2.6%** |
| **側方入路（lateral approach）** | **暫時性橈神經淺支麻痺** | **2.9%** |

> **Danger zone**：ESIN 的併發症與**入路選擇直接相關**——背側入路留意 EPL 斷裂，側方入路留意橈神經淺支。

### 4.2 固定構造的策略性選擇

| 臨床情境 | 建議構造 | 理由 |
|----------|----------|------|
| 青少年、長度不穩定或位於**幹骺接合處**的骨折 | **板螺絲 ORIF** | ESIN 較不適合；板螺絲為成人標準 |
| 需要保留外觀、單骨固定可行 | **ESIN（單骨）** | 與雙骨固定結果相當 |
| 橈骨 ESIN 起始點 | 第一／第二或第二／第三背側間隙、<span style="color:#22d3ee">Lister 結節</span> | 併發症依入路而異（見 4.1） |
| 混合需求 | **橈骨板螺絲＋尺骨 ESIN／Steinmann pin** | hybrid construct |

> **Pearl**：**留在皮膚外的 Steinmann pin** 與其他固定方式的**感染、再骨折與整體併發症率相近**，不必因「外露」而過度憂慮。

## 5. 實證更新與 OKU 14 重點 (Recent Evidence & Take-Home Points)

### 5.1 關鍵研究與證據等級整理

| 主題 | 來源 | 證據等級與結論 |

| 肥胖兒童與正常體重兒童的前臂骨折特徵（565 例） | Li Y, et al: J Pediatr Orthop 2020;40(2):e127-e130 | **Level III**（正常體重者開放性骨折為 **4.1 倍**） |

### 5.2 OKU 14 Key Study Points（本章重點整理）

- **Monteggia 骨折脫位**多數急性病例可藉**閉合復位與石膏固定**成功處理；但**慢性 Monteggia 病灶可自手術介入獲益**（**尺骨截骨與環狀韌帶修復**）。**雙骨前臂骨折**多可保守處理，**手術介入考慮用於青少年與近端橈骨骨折**。
- **11 歲以下兒童、傷後 7 天內**的急性舟狀骨骨折，**93% 在至少一個可取得的 X 光 view 上可見，21% 在所有 view 上可見**；**Type I 與 type II 掌骨頸骨折**可用**可拆除的手指式夾板**做非手術處理（**成角不超過 30°、移位不超過 25%，且就診時無旋轉錯位**）。
- **急性 Seymour 骨折**可在**急診**以 **I&D、復位、夾板固定與抗生素疗程**妥善處理。

### 5.3 骨科專科考試核心總結（Take-Home Points）

1. **整體原則**：多數小兒前臂、腕部與手部骨折可**閉合復位＋石膏**成功治療；**cast index < 0.80**、肘屈曲 **90°**、骨間成形為固定關鍵；追蹤 X 光於 **1、2、4、6 週**（**可省略第 4 週**）。可接受復位依年齡分層，**近端橈骨需更接近解剖對位（<10°）**。
2. **高風險族群**：**近端橈骨幹骨折**、**肥胖兒童**與**開放性骨折**是治療失敗的高風險族群，應提早降低手術介入門檻；**ESIN 與板螺絲**的療效與併發症無差異，選擇依部位與外觀需求決定。
3. **急症與腕部**：**骨筋膜室症候群**延遲就診仍應切開減壓；**Galeazzi** 兒童多可保守治療；**Torus/buckle 骨折**可用腕托或軟繃帶居家拆除；遠端橈骨骺板骨折須避免反覆復位與延遲復位。
4. **舟狀骨與手部**：多數急性舟狀骨骨折初次 X 光即可見，無移位者以短臂拇指人字石膏固定；**buddy taping 為安全的指骨骨折固定方式**；**掌骨頸 type I、type II 可非手術**；**Seymour 骨折**須移除甲板、取出嵌入甲床並沖洗後復位。

## Summary

- **整體原則**：多數小兒前臂、腕部與手部骨折可**閉合復位＋石膏固定**成功；關鍵在**辨認會失敗的族群**並提早介入。可接受復位依年齡分層（年長者成角 **<10°**、旋轉 **<30°**、縮短 **<1 cm**）；**cast index < 0.80**、肘屈曲 **90°**、骨間成形為固定關鍵；追蹤 X 光於 **1、2、4、6 週**。
- **高風險族群**：**近端橈骨幹骨折 70%–80%** 復位失敗；**肥胖兒童**復位喪失與手術需求較高；**開放性骨折**占橈尺骨骨折最高 **9%**，**Gustilo I 可非手術（感染 0 vs. 1.9%）**，**type II、III 必須手術**；**ESIN 與板螺絲**在癒合時間（**3–6 個月**）、旋轉、成角與併發症**無差異**，但**背側入路 EPL 斷裂 2.6%**、**側方入路橈神經淺支麻痺 2.9%**。
- **急症與腕部**：**骨筋膜室症候群**占 **27%**、平均 **25.4 小時**後切開、**85% 良好結果**，**延遲超過 24 小時仍應切開**；**Galeazzi** 兒童 **85%** 可閉合復位＋前臂旋後位長臂石膏；移位性遠端橈骨**閉合石膏復位喪失 20%–39%**、**立即鋼針固定 0**，鋼針併發症 **6%–38%**；骺板骨折**傷後超過 10 天復位與反覆復位**增加阻滯（type II 最高 **4.3%**），前 6 個月**每月重塑 2°–2.59°**。
- **舟狀骨與手部**：**89%** 傷後 30 天內初次 X 光可見；**11 歲以下、7 天內**者 **93%** 至少一個 view 可見、**21%** 全部可見；無移位者**短臂拇指人字石膏 6–12 週、癒合率 90%**，手術者**癒合率最高 96.5%**；**buddy taping 為安全替代**；**初次成角 >10%** 者需 1 週追蹤；**掌骨頸 type I、type II 可非手術**（成角 ≤30°、移位 ≤25%、無旋轉錯位）；**Seymour 骨折**須移除甲板、沖洗、取出嵌入甲床並復位，**89%** 可在急診處理。
