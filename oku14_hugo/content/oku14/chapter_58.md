# Chapter 58: Pediatric Shoulder, Upper Arm, and Elbow Trauma — 小兒肩部、上臂與肘部創傷

## 章節導讀

小兒上肢骨折多可保守治療，但**髁上骨折**與**血管神經損傷**是例外。本章依「臨床評估、分型決策、治療指引、血管併發症與入路陷阱、實證重點」五層次整理，並以表格呈現發生率、年齡分界與位移容忍門檻。

## 1. 臨床評估與關鍵解剖 (Clinical Evaluation & Key Anatomy)

### 1.1 傷病概覽與發生率

小兒上肢骨折與脫位是轉診骨科常見原因，**正確診斷與處置有助及時恢復功能**。

| 傷病 | 原文數據 | 典型年齡／機轉 |
|------|----------|----------------|
| **肩關節脫位** | 較少見（原文未給百分比） | 男性青少年，contact sports |
| **近端肱骨骨折** | 佔小兒骨折 **2%** | **> 5 歲**多為 Salter-Harris II 型延伸至幹骺端 |
| **肱骨幹骨折** | 佔小兒骨折 **5%** | **< 3 歲**或 **> 10 歲**；出生相關者見臂叢麻痺 |
| **肱骨髁上骨折** | **小兒最常見的肘部骨折** | **5–8 歲**；**> 90%** 為 extension type |
| **外髁骨折** | 第二常見肘部骨折，佔小兒肘部骨折 **10%–20%** | 幼兒外髁以軟骨為主，關節面難評估 |
| **內上髁骨折** | 原文未給百分比 | 單獨發生或合併 **elbow dislocation** |
| **肘關節脫位** | 佔小兒肘部傷害約 **3%** | 最常為 **posterior 或 posterolateral** |
| **鷹嘴骨折** | 約佔小兒肘部骨折 **7%** | 多為 **triceps 近端骨突撕脫** |
| **橈骨頸骨折** | 佔小兒肘部傷害 **5%–10%**，較橈骨頭骨折常見 | 伸直上肢跌倒、valgus force；亦可伴隨肘脫位 |

> **Pearl**：**外髁骨折的關節面在幼兒主要由軟骨構成**，X 光難以判讀，需依賴 **internal oblique view（內斜位）** 判斷位移量，而非只看 AP 與 lateral。

### 1.2 肩部：肩關節脫位

小兒肩關節脫位較少見，因**近端肱骨生長板通常先於關節軟組織失效**。

| 評估面向 | 原文要點 |
|----------|----------|
| **影像檢查** | 應含 **AP、scapular Y 與 axillary 三種檢視** |
| **方向** | 最常為 **anterior（前脫位）** |
| **急性處置** | **Closed reduction（閉鎖復位）** 後以 **sling（吊帶）** 固定 |
| **神經檢查** | **復位後的神經學檢查必須記錄**；**axillary nerve（腋神經）最常受損** |
| **復健** | 首次脫位者**固定 1–2 週**後即可參與 **physical therapy** |
| **再脫位風險** | **男性與較年輕的病人**較易再脫位；**超過 70%** 發生重複脫位 |

> **Danger zone**：每次脫位都會對 <span style="color:#22d3ee">glenoid（肩胛盂）</span> 造成損傷，近年有學者主張對**高風險族群**在**首次**脫位後即手術治療。

### 1.3 上臂：近端肱骨與肱骨幹骨折

**近端肱骨骨折**：生長板提供該骨 **80% 的生長量**，**塑型潛力充足**，多數可保守；**> 5 歲**者多為 Salter-Harris II 型、延伸至幹骺端。

**肱骨幹骨折**：佔小兒骨折的 **5%**，最常見於 **< 3 歲**或 **> 10 歲**者。若為**出生相關損傷**，嬰兒須**重新評估是否合併 brachial plexus palsy（臂叢麻痺）**——此類骨折**接近四分之一**會出現臂叢麻痺；病人也可能因疼痛以 **pseudoparalysis（假麻痺）** 表現。

### 1.4 肘部解剖與神經學危險區

| 結構 | 臨床意義 |
|------|----------|
| **Anterior humeral line（肱骨前緣線）** | 側位 X 光應通過 <span style="color:#22d3ee">capitellum（小頭）</span> 的**中 1/3**；**但 < 5 歲**者**觸及**小頭即可 |
| **Posterior fat pad sign（後方脂肪墊徵）** | 側位 X 光可能僅以此提示**隱性骨折**（含 Gartland I 型髁上骨折與無移位橈骨頸骨折） |
| **Radiocapitellar joint** | 所有檢視中**橈骨頸與橈骨頭都應指向小頭**；可用 **Greenspan view** 評估 |
| **Ulnar nerve（尺神經）** | 內上髁固定與**內側針**置入時的關鍵危險構造 |
| **Posterior interosseous nerve（骨間後神經）** | 橈骨頸開放復位時的關鍵危險構造 |
| **Brachial artery（肱動脈）／median nerve（正中神經）** | 可能**披覆於骨折碎塊上**或**卡入骨折端**；為無脈手與 Volkmann 缺血核心 |

> **Pearl**：<span style="color:#fbbf24;font-weight:600">前緣線判讀必須配合年齡</span>——**< 5 歲**只需「觸及」小頭即屬正常，套用成人「通過中 1/3」標準會造成過度治療。

## 2. 分型系統與決策矩陣 (Classification & Decision Making)

### 2.1 Gartland 分型與髁上骨折變異

**肱骨髁上骨折**為小兒最常見的肘部骨折，依**移位方向**分為 extension type（伸長型）與 flexion type（屈曲型）；**超過 90%** 為伸長型，再依 **Gartland 分型**細分，基礎為**遠端骨折塊的後方移位**。

| 分型 | 影像／手術所見 | 原文處置 |
|------|----------------|----------|
| **Type I** | 無移位或極輕微成角；側位 X 光**可能僅見 posterior fat pad sign** | **長臂石膏 3–4 週** |
| **Type II** | **後方 hinge（後方鉸鏈）完整** | **許多 Type II 需手術**（遠端肱骨重塑潛力差） |
| **Type III** | **後方皮質完全破壞**，遠端骨折塊**完全向後移位** | **手術治療** |
| **Type IV（修改版 Gartland）** | **只能術中診斷**；前後**骨膜環周性破壞**，屈伸皆**極度不穩定** | 屬不穩定損傷 |

手術治療理由為**遠端肱骨重塑潛力差**，加上要**降低伸直位 malunion（畸形癒合）、正常活動弧受損與 cubitus valgus（肘外翻）**；**屈曲型同樣以手術處理**，屬**類似 Gartland III 伸長型的不穩定損傷**。

### 2.2 年齡決定的畸形與位移容忍度

| 情境 | 可接受範圍 | 原文說明 |
|------|------------|----------|
| **近端肱骨骨折** | 原文指出**文獻並未訂定成角絕對數值** | **> 13 歲**、成角 **> 40°**、或移位**超過骨干寬度 2/3（Neer IV）**者，手術可能有益 |
| **近端肱骨（年齡效應）** | 年輕者容忍度較高 | **剩餘生長量越多，可忍受成角與移位越大** |
| **肱骨幹骨折** | **> 15° 至 30°** 成角（尤其 **varus 內翻**）可能需手術 | **越近端可容忍成角越小** |
| **橈骨頸骨折 < 10 歲** | 成角可接受至 **45°** | — |
| **橈骨頸骨折 > 10 歲** | 成角可接受至 **30°**，可接受 **2 mm** 平移 | — |
| **外髁骨折** | 位移 **< 2 mm** 可用長臂石膏 | 位移 **> 2 mm** 應介入（依 internal oblique 測量） |
| **內上髁骨折** | 位移 **> 5 mm** 為手術適應症 | **8 mm** 時多數外科醫師已選手術；**≥ 19 mm** 時**所有**醫師皆選固定 |

> **Pearl**：橈骨頸骨折**只能容忍極少量 translation**，因橈骨頭平移形成 **cam effect（凸輪效應）**並阻礙活動。

## 3. 治療指引：保守治療與手術適應症 (Treatment Algorithm)

### 3.1 肩部與上臂

**鎖骨骨折**：**中段鎖骨骨折**手術與保守治療**結果沒有差異**，功能結果皆良好、評分相當，**保守病人外觀滿意度相等或更好**。手術保留給**血管損傷、開放性骨折與嚴重皮膚帳篷狀變形（severe skin tenting）**。

<!-- FIG: 圖 2：急性左側鎖骨骨折 100% 位移，以及非手術治療 3 個月後的癒合 X 光 -->

**肩關節脫位**：**復發性脫位**可考慮手術；方式（**arthroscopic 或 open**）由**同時存在的肩部病變**決定：<span style="color:#22d3ee">Hill-Sachs lesions</span>、**labral tears（盂唇撕裂）**、**bony Bankart lesions**。

**近端肱骨骨折**

| 情境 | 處置 |
|------|------|
| **無移位**或**圍產期**骨折 | **sling、shoulder immobilizer** 或**年長兒童 hanging arm cast**，**3–4 週** |
| **絕對手術適應症** | **開放性骨折**與**合併血管損傷骨折** |
| **可能有益的手術** | **> 13 歲**、成角 **> 40°**、移位**超過骨干寬度 2/3（Neer IV）** |
| **機械性阻擋而必須手術** | **縮短的骨干與 glenoid 撞擊**致內／外旋受阻；或 **biceps tendon（肱二頭肌肌腱）嵌頓**致復位受阻 |
| **固定方式** | **closed 或 open reduction** 加 **percutaneous wires、cannulated screws、plates 或 retrograde elastic intramedullary nails** |
| **術後恢復** | **3–4 個月**後多數病人可回到完全活動 |

<!-- FIG: 圖 3：急性左側近端肱骨骨折的兩張 X 光，以及受傷 6 個月後癒合的左肩 X 光 -->

> **Pearl**：近端肱骨骨折的手術門檻**沒有文獻共識的絕對成角數值**；應以**年齡、剩餘生長量與機械性阻擋**綜合判斷。

**肱骨幹骨折**：嬰幼兒以 **swathe** 或 sleeve 固定胸前；年長兒童與青少年以 **coaptation splint、Sarmiento brace 或 hanging arm cast，約 6 週**。

| 手術適應症 | 說明 |
|------------|------|
| **開放性骨折** | 明確手術適應症 |
| **成角 > 15° 至 30°** | 可能需手術，**尤其 varus 成角**；**越近端可容忍成角越小** |
| **固定方式** | **flexible elastic intramedullary nails、plating、external fixation** 皆有描述 |
| **彈性釘後** | 固定 **1–2 週**；**影像癒合可見於術後 7–10 週** |
| **手術 vs. 保守** | 手術**縮短固定時間、改善影像外觀**，但**長期功能與治療後疼痛無差異** |

> **Danger zone**：手術治療肱骨幹骨折的代價是再次麻醉與器械風險，而長期功能與疼痛優勢並未確立，應在與家屬討論時明確說明。

### 3.2 肱骨髁上骨折

**Type I** 採**長臂石膏 3–4 週**；**Type III 與許多 Type II** 採手術治療。**術前神經學評估是關鍵步驟**：約 **11%** 病人出現上肢神經麻痺。

| 骨折型態 | 最常受損的神經與比例 |
|----------|----------------------|
| **Extension type（伸長型）** | <span style="color:#e2e8f0">anterior interosseous nerve（AIN，骨間前神經）</span> **5.3%**；radial **4.5%**；median **3.3%**；ulnar **2.3%** |
| **Flexion type（屈曲型）** | **ulnar nerve（尺神經）16%** |

- **AIN 或正中神經麻痺**者可能**失去察覺疼痛加劇的能力**，而疼痛加劇是**早期 compartment syndrome（骨筋膜室症候群）**的徵象，故**術前必須反覆檢查**（**被動牽拉痛、疼痛加劇、止痛藥需求增加**）。**單獨 AIN 麻痺**者常可**在受傷後 2–3 個月內自行恢復功能**。另須評估**同側上肢合併損傷**（**遠端橈骨與前臂幹骨折**），會**增加前臂骨筋膜室症候群的風險**。

<!-- FIG: 圖 4：Gartland I 型、II 型與 III 型髁上骨折的側位 X 光（可見後方脂肪墊徵） -->

**手術固定**

| 步驟 | 技術要點 |
|------|----------|
| **復位目標** | 側位 X 光**恢復 anterior humeral line 位置**並**恢復冠狀排列** |
| **復位手法（伸長型）** | 先以 **milking of the arm** 使 **brachioradialis／brachialis** 自骨折處分離，再**牽引與屈肘**，**旋前**閉合**外側緣**或**旋後**閉合**內側緣** |
| **開放復位指徵** | **不穩定骨折**，或**骨膜、brachioradialis 或神經血管構造嵌頓** |
| **鋼針配置** | **常用 2–3 支發散（divergent）外側針**達**最大擴散（maximal spread）** |
| **穩定性增強因子** | **較大直徑鋼針、增加鋼針數目、一根內側針** |
| **內側針的時機** | **外側針適當後仍有旋轉不穩定**者；置放時**必須警覺尺神經位置** |
| **術後** | **3–4 週拔針**後即可活動；**正常活動範圍通常 2 個月回復**，**多數不必轉介物理治療** |

> **Pearl**：<span style="color:#fbbf24;font-weight:600">骨膜與 brachioradialis 的嵌頓</span>是髁上骨折復位失敗的重要原因——看似已復位仍不穩定時應考慮開放復位。

### 3.3 肱骨外髁骨折

外髁骨折為**第二常見的肘部骨折**，佔小兒肘部骨折 **10%–20%**，屬**關節內骨折**，需**接近解剖學的復位**。

| 處置 | 原文要點 |
|------|----------|
| **位移量判定** | 以 **internal oblique view** 最佳顯示外髁骨折位移 |
| **< 2 mm 位移** | **長臂石膏 4–5 週** |
| **> 2 mm 位移** | **應接受介入處置** |
| **穩定來源** | 穩定性由 **cartilaginous hinge（軟骨鉸鏈）的完整性**賦予 |
| **手術方式** | **closed 或 open reduction** 加**經皮鋼針固定**或**壓迫螺釘** |
| **術中評估** | 閉合復位後可藉 **elbow arthrography** 評估**關節面**與**軟骨鉸鏈** |
| **開放復位入路** | **外側入路**，**須避免解剖外髁後方軟組織**，以**保留血供並降低 osteonecrosis（缺血性壞死）風險** |
| **鋼針** | **2–3 支發散的光滑鋼針**，**術後 4–6 週拔除**；幼兒**極軟骨化**碎片需**更多發散鋼針** |
| **癒合與固定時間** | 因**滑液浸泡骨折處**癒合**需時甚久**；**拔針後石膏可延至術後 8 週** |

<!-- FIG: 圖 5：急性外髁骨折的 AP 與側位 X 光，以及開放復位加經皮鋼針固定後的 AP 與側位 X 光 -->

| 併發症 | 發生率與重點 |
|--------|----------------|
| **Lateral spur formation（外側骨刺）** | 最常見，源自**骨性過度生長**，與**初始骨折位移量（骨膜掀起程度）**相關；**僅具美容影響** |
| **Osteonecrosis** | **1.4%**，與 **Type III 骨折**相關；7 例中 5 例**無疼痛**、6 例**恢復完整功能**，**皆無 varus 或 valgus 殘餘畸形** |
| **Nonunion（不癒合）** | **1%** |
| **Malunion（畸形癒合）** | **0.6%** |
| **Cubitus valgus（肘外翻）** | **0.4%** |
| **Tardy ulnar nerve palsy（遲發性尺神經麻痺）** | 原文列於併發症清單但未給出具體百分比 |

> **Danger zone**：外髁骨折即使「適當處理」，仍可能發生不癒合、畸形癒合、缺血性壞死與遲發性尺神經麻痺——尤其**被漏診**與**已移位**骨折，囑咐回診追蹤是必要的。

### 3.4 肱骨內上髁骨折

內上髁可**單獨骨折**，也可**與肘關節脫位同時發生**。它是 <span style="color:#22d3ee">ulnar collateral ligament（尺側副韌帶）</span> 與 **flexor pronator mass（屈肌旋前肌群）** 的附著點，可因**大力 valgus force**或跌倒而遭撕脫。

| 評估與處置 | 原文要點 |
|------------|----------|
| **位移評估困難** | 碎片通常**向前移位**，標準 AP 或 lateral 難以判讀；**distal humeral axial view** 較能評估 |
| **歷史上的保守做法** | **長臂石膏 3–4 週**、**3 個月**回運動 |
| **手術適應症** | **肘脫位復位後碎片嵌頓於關節內**、**肘不穩定**、或**位移 > 5 mm** |
| **新興趨勢** | 愈來愈多主張**固定**以**容許早期活動**並改善**合併脫位時的肘穩定性** |
| **固定方式** | **幼兒用 Kirschner wires**、**年長兒童用 cannulated screws**；**不論何種植入物都須避免傷及尺神經** |
| **2019 年醫師差異研究** | **合併肘脫位**與**骨折位移增加**是選擇手術的**兩項主要因素**；**8 mm** 多數醫師已選手術，**≥ 19 mm** **所有**醫師皆選固定 |
| **2020 年系統性回顧** | 手術**癒合率較高**、**可較早允許活動與回運動**；受傷後有**尺神經症狀**者術後**改善較佳** |

> **Pearl**：**嵌頓於關節內的內上髁碎片是手術絕對適應症**——復位後必須例行檢查。

### 3.5 肘關節脫位

**尺肱關節脫位**約佔小兒肘部傷害 **3%**，最常為 **posterior 或 posterolateral**；可合併肘部骨折（**最常見為內上髁**）。

| 處置步驟 | 原文要點 |
|----------|----------|
| **復位** | 以 **closed reduction（閉鎖復位）** 為主 |
| **復位後影像** | 仔細評估**復位同心性**與**是否碎片嵌頓（最常見為內上髁）** |
| **固定** | 若復位可接受，**長臂石膏最長 2 週**後開始活動；**約 5 個月**回完全運動 |
| **固定時間的代價** | **固定越久，末端伸直（terminal extension）喪失機會越高** |
| **手術** | **碎片嵌頓**時必須手術；亦可因**合併損傷**或**持續不穩定**需手術 |
| **極幼兒的鑑別** | X 光須仔細判讀以**區分肘脫位與 transphyseal separation（生長板分離）**；後者**可能與 child abuse（虐待兒童）有關且需手術固定** |

<!-- FIG: 圖 6：肘關節脫位合併內上髁骨折的 AP 與側位 X 光，以及內上髁骨折開放復位螺釘固定後的術中 X 光 -->

> **Danger zone**：幼兒肘部創傷若被誤認為單純脫位，須先排除 **transphyseal separation**——處置截然不同，且與非意外傷害有關。

### 3.6 鷹嘴與橈骨頸骨折

**鷹嘴骨折**：佔小兒肘部骨折約 **7%**，多為 **triceps 近端骨突撕脫**，也可繼發於**脫位**或**直接創傷**。

| 面向 | 原文要點 |
|------|----------|
| **保守治療** | **石膏 4 週**，適用於**輕微移位、關節面平整**者 |
| **手術適應症** | **移位骨折需手術固定**以**恢復正常 triceps 功能** |
| **固定方式** | **tension band technique（鋼絲或縫線張力帶）**；**橫行非粉碎骨折可單一空心螺釘**；**粉碎骨折用 open reduction and plating** |
| **術後** | **固定最長 4 週**後依耐受度開始活動 |
| **特殊提醒** | **無創傷、雙側或撕脫型鷹嘴骨折**應懷疑 **osteogenesis imperfecta（成骨不全）** |

<!-- FIG: 圖 7：鷹嘴骨折的側位 X 光，以及開放復位加鋼針固定後的術中側位與 AP 影像 -->

**橈骨頭與橈骨頸骨折**

| 面向 | 原文要點 |
|------|----------|
| **發生率** | **橈骨頸骨折比橈骨頭骨折常見**，佔小兒肘部傷害 **5%–10%** |
| **機轉** | 伸直上肢跌倒合併 **valgus force**；亦可於**肘脫位**時發生 |
| **影像** | 應含 **Greenspan view**；側位 **posterior fat pad sign** 可能提示**隱性骨折（含無移位橈骨頸）** |
| **可接受範圍** | **< 10 歲**成角可接受至 **45°**；**> 10 歲**成角可接受至 **30°** 且可接受 **2 mm** 平移 |
| **超出範圍時** | **closed reduction 為第一線**；**translation 僅能容忍極少量**，因 **cam effect** 阻礙活動 |
| **閉合復位手法** | **Patterson technique**（肘伸直、旋後下以 varus force 對橈骨頭加壓）、**Israeli technique**、**Esmarch technique** |
| **復位後** | **長臂石膏 2–3 週** |
| **2021 年研究** | **成角 ≥ 60°** 或**受傷後超過 24 小時**才就醫者**較可能需手術** |
| **閉合失敗時** | 需手術固定；可用 **Steinmann pin 鈍端或其他鈍器**做**經皮輔助復位**，亦可用**逆行髓內釘**（**Métaizeau technique**） |

<!-- FIG: 圖 8：急性橈骨頸骨折的 AP 與側位 X 光、復位後的 AP 與側位關節攝影，以及術後 AP 與側位 X 光 -->

> **Pearl**：橈骨頸骨折「看著還好」不等於「可以接受」——年齡是關鍵：**10 歲以下可接受 45°**，10 歲以上僅 **30°**，平移僅 **2 mm**。

## 4. 血管神經併發症與手術入路陷阱 (Vascular Complications & Surgical Pearls)

### 4.1 無脈手與粉紅無脈手

髁上骨折合併的**無脈肢體**可分兩類：**無脈但有灌流**（**capillary refill < 2 秒**，且**手部皮膚顏色為病人平常的顏色**）與**無脈且無灌流**（**手部沒有顏色**）。

| 處置原則 | 原文要點 |
|----------|----------|
| **無脈且無灌流** | 應**緊急送入手術室**，目標為**恢復遠端肢體血流** |
| **血管解剖風險** | **肱動脈與／或正中神經**可能**披覆於骨折碎塊上**或**卡入骨折端** |
| **真正的血管損傷比例** | **無脈**病人中**至多 14%** 有真正血管損傷 |
| **脈搏消失 + AIN／正中神經麻痺** | 應**高度懷疑合併肱動脈損傷**或**需開放復位** |
| **研究數據** | 「無脈髁上骨折合併 AIN 或正中神經麻痺」**27% 需開放復位**、**8% 發生骨筋膜室症候群** |
| **第一步** | **Closed reduction 是第一步**，常可**恢復橈動脈脈搏（觸診或 Doppler）**或**改善手部灌流**——持續無脈可能只是**肱動脈痙攣**所致 |
| **促進血流** | **升高室溫**並以**溫毛巾覆蓋患肢** |
| **復位固定後仍無灌流** | 須**拔除鋼針**並**可能需要血管探查** |
| **有灌流但無脈** | 為**處置爭議點**，但**多數可在術後密切觀察下處理** |
| **AAOS 建議** | 對**無脈但灌流良好**者是否開放探查，**AAOS 的建議並無定論（inconclusive）** |

> **Pearl**：無脈手處置順序為**復位 → 給熱 → 觀察灌流 → 必要時拔針探查**；「**手部顏色**」比「**是否有脈搏**」更能區分緊急程度。

### 4.2 Volkmann 缺血與缺血性攣縮

**Volkmann ischemia（沃爾克曼缺血）**是上肢損傷的**罕見併發症**，來自**被遺漏的骨筋膜室症候群、動脈阻塞或兩者兼有**。

| 面向 | 原文要點 |
|------|----------|
| **急性骨筋膜室症候群** | **筋膜室內腫脹與壓力過高**，導致**該室內肌肉與神經不可逆死亡** |
| **小兒族群的診斷困難** | **三個 A**：**anxiety（焦慮）、agitation（躁動）、increasing analgesic requirements（止痛藥需求增加）**為骨筋膜室症候群迫近的重要徵象 |
| **被動牽拉痛** | 另一早期徵象，但**要求病人能溝通配合檢查** |
| **年齡因素** | **年齡愈小，診斷延誤風險愈高**，原因在**檢查溝通困難** |
| **Volkmann 缺血性攣縮** | 發生於**前臂掌側筋膜室**急性骨筋膜室症候群後，造成**屈肌壞死與瘢痕**，導致**腕與手指屈曲畸形**，功能上具**毀滅性** |
| **最高危險群** | **移位的髁上骨折**，尤其**合併血管損傷或正中神經損傷**者 |
| **骨筋膜室症候群** | **早期發現即建議緊急 fasciotomy（筋膜切開減壓）** |
| **動脈阻塞** | 若**動脈阻塞且無側支血流**，應**緊急處理** |
| **2019 年研究** | 評估 **26 例**髁上骨折合併缺血性損傷、其後發展出前臂肌缺血性攣縮的病人；提示：<span style="color:#fbbf24;font-weight:600">無脈髁上骨折合併疼痛加劇與神經損傷進展時，骨折治療應包含血管與神經的探查</span> |

> **Danger zone**：**三個 A** 在成人常被歸因於其他原因，但在**小兒骨筋膜室症候群**中是極重要的早期訊號——尤其**移位髁上骨折**或**合併正中神經損傷**者。

### 4.3 手術入路與危險地雷總覽

橈骨頸入路細節見下表；其餘陷阱已於 3.2–3.6 說明。

| 手術 | 危險地雷 | 原文建議 |
|------|----------|----------|
| **橈骨頸開放復位** | **骨間後神經** | Kaplan／Kocher approach 前先**旋前前臂**，使該神經**自視野前方移出**；**開放治療併發症率接近 40%**，最常見為**旋前與旋後的僵硬**，其他含 **heterotopic ossification、osteonecrosis、radioulnar synostosis 與骨間後神經損傷**，此族群**經常需要物理治療** |
| **橈骨頸鋼板固定** | 極少需要；超出 **safe zone** 造成旋前旋後撞擊 | 須留在**橈骨莖突與 Lister tubercle 間的 90° 弧區** |

> **Pearl**：小兒肘部與上臂的手術決策圍繞在**兩件事**——**能否用最小切口達到穩定固定**，以及**能否在不危及神經血管下完成復位**。

### 5.2 骨科專科考試核心總結（Take-Home Points）

| 主題 | 必記數值與結論 |
|------|--------------|
| **發生率** | 近端肱骨 **2%**、肱骨幹 **5%**（小兒骨折）；外髁 **10%–20%**、鷹嘴 **7%**（小兒肘部骨折）；肘脫位 **3%**、橈骨頸 **5%–10%**（肘部傷害） |
| **近端肱骨** | 生長板 **80%** 生長量；絕對手術適應症僅**開放骨折與血管損傷**；**> 13 歲、> 40°、位移 > 2/3 骨干寬度（Neer IV）**可能有益；文獻**未訂定成角絕對值** |
| **肱骨幹** | 出生相關骨折**約四分之一合併臂叢麻痺**；swathe／sleeve、coaptation splint／Sarmiento brace／hanging arm cast **約 6 週**；**> 15°–30°**（varus、越近端越嚴格）可能需手術；彈性釘後固定 **1–2 週**、**7–10 週**影像癒合 |
| **髁上骨折** | **5–8 歲**、**> 90%** 伸長型；Gartland **I** 石膏 **3–4 週**，**III 與許多 II** 及**屈曲型**手術；神經麻痺約 **11%**（伸長型 **AIN 5.3%**、屈曲型**尺神經 16%**）；**Type IV 僅能術中診斷** |
| **無脈手** | 有灌流（**capillary refill < 2 秒**）vs. 無灌流（**緊急手術**）；**至多 14%** 真正血管損傷；**27%** 需**開放復位**、**8%** 骨筋膜室症候群；仍無灌流須**拔針探查** |
| **Volkmann 缺血** | **三個 A** 為小兒早期徵象；**移位髁上骨折合併血管或正中神經損傷**風險最高；早期須**緊急筋膜切開** |
| **外髁骨折** | **< 2 mm** 石膏 **4–5 週**、**> 2 mm** 介入；**軟骨鉸鏈賦予穩定性**；開放復位**外側入路、勿解剖後方軟組織**；鋼針 **2–3 支**、**4–6 週**拔除、石膏延至 **8 週**；缺血性壞死 **1.4%**、不癒合 **1%**、畸形癒合 **0.6%**、肘外翻 **0.4%** |
| **內上髁骨折** | 石膏 **3–4 週**、**3 個月**回運動；手術適應症：**關節內嵌頓、肘不穩定、位移 > 5 mm**；**8 mm** 多數醫師選手術、**≥ 19 mm** 全部選手術 |
| **肘關節脫位** | **復位後須檢查內上髁是否嵌頓**；石膏**最長 2 週**（**固定越久越易失去末端伸直**）、**約 5 個月**回運動；幼兒須**排除 transphyseal separation** |
| **鷹嘴骨折** | **移位需手術**；術後固定**最長 4 週**；**無創傷、雙側或撕脫型**須懷疑 **osteogenesis imperfecta** |
| **橈骨頸骨折** | **< 10 歲 45°**、**> 10 歲 30° 與 2 mm 平移**；石膏 **2–3 週**；**成角 ≥ 60°** 或**延誤 > 24 小時**者較可能需手術；**Métaizeau** 經皮輔助復位；**開放併發症率接近 40%**；鋼板須留在 **90° 弧區** |

## Summary

- **整體原則**：小兒上肢骨折多可保守（近端肱骨生長板 **80%** 生長量），但**髁上骨折**與**血管神經損傷**是例外。
- **肩部**：影像須含 **AP／scapular Y／axillary**；**腋神經最常受傷**；**> 70%** 重複脫位，**1–2 週**後可開始物理治療；鎖骨骨折手術與保守**結果無差異**。
- **上臂**：近端肱骨**絕對手術適應症僅開放骨折與血管損傷**；肱骨幹**出生相關者約四分之一合併臂叢麻痺**，保守需 **約 6 週**固定，**> 15°–30°**（varus、越近端越嚴格）可能需手術。
- **髁上骨折**：**5–8 歲**、**> 90%** 伸長型；Gartland **I** 石膏 **3–4 週**，**III 與許多 II** 及**屈曲型**手術；神經麻痺約 **11%**（伸長型 **AIN 5.3%**、屈曲型**尺神經 16%**）；**Type IV 僅能術中診斷**。
- **無脈手／Volkmann**：無灌流者**緊急手術**，**至多 14%** 有真正血管損傷；**三個 A** 為小兒早期徵象；**移位髁上骨折合併血管或正中神經損傷**風險最高，早期須**緊急筋膜切開**。
- **其他肘部骨折**：外髁 **10%–20%**，**< 2 mm** 石膏、**> 2 mm** 介入；內上髁**嵌頓於關節為絕對手術適應症**、**> 5 mm** 手術、**8 mm** 多數選手術、**≥ 19 mm** 全部選手術；鷹嘴 **7%**、**移位需手術**、**無創傷／雙側／撕脫型須懷疑 osteogenesis imperfecta**；橈骨頸**開放治療併發症率接近 40%**。
