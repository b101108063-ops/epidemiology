# Chapter 43: Ligament Injuries to the Knee — 膝關節韌帶損傷

## 章節導讀

膝關節韌帶損傷在骨科創傷與運動醫學中極為常見，可源於低能量創傷（常伴隨解剖易感因子）或高能量能量外傷（如膝關節脫位）。當韌帶結構失能導致脛股關節不穩定時，軟骨表面與半月板將承受異常剪力而遭受二次傷害；同樣地，復發性髕股關節不穩定亦會引發累積性軟骨損害並導致創傷後關節炎。本章整合解剖生物力學、影像特徵、分類系統與最新實證指引，詳細梳理前十字韌帶（ACL）、後十字韌帶（PCL）、內側副韌帶（MCL）、後外側角（PLC）及髕股內側韌帶（MPFL）之非手術與手術重建處置原則。

---

## 1. 臨床評估與關鍵解剖 (Clinical Evaluation & Key Anatomy)

膝關節在完全伸直時雖具備骨骼結構的解剖穩定性，但其活動並非純粹的樞紐（hinge）運動，而是伴隨屈伸進行滾動（rolling）與滑動（gliding）。關節周圍的靜態韌帶與動態肌肉結構是維持關節穩定的核心。

### 1.1 前十字韌帶與後十字韌帶之解剖與生物力學

膝關節兩條十字韌帶在前後向位移與旋轉穩定度中扮演關鍵的角色：

| 韌帶結構 | 束別分型 (Bundles) | 股骨附著點 (Femoral Footprint) | 脛骨附著點 (Tibial Footprint) | 臨床評估與功能 |
| :--- | :--- | :--- | :--- | :--- |
| **<span style="color:#e2e8f0">ACL（前十字韌帶）</span>** | **前內側束 (AM bundle)**：較垂直<br>**後外側束 (PL bundle)**：較傾斜 | 髁間窩外側壁後方，以雙分界脊（bifurcate ridge）為中心 | 脛骨棘之間，大致與外側半月板前角後緣成一直線 | **AM 束**限制脛骨前移（以 <span style="color:#60a5fa;font-weight:600">Lachman test</span> 最敏感）；**PL 束**提供旋轉抑制（與 <span style="color:#60a5fa;font-weight:600">pivot shift test</span> 相關） |
| **<span style="color:#e2e8f0">PCL（後十字韌帶）</span>** | **前外側束 (AL bundle)**：較粗大<br>**後內側束 (PM bundle)** | 髁間窩內側壁極前方且垂直，緊鄰關節軟骨 | 脛骨平台後方下落處（champagne glass drop-off） | 限制脛骨後移與前內側旋轉。<span style="color:#f87171">Grade 3 損傷（後抽屜試驗 >10 mm）</span>常提示合併多重韌帶損傷 |

> **Pearl**：ACL 重建術後患者的臨床預後與術後檢查是否存在 **pivot shift** 具有顯著相關性。

### 1.2 後外側角、內側副韌帶與後斜韌帶

膝關節內側與外側靜態穩定結構對於抵抗冠狀面（張開力）及旋轉應力至關重要：

- **<span style="color:#22d3ee">Posterolateral Corner (PLC，後外側角)</span>**：主要包含 <span style="color:#e2e8f0">LCL（外側副韌帶）</span>、<span style="color:#e2e8f0">popliteus tendon（膕肌腱）</span>、<span style="color:#e2e8f0">popliteofibular ligament (PFL，膕腓韌帶)</span>、<span style="color:#e2e8f0">iliotibial band（腸脛束）</span>與 <span style="color:#e2e8f0">biceps femoris（股二頭肌）</span>。PLC 穩定膝關節抗內翻應力與脛骨外旋。臨床上使用 **<span style="color:#60a5fa;font-weight:600">Dial test</span>** 評估（圖 1）。

- **<span style="color:#22d3ee">Medial Collateral Ligament (MCL，內側副韌帶)</span>**：分為深層（與內側半月板相連）與淺層（<span style="color:#e2e8f0">sMCL</span>）。sMCL 為外翻應力的主要抑制結構，源自股骨內上髁後上方，附著於關節線遠端 **6 cm** 處。
- **<span style="color:#22d3ee">Posterior Oblique Ligament (POL，後斜韌帶)</span>**：源自股骨收肌結節（adductor tubercle），附著於脛骨後側與關節囊，控制前內側旋轉並輔助外翻穩定。

> **Danger zone**：MCL 脛骨端撕裂可能導致類似大拇指 Stener 病變的 **<span style="color:#f87171">脛骨端 Stener-like lesion</span>** — 撕裂的 sMCL 遠端退縮並翻出至鵝足肌腱（pes anserinus）上方，致使其無法自行貼回原附著點癒合。

髕骨為解剖上的籽骨（sesamoid bone），承受極大剪力。在女性等骨盆較寬的族群中，Q 角增大容易導致髕骨外側軌跡偏移或脫位。

- **<span style="color:#22d3ee">Medial Patellofemoral Ligament (MPFL，髕股內側韌帶)</span>**：為抑制髕骨外側位移的主要靜態結構，起源自收肌結節與內上髁之間的鞍狀區（saddle region），主要附著於髕骨赤道上方（上 1/2）。其纖維亦延伸至股四頭肌腱，故更精確稱為 **<span style="color:#e2e8f0">Medial Patellofemoral Complex (MPFC)</span>**。
- **髕骨不穩定解剖易感因子**：
  1. 滑車發育不良（trochlear dysplasia）
  2. 高位髕骨（patella alta）
  3. 脛骨結節至滑車溝距離（<span style="color:#e2e8f0">TT-TG distance</span>）過大
  4. 膝外翻（genu valgum）
  5. 股骨前傾角過大（excessive femoral anteversion）

## 2. 影像學診斷與分型矩陣 (Imaging & Classification)

X 光影像為初步評估的基礎，負重照（weight-bearing radiograph）能反映動態負載下的關節間隙；高階影像（CT 與 MRI）則提供軟骨、半月板與韌帶完整性的精確細節。

### 2.1 韌帶損傷之 X 光與高階影像特徵

| 韌帶／結構 | 影像檢查首選 | 關鍵影像特徵與臨床意義 |
| :--- | :--- | :--- |
| **ACL** | Plain radiograph / MRI (Gold standard) | X 光可見 **<span style="color:#60a5fa;font-weight:600">Segond fracture</span>**（脛骨前外側囊撕脫骨折，圖 2），為 ACL 撕裂之特異性病徵。MRI 可見股骨外側髁 (LFC) 與脛骨後外側平台 (PLTP) 之 **<span style="color:#60a5fa;font-weight:600">pivot-shift 骨挫傷</span>**（圖 3），預示未來創傷後關節炎風險。 |
| **PCL** | Radiograph / CT / MRI / CT Angiography | 側位 X 光可見脛骨後沉（posterior sag）。骨折撕脫可由 CT 確認。<span style="color:#f87171">若 ABI < 0.9 或脈搏非對稱</span>，必須行 **<span style="color:#f87171">Contrast-enhanced CT</span>** 評估膕動脈（popliteal artery）血管損傷。 |
| **MCL** | Plain radiograph / MRI | X 光可見 **<span style="color:#e2e8f0">Pellegrini-Stieda lesion</span>**（股骨內上髁鈣化／撕脫骨片，常為慢性陳舊發現）。MRI 可鑑別脛骨端 Stener-like lesion。 |
| **PLC** | Radiograph / MRI | X 光可見腓骨頭撕脫骨折（fibular head avulsion / arcuate sign），提示嚴重韌帶結構受損。 |
| **MLKI (膝脫位)** | Trauma X-ray / Stress fluoroscopy / CTA | 可攜式 X 光可見關節囊撕脫（圖 4）；麻醉下透視應力照可評估鬆弛度（圖 5）。 |


> **Pearl**：脛骨後傾角（<span style="color:#e2e8f0">Posterior Tibial Slope, PTS</span>）過大被公認為 ACL 重建失敗的高風險因子；冠狀面畸形（如膝內翻）亦會增加重建韌帶之應力。翻修手術前應拍攝雙下肢全長負重照與 CT 以評估先前骨隧道位置與大小。

膝關節韌帶損傷的治療決策取決於受損韌帶種類、鬆弛程度、患者年齡、活動需求及是否合併軟骨／半月板損傷。

### 3.1 膝關節四大主要韌帶之治療決策演算法

| 韌帶結構 | 保守治療適應症與處置 | 手術治療適應症 | 手術策略與實證更新 |
| :--- | :--- | :--- | :--- |
| **ACL** | 低運動需求、高齡、無剪力旋轉運動需求者。配合肌力強化與護具。 | 青年、高需求運動員（從事轉向／樞紐運動）、合併半月板可縫合撕裂者。 | **ACLR（重建術）**：BTB（骨-髕腱-骨）為高強度標準；股四頭肌腱（QT）亦廣受採用。<br>**<span style="color:#60a5fa;font-weight:600">BEAR 技術</span>**：FDA 於 2020 年核准之吸收性膠原蛋白修復技術。RCT 證實 2 年追蹤下其鬆弛度不亞於自體移植，且膝繩肌肌力顯著較佳。 |
| **PCL** | 單純 Grade 1 與 Grade 2 撕裂；大部分伸直位穩定的單純 Grade 3 撕裂。採用伸直位護具固定與股四頭肌訓練。 | 具持續不穩定症狀之單純 Grade 3 撕裂、脛骨撕脫骨折、或作為多重韌帶損傷（MLKI）之一部分。 | **PCL 重建**：單束（重建 AL 束） vs. 雙束（AL + PM 束）；脛骨隧道法 vs. 脛骨嵌合修復法（tibial inlay）。撕脫骨折行解剖復位固定。 |
| **MCL** | 單純 Grade 1、Grade 2 及近端 Grade 3 撕裂。具極佳自癒潛能，使用鉸鏈式護具並早期活動。 | 遠端脛骨端撕裂（Stener-like lesion）、外翻應力於伸直位即鬆弛、關節內嵌頓或保守治療失敗者。 | 早期急性高質量組織行修復；陳舊或組織不良者行 **MCL + POL 雙束重建**。 |
| **PLC** | 單純 Grade 1 與 Grade 2 撕裂。 | Grade 3 撕裂、腓骨頭骨折撕脫或 MLKI。<span style="color:#f87171">單純 Primary repair 失敗率高達 37%–40%</span>。 | 首選 **PLC 重建**（失敗率僅 6%–9%）。可採用腓骨為主（fibular-based，如 Arciero/LaPrade）或雙隧道法（圖 8）。 |

| **PLC** | 單純 Grade 1 與 Grade 2 撕裂。 | Grade 3 撕裂、腓骨頭骨折撕脫或 MLKI。<span style="color:#f87171">單純 Primary repair 失敗率高達 37%–40%</span>。 | 首選 **PLC 重建**（失敗率僅 6%–9%）。可採用腓骨為主（fibular-based，如 Arciero/LaPrade）或雙隧道法（圖 8）。 |

> **Danger zone**：慢性 ACL 功能不全會導致膝關節前後向位移增加，進而造成內側半月板後角負擔過載並引發二次撕裂（如桶柄狀撕裂，圖 7）。因此，存在旋轉不穩定者應儘早重建以保護半月板與關節軟骨。

### 3.2 髕股關節不穩定之治療演算法

髕骨首次外側脫位與復發性不穩定的處理原則如下：

```
                    髕骨外側脫位 (Patellar Dislocation)
                                   │
         ┌─────────────────────────┴─────────────────────────┐
         ▼                                                   ▼
 首次脫位 (First-time)                               復發性脫位 (Recurrent)
 無骨軟骨游離體／無嚴重結構畸形                      或合併骨軟骨游離體／撕脫骨折
         │                                                   │
         ▼                                                   ▼
    非手術保守治療                                      手術介入處置
 護具固定 + 股四頭肌／VMO 復健                        行 MPFL 重建術 (MPFL Reconstruction)
                                                             │
                                          ┌──────────────────┴──────────────────┐
                                          ▼                                     ▼
                                  TT-TG > 20 mm / Patella Alta            嚴重滑車發育不良
                                          │                               (Dejour B/D)
                                          ▼                                     ▼
                                併行脛骨結節截骨術 (TTO)                併行滑車成形術 (Trochleoplasty)
```

> **Pearl**：研究（Arendt et al）顯示，對於慢性復發性髕骨脫位，單純行 **MPFL primary repair（主修復）失敗率極高**；臨床應採用自體或異體肌腱進行 **MPFL 重建術**。

## 4. 手術入路與危險地雷 (Surgical Approach & Pearls)

### 4.1 等長性與 MPFL 股骨隧道定位 (Schöttle Point)

韌帶重建手術的核心在於還原解剖附著點與維持適度張力。交叉韌帶與副韌帶重建需在靜息張力下固定以獲得最大穩定度；但 **MPFL 僅作為制動帶（checkrein）**，切勿過度緊繃，否則會導致髕股關節內側過載與早期軟骨退化。

- **<span style="color:#fbbf24">Schöttle Point（MPFL 股骨隧道 X 光定位地標）</span>**：
  在標準側位 X 光下（圖 9）：
  1. 沿股骨後側皮質延伸線前方 **1 mm**。
  2. 股骨內側髁後緣起點遠端 **2.5 mm**。
  3. 位於 Blumensaat 線近端。

### 4.2 膝關節脫位與多重韌帶損傷 (MLKI) 處置 pearls

膝關節脫位（Multiligament Knee Injury, MLKI）屬於骨科急診，處置重點如下：

> **Danger zone**：膝關節脫位極易合併 **膕動脈（popliteal artery）** 與 **腓總神經（peroneal nerve）** 損傷。即便血管復位後復脈，若 <span style="color:#f87171">ABI < 0.9</span>，仍必須立即進行血管 CT 造影（CTA）以排除內膜內夾層形成與血栓。

- **PCL 脛骨隧道建立之危險區**：鑽取 PCL 脛骨隧道時，鑽頭突破脛骨後皮質極易傷及緊鄰之膕動脈。術中應結合透視引導、使用後側關節囊保護器（capsular protector）或經後內側入路直接視覺監測。
- **骨隧道撞擊與防碰撞（Tunnel Collision）**：在 MLKI 多韌帶重建或 ACL 翻修術中，股骨與脛骨端有多個骨隧道（如 ACL + LCL + Popliteus）。術中需透過三維立體鑽孔角度偏轉，避免骨隧道互相交錯破壞。

### 5.2 骨科專科考試核心總結（Take-Home Points）

1. <span style="color:#60a5fa;font-weight:600">Segond 骨折</span> 是前十字韌帶（ACL）撕裂的特異性 X 光病徵，代表前外側關節囊／ALL 自脛骨撕脫。
2. MRI 上膝關節外側股骨髁（LFC）與後外側脛骨平台（PLTP）的 <span style="color:#60a5fa;font-weight:600">pivot-shift 骨挫傷</span>，提示受力機轉並預示創傷後關節炎。
3. <span style="color:#60a5fa;font-weight:600">BEAR (Bridge-Enhanced ACL Repair)</span> 採用吸收性膠原蛋白矩陣與自體血，Level I 實證顯示其 2 年關節鬆弛度不亞於自體移植重建，且腿後肌肌力恢復更佳。
4. PCL 損傷或膝關節脫位時，若 <span style="color:#f87171">ABI < 0.9 或脈搏非對稱</span>，必須立即行對比劑增強 CT 血管造影（CTA）排除膕動脈損傷。
5. MCL 遠端撕裂可發生 <span style="color:#f87171">脛骨端 Stener-like lesion</span>（sMCL 退縮至鵝足肌腱上方），此類損傷難以自癒，常需手術介入。
6. <span style="color:#f87171">PLC（後外側角）單純主修復失敗率高達 37%–40%</span>，臨床應優先選擇韌帶重建術（失敗率僅 6%–9%）。
7. MPFL 為抑制髕骨外側位移的主要靜態結構，股骨隧道定位點為 <span style="color:#fbbf24">Schöttle point</span>。MPFL 移植物僅作 checkrein，嚴禁過度拉緊。
8. 評估髕股不穩定時，<span style="color:#e2e8f0">CT 與 MRI 所測得之 TT-TG 數據不完全等同</span>，不可互相替換判讀。

## Summary

本章完整歸納膝關節韌帶損傷（包含 ACL、PCL、MCL、PLC 及 MPFL）之解剖結構、生物力學、影像診斷與實證處置指引。臨床上應結合 Segond 骨折、pivot-shift 骨挫傷、Dejour 滑車發育不良分型與整套軟組織影像進行精確評估。治療決策強調個別化：ACL 可考量 BEAR 修復或自體腱重建；PCL 與 MCL 具一定非手術自癒潛能但需嚴防 Stener-like 殘疾與膕動脈損傷；PLC 重建遠優於單純修復；MPFL 重建則須以 Schöttle 點精確定位且切忌過緊。掌握解剖等長性與關鍵地雷，能有效維持關節穩定性並避免創傷後關節炎。
