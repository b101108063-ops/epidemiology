# Chapter 9: Musculoskeletal Imaging Principles — 肌肉骨骼影像學原則

## 章節導讀

骨科影像學的臨床決策核心只有一句話：**用最低的輻射、最少的成本，得到足以改變處置的答案**。本章第一節依序介紹 X 光攝影、透視、雙能 X 光吸收測量（DXA）、CT、MRI、超音波與核醫的原理與適應症；第二節聚焦 MRI 的序列與訊號判讀、金屬假影抑制與顯影劑；第三節整理創傷、關節炎、腫瘤、感染與術前規劃的臨床演算法；第四節提出誤讀陷阱與輻射安全規範。

## 1. 影像檢查的選擇與適應症 (Modality Selection & Indications)

### 1.1 X 光攝影 (Plain Radiography)

**X 光仍是絕大多數骨科疾病的初始檢查**，尤其是創傷與骨折。

| 臨床情境 | X 光的角色 |
|----------|------------|
| <span style="color:#60a5fa">骨折</span> | 首選；便携式 X 光可於創傷現場立即取得 |
| <span style="color:#60a5fa">骨性關節炎</span> | <span style="color:#34d399">負重 X 光為診斷黃金標準</span>（Figure 3） |
| <span style="color:#60a5fa">發炎性關節病</span> | 結合實驗室與臨床檢查診斷與追蹤 |
| <span style="color:#60a5fa">軟組織鈣化</span> | 痛風、偽痛風、腫瘤性鈣化症、<span style="color:#22d3ee">骨化性肌炎</span>（Figure 4）、異位性骨化 |

**創傷特別提醒**：便攜式 AP X 光（Figure 2）可同時顯示近端與遠端股骨、假體周圍骨折、髓內裝置斷裂與遠端鎖定螺絲、幹骺端骨折合併股骨頸骨折。若懷疑**節段不穩定（segment instability）**，可加拍**延伸片（extension films）**協助判斷。

**判讀重點**：X 光對**關節間隙、對位、骨贅（osteophyte）**與其他退變後遺征象非常準確；負重位影像是評估骨性關節炎與退變的**黃金標準**。腫瘤方面，**轉變區廣（wide zone of transition）**提示惡性或侵襲性，**界線清楚（well-marginated）**提示良性；<span style="color:#60a5fa">骨肉瘤</span>與<span style="color:#60a5fa">軟骨肉瘤</span>可由 X 光診斷，<span style="color:#60a5fa">內生軟骨瘤（enchondroma）</span>多為偶然發現但必須與惡性病變區分。

> **Pearl**：X 光看到的鈣化型態往往改變鑑別方向——「爆米花狀鈣化」提示軟骨來源，「骨化性肌炎」的**骨外成熟骨化**與骨肉瘤的骨膜反應不同。

### 1.2 透視 X 光 (Fluoroscopy)

<span style="color:#e2e8f0">Fluoroscopy</span>（透視）指**即時的 X 光影像**，讓臨床醫師在活體操作過程中同步取得影像資訊。

- **評估不穩定骨折型態**：如 <span style="color:#22d3ee">髖臼</span>骨折術後以活體 X 光 **loading 髖關節**評估穩定性；或於踝骨折固定後**施壓遠端脛腓聯合（syndesmosis）**檢查韌帶複合體完整性。
- **最常見的用途是術中導引**：脊椎與創傷手術的螺絲置入、骨折復位可即時回饋，使**微創與經皮手術**得以實現；亦用於**影像導引關節抽吸與注射**。

### 1.3 雙能 X 光吸收測量 (Dual-Energy X-ray Absorptiometry, DXA)

DXA 由 X 光技術演變而來，用來**計算骨礦物密度（bone mineral density）**，並據以推估骨質疏鬆相關骨折（脊椎壓迫骨折、髖骨折、<span style="color:#22d3ee">遠端橈骨</span>骨折）的風險。仍有更複雜且準確的骨密度評估技術在發展中（見 2.6）。

### 1.4 電腦斷層 (Computed Tomography, CT)

CT 以**旋轉的 X 光束**產生橫斷面影像：X 光管位於環形 gantry 內，病人躺在檢查床上緩慢通過，X 光管繞病人旋轉；穿過身體的 X 光由對側多個偵測器接收，資料經電腦重建成影像。

**雙能 CT（Dual-Energy CT）**：使用**兩種不同能量的 X 光**取得影像，以呈現不同的組織對比。可採**雙源雙能**（兩組 X 光管與偵測器呈 90° 配置）或**快速千伏切換（rapid kilovoltage switching）**。

| 雙能 CT 臨床應用 | 原理 |
|------------------|------|
| <span style="color:#60a5fa">金屬假影抑制</span> | 結合兩組能量資料後處理，降低骨科假體造成的金屬假影<sup>12</sup> |
| <span style="color:#60a5fa">痛風診斷</span> | 依鈣與單酸尿酸鹽（MSU）結晶不同的衰減特性辨識（Figure 5） |
| <span style="color:#60a5fa">骨髓水腫</span> | 從骨髓中「移除」骨組織後處理產生水腫對應圖 |
| <span style="color:#60a5fa">韌帶與肌腱分析</span> | 利用膠原結構的特殊衰減特性 |
| <span style="color:#60a5fa">骨病灶偵測</span> | 測量含水量、骨組成與強化特性 |

> **Pearl**：傳統 CT 即便使用假影抑制技術，仍受金屬假影限制而降低影像品質；雙能 CT 的價值不只在「看得見」，更在於**辨識關節置換假體周圍的骨與軟組織病變**。

**錐狀射束 CT（Cone-beam CT）**：使用**錐狀 X 光束與平面探測器**（相較傳統 CT 的扇形束與線狀探測器），X 光管與探測器繞病人旋轉，影像可重建於三個平面。優點為肢體**負重 CT**、高空間解析度、**劑量低於傳統 CT**；限制為軟組織評估能力有限、**視野（FOV）小**。適應症包括放射學隱匿性骨折、負重位骨性關節炎評估、慢性骨髓炎的**死骨（sequestrum）**評估。

### 1.5 磁振造影 (Magnetic Resonance Imaging, MRI)

MRI **不使用輻射**，利用各組織**氫原子質子**在強磁場中的行為成像，因此被視為**孕婦與兒童安全的檢查**。相較 CT，MRI **較貴、較慢**，但**軟組織解析度明顯較佳**；涉及**皮質骨與骨小樑**的問題仍以 CT 為選擇。

### 1.6 超音波 (Ultrasonography)

超音波以**高頻聲波**由探頭送入軟組織，部分聲波反射回探頭並由電腦處理成像；**不使用游離輻射**，且可產生**即時影像**。骨科超音波通常使用**高頻線性探頭**評估表淺軟組織結構，**低頻凸陣探頭**評估較深部構造。

### 1.7 核醫 (Nuclear Medicine)

核醫為**功能性影像**，需使用放射性藥物（多為靜脈注射），藥物累積於目標組織並釋放 gamma 輻射，由特殊偵測器偵測成像。

- **單光子發射 CT（SPECT）**：一般使用 **Technetium-99m** 為示蹤劑。
- **正子斷層（PET）**：最常用 **Fluorine-18-fluorodeoxyglucose（<sup>18</sup>F-FDG）**，累積於葡萄糖代謝活性高的組織；F-18 釋放正子，與電子相遇後發生**正子／電子湮滅**，產生兩個方向相反的 gamma 光子，再將核醫資料**疊加於同步取得的 CT 影像**上完成解剖定位（Figure 10）。

> **Pearl**：核醫檢查的共同盲點是**特異性低**——感染或發炎、創傷或骨折、良性與惡性腫瘤都會造成攝取升高（PET）或骨轉換增加（骨掃描），看到「陽性」不等於看到「惡性」。

### 1.8 輻射安全 (Radiation Safety)

隨著透視、便携式攝影與術中 CT 的廣泛使用，輻射安全對**病人與醫護人員**都至關重要；過度曝露會增加癌症與白內障等風險。

| 項目 | 數值 |
|------|------|
| <span style="color:#60a5fa">身體（軀幹）</span> 年最大劑量限值 | <span style="color:#f87171;font-weight:600">20 mSv / 年</span> |
| <span style="color:#60a5fa">甲狀腺與眼睛</span> 年最大劑量限值 | <span style="color:#f87171;font-weight:600">150 mSv / 年</span> |
| <span style="color:#60a5fa">手部</span> 年最大劑量限值 | <span style="color:#f87171;font-weight:600">500 mSv / 年</span> |
| 0.5 mm 鉛圍裙阻擋率 | <span style="color:#34d399">最高 95%</span> 輻射 |
| 鉛護目鏡阻擋率 | <span style="color:#34d399">90%</span> |
| 距離效應 | 散射 ∝ 1/距離²；<span style="color:#fbbf24">距離 4 倍遠 → 曝露為 1/16</span> |

> **Danger zone**：手術室中最常被忽略的是**甲狀腺與手部的防護**。最小 C 臂（mini C-arm）的暴露仍有爭議：理論上因**更靠近射源**，即使輸出較低，**手部劑量仍可能高於一般 C 臂**——術者的手必須盡可能遠離射源。

**病人端**：**孕婦**（胎兒接受游離輻射原則上屬禁忌，除非情況危急）與**兒童**（暴露具爭議，除非必要應避免）需特別小心。從輻射角度而言 **MRI 是安全的**；X 光劑量相對低，**CT 劑量可高出許多**。輻射相關致癌風險**與劑量成正比且整體偏低，但難以精確量化**。

## 2. MRI 序列與訊號判讀 (Sequences & Signal Interpretation)

### 2.1 MRI 物理與弛豫時間

MRI 掃描機以**強磁場**作用於目標組織的質子；質子與磁場對齊後其自身磁場也對齊主磁場，此現象稱為**進動（precession）**。接著經由各種線圈（如**膝關節線圈**）施加**射頻脈衝**；當射頻頻率與進動頻率相同時即發生**共振**，質子吸收射頻能量而改變排列。脈衝停止後，質子以不同速率重新與主磁場對齊——兩個關鍵時間即 **T1 與 T2 弛豫時間**。弛豫中質子發出的訊號由射頻線圈接收，再由電腦分析成影像<sup>22</sup>。

### 2.2 骨科常用的四種序列

骨科影像的主幹序列為 **T1 加權、T2 加權、質子密度（proton density）與梯度回波（gradient echo）**。**脂肪抑制（fat suppression）**是藉由射頻脈衝「關掉」序列中的明亮脂肪訊號。

### 2.3 各序列的臨床角色

| 序列 | 影像特性 | 最佳用途 |
|------|----------|----------|
| <span style="color:#60a5fa">T2 加權（流體序列）</span> | 液體與水腫呈**高訊號** | <span style="color:#22d3ee">水腫</span>、積液、病灶的整體評估 |
| <span style="color:#60a5fa">T1 加權（軟組織序列）</span> | 脂肪（含骨髓脂肪）**明亮**；單純液體**暗** | 解剖構造；**對比劑 T1 + 脂肪抑制**用於評估各組織的**強化型態** |
| <span style="color:#60a5fa">質子密度 (PD)</span> | 介於 T1 與 T2 之間，權重反映質子實際密度 | 關節檢查；<span style="color:#22d3ee">液體</span>與<span style="color:#22d3ee">軟骨</span>對比最佳 |
| <span style="color:#60a5fa">梯度回波 (GRE)</span> | 以梯度磁場成像，對**磁場不均質高度敏感** | 偵測含**鈣化**或**血鐵質（hemosiderin）**的病灶，如<span style="color:#60a5fa">色素絨毛結節性滑膜炎 (PVNS)</span> |

> **Pearl**：GRE 序列的「暗暈（dark blooming）」假影雖是雜訊，卻是**金屬、鈣化與血鐵質沉積的線索**——這是它最常被使用的理由。

### 2.4 金屬假影抑制 (Metallic Artifact Reduction)

骨科 MRI 的金屬假影會造成**影像品質下降**，遮蔽植入金屬物**鄰近的骨與軟組織病變**，並會**連帶破壞脂肪抑制**。**磁場強度與金屬假影量成正比**——1.5T 的假影少於 3T。

| 傳統金屬假影抑制參數 | 專屬技術 |
|----------------------|----------|
| 增大頻寬、減薄切片選擇、延長回波串列長度、增大影像矩陣 | <span style="color:#60a5fa">SEMAC</span>（slice encoding for metal artifact correction） |
| 以 **STIR（short tau inversion recovery）** 序列做脂肪抑制 | <span style="color:#60a5fa">MAVRIC</span>（multiacquisition with variable resonance image combination） |
| | <span style="color:#60a5fa">WARP</span>（Siemens Healthcare；多項技術的組合） |

**STIR 的原理**：利用水與脂肪**不同的 MRI 弛豫時間**產生脂肪抑制影像，因此在有金屬裝置時能提供**更可靠的脂肪抑制**<sup>23</sup>。專屬金屬抑制技術可顯示原本被金屬硬體假影遮蔽的病變（Figure 8：全髋關節置換後左髖假性腫瘤）。

### 2.5 對比劑 (Contrast) 的使用原則

<span style="color:#fb923c">Gadolinium</span> 為**順磁性**化合物，在 MRI 中的角色類似 CT 的含碘對比劑。

| 項目 | 內容 |
|------|------|
| 訊號表現 | 於 **T1 加權**影像上訊號增強，在**脂肪抑制影像**上對比更明顯 |
| 強化機轉 | 強化程度**與軟組織血管密度成正比** |
| 主要適應症 | <span style="color:#60a5fa">腫瘤性</span>與<span style="color:#60a5fa">感染性</span>病因 |
| 囊腫 vs 實質腫塊 | 囊腫呈**環狀強化**，實質腫塊呈**不均勻強化** |
| 腫瘤活性 | 可區分**活性腫瘤組織**與**不強化的壞死** |
| 感染 vs 血腫 | **膿腫有厚強化壁**，對照不強化的血腫 |
| 脊椎應用 | 區分**早期瘢痕組織（會強化）**與**椎間盤（不強化）** |
| 關節內對比 | 可在影像導引下注入，評估關節內結構 |

> **Pearl**：**多數肌肉骨骼 MRI 不需要對比劑**——創傷與退變性病變在無對比下已能良好顯示；只有當問題是「這個病灶是活的嗎？是發炎還是腫瘤嗎？」時才加做對比。

### 2.6 磁場強度與解析度

MRI 磁場強度以 **Tesla (T)** 為單位。技術進步使 **3T（而非 1.5T）** 的檢查更普遍，帶來**更好的影像解析度**與**更短的掃描時間**。針對嚴重**幽閉恐懼症（claustrophobia）**可提供**開放式 MRI**，但其解析度**顯著下降**

**骨密度評估與骨質紋理分析**：DXA 仍是骨質疏鬆評估的主流，但以電腦輔助分析 X 光片的**骨紋理分析（bone texture analysis）**可評估骨小樑的質地與強度，準確度較佳並逐漸被接受。**定量 CT（quantitative CT）**則以 CT 技術達成相似目標，以更高的準確度決定骨結構與強度<sup>20,21</sup>。

## 3. 臨床影像演算法 (Clinical Algorithms)

### 3.1 創傷

| 臨床問題 | 建議檢查 | 理由 |
|----------|----------|------|
| 骨折初篩 | <span style="color:#60a5fa">X 光</span> | 首選；負重位片不可省略 |
| 懷疑韌帶／軟組織損傷 | <span style="color:#60a5fa">MRI</span> | 韌帶與軟骨損傷、關節面與骨髓水腫評估 |
| **壓力性骨折** | <span style="color:#60a5fa">MRI</span> | 對壓力性骨折**高度敏感** |
| **隱匿性股骨頸骨折** | <span style="color:#60a5fa">MRI 優於 CT</span> | 2020 年研究：MRI 較敏感，尤其偵測隱匿性股骨頸骨折<sup>26</sup> |
| X 光與 CT 皆陰性的頸椎 | <span style="color:#60a5fa">MRI</span> | 仍可能需 MRI 偵測**韌帶斷裂** |
| 頸椎 MRI 陰性 | <span style="color:#60a5fa">CT 脊髓造影</span> | 替代方案（見 3.5） |
| 脊椎 | <span style="color:#60a5fa">MRI 為首選</span> | 椎間盤疾病、脊髓壓迫、脊髓病變 |

> **Pearl**：一份「有限式」MRI 協定即可達成 **100% 敏感度**偵測髖骨折（平均掃描時間 5 分鐘）——診斷效率與敏感度可以兼顧，但必須事先與影像科訂定可操作的協定。

### 3.2 關節炎與關節疾病

- 評估**關節退化**時，MRI **通常不是首選**；雖然 MRI 可顯示**軟骨變薄與損傷**、**軟骨下骨磨損**與**骨贅**，但疑似骨性關節炎仍以**負重 X 光為黃金標準**。
- 韌帶與肌腱病變可由 MRI 評估，在特定臨床情境很重要，例如**評估旋轉肌袖狀況以決定全肩關節置換採用解剖型或反轉型**。
- **發炎性關節病**以 X 光結合實驗室與臨床檢查診斷與追蹤。
- **CT 關節造影**（關節內注入對比劑）可評估**軟骨缺損、半月板與唇狀韌帶撕裂**，適用於**有 MRI 禁忌**者。

### 3.3 腫瘤

**CT 的定位**：**胸腹腔臟器內的軟組織腫瘤**以 CT 為選擇性檢查，且為**多數癌症分期**的有用工具；其他軟組織與**骨髓**評估則以 **MRI 為佳**，但 MRI 禁忌時仍可使用 CT，CT 亦用於**偵測與描述鈣化**，並評估**骨性構造與皮質完整性**（尤其**迫近性骨折**）。

**MRI 的定位**：任何疑似**軟組織腫瘤**與多數**骨腫瘤**都以 MRI 為主；它是原發性骨惡性腫瘤（如骨肉瘤、軟骨肉瘤、<span style="color:#60a5fa">伊文氏肉瘤</span>）常規 X 光評估的一部分，**最適合評估軟組織延伸範圍與量化骨髓內侵犯程度**<sup>27</sup>，也是**軟組織腫瘤的首選**。疑似腫瘤時**通常需要靜注 gadolinium 對比劑**；使用適當的 MRI 序列並觀察**強化型態**，常可區分良性與惡性<sup>28</sup>。

### 3.4 感染

- **雙能 CT** 可**非侵入性診斷痛風**（Figure 5），準確辨識 MSU 結晶；傳統上痛風需以**關節穿刺取得關節液**分析 MSU 結晶來診斷。
- **MRI 對比劑**區分**膿腫（厚強化壁）**與**血腫（不強化）**。
- **核醫**（骨掃描、PET-CT）對發炎與感染敏感，但**特異性低**。

### 3.5 術前規劃與影像導引手術

**CT 對術前規劃的影響**主要在複雜骨折的評估與治療，以及結合各種**手術導引技術**的手術。軸位 CT 可轉換成**三維重建影像**，提升骨折復位規劃的可靠性<sup>13</sup>。

**機器人輔助手術**一般**要求術前 CT**：以專屬 CT 協定掃描目標骨或關節（部分可術中執行），再以**動作捕捉**與病人身上的**參考標記物**在術中對位；此後即可**即時導引鋸片、鑽頭或螺絲**，**不需切割導引器（cutting guides）或即時透視**。2021 年研究顯示此法可提升多種應用的手術準確度<sup>14</sup>。術前 CT 亦可用於製作**三維列印的病人客製模型**、複雜截骨或切除的**三維列印切割導引器**，以及**病人專屬植入物**；但**製造成本與時間**使其僅限於複雜且罕見的病例。

CT 亦可評估植入硬體，判斷**鬆動、骨溶解、骨長入與不癒合**。

**影像導引介入治療**（多由放射科或介入放射科執行）：

| 技術 | 適應症與地位 |
|------|-------------|
| <span style="color:#60a5fa">CT 導引針頭活檢</span> | 可取得多數解剖部位的組織，**可取代併發症較高的開放活檢** |
| <span style="color:#60a5fa">CT 導引射頻燒灼 (RFA)</span> | **骨樣骨瘤的標準治療（standard of care）**<sup>17</sup>（Figure 6） |
| <span style="color:#60a5fa">疼痛受器消融</span> | 脊椎或其他部位的疼痛受器消融<sup>18</sup> |
| <span style="color:#60a5fa">微波消融與冷凍消融</span> | 適應症持續擴展；系統性回顧分析 36 篇研究報告**整體成功率 92%**，RFA 與冷凍消融**成功率無差異**，但**冷凍消融副作用較少**<sup>18</sup>；冷凍消融因**可見的冰球（ice ball）**利於安全地對準鄰近重要構造的病灶<sup>19</sup> |

> **Danger zone**：**CT 對比劑禁忌**——對含碘對比劑**過敏**者不建議使用；接受對比劑增強 CT 前應**測量腎小球濾過率（GFR）**。**GFR 低於 30 mL/min** 者，必須仔細評估**風險與效益並與病人討論後**再決定是否施打靜脈對比劑。

### 3.6 核醫檢查的選擇

| 檢查 | 適應症 | 限制 |
|------|--------|------|
| <span style="color:#60a5fa">PET-CT</span> | <span style="color:#fbbf24">轉移或多中心腫瘤</span>；捕捉一般 CT 可能漏掉的小轉移灶；腫瘤科用於淋巴瘤或小兒肉瘤的**治療反應**評估<sup>33</sup> | 昂貴、**游離輻射量可觀**、**敏感度極高但特異度差**，偽陽性多 |
| <span style="color:#60a5fa">骨掃描（三階段）</span> | 骨轉移、壓力性骨折、發炎或感染（骨髓炎）<sup>34</sup> | **解析度較低**；良性病灶常偽陽性 |
| <span style="color:#60a5fa">骨掃描—偽陽性陷阱</span> | <span style="color:#f87171">內生軟骨瘤（enchondroma）</span> **一定會顯影**，因此**不適合、也無助於**此診斷 | — |
| <span style="color:#60a5fa">骨掃描—偽陰性陷阱</span> | <span style="color:#f87171">多發性骨髓瘤</span> 顯影**不可靠**<sup>35</sup> | 此時應以**骨系列 X 光（bone survey radiographs）**作為較合適的篩檢工具 |

**PET 數值的客觀化**：以 **Standard Uptake Value (SUV)** 單位量測，可將一次掃描與另一次掃描**客觀比較**。

## 4. 陷阱與爭議 (Pitfalls & Misinterpretation)

### 4.1 影像假影 (Artifacts)

| 假影 | 發生情境 | 誤診風險 |
|------|----------|----------|
| <span style="color:#60a5fa">各向異性 (anisotropy)</span> | 超音波束**斜行於肌腱纖維**，反射性喪失 | 原本明亮（hyperechoic）的**肌腱纖維變暗（hypoechoic）**，偽似病變 |
| <span style="color:#60a5fa">波束邊緣假影</span> | 大型肌腱邊緣產生**人工後方陰影** | 偽似肌腱斷裂或**肌腱病變（tendinosis）** |
| <span style="color:#60a5fa">金屬假影</span> | CT／MRI 中的植入物 | 遮蔽假體周圍病變，並破壞 MRI 脂肪抑制 |
| <span style="color:#60a5fa">GRE 暗暈 (blooming)</span> | 含鈣化、血鐵質或金屬 | 需辨識為**線索**而非雜訊（PVNS） |

### 4.2 常見誤讀陷阱

> **陷阱 1：用非負重 X 光評估骨性關節炎**。負重位是診斷黃金標準，非負重片會低估關節間隙狹窄。

> **陷阱 2：把 CT 當成軟組織與骨髓的第一選擇**。CT 擅長**皮質骨與骨小樑**；軟組織與骨髓首選仍是 **MRI**。

> **陷阱 3：對多數肌肉骨骼 MRI 過度使用對比劑**。創傷與退變病變無需對比；對比劑應保留給**腫瘤與感染**的鑑別問題。

> **陷阱 4：忽略 CT 對比劑的腎毒性**。**GFR < 30 mL/min** 必須先做風險效益評估並與病人討論。

> **陷阱 5：把核醫的陽性攝取當成惡性**。感染、發炎、創傷、骨折與良性病灶都會產生攝取升高。

> **陷阱 6：以骨掃描診斷內生軟骨瘤或排除骨髓瘤**。前者**一定顯影**（無診斷價值），後者**顯影不可靠**（應用骨系列 X 光）。

> **陷阱 7：過度依賴超音波**。超音波**高度依賴操作者**，經驗不足的技術人員或臨床醫師可能產生**不可靠的結果**。

> **陷阱 8：忽略醫護人員自身的輻射暴露**。散射 ∝ 1/距離²——**伸手去調整 C 臂**的劑量遠高於站在遠處觀看。

### 4.3 檢查選擇的「決策紀律」

每一張影像檢查都應能回答一個**會改變處置**的問題：

1. 問題是**骨**還是**軟組織**？骨 → X 光／CT；軟組織 → MRI／超音波。
2. 需要**功能／全身**資訊嗎？→ 核醫。
3. 需要**即時動態**或**即時導引**嗎？→ 超音波或透視。
4. 是否需要**負重位**資訊？→ 負重 X 光或錐狀射束 CT。
5. 病人是否**懷孕或為兒童**？→ 優先考慮**無游離輻射**的檢查（MRI、超音波）。

> **Pearl**：MRI 沒有輻射但**不代表零成本**——較貴、較慢、有幽閉恐懼與金屬植入物限制；CT 無對比劑過敏問題但**劑量可高出許多**。每一項檢查都是取捨。

## 5. OKU 14 重點與核心總結 (Key Study Points & Take-Home Points)

### 5.1 本章關鍵研究重點 (Key Study Points)

- **一般 X 光攝影**仍是**骨性關節炎與骨折**的首選檢查，應在檢查流程的**最初**開立，尤其創傷情境。
- **CT** 對複雜骨性解剖與病變有用，可用於**術前與術中導引**，也用於**影像導引介入治療**。
- **MRI** 最適合**軟組織病變**（肌腱、韌帶、軟骨、脊椎）與腫瘤評估；對比劑用於**感染或腫瘤**情境。
- **超音波**便宜、無侵入，但**易受使用者技術影響**；用於影像導引抽吸／注射與**動態**評估肌腱與淺層軟組織病變。
- **核醫**為快速發展中的領域，通常用於腫瘤與感染，也可用於愈來愈多其他疾病。
- 開立與執行檢查時都應**審慎**，因為對**病人與醫護人員**皆存在風險。

### 5.2 骨科專科考試核心總結（Take-Home Points）

1. **第一選擇仍是 X 光**；**負重 X 光**是骨性關節炎的黃金標準。
2. **CT 強於皮質骨**（骨折、複雜解剖、迫近性骨折、金屬假影）；**MRI 強於軟組織與骨髓**（韌帶、肌腱、軟骨、脊椎、隱匿性骨折、感染、腫瘤）。
3. **MRI 對隱匿性股骨頸骨折比 CT 敏感**；有限式協定即可達 100% 敏感度、平均掃描 5 分鐘。
4. **雙能 CT** 四大應用：<span style="color:#60a5fa">金屬假影抑制、痛風 MSU 偵測、韌帶／肌腱分析、骨髓水腫與骨病灶偵測</span>。
5. **錐狀射束 CT**：肢體負重、高解析、低劑量，但**軟組織評估有限、FOV 小**。
6. **MRI 訊號判讀**：T2 看水腫與液體；T1 看解剖；PD 看液體與軟骨；GRE 看鈣化與血鐵質；**STIR 在金屬假體旁脂肪抑制最可靠**；1.5T 假影少於 3T。
7. **多數肌肉骨骼 MRI 不需對比劑**；<span style="color:#fb923c">Gadolinium</span> 主要用於**腫瘤與感染**。
8. **CT 對比劑**：含碘過敏禁用；**GFR < 30 mL/min** 須先做風險效益評估並與病人討論。
9. **核醫**：PET-CT **高敏感、低特異**；骨掃描三階段（血流、血池、延遲）；**內生軟骨瘤一定顯影**、**骨髓瘤顯影不可靠**。
10. **輻射安全**：身體 **20 mSv/年**、甲狀腺與眼睛 **150 mSv/年**、手部 **500 mSv/年**；鉛圍裙可擋 **95%**、鉛護目鏡 **90%**；**距離 4 倍遠 → 曝露 1/16**。
