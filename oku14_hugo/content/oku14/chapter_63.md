# Chapter 63: Pediatric Hip Disorders — 小兒髖部疾病

## 章節導讀

本章以四個小兒髖部核心疾病為主軸：<span style="color:#e2e8f0">developmental dysplasia of the hip（DDH）</span>、<span style="color:#e2e8f0">slipped capital femoral epiphysis（SCFE）</span>、<span style="color:#e2e8f0">Legg-Calvé-Perthes disease（LCP）</span>與 <span style="color:#e2e8f0">femoroacetabular impingement（FAI）</span>。內容依「臨床評估與影像 → 分型系統 → 治療時序 → 陷阱與爭議」四層次串接，最後收束於實證更新與專科考試重點。

## 1. 核心概念與臨床評估 (Core Concepts & Clinical Evaluation)

### 1.1 四個疾病的定位與共通原則

| 疾病 | 病理本質 | 發病／盛行區間 | 治療核心 |
|------|----------|------------------|----------|
| **DDH** | 髖臼發育不足伴股骨頭半脫位或脫位 | 新生兒期即可能存在；**5 歲以上**可用 AP 與 false-profile 影像量化覆蓋 | 嬰兒期以 **Pavlik harness** 為主，必要時復位 |
| **SCFE** | 骨骺板處的旋轉變形，近端股骨幹相對骨骺**伸展與外旋** | 發生率 **每 10 萬人 10 例** | **原位螺釘固定**保護後方韌帶血管 |
| **LCP** | 近端股骨骨骺**特發性骨壞死**，致頭部粗大變形與關節不相稱 | 好發 **4 至 8 歲** | **包容（containment）**並保存活動度 |
| **FAI** | 生理活動範圍內股骨近端與髖臼的**撞擊（abutment）** | 青少年與年輕成人 | **保守優先**，必要時手術 |


### 1.2 DDH：臨床檢查與影像

DDH 的影像與臨床監測有兩個層次：新生兒期以**超音波**為主，較大兒童以**骨盆 AP 與 false-profile 放射影像**為主。在 AP 與 false-profile 骨盆放射影像上分別取得量測值；**5 歲以上**的病人，這些量測可用來描述**股骨頭覆蓋率與髖臼缺損**，較常用於**較大兒童的髖關節發育不良**。


### 1.3 青少年與年輕成人髖關節發育不良的臨床表現

即使有新生兒期的篩檢，仍有病例直到**青少年期或成人期**才被診斷。多數病人可能**無症狀**，但一般認為**早期矯正可降低退化性髖關節疾病的風險**：異常的運動方式會改變接觸壓力並導致**早期骨關節炎**，因此**即使輕度發育不良與輕微的股骨中心外移（lateralization of the hip center）也會增加早發骨關節炎的風險**。畸形通常為**多平面（multiplanar）**：不只是前外側髖臼缺損，也可能合併**後側與整體性缺損**以及**髖臼深度變淺**；**Coxa valga**與**股骨前傾過大**亦常見。

| 面向 | 原文重點 |
|------|----------|
| **症狀** | **髖痛**，特別是**腹股溝或沿腹股溝皺褶**——即 **C sign**；疼痛起病通常**隱匿** |
| **外側痛與步態** | 可能出現**外側痛**與因**外展肌疲勞（abductor fatigue）**造成的 **Trendelenburg 步態** |
| **其他表現** | 多數病人**健康且活動力佳**，但可能同時有**下背痛與憂鬱（depression）** |
| **發病與畸形程度** | 畸形**越嚴重**、活動量**越高**，**就診越早** |
| **前側恐懼試驗** | <span style="color:#22d3ee">anterior apprehension test</span>：**髖關節逐漸外旋與伸展時**出現不適或恐懼即為陽性 |

### 1.4 青少年髖關節發育不良的影像判讀

影像檢查是描述青少年發育不良的重要工具，**高品質的放射影像**對準確診斷不可或缺；**骨盆的輕微變化或旋轉**都可能改變判讀。

| 量測／影像 | 定義與原文門檻 |
|------------|----------------|
| **LCEA（angle of Wiberg）** | **AP 骨盆**放射影像；**<20°** 定義為發育不良 |
| **Ténnis angle** | **AP 骨盆**放射影像；**>10°** 定義為發育不良 |
| **Extrusion index、Shenton line、股骨頸幹角** | 由 AP 放射影像取得的其他量測 |
| **FEAR index** | 髖臼指數相對於**近端股骨骺痕水平部分**的夾角；**<5°** 代表**穩定髖，不需手術介入** |
| **Anterior CEA（angle of Lequesne）** | **false-profile 視位**的前方覆蓋；**<20°** 為發育不良 |
| **3D CT 重建** | 精確描述**髖臼形態**，用於**診斷與手術規劃** |
| **MRA／cartilage-sensitive 序列** | 判讀**唇狀病變**與**軟骨損傷**；**MRI 軟骨損傷陽性為 PAO 後不良結果的預測因子** |


### 1.5 SCFE 的臨床檢查與影像

SCFE 是**近端股骨頭脆弱骺板層級的旋轉變形**，近端股骨幹相對於骨骺**伸展並外旋**。原文強調**早期診斷與治療已被證實有較佳結果**，但**變形已發生且隨後出現關節損傷才就診的晚診病例並不罕見**。症狀通常**含糊**，疼痛可**間歇**，甚至**轉移痛**至其他部位（如**大腿或膝蓋**）。

| 面向 | 原文重點 |
|------|----------|
| **高風險族群** | **體重過重**兒童，以及有**內分泌或代謝疾病**或 **Down syndrome** 的病人，出現**髖痛或膝痛**時應篩檢 SCFE |
| **理學檢查** | 因**滑膜炎**或**撞擊**，出現**內旋減少**與**被動屈曲減少** |
| **Drehmann sign** | 屈髖時出現**被動外旋與外展** |
| **急性型表現** | 可能**突然出現股骨頭與骺板的急性分離** |
| **臨床症狀但 X 光陰性** | **MRI** 可診斷 **preslip**，典型為**近端股骨骺板周圍水腫** |
| **滑脫程度低估** | 一般放射影像可能**低估變形程度**，可用 **CT 或 MRI** 輔助 |
| **MRI 的其他用途** | 診斷 **preslip**（**骺板擴寬**或**骨骺結節處透亮線**）；評估既存撞擊造成的**軟骨與唇狀病變** |
| **CT 的其他用途** | 在 **acute-on-chronic 或慢性 SCFE** 中顯示**後側骨痂**，協助**重建手術規劃** |

### 1.6 LCP 的臨床表現與影像

LCP 為**近端股骨骨骺的特發性骨壞死**，導致**粗大變形、關節不相稱與隨後的功能障礙**。其病程為**可預期的長序列**：骨壞死 → 血管再通 → 碎裂 → 再骨化 → 重塑。

| 面向 | 原文重點 |
|------|----------|
| **好發年齡** | 通常 **4 至 8 歲**起病，**骨骼年齡可延遲最多 1 年** |
| **族群** | 較常見於**北歐血統的白人男性** |
| **雙側** | **10% 至 20%** 為雙側；雙側者應**排除骨骼發育不良** |
| **病程長度** | **2 至 5 年**才進入癒合期 |
| **主要表現** | **跛行**，早期可合併**隱匿起病的疼痛**；進入碎裂期後疼痛**更集中於髖部**，通常**間歇性**，可定位於**腹股溝、髖、大腿或膝蓋** |
| **活動度變化** | **內旋與外展**逐漸喪失 |
| **晚期變化** | 頭部塌陷 → **外展肌力臂縮短與 Trendelenburg 步態**；進一步塌陷 → **雙下肢長差與髖內收肌攣縮** |
| **MRI 的限制** | **發病前 6 個月內**的一般 **MRI 可能低估**軟骨損傷與骨壞死，因**缺血表現有延遲** |
| **Perfusion MRI** | 較能顯示**血管性**並劃定**壞死與再血管化範圍**；但年幼病人**通常需要鎮靜**，且**仍有爭議** |
| **關節攝影** | **術中**常用以**動態評估活動度**，尤其是 **hinged abduction** |
| **CT 與 3D 重建** | 提供**股骨頭與髖臼粗大變形**資訊，用於**手術規劃** |


### 1.7 FAI 的臨床檢查與影像

FAI 是**生理活動範圍內近端股骨與髖臼之間撞擊**的結果。最常見的形式是**股骨頭頸交界處與髖臼的關節內異常接觸**，造成**疼痛與軟骨唇狀損傷（chondrolabral damage）**。

| 分型 | 形態特徵與原文重點 |
|------|---------------------|
| **Cam lesion（凸輪型）** | **股骨頭頸交界**異常，可能由**青少年期反覆高衝擊屈曲活動**造成；反覆壓力使**近端股骨骺板 epiphyseal cupping 增加**以提供穩定，骨量增加與重塑使**股骨頸表面變成凸面**而非正常發育髖的**凹面**；亦可**次發於 LCP 與 SCFE 癒合後的變形** |
| **Pincer lesion（鉗狀型）** | **病理性髖臼過度覆蓋**：可為**局部性**（如**髖臼後傾**）或**整體性**（如 **coxa profunda / protrusio**）；撞擊可來自**股骨、髖臼，或更常見兩者兼有** |

| 面向 | 原文重點 |
|------|----------|
| **典型症狀** | **活動相關的腹股溝或前側髖痛**，**屈曲時加劇** |
| **外側痛** | 位於**大轉子附近**的外側髖痛可與**異常步態力學**有關 |
| **誘發動作** | **被動屈曲（>90°）、內收與內旋**會加劇疼痛（即 **anterior impingement test**） |
| **放射影像** | **站立 AP、側位、false-profile 與 modified Dunn** 攝影可評估**非球形的頭頸交界**與**髖臼過度覆蓋** |
| **Cam 的影像門檻** | **alpha angle >50° 至 55°**，或 **head-neck ratio >0.17**；**pistol grip deformity** 亦提示 cam |
| **Pincer 的影像** | **acetabular protrusio、coxa profunda 與／或 retroversion**；**crossover sign** 提示**髖臼後傾**；**較大的外側或前方 center-edge angle** 亦提示 pincer |
| **最佳影像** | **CT 加上 3D 重建**描述畸形；**MRI 關節攝影**是評估**關節內軟骨或唇狀病變的最佳檢查** |

## 2. 分型系統與決策矩陣 (Classification & Decision Making)

### 2.1 SCFE 的三套分型

**時間分型（temporal classification）**：以**症狀持續長短**區分——**急性（acute，<3 週）**對**慢性（chronic，>3 週）**；**acute-on-chronic（慢性驟然惡化）**者則報告慢性疼痛後**突然加劇**。

**穩定性分型（Loder classification）**

| 分型 | 定義 | 預後意義 |
|------|------|----------|
| **Stable（穩定）** | 病人**可步行**，**無論是否使用輔助器具（crutches）** | 骨壞死風險低 |
| **Unstable（不穩定）** | 病人**即使有輔助器具仍無法步行** | 骨壞死風險顯著升高 |

髖關節穩定性與**骨壞死風險**相關：某研究發現**不穩定髖 47%**、穩定髖 **0%** 發生骨壞死；但**較新的文獻報告不穩定髖的骨壞死風險約為 23.9%**。另一研究**質疑穩定性的定義**：**58 例**術前可步行者中有 **17 例**在**術中**被判定為不穩定；**24 例**術前無法負重者中也有 **13 例**在術中判定為穩定。


**滑移嚴重度（percent slip 與 Southwick angle）**：依 **AP 與 frog-leg 放射影像**上所見的變形程度分級。

| 嚴重度 | 滑移百分比 | Southwick 角 |
|--------|------------|--------------|
| **Mild（輕度）** | **33%**（以內） | **<30°** |
| **Moderate（中度）** | **33% 至 66%** | **30° 至 60°** |
| **Severe（重度）** | **>66%** | **>60°** |


### 2.2 LCP 的分型系統

**Waldenstróm 影像分期**描述 LCP 的自然病程，**改良版**再細分以提升可靠度：**Stage I** 為骨骺內骨質**硬化與壞死**；**Stage II** 為骨骺**碎裂**，伴隨**骨吸收**與**軟骨性原基（cartilaginous anlage）的化生改變**，此期**負重可造成骨質弱化與股骨頭變形**；**Stage III** 因**血管再通**而發生**再骨化**，可能走向**正常髖血管性**，也可能出現**跨越骺板的血管性與骺板阻斷形成（physeal bar formation）**；**Stage IV** 股骨頭**已再骨化**，代表 Perthes 病的**最終癒合期**。

**改良 Waldenström 分期（Figure 10 的細分）**

| 細分期 | 原文描述 |
|--------|----------|
| **IA** | 骨骺**全部或部分硬化**，**無骨骺高度喪失** |
| **IB** | 骨骺**部分硬化**，**有骨骺高度喪失**，**無骨骺碎裂** |
| **IIA** | 骨骺**剛開始碎裂**；於 AP 視位或 **Lauenstein frog-lateral 視位**可見**一或兩條垂直裂隙** |
| **IIB** | **碎裂已進行**；**碎裂骨骺外側沒有新生骨** |
| **IIIA** | 碎裂骨骺**外側可見早期新生骨**；新生骨**質地不正常**，較「多孔（porotic）」，覆蓋**不到骨骺寬度的三分之一** |
| **IIIB** | **質地正常的新生骨覆蓋超過骨骺寬度的三分之一** |
| **IV** | **癒合完成**，**無缺血性骨質的影像學證據** |

**預後相關分型**

| 分型 | 內容 | 預後意義 |
|------|------|----------|
| **Stulberg classification** | 依**股骨頭癒合後的關節相稱性與形態**分類，與**成熟期髖關節早期骨關節炎**的風險相關 | 骨關節炎嚴重度**隨每一分期遞增**（髖愈來愈非球形、關節愈來愈不相稱）；提供**較客觀的分期參數**與良好的觀察者間信度 |
| **Catterall classification** | 依**碎裂期**時**股骨頭受累的位置與範圍**分類 | 相關的「**head at risk（危險頭）**」影像徵象包括：**股骨頭外側半脫位、外側鈣化、彌漫性骨幹反應、水平骺板**，以及 **Gage sign**——**骨骺或骨幹外側緣的 V 形透亮線** |
| **Herring lateral pillar** | 依**外側骨柱高度**：**完整者為 A 群**、**>50% 者為 B 群**、**<50% 者為 C 群** | **A 群**預後通常良好；**B 群中大於 6 歲者**與**所有 C 群病人**結果不佳 |
| **外側柱高度分類（早期碎裂期）** | 依**早期碎裂期股骨頭外側骨柱高度**分類；**早期碎裂通常發生於症狀出現後約 6 個月** | 缺點是**僅在碎裂期可靠**，需**連續放射影像**做時序分類，因此**可能錯過較不侵入性治療的時機窗** |


**未治療 LCP 的長期結果**：**追蹤 <40 年**的長期研究報告，多數病人**雖有股骨頭變形仍無症狀且活動正常**；**更長期的追蹤**顯示**髖關節持續進行性惡化**——**平均 47.7 年**後，**40% 需接受關節置換（arthroplasty）**、**40% 仍維持活動**、**10% 有致殘性疼痛**、**最後 10% 病人報告的病人自述結果評分不佳**。

### 2.3 綜合決策矩陣

| 臨床情境 | 建議方向 | 原文依據 |
|----------|----------|----------|
| **DDH：治療時機** | 治療結果**直接與初次治療年齡及嚴重度相關**；**嬰兒期未手術治療者長期結果最佳** | 管理段首句 |
| **DDH：股骨頭已同心復位並維持** | 年幼兒童**內在生長潛力**可讓**髖臼發育** | Pavlik 段落 |
| **DDH：harness 3 至 4 週無改善** | **停用 harness**，常需**閉鎖或開放復位** | 監測段落 |
| **DDH：harness 可復位但仍不穩** | 轉用**剛性外展支架**再 **3 至 4 週** | 同上 |
| **DDH：harness 失敗且持續脫位** | **閉鎖復位加關節攝影**，評估能否在 **Ramsey safe zone** 內復位 | Figure 5 段落 |
| **DDH：無法在 safe zone 內復位** | **開放復位**去除所有**復位阻礙** | 開放復位段 |
| **DDH：>18 個月** | 可**合併骨盆截骨（Salter、Dega 或 Pemberton）** | 骨盆截骨段 |
| **DDH：青少年發育不良** | 多數**未合併關節炎者**接受**骨盆截骨**；**輕度有症狀者**先藥物、物理治療與活動調整 | 青少年管理段 |
| **DDH：軟骨與唇狀病變** | **髖關節鏡**作為**輔助**治療 | 同上 |
| **SCFE：穩定型** | **經皮原位固定**為**首選治療** | 管理段首句 |
| **SCFE：不穩定型** | 多數外科醫師主張**24 小時內介入** | 不穩定段 |
| **SCFE：殘餘畸形致症狀性 FAI** | 應**矯正**（骨軟骨成形術或股骨近端截骨） | 殘餘畸形段 |
| **LCP：<6 歲起病** | **80% 良好結果**，不論手術或保守 | 年齡段 |
| **LCP：6 至 8 歲起病** | **手術 68%–69% vs. 支具 62%，無顯著差異**；但**支具不如骨盆截骨** | 同上 |
| **LCP：>8 歲起病** | **重塑潛力下降**；**lateral pillar C** 手術與非手術**無差異** | 同上 |
| **LCP：支具失敗** | **無統一演算法**；可選 **VDRO** 或**骨盆截骨** | 治療段 |
| **FAI** | **第一線為非手術治療**；合併軟骨唇狀病變才考慮手術 | 管理段 |

## 3. 治療指引：分階段與術式選擇 (Treatment Algorithm)

### 3.1 DDH：嬰兒期的 Pavlik harness 與復位

在**其他方面正常發育的新生兒**中，Pavlik harness 可成功治療**約 90% 的穩定型發育不良髖**與 **73% 的 Ortolani 檢查陽性髖**。harness **動態地將髖置於屈曲與外展位**，此姿勢已證實有助於**同心復位並維持之**，讓**髖臼重塑（acetabular remodeling）**得以進行。

| 面向 | 原文重點 |
|------|----------|
| **成功率較低的族群** | **神經肌肉疾病與脊髓脊膜膨出（myelomeningocele）病人**、**arthrogryposis（先天性多發性關節攣縮）**、**極度韌帶鬆弛的嬰兒（嚴重 Ehlers-Danlos syndrome）**、**大於 12 個月的嬰兒** |
| **體型過大或力量過強者** | 可**直接以 abduction brace 開始** |
| **治療期間方案** | **仍有爭議**：2021 年研究比較「逐步減除」與「超音波正常即停用」，**1 年時殘餘發育不良風險無差異**，但減除組穿戴時間**更長** |
| **殘餘發育不良** | 結果**並不一致**：某研究顯示**治療後將近 15 個月仍有 29% 的髖**高於平均值**兩個標準差以上**（儘管當時超音波已呈正常） |
| **併發症** | **骨壞死（osteonecrosis）**與**股神經麻痺（femoral nerve palsy）**；後者**與過度髖屈曲（>120°）有關**，且**可預測治療失敗**，因**處理必須停用 harness 直到麻痺緩解** |
| **監測方式** | **臨床檢查與覆蓋性超音波** |


**閉鎖復位與石膏固定**：至**行走年齡**仍持續脫位且**支架治療失敗**者，應行**閉鎖復位加關節攝影**，評估股骨頭能否在 **Ramsey safe zone**（維持復位所需的**最小外展與屈曲範圍**）內復位。**牽引（traction）**讓**攣縮肌肉溫和延展**後再復位；亦可對**腰大肌與內收肌**做**軟組織延長**以利復位並**擴大 safe zone**。**同心復位後**上 **hip spica 石膏 4 至 6 週**，之後**重複髖關節攝影**確認復位維持，再**重複上石膏**；其後穿戴 **abduction brace 直到影像上髖臼發育不良緩解**。


| 長期結果比較 | 原文數據 |
|--------------|----------|
| **2021 年現代演算法研究（10 年追蹤）** | **閉鎖復位**（即便疾病較輕）**需要二次手術的比率顯著高於開放復位：47% vs. 30%** |
| **Iowa group 長期結果** | **閉鎖復位**者**平均 48 年後有 50% 的髖接受 THA**；**年長者的雙側病變**手術風險更高 |
| **開放復位後之 THA** | 某研究顯示 **54%** 的病人在**平均 45 年後**接受 THA |

**開放復位與骨盆截骨**：股骨頭**無法在 safe zone 內同心復位**時，需**開放復位**去除所有**復位阻礙**。**Anteromedial approach** 通常用於 **1 歲以下**嬰兒，可**更直接接近復位阻礙**；**體位擺放容易、失血量少**，最適合**雙側脫位**；**須小心靠近內側股骨回旋動脈（medial femoral circumflex artery）**；若未做 **ligamentum teres 重建**，復位穩定性**取決於「human position」的 hip spica**。**Anterior approach** 用於 **12 個月以上**兒童，並**加上 capsulorraphy（關節囊縫合）**以增加穩定性。**行走年齡以後**可能需要**股骨短縮截骨**以降低張力、協助復位並**降低骨壞死風險**；同時可**矯正過度的股骨前傾**。**18 個月以後**可**合併骨盆截骨**。髖臼發育不良的**重塑主要發生在最初 4 年**，**4 歲以後變化極小**，故**嚴重發育不良者可能需要骨盆截骨**。

| 骨盆截骨 | 類型 | 原文重點 |
|----------|------|----------|
| **Salter innominate osteotomy** | **旋轉性完全截骨** | 以**恥骨聯合**為支點，**平均可獲得 15° 前方覆蓋與 25° 外側覆蓋** |
| **Pemberton osteotomy** | **不完全截骨** | 以**開放的三輻狀軟骨**為支點；**同時破壞內外側骨板**，**止於坐骨大孔之前**，形成**後方支點**以獲得更多**前外側覆蓋** |
| **Dega osteotomy** | **不完全截骨** | **破壞的內側骨板較少**，**最適合需要更多外側覆蓋**者 |


**併發症**：**髖關節復發脫位**是 DDH 處理中最令人恐懼的併發症之一，處理取決於**根本原因**；**治療後早期復發脫位**者必須先**排除任何技術性或術中操作錯誤**，若有發現**應立即處理**。**Meta-analysis 顯示以下因素並未增加骨壞死風險**：**開放或閉鎖治療**、**延遲治療至 1 歲**、**手術入路（前側 vs. 前內側）**。關於 **ossific nucleus（骨化核）**，歷史上對其是**保護性**或**增加骨壞死風險**有爭議，meta-analysis 顯示**嬰兒期 DDH 治療中存在骨化核並未增加骨壞死風險**；部分學者建議以 **perfusion MRI** 評估股骨頭灌流。

### 3.2 青少年與年輕成人髖關節發育不良的治療

青少年髖關節發育不良的治療取決於**發育不良嚴重度、是否合併關節炎、以及病人症狀與活動程度**。到青少年期，**髖關節已不再保有重塑所需的塑性**，故**手術介入往往必需**。

| 情境 | 處置 | 原文重點 |
|------|------|----------|
| **症狀性發育不良（尤其半脫位）的非手術治療** | — | **成功率較低**；因**已知有過早關節炎的風險**，可能導致**早期關節置換** |
| **輕度髖臼發育不良且有症狀、病人希望避免手術** | **抗發炎藥物**、**核心肌與髖外展肌強化物理治療**、**活動調整** | 可**短期緩解症狀** |
| **無關節炎的青少年發育不良** | **骨盆截骨**改善**關節相稱性與穩定性** | 為大多數病人的處置 |
| **關節內軟骨與唇狀病變** | **髖關節鏡**作為**輔助治療** | **單獨以關節鏡作為 DDH 的確定性治療並無良好支持**，因**無法處理根本的骨性髖臼缺損與版本異常**；**對 pincer 病灶行 osteochondroplasty 可能增加髖關節不穩** |
| **關節鏡合併 PAO** | 2019 年研究：**術後 5 年**所有病人的**病人報告結果與疼痛分數皆改善**，**無人轉為 THA** | 但**長期追蹤下 THA 的比率會上升** |

**骨盆重建截骨**：**Steel、Sutherland 與 Dial 截骨**皆曾用於**封閉三輻狀軟骨**但**各有其限制**；**Ganz PAO** 是**骨骼成熟後最常用的截骨**，使用**三個完全截骨**、**保留後柱**，可進行**多方向矯正**。**股骨截骨**可改變**近端股骨的 varus 或 valgus 排列**以改變**受損軟骨上的應力**，但**很少單獨使用**，可在**骨盆截骨之後**改善**活動度與關節相稱性**，因為**相對股骨後傾**會大幅限制髖活動。長期數據：**PAO 10 年與 20 年存活率為 86% 與 60%**；**PAO 失敗的風險因子為年齡較大與 Ténnis 分級較高**；在**高流量關節置換中心**的研究中，既往有骨盆截骨者接受 THA 時**需要更多植骨、更多螺釘固定、手術時間更長、出血更多**。


### 3.3 SCFE 的治療

現代 SCFE 治療為**骨骺的手術固定**，目標是**提供穩定性以保護後方韌帶血管（posterior retinacular vasculature）**，同時**將併發症（軟骨溶解、骨壞死、病情進展）風險降到最低**。**經皮原位固定**為**穩定型 SCFE 的首選治療**；**單支空心螺釘**須**置於骨骺中心、與骺板垂直，且正側位影像上至少有 5 個螺紋跨越骺板**，即可提供良好穩定性且**併發症最少**。這是歷史上單支螺釘固定的**必然結果（骨骺阻滯）**；2021 年研究討論**伸縮式固定（telescoping fixation）**以**限制腿長差**並**減少年輕病人後續追加手術**，部分外科醫師更以**植骨**方式骨骺阻滯以確保骺板閉合與穩定。


**不穩定型 SCFE** **管理困難、併發症風險較高**：**急性骨骺位移與相關血腫（hemarthrosis）使後方韌帶血管處於風險中**，**多數外科醫師主張在 24 小時內介入**。處理選項包括**自然復位加經皮雙螺釘固定**、**血腫減壓**（以減輕對骨骺灌流的**壓迫效應 tamponade effect**）與**術中灌流監測**；**序列放射影像、觀察等待骨壞死徵象、術後骨掃描或 perfusion MRI** 亦**逐漸獲得支持**。**前方或前外側入路開放手術加部分輕柔徒手復位**已有報告**僅 4.7% 的骨壞死發生率**；**modified Dunn procedure** 則是建立**保護血管的 retinacular flap** 後復位骨骺，雖原始結果令人鼓舞，但研究報告**不穩定型 SCFE 有 26% 至 29% 的骨壞死率**，另一研究顯示**滑移越嚴重、骨壞死風險越高，總發生率達 37%**。


**對側髋的預防性固定**：有報告指出**三分之一**的病人在**指徵性 SCFE 後 18 至 24 個月內**出現**雙側或後續對側滑脫**。**女孩 <10 歲**與**男孩 <12 歲**風險較高；**Modified Oxford score**（考量髖周圍多個骨化中心）是**最佳預測因子**；**posterior slope** 取自 **frog-leg 側位**，為骨骺相對於**垂直於股骨頸長軸之直線**的傾斜度，**健側 >15° 至 18° 即建議對側固定**。**體重高於正常者**，以及 **Down syndrome** 或**內分泌疾病**病人，**建議預防性固定**；某研究結論指出這在**高危病人中是財務上合理的**。

初次滑脫與固定後，**股骨骨幹的殘餘變形**可導致**軟骨損傷與過早骨關節炎**；**SCFE 續發的症狀性 FAI 應加以矯正**，**尤其在重度滑脫者**。矯正層級依位置由骨骺向遠端排列：**骨骺層級為 capital realignment（surgical hip dislocation 與 modified Dunn）**、**股骨頸層級為 Kramer 與 Barmada**、**轉子間層級為 Imhauser（屈曲）或 Southwick（屈曲與外翻）**、**股骨轉子下截骨**，另可使用 **osteochondroplasty**。


### 3.4 LCP 的治療

**包容治療（containment）**：目標是**包容髖關節並保存活動度**，以**將殘餘股骨頭變形降到最低**。利用**年幼時股骨頭的可塑性**，**讓頭部保持在凹陷的髖臼內**，理想上可**維持股骨頭的球形（sphericity）**。某研究顯示**股骨頭外移與髖臼發育不良改變之間存在相關性**：**股骨頭相對於髖臼的位置會影響髖臼的生長與發育**。**包容的達成方式**包括**內收肌延長（adductor lengthening）**、**Petrie 石膏固定**後接 **A-frame 支具**。**必須保留髖外展至少 30°**，以**降低頭部被擠出（head extrusion）的風險**。軟組織手術、治療與支具可**避免股骨截骨相關的肢體縮短與外展肌功能障礙**；但**支具持續時間長，對病人與家庭可能笨重**。


**支具失敗後的手術**：支具管理失敗後**沒有公認可接受的統一演算法**：部分外科醫師偏好**股骨 varus derotational osteotomy（VDRO）**，另有部分偏好**骨盆截骨（Salter、triple、shelf）**以提供包容。**股骨頭與骨幹的大部分變形與外側擠出發生在碎裂期**，某研究因此建議**在進行性碎裂發生前施行 VDRO**，以**縮短碎裂期長度**並**改善股骨頭的球形**；**2020 年研究**再次證實 VDRO 者**碎裂期較短、外側柱變窄較少**，但**只有少數病人完全跳過碎裂期**。**Salter 或 Triple** 是有效的包容介入方式；**Shelf 與 Chiari 截骨**屬**關節外（extracapsular）**手術，同樣可**增加外側頭部覆蓋**。回顧性研究顯示**股骨＋Salter 聯合截骨**與**單獨骨盆截骨**或**單獨 VDRO** 相比，**結果無差異**。

**年齡與結果**

| 年齡層 | 原文結果 |
|--------|----------|
| **<6 歲起病** | **80% 有良好結果**，不論手術或非手術；**lateral pillar A 或 B** 尤其如此。**4 至 6 歲**病人若屬 **lateral pillar B/C 或 C**，**較可能結果不佳**。但**並非所有 <6 歲病人都良好**——**每 5 例中有 1 例**為 **Stulberg III 或更差的結果** |
| **6 至 8 歲起病** | 多中心研究顯示**手術（68% 至 69% 成功率）與非手術（支具，62% 成功率）間無顯著差異**；2020 年研究顯示此年齡層**支具效果不如骨盆截骨**——6 至 8 歲行骨盆截骨者在骨骼成熟時**股骨頭外移較少**，且 **acetabular index、Sharp angle 與髖臼深度／寬度比值較佳**；但**兩組在髖痛與活動度上無差異** |
| **>8 歲起病** | **髖臼重塑潛力較少**。前瞻性多中心研究顯示：**lateral pillar C** 病人手術與非手術管理**結果無差異**；但**lateral pillar B 或 B/C** 病人**確有臨床效益，但幅度有限** |


**Hinged abduction 與殘餘畸形重建**：**Hinged abduction（鉸鏈式外展）**是**擠出的股骨頭在髖外展時以髖臼外側為支點鉸動**的獨特現象；**股骨頭一旦變形後，沒有任何手術被證明是對 hinged abduction 的最佳解法**。選項包括**產生 valgus 的截骨**、**hip arthrodiastasis**（透過**外固定架**）、**surgical hip dislocation 合併 osteochondroplasty**，以及**femoral head reduction osteotomy**（早期結果令人鼓舞，但**手術困難，長期結果尚待釐清**）。

| LCP 殘餘變形情境 | 處置 | 原文數據 |
|----------------|------|----------|
| **殘餘變形** | **Osteochondroplasty**（**關節鏡或開放**），將股骨頭塑回正常或至少**與髖關節相稱** | — |
| **大轉子過高與相對 coxa vara** | **相對股骨頸延長（relative femoral neck lengthening）** | — |
| **兩者合併手術** | 上述兩者合併 | **75% 報告症狀改善，僅 10% 需要 THA** |
| **有髖關節不穩定的疑慮** | 行 **PAO（髖臼周圍截骨）** | — |
| **已合併骨關節炎** | **標準手術為關節置換**，可**增加患側肢體長度** | 2021 年研究：**98.4% 無需翻修**，平均**延長患側 1.4 cm**，**無神經麻痺**，術後 **Harris hip score 85.3**；但 **20 年追蹤**研究報告 **THA 整體存活率僅 70%** |


### 3.5 FAI 的治療

**第一線管理應為非手術治療的試驗**：**活動調整**（**避免加重髖部症狀的動作，尤其是屈曲超過 90°**）、**物理治療**與**非類固醇消炎藥（NSAIDs）**。**症狀性 FAI 合併軟骨唇狀病變**可受益於**髖關節鏡或開放手術**；FAI 可導致**髖關節骨關節炎**，但**治療可減少軟骨退變**。一項**隨機對照試驗**發現**髖關節鏡與物理治療皆能改善症狀性 FAI 的生活品質**，但**關節鏡的結果較佳**。中期追蹤比較**關節鏡**與 **surgical hip dislocation**：**兩者結果皆良好，關節鏡組 93%、開放組 90%**；**唯一有統計顯著差異的是一般健康生活品質分數（關節鏡組較高）**。當**軟骨唇狀病變合併嚴重 cam 畸形、髖關節發育不良與／或不穩**時，**關節鏡很可能不足**。**存在軟骨損傷或骨關節炎**是**治療失敗的最強預測因子**；轉為 THA 的風險與**年齡較大**、**症狀持續超過 1.5 年**、**Harris Hip Score 較差**相關。

## 4. 陷阱與爭議 (Pitfalls & Controversies)

### 4.1 治療時機與分型判讀的陷阱

| 陷阱／爭議 | 原文說明 |
|------------|----------|
| **DDH 治療後不再追蹤** | **即使嬰兒期治療成功，殘餘髖臼發育不良的風險仍在**，必須**追蹤至骨骼成熟** |
| **Pavlik harness 拖太久** | **3 至 4 週無改善**仍繼續使用，只會**延後必要的復位手術**；**股神經麻痺本身即是治療失敗的預警訊號** |
| **SCFE 穩定性的定義** | 臨床穩定性**與術中穩定性不一致**：58 例可步行者中 **17 例**術中不穩定；24 例不可負重者中 **13 例**術中穩定 |
| **SCFE 骨壞死率** | 早期研究報告**不穩定髖 47%**、穩定髖 0%；**較新的文獻約為 23.9%** |
| **Modified Dunn 的骨壞死率** | 原始結果令人鼓舞，但後續研究報告**不穩定 SCFE 26% 至 29%**；另一研究**總發生率 37%** |
| **SCFE 不穩定型延後介入** | 多數外科醫師主張**24 小時內介入**；血腫的**壓迫效應**會傷害骨骺灌流 |
| **LCP 的 Herring 分型使用時機** | 依**外側柱高度**的分類**僅在碎裂期可靠**，需**連續放射影像**，**可能錯過較不侵入性治療的時機窗** |
| **LCP 過度依賴年齡** | 原文特別澄清：**並非所有 <6 歲病人都良好**——**每 5 例中 1 例為 Stulberg III 或更差** |
| **LCP 手術 vs. 支具（6 至 8 歲）** | 多中心研究：**68% 至 69% vs. 62%，無顯著差異**；但 2020 年研究顯示**支具不如骨盆截骨** |
| **LCP 關節置換的長期代價** | 5 年存活率 **98.4%**，但 **20 年僅 70%** |
| **FAI 的手術方式** | 關節鏡 vs. 開放：**93% vs. 90%**，僅**一般健康生活品質**有顯著差異；關節鏡在**嚴重 cam 畸形＋發育不良／不穩**時**很可能不足** |

### 4.2 術式選擇的地雷

各術式的併發症、風險數值與技術注意事項已整合於第 3 節治療表格；決策時須同時衡量復位穩定性、骨壞死、殘餘畸形及長期關節置換風險。

### 4.3 需要與病人及家屬長期溝通的議題

長期溝通應涵蓋 DDH 追蹤至骨骼成熟、SCFE 對成年功能的影響，以及 LCP 漫長病程、外觀與症狀不一致及未來關節置換可能性。

## Summary

小兒髖部疾病的共同主線是**早期辨識**：DDH 在嬰兒期介入效果最好，Pavlik harness 對穩定型約 **90%**、Ortolani 陽性約 **73%** 有效，但 **3 至 4 週無改善即應停用**並轉向復位手術，且**治療後仍須追蹤至骨骼成熟**以監測殘餘髖臼發育不良；閉鎖復位須以**關節攝影確認 Ramsey safe zone** 並配合 spica 石膏，其**10 年二次手術率 47%**、**48 年後 50% 需 THA**。

青少年髖關節發育不良以 **LCEA <20°** 或 **Ténnis 角 >10°** 定義，**FEAR index <5°** 提示穩定髖，**Ganz PAO** 為骨骼成熟後最常用術式（**10 年存活 86%、20 年 60%**）。SCFE 治療以**穩定型原位固定**（單支空心螺釘、**至少 5 個螺紋跨越**）為首選，**不穩定型需 24 小時內介入**但 modified Dunn 骨壞死率達 **26%–29%**，並以 **Modified Oxford score** 與 **posterior slope >15°–18°** 決定對側預防性固定。LCP 的治療核心是**包容**，**外展至少 30°**，預後與起病年齡高度相關（**<6 歲 80% 良好、6 至 8 歲手術與支具無顯著差異、>8 歲重塑受限**），續發骨關節炎的 THA **20 年存活率僅 70%**。最後，**FAI 第一線為非手術治療**，**軟骨損傷與骨關節炎是失敗的最強預測因子**。
