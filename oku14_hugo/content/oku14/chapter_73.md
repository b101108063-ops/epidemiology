# Chapter 73: Metastatic Tumors of Bone — 骨轉移性腫瘤

## 章節導讀

成人破壞性骨病灶最常見的原因是轉移性癌或血液惡性腫瘤；骨科醫師的任務不只是固定骨折，而是先確認診斷、估計存活與骨折風險，再整合全身治療、放療及耐久重建。本章由腫瘤—骨微環境出發，建立未知原發癌評估、原發癌別矩陣、長骨與脊柱處置，以及避免災難性誤治的實務路徑。

---

## 1. 核心生物學、臨床評估與分期 (Biology, Evaluation and Staging)

### 1.1 骨轉移的惡性循環

轉移細胞並非只被動占據骨骼，而是利用骨重塑形成自我增強的微環境。腫瘤細胞釋放副甲狀腺素相關蛋白等溶骨訊號，促使成骨細胞增加 <span style="color:#e2e8f0">RANKL</span>；RANKL 刺激破骨細胞生成與骨吸收，骨基質因此釋出轉化生長因子 β 等因子，再反向促進腫瘤細胞產生副甲狀腺素相關蛋白。結果是骨吸收、血管新生與侵襲性生長彼此放大。

| 循環環節 | 來源描述 | 臨床意義 |
|---|---|---|
| 腫瘤訊號 | 副甲狀腺素相關蛋白影響 RANK／RANKL 路徑 | 促使破骨細胞活化，形成溶骨病灶 |
| 成骨細胞反應 | 成骨細胞釋放 RANKL | 連結腫瘤細胞與破骨細胞生成 |
| 骨吸收 | 破骨細胞增加骨質吸收 | 疼痛、結構弱化與病理性骨折風險上升 |
| 骨基質回饋 | 骨吸收釋出並活化轉化生長因子 β | 再刺激副甲狀腺素相關蛋白，使循環持續 |
| 臨床終點 | 血管新生、骨破壞與侵襲性生長增加 | 支持放療、骨修飾藥物及穩定手術的整合策略 |

<!-- FIG: 腫瘤細胞透過副甲狀腺素相關蛋白、RANKL、破骨細胞與轉化生長因子 β 形成骨破壞惡性循環 -->

> **Pearl**：平片上的溶骨或成骨外觀反映不同腫瘤生物學，但影像型態不能取代組織診斷；同一病人也可能有混合型病灶。

### 1.2 病史與理學檢查：區分腫瘤痛與機械痛

病人常以逐漸加重、負重時明顯的疼痛就醫。持續休息痛可直接源自腫瘤；特別由負重誘發的疼痛則提示病灶已削弱骨骼，必須警覺即將發生的病理性骨折。詢問既往與家族癌症史時，不能因原發癌已緩解多年而排除轉移，尤其乳癌、腎細胞癌與攝護腺癌可在多年後才出現骨病灶。

病史還應尋找常見原發癌線索，例如乳房腫塊、攝護腺肥大相關頻尿、疲倦、非預期體重減輕，以及吸菸、環境暴露等危險因子。檢查可能見跛行、保護性姿勢或關節活動疼痛。對轉子周圍病灶，抗重力直腿抬高會讓髖關節承受超過體重兩倍的負荷；若此動作完全無痛，對即將骨折相對令人放心，但不能單獨否定影像所示的高風險破壞。

| 評估問題 | 來源線索 | 決策用途 |
|---|---|---|
| 疼痛是否與負重直接相關？ | 機械性疼痛提示骨骼弱化 | 決定保護負重、骨折評分與預防固定需求 |
| 是否有持續休息痛？ | 可由腫瘤本身造成 | 支持局部放療、藥物與疼痛專科共同處置 |
| 是否曾罹癌且長期緩解？ | 乳癌、腎癌、攝護腺癌可晚期轉移 | 不因時間久而排除轉移，但仍須取樣 |
| 是否能無痛直腿抬高？ | 動作跨髖負荷逾體重兩倍 | 無痛僅降低轉子周圍即將骨折的疑慮 |
| 是否有步態、活動或神經改變？ | 跛行、護肢、活動痛或神經症狀 | 導向長骨穩定、脊柱緊急評估或輔具安排 |

> **Danger zone**：把所有癌症病人的新骨痛都視為「已知轉移」會漏掉第二種惡性腫瘤或原發骨腫瘤；診斷捷徑可能使後續保肢機會消失。

### 1.3 系統性評估路徑與 85% 診斷率

對疑似骨轉移，尤其 40 歲以上成人的破壞性骨病灶，來源建議依序整合病史與理學檢查、受累整根骨的兩個正交平面平片、實驗室檢查、胸部／腹部／骨盆 CT、全身骨掃描，最後對最容易且適當的病灶進行切片。這套標準路徑可在 <span style="color:#34d399;font-weight:600">85%</span> 病人得到正確診斷與原發位置。

| 步驟 | 必須回答的問題 | 對後續處置的影響 |
|---|---|---|
| 病史與檢查 | 是腫瘤痛、機械痛、神經壓迫，還是其他病因？ | 判斷緊急程度、負重限制與可能原發癌 |
| 整根骨雙平面平片 | 病灶為溶骨、成骨或混合型？是否已有骨折？ | 評估結構破壞、規劃植入物涵蓋範圍 |
| 實驗室 | 是否有高血鈣、貧血、腎功能問題、骨髓瘤或感染線索？ | 縮小鑑別並辨識麻醉與治療風險 |
| 胸／腹／骨盆 CT | 胸腔、後腹腔或骨盆是否有原發腫瘤與內臟轉移？ | 提供分期、預後與可取樣病灶 |
| 全身骨掃描 | 是孤立病灶或廣泛骨轉移？ | 影響手術姿勢、插管、負重與其他骨折預防 |
| 最易取得病灶切片 | 組織究竟是轉移癌、血液腫瘤或原發骨腫瘤？ | 在任何污染性固定前建立確診 |

<!-- FIG: 疑似骨轉移的標準流程，由病史、平片、實驗室、胸腹骨盆 CT、全身骨掃描至最易取得病灶切片 -->

> **Pearl**：檢查不是一串互相取代的選項；它們分別回答結構、全身腫瘤負荷、原發位置與組織診斷，合併使用才達到 85% 的診斷效能。

### 1.4 影像選擇與限制

平片必須涵蓋整根受累骨並取得兩個正交平面。肺、甲狀腺、腎與胃腸道癌，以及多數造血系統惡性腫瘤，常呈透亮的溶骨性病灶；攝護腺與膀胱癌典型呈不透光的成骨性基質；乳癌則常為溶骨與成骨混合型。未知原發癌做胸／腹／骨盆 CT，是因常見骨轉移原發位置多在胸腔、後腹腔及骨盆。

鎝-99m 磷酸鹽骨掃描藉全身成骨活性估計骨轉移負荷，可區分孤立與廣泛疾病，也能找出需要保護負重、預防固定、改變手術擺位或插管方式的其他病灶。然而骨髓瘤與腎細胞癌可能缺少顯著成骨反應，假陰性率較高。全身 PET/CT 可一次評估轉移負荷並尋找原發癌，但來源研究顯示，它在未知原發骨轉移中並未優於標準路徑來找出原發癌。

| 原發／疾病 | 常見骨影像 | 特別限制或提示 |
|---|---|---|
| 肺癌 | 多為溶骨性 | 對肘、膝遠端的肢端轉移有獨特偏好 |
| 甲狀腺癌 | 多為溶骨性 | 病灶高血管性，手術出血風險高 |
| 腎細胞癌 | 多為溶骨性 | 骨掃描可假陰性；病灶高血管性 |
| 胃腸道癌 | 多為溶骨性 | 仍須依全身分期與組織確認 |
| 造血系統惡性腫瘤 | 多為溶骨性 | 骨髓瘤骨掃描敏感度有限 |
| 攝護腺癌 | 典型成骨性 | 病灶可見鈣化、不透光基質 |
| 膀胱癌 | 典型成骨性 | 影像型態仍不取代切片 |
| 乳癌 | 常為混合型 | 骨轉移相較腦、肺、肝或多系統轉移預後較佳 |

<!-- FIG: 攝護腺癌骨轉移的成骨外觀與甲狀腺癌骨轉移的溶骨外觀比較 -->

> **Danger zone**：正常骨掃描不能可靠排除骨髓瘤或腎細胞癌骨病灶；PET/CT 也不應被當作跳過標準未知原發評估的捷徑。

### 1.5 實驗室檢查與組織診斷

全血球計數用於發現貧血與異常細胞分布；完整代謝檢查包括血清鈣、鹼性磷酸酶及乳酸脫氫酶，可辨識危險的高血鈣，也提供預後資訊。紅血球沉降率與 C 反應蛋白對排除成人破壞性骨病灶的另一原因——骨髓炎——具敏感性。血清與尿液蛋白電泳合用，對骨髓瘤具高敏感度與特異度：血清蛋白電泳可偵測約 <span style="color:#34d399;font-weight:600">80%</span> 骨髓瘤；另有 <span style="color:#fbbf24;font-weight:600">10%–15%</span> 僅產生輕鏈，必須靠尿液檢測增加敏感度，最終常以切片確認。

部分中心也會加入甲狀腺刺激素與游離甲狀腺素以評估甲狀腺癌，或以尿液檢查找腎細胞癌相關顯微血尿。這些檢查是線索，不是組織診斷的替代品。

任何非典型的孤立骨病灶均應切片。曾有局限癌症的病人若出現新骨病灶，該病灶有 <span style="color:#f87171;font-weight:600">15%</span> 機率是與原癌無關的惡性腫瘤。骨內擴髓後放入髓內器械，會污染整根骨與周邊軟組織，並有理論上的全身腫瘤播散風險。因此應在固定前做開放或粗針切片；若在同一次麻醉下處理，必須等待冷凍切片，結果不明確或疑似原發骨惡性腫瘤時立即中止固定。

> **Danger zone**：對未確診孤立病灶先擴髓再固定，是本章最嚴重的可避免錯誤；污染範圍可從局部病灶變成整根骨與周邊軟組織。

## 2. 原發癌別、骨病灶與預後矩陣 (Primary Tumor and Prognostic Matrix)

### 2.1 各原發癌的骨生物學與手術意義

不同原發癌造成的骨病灶，不只影響影像，也直接決定出血、放療反應、局部控制與固定耐久性。攝護腺癌細胞表現 endothelin-1，可直接刺激成骨細胞產骨，解釋其成骨性傾向。肺癌的副甲狀腺素相關蛋白則以類似乳癌的方式影響 RANK／RANKL，通常形成溶骨病灶。

腎細胞癌過度表現表皮生長因子受體、血管內皮生長因子受體及血小板衍生生長因子受體，病灶高度血管化；甲狀腺癌則因纖維母細胞生長因子與血管內皮生長因子過度表現而容易出血。骨髓瘤病灶也可因血管內皮生長因子表現而出血。這些病灶需在手術前主動規劃血液準備與栓塞可能性。

| 原發癌／疾病 | 典型骨行為 | 來源特有臨床重點 | 手術或局部控制含意 |
|---|---|---|---|
| 乳癌 | 常為混合型；RANKL 相關骨破壞 | 受雌激素、黃體素及 Her2-neu 受體狀態影響；骨轉移預後較其他轉移型態佳 | 全身治療依受體狀態；局部治療依疼痛與結構風險 |
| 攝護腺癌 | 典型成骨性 | endothelin-1 刺激成骨；可用外科去勢或荷爾蒙促效／拮抗劑做雄性素剝奪 | 仍可能疼痛、骨折或脊髓壓迫，不能因成骨外觀低估風險 |
| 肺癌 | 多為溶骨性，可見肢端轉移 | 生長因子抑制劑具角色；denosumab 相較 zoledronic acid 有特定證據 | 依預後選擇固定耐久度；肢端病灶亦須列入鑑別 |
| 腎細胞癌 | 溶骨、高血管性、放療與刮除反應不一 | 生長因子抑制劑具角色；孤立轉移切除優於刮除的存活結果 | 骨盆等部位術前栓塞；局部不足可能持續進展並使固定失敗 |
| 濾泡型甲狀腺癌 | 多為溶骨、高血管性 | 是甲狀腺癌中最常骨轉移的亞型；轉移顯著降低長期存活 | 考慮栓塞；巨大轉移可造成放射碘匯集效應而需切除 |
| 骨髓瘤／漿細胞瘤 | 紅骨髓豐富部位的溶骨病灶 | 疼痛、貧血、腎功能不全；年輕健康者可在化療外加幹細胞移植 | 骨掃描可漏診；高血管病灶考慮栓塞 |
| 骨淋巴瘤 | 骨破壞型態不一 | 依病理亞型存活不同，通常可治療且多對全身化療有反應 | RANKL 與血管內皮生長因子均參與骨破壞 |

> **Pearl**：原發癌別同時是生物學、手術風險與存活預測變項；固定策略不能只看「骨洞有多大」。

### 2.2 自然病程與存活預測

屍體解剖研究顯示，超過 <span style="color:#fbbf24;font-weight:600">70%</span> 的乳癌與攝護腺癌病人在死亡時已有骨轉移。因骨轉移常見、對總存活的影響通常低於腦、肺、肝或多系統轉移，且全身治療持續進步，骨轉移已成為癌症自然病程的常見部分。這也使手術目標從單純短期救援，轉向能立即使用且撐過病人剩餘生命的重建。

PATHFx 等工具可協助估計有症狀骨轉移病人的剩餘存活。各模型共同的重要因子包括內臟轉移、多發骨轉移、病理性骨折及原發腫瘤類型；模型只能支援判斷，不能取代共病、治療反應與照護目標。

| 預後因子 | 對存活的方向 | 對骨科策略的影響 |
|---|---|---|
| 內臟轉移 | 不利 | 避免恢復期漫長或無法及時負重的重建 |
| 多發骨轉移 | 不利 | 評估全身負荷、其他骨折風險與手術擺位 |
| 已完成病理性骨折 | 不利 | 多數仍固定，但併發症、住院與功能負擔較高 |
| 原發腫瘤種類 | 依腫瘤而異 | 決定放療敏感性、局部進展與植入物耐久需求 |
| 可用全身治療與治療反應 | 來源強調現代治療改善存活 | 預期較長存活者需避免短期構造日後失效 |
| 病人目標與共病 | 決定可承受手術範圍 | 在疼痛、功能、風險與恢復時間間取得平衡 |

> **Danger zone**：短預後不能成為忽略疼痛與穩定的理由；相反地，預後改善也意味著過於脆弱的短期固定可能在病人仍存活時失效。

### 2.3 非手術總體策略

完成診斷、預後與照護目標評估後，應由腫瘤科、放射腫瘤科、骨科、疼痛與復健團隊共同規劃。多數骨轉移病人會接受多種非手術治療；手術通常保留給非手術措施失敗、即將骨折、已骨折、神經功能惡化或無法控制的機械性疼痛。

癌症疼痛常比一般骨科疼痛複雜，可採多模式止痛、慢性疼痛專科及審慎使用長效止痛藥。下肢可用助行器限制負重並降低跌倒風險；上肢則可用支具保護病灶，部分病理性骨折亦可能在支具下癒合。選擇保守治療時仍需監測疼痛、功能、變形與神經變化，不能只安排一次追蹤。

> **Pearl**：輔具、支具與止痛並非「沒有治療」；對低骨折風險或手術負擔不相稱者，它們是以功能與安全為核心的積極處置。

## 3. 長骨骨折風險、固定門檻與重建策略 (Long-Bone Fracture Risk and Reconstruction)

### 3.1 為何要在骨折前辨識高風險病灶

肝膽惡性腫瘤、腎細胞癌與骨髓瘤較常以已完成病理性骨折就醫。骨轉移相關住院中，接近 <span style="color:#f87171;font-weight:600">5%</span> 涉及長骨已完成骨折的固定；相較預防性固定，骨折後手術住院更久、成本更高，病人早期疼痛較重、功能與腫瘤學結果較差，且 30 日重大術後併發症較多。

預防性固定可能伴隨存活優勢，但可能有選擇偏差：外科醫師較常替預期存活較久者預防固定。較低併發症、較短住院與較低成本仍支持及早辨識高風險病灶。

| 結果面向 | 預防性固定 | 已骨折後固定 |
|---|---|---|
| 疼痛與早期功能 | 較佳 | 疼痛較多、早期功能較差 |
| 30 日重大併發症 | 較低 | 較高 |
| 住院時間 | 較短 | 較長 |
| 直接醫療成本 | 較低 | 急性骨折處置顯著較高 |
| 存活 | 觀察研究可能較佳 | 較差，但可能受選擇偏差影響 |
| 手術本身風險 | 仍有擴髓與栓塞等風險 | 同時承擔骨折、失血與更差身體狀態 |

> **Pearl**：預防固定的理由不只在避免骨折本身，也在於讓病人以較低急性生理負擔恢復疼痛控制與活動能力。

### 3.2 Mirels 評分與其限制

Mirels 系統由 78 個轉移病灶的回溯資料建立，依影像外觀、病灶占骨幹直徑比例、部位與疼痛各給 1–3 分。總分 <span style="color:#fbbf24;font-weight:600">8 分以上</span> 應在放療前考慮預防性固定。後續研究顯示它在不同經驗程度的臨床人員間具有再現性，整體敏感度 91%，但特異度僅 35%，因此可能造成過度治療。

| 因子 | 1 分 | 2 分 | 3 分 |
|---|---|---|---|
| 影像外觀 | 成骨性 | 混合型 | 溶骨性 |
| 病灶占骨幹直徑 | 小於 1/3 | 1/3–2/3 | 大於 2/3 |
| 部位 | 上肢 | 下肢 | 轉子周圍 |
| 疼痛 | 輕微 | 中度 | 功能性疼痛 |

| 評分資訊 | 來源數字 | 解讀 |
|---|---|---|
| 建立樣本 | 78 個轉移病灶 | 回溯建立，外推時需保留臨床判斷 |
| 考慮固定門檻 | 總分 ≥8 | 應在放療前考慮預防固定，不是機械式自動開刀 |
| 敏感度 | 91% | 適合找出高風險病灶 |
| 特異度 | 35% | 偽陽性多，可能導致過度治療 |

多發性骨髓瘤專屬新評分納入較大病灶、較長病灶持續時間、疼痛與干骺端位置，2021 年研究顯示敏感度優於 Mirels 且特異度不劣。其他發展包括機器學習、CT 剛性分析、有限元素分析與淨效益分析。不論工具多精密，縱向研究仍指出<span style="color:#60a5fa;font-weight:600">骨痛可能是單一最重要預測因子</span>。

> **Danger zone**：Mirels 低特異度使「分數達門檻」不等於所有病人都該手術；原發癌、病灶進展、預後、疼痛與可承受風險仍須共同判斷。

### 3.3 手術共同原則：一次處理所有弱點

手術目標是減痛、改善功能、恢復穩定並預防或處理骨折。病人選擇須納入共病與化療、放療時序；手術應處理同一骨段所有弱化區。因治療、廢用與腫瘤均降低骨品質，常以 <span style="color:#e2e8f0">polymethyl methacrylate</span> 骨水泥提供立即穩定。

構造須兼顧立即可用與長期耐久。腎、甲狀腺與骨髓瘤等高血管病灶應考慮術前栓塞；能立即負重、快速恢復功能的方案通常優於數月復健。

> **Pearl**：轉移性骨病變的理想植入物，原則上應比病人活得更久；不要把骨癒合當作唯一穩定來源。

### 3.4 上肢：保留功能以支撐日常活動與移位

上肢骨轉移占骨病灶不到 20%，較下肢、脊柱與骨盆少，也較常能保守治療。但上肢疼痛或骨折會破壞日常活動、助行器使用與移位能力。肩胛骨與鎖骨較少受累，多數病人非手術治療結果良好。

肱骨是常見位置。刮除、骨水泥與鋼板內固定可提供高生物力學穩定；瀰漫性受累時可用髓內器械，並視情況加刮除或骨水泥。近端肱骨若高度粉碎或腫瘤廣泛，可切除後以半肩關節、反式全肩或模組式近端肱骨腫瘤假體重建，通常能良好止痛，但功能不一。肱骨幹廣泛破壞或既有植入物因局部疾病失控而失敗時，可選擇性使用節段金屬假體。遠端肱骨病灶少見且骨量有限，通常刮除、骨水泥配合一或兩塊關節周圍鋼板；模組式遠端肱骨假體可恢復長度與合理肘功能，但耐久度較低。

| 上肢位置 | 建議策略 | 主要限制 |
|---|---|---|
| 肩胛骨／鎖骨 | 多數可非手術治療 | 依疼痛與功能持續追蹤 |
| 近端肱骨局限病灶 | 刮除、骨水泥、鎖定鋼板，可加結構移植物 | 需跨越缺損並提供立即穩定 |
| 肱骨瀰漫受累 | 髓內固定，可合併刮除／骨水泥 | 固定前必須已有組織診斷 |
| 近端肱骨廣泛破壞 | 半肩、反式全肩或近端肱骨假體 | 止痛佳，功能結果不一 |
| 肱骨幹大段破壞／固定失敗 | 節段金屬假體 | 選擇性適應症，手術負擔較大 |
| 遠端肱骨 | 刮除、骨水泥、一或兩塊關節周圍鋼板；必要時假體 | 骨量與重建選項有限，假體耐久較低 |
| 前臂、腕、手 | 依解剖位置個別化，常可保守 | 手術利益須超過局部處置負擔 |

> **Danger zone**：上肢不是「非負重所以不重要」；失去上肢支撐會讓病人無法使用助行器或完成床椅移位。

### 3.5 股骨頸與近端股骨：選擇假體或髓內固定

股骨頸承受高機械應力，廣泛病灶若局部進展，內固定容易失敗，因此常使用假體重建。多數轉移病人的活動需求與存活有限，半髖關節通常足夠；較活躍者、已有退化性關節炎或髖臼受累者，可選全髖關節。過去偏好長柄骨水泥植入物以保護盡可能多的股骨，但近年資料指出長柄有心肺併發症、技術困難與日後翻修挑戰；病灶局限且風險高者，短柄可能合理。

轉子間與轉子下區同樣容易因機械負荷骨折，多數可用含頭頸螺釘的髓內固定保護股骨頸。若骨破壞廣泛、病灶抗放射、已完成骨折或既有固定失敗，可切除後使用 calcar-replacing 假體或模組式近端股骨腫瘤假體。

| 近端股骨情境 | 優先考量 | 來源理由 |
|---|---|---|
| 廣泛股骨頸病灶 | 假體重建 | 局部進展時內固定易因機械力失敗 |
| 一般低需求、有限存活 | 半髖關節 | 多數情境已能提供適當重建 |
| 活動較高、既有關節炎或髖臼受累 | 全髖關節 | 同時處理髖臼與關節面需求 |
| 局限病灶且心肺風險高 | 可考慮短柄 | 避免長柄骨水泥相關心肺與技術負擔 |
| 轉子間／轉子下多數病灶 | 頭髓釘 | 穩定病灶並保護股骨頸 |
| 廣泛破壞、抗放射、已骨折或固定失敗 | 切除加近端股骨假體 | 提供較耐久且立即穩定的重建 |

<!-- FIG: 腎細胞癌轉子間大型轉移廣泛切除後，以骨水泥近端股骨置換與全髖關節重建 -->

<!-- FIG: 甲狀腺癌轉子間即將病理性骨折，以長型頭髓釘預防性固定 -->

> **Pearl**：股骨頸病灶與轉子區病灶不能套用同一固定方式；前者常需假體，後者多可用頭髓釘，但廣泛破壞與局部控制不佳時仍應升級為切除重建。

### 3.6 股骨幹、遠端股骨與脛骨

股骨幹病灶通常使用髓內釘。若股骨頭頸未受累，來源顯示可安全使用不含頭頸保護構件的髓內釘，因之後出現股骨頸病灶相對少見。遠端股骨多以鎖定鋼板螺釘固定，空腔性缺損加骨水泥；特定型態可用逆行髓內釘，但缺點是可能把腫瘤帶入膝關節，並在近端股骨的植入物末端造成應力集中。

脛骨、踝與足部轉移較少，須依大小與位置個別化。脛骨髓內釘可保護整根脛骨；小型局部病灶則可刮除、骨水泥並以鋼板螺釘固定。

| 部位 | 常用重建 | 陷阱 |
|---|---|---|
| 股骨幹 | 髓內釘 | 診斷不明時不可先擴髓；需涵蓋所有弱化區 |
| 股骨幹且頭頸正常 | 可不加頭頸構件 | 先確認頭頸確實未受累 |
| 遠端股骨空腔病灶 | 刮除、骨水泥、鎖定鋼板跨越缺損 | 構造須有足夠跨度與即時穩定 |
| 遠端股骨特定型態 | 逆行髓內釘 | 可能污染膝關節，近端形成應力集中 |
| 脛骨瀰漫或長段風險 | 脛骨髓內釘 | 需評估整根骨與軟組織狀況 |
| 脛骨小型局部病灶 | 刮除、骨水泥、鋼板螺釘 | 依病灶位置個別化 |

<!-- FIG: 遠端股骨胰臟癌大型溶骨病灶，以刮除、骨水泥鋼筋式重建及外側鎖定鋼板跨越股骨 -->

> **Danger zone**：逆行釘雖可處理部分遠端股骨病灶，卻可能造成膝關節腫瘤外溢；必須把污染路徑納入手術選擇。

## 4. 脊柱與骨盆轉移處置 (Spine and Pelvic Metastases)

### 4.1 脊柱：神經惡化即需緊急升級

脊柱轉移常可用放療、全身化療與雙磷酸鹽非手術處理；但任何進行性神經缺損都應考慮手術和／或緊急放療。進行性神經缺損的危險因子包括溶骨病灶、椎弓根受累，以及後柱受累。椎弓根病灶可在平片呈現 <span style="color:#e2e8f0">winking owl sign</span>。

明顯或進行性神經缺損是手術適應症；難治性疼痛或非手術治療下變形仍惡化者也應考慮手術。術式取決於病灶位置、變形及病人能安全承受的範圍，可包括前路椎體切除、後路減壓加器械固定，或前後路合併手術。

| 脊柱情境 | 來源建議 | 緊急程度／目的 |
|---|---|---|
| 無進行性神經缺損且症狀可控 | 放療、全身治療、雙磷酸鹽 | 控制疼痛與局部疾病，持續監測 |
| 溶骨、椎弓根或後柱受累 | 提高對神經惡化的警覺 | 密切追蹤神經功能與穩定性 |
| 進行性神經缺損 | 手術和／或緊急放療 | 避免不可逆神經損害 |
| 明顯神經缺損 | 手術適應症 | 減壓並依需要恢復穩定 |
| 難治性疼痛或變形持續進展 | 考慮手術 | 改善疼痛、穩定與照護功能 |
| 前柱廣泛受累 | 可需前路椎體切除 | 去除壓迫、重建前柱 |
| 後方壓迫／不穩 | 後路減壓與器械固定 | 神經減壓與穩定 |
| 複雜多柱病灶 | 可需前後路合併 | 依病人承受度調整手術範圍 |

> **Danger zone**：進行性神經症狀不是常規門診追蹤事項；必須立即協調脊柱外科與放射腫瘤團隊，因延誤可能造成永久功能喪失。

### 4.2 骨盆非負重區與髖臼周圍病灶

骨盆非負重區病灶常可用放療、雙磷酸鹽或 denosumab 與化療處理，骨性結構可能隨時間重建。依位置與症狀，選擇性個案可用經皮骨水泥成形術，或有限開放切除／刮除。

髖臼周圍病灶則因負重與骨缺損形成特殊挑戰，治療取決於破壞範圍。低功能需求且劇痛者可考慮非重建性的 Girdlestone 切除關節成形術，或有限重建如坐骨股骨融合。其他選項包括標準髖關節置換、翻修型髖臼組件與 cup-cage 構造、Harrington 型骨水泥／鋼筋構造，以及腰薦骨盆固定。

| 骨盆位置／需求 | 治療選項 | 決策重點 |
|---|---|---|
| 非負重區、症狀可控 | 放療、骨修飾藥物、化療 | 可能隨時間出現骨性重建 |
| 局部疼痛且適合微創 | 經皮骨水泥成形 | 選擇性使用，依病灶位置與症狀 |
| 局部可處理病灶 | 有限開放切除／刮除 | 平衡局部控制與手術負擔 |
| 嚴重疼痛、低功能需求 | Girdlestone 或坐骨股骨融合 | 以止痛與照護便利為目標 |
| 可重建髖臼缺損 | 標準或翻修型髖關節組件、cup-cage | 依剩餘骨量與缺損範圍選擇 |
| 廣泛髖臼周圍破壞 | Harrington 型骨水泥／鋼筋或腰薦骨盆固定 | 取得立即且可負重的穩定 |

來源病例以四支 6.5 mm 部分螺紋後柱螺釘、骨水泥、骨水泥型髖臼杯與股骨柄重建乳癌造成的近端股骨及髖臼病灶。另一系列的部分骨盆籠架加骨水泥全髖構造，在 4 年時再手術／翻修率為 <span style="color:#fbbf24;font-weight:600">16%</span>，顯示這類重建雖可用，仍需依預期存活評估耐久度。

> **Pearl**：骨盆病灶要先區分是否位於負重髖臼；非負重區可等待全身治療與放療反應，髖臼結構失效則常需立即負重的機械重建。

## 5. 放療、全身治療、骨修飾藥物與消融 (Radiation, Systemic and Ablative Therapy)

### 5.1 腫瘤專一全身治療

細胞毒性化療是多數播散癌症治療主軸，但部分疾病有特異性策略。乳癌依分期與雌激素、黃體素及 Her2-neu 受體狀態選擇治療，受體狀態同時影響預後。攝護腺癌可經睪丸切除和／或荷爾蒙促效劑、拮抗劑做雄性素剝奪。轉移性肺癌與腎癌對生長因子抑制劑特別敏感；骨髓瘤可接受化療，年輕且健康者另可加入幹細胞移植；淋巴瘤通常對全身化療反應良好。

> **Pearl**：骨科局部處置必須配合疾病專一全身治療時序；同樣的骨洞，在可快速縮小的淋巴瘤與局部持續進展的腎細胞癌，耐久策略不應相同。

### 5.2 外照射與放射性藥物

外照射是骨轉移主要治療，可單獨使用或輔助手術，適應症包括疼痛、即將發生的病理性骨折及進行性神經症狀。2019 年隨機試驗顯示，單次立體定位放射治療在疼痛反應上不劣於傳統多次分割外照射。

長骨完成固定後，應等待傷口癒合再放療；照射範圍要涵蓋整個植入物所及區域，以改善局部控制並降低固定失敗。播散病灶造成的疼痛若對其他措施無效，可考慮放射性藥物。samarium-153 或 strontium chloride-89 可把放射送達全骨骼，並已核准用於攝護腺癌、骨肉瘤等疼痛性骨轉移；iodine-131 常用於轉移性甲狀腺癌。大型甲狀腺轉移灶若吸收大量放射碘而妨礙原發癌有效治療，可考慮切除該轉移灶。

| 放射方式／情境 | 來源用途 | 重要時序或限制 |
|---|---|---|
| 傳統外照射 | 疼痛、即將骨折、神經症狀 | 高機械性骨折風險仍需先評估固定 |
| 單次立體定位放療 | 以疼痛反應評估，不劣於多次分割 | 證據針對以非脊柱骨轉移為主的病人 |
| 長骨術後放療 | 改善局部控制、降低固定失敗 | 傷口癒合後進行，涵蓋整個植入物區域 |
| samarium-153／strontium chloride-89 | 播散且其他措施難控的全骨骼疼痛 | 用於特定疼痛性骨轉移疾病 |
| iodine-131 | 轉移性甲狀腺癌 | 巨大轉移造成匯集效應時可先切除 |

> **Danger zone**：對結構即將失效的長骨只做放療，可能來不及防止骨折；固定與放療不是互斥選項，而須依機械風險安排先後。

### 5.3 雙磷酸鹽與 denosumab

每位骨轉移病人均應考慮雙磷酸鹽或 <span style="color:#fb923c">denosumab</span>。雙磷酸鹽抑制破骨細胞，降低骨骼相關事件並減少疼痛，最常用靜脈藥為 <span style="color:#fb923c">zoledronic acid</span>。骨骼相關事件包括病理性骨折、臨床明顯脊髓壓迫、因疼痛或即將骨折而需要骨放療，以及需要預防性手術。

雙磷酸鹽主要併發症是顎骨壞死、偶發腎毒性及長期使用後的非典型股骨骨折；現代藥物的顎骨壞死風險較低。denosumab 是抗 RANKL 人類單株抗體，以皮下注射每月到每 3 個月給藥。它在轉移性乳癌與肺癌延後骨骼相關事件方面優於 zoledronic acid；對骨髓瘤與其他癌症延後事件不劣於 zoledronic acid；在肺癌資料中整體存活優於 zoledronic acid。

| 比較項目 | 雙磷酸鹽／zoledronic acid | denosumab |
|---|---|---|
| 機轉 | 抑制破骨細胞活性 | 抗 RANKL 單株抗體 |
| 給藥 | zoledronic acid 常用靜脈注射 | 皮下注射，每月到每 3 個月 |
| 乳癌與肺癌骨轉移 | 有效降低骨骼相關事件 | 延後事件時間優於 zoledronic acid |
| 骨髓瘤與其他癌症 | 有效 | 延後事件不劣於 zoledronic acid |
| 肺癌整體存活 | 比較基準 | 來源顯示優於 zoledronic acid |
| 主要風險 | 顎骨壞死、腎毒性、非典型股骨骨折 | 低血鈣、顎骨壞死、非典型股骨骨折 |
| 特殊禁忌 | 依腎功能評估 | 懷孕禁用，因可能傷害胎兒 |
| 成本 | 藥價較低 | 藥價高，但因減少事件可能整體更具成本效益 |

每月 denosumab 長期使用者的多中心回溯資料顯示，非典型股骨骨折率為 <span style="color:#f87171;font-weight:600">1.8%</span>，使用超過 <span style="color:#f87171;font-weight:600">3.5 年</span> 者較高。2019 年成本分析認為，denosumab 雖藥價較高，減少骨折與其他事件後整體成本可能低於雙磷酸鹽。另有隨機試驗顯示，乳癌或去勢抗性攝護腺癌骨轉移病人每 12 週給藥，在症狀性骨骼事件方面不劣於每 4 週給藥，可降低成本並改善便利性。

> **Danger zone**：denosumab 與雙磷酸鹽都不能取代高風險長骨的機械穩定；長期用藥還須警覺非典型股骨骨折，而不是把新股骨痛一概歸因於轉移。

### 5.4 微創消融與骨水泥技術

經皮骨水泥成形術可用於選擇性骨盆病灶；骨水泥也可在開放刮除後填補空腔，配合鋼板或髓內固定提供立即穩定。它是機械補強，不能取代組織診斷或全身疾病控制。

來源未提供其他熱消融方式的數值門檻或比較結果，故不延伸其療效。已有進行性神經缺損、廣泛承重骨破壞或完成骨折時，仍以減壓與耐久穩定為目標。

> **Pearl**：骨水泥能立即填補缺損，但不能阻止局部腫瘤進展；抗放射或局部控制差的疾病須同步考慮切除範圍與更耐久重建。

## 6. 手術陷阱、實證更新與 OKU 14 重點 (Pitfalls, Evidence and Take-Home Points)

### 6.1 最常造成失敗的決策

| 陷阱 | 可能後果 | 來源支持的修正 |
|---|---|---|
| 把既往癌症病人的孤立骨病灶直接視為轉移 | 漏掉 15% 與原癌無關的惡性腫瘤 | 非典型孤立病灶先切片 |
| 未確診即擴髓與放入髓內釘 | 污染整根骨及周邊軟組織，可能擴大腫瘤處置範圍 | 固定前粗針或開放切片；冷凍切片不明即中止 |
| 只照射高機械風險長骨 | 放療前即骨折或日後固定失敗 | 以疼痛、Mirels 與臨床風險考慮預防固定 |
| 局部固定未涵蓋所有弱化區 | 新病灶或應力集中導致構造失效 | 一次處理該骨所有弱點，依位置跨越缺損 |
| 只追求短期固定 | 病人因全身治療存活延長後發生植入物失效 | 同時設計立即穩定與長期耐久 |
| 忽略腎、甲狀腺、骨髓瘤的高血管性 | 大量術中失血 | 術前考慮栓塞並規劃血液準備 |
| 長骨固定後只照射病灶本體 | 植入物沿線局部控制不足 | 傷口癒合後照射整個植入物涵蓋區 |
| 進行性神經缺損仍常規等待 | 永久神經損害 | 立即評估手術和／或緊急放療 |
| 將 Mirels 分數當成自動手術命令 | 因 35% 特異度而過度治療 | 納入預後、疼痛、原發癌與病灶位置 |
| 為保護整根股骨一律用長柄 | 增加心肺風險、技術困難與翻修負擔 | 局限病灶及高風險者可考慮短柄 |

> **Danger zone**：轉移病人的手術不等於可以降低腫瘤學紀律；未切片固定與不必要污染，仍可能造成災難性後果。

### 6.2 可直接改變實務的實證更新

1. 標準未知原發評估加最易取得病灶切片，可在 85% 病人確認診斷與原發位置；PET/CT 雖可描述總轉移負荷，並未提高原發癌檢出率。
2. 2019 年隨機試驗顯示，單次立體定位放療的疼痛反應不劣於傳統多次分割外照射。
3. Mirels 系統敏感度 91%、特異度 35%；新骨髓瘤專屬評分、CT 剛性、有限元素與機器學習嘗試改善預測，但疼痛仍可能是最重要單一指標。
4. 預防固定相較骨折後固定，與較短住院、較低 30 日重大併發症及較低成本相關；觀察到的存活優勢可能受病人選擇影響。
5. denosumab 在特定癌別延後骨骼相關事件的效果優於或不劣於 zoledronic acid；每 12 週相較每 4 週給藥，在特定乳癌與攝護腺癌族群不劣。
6. 近端股骨轉移並非一律需要長柄；對局限疾病或高心肺風險者，短柄可能避免長柄骨水泥帶來的負擔。
7. 股骨幹病灶若頭頸未受累，髓內釘未必需要頭髓構件，因後續股骨頸病灶相對少見。
8. 破壞性髖臼轉移使用部分骨盆籠架加骨水泥全髖重建的病例系列，4 年再手術／翻修率為 16%，提醒構造仍需配合預期存活選擇。

> **Pearl**：本章的更新不是尋找單一最佳器械，而是把診斷、存活、骨折風險與局部生物學同時放進決策。

### 6.3 數值與門檻總整理

| 指標 | 來源數字 | 使用方式 |
|---|---|---|
| 標準未知原發路徑診斷率 | 85% | 病史、平片、實驗室、胸腹骨盆 CT、骨掃描及切片合併 |
| 既往癌症病人新骨病灶為無關惡性腫瘤 | 15% | 支持固定前切片 |
| 乳癌／攝護腺癌死亡時有骨轉移 | >70% | 說明骨轉移的高盛行率 |
| 血清蛋白電泳偵測骨髓瘤 | 約 80% | 需加尿液蛋白電泳 |
| 僅產生輕鏈骨髓瘤 | 10%–15% | 只能由尿液增加檢出敏感度 |
| Mirels 固定考量門檻 | ≥8 分 | 放療前考慮預防固定 |
| Mirels 敏感度／特異度 | 91%／35% | 高敏感、低特異，避免機械式套用 |
| 骨轉移住院涉及長骨完成骨折固定 | 接近 5% | 支持骨折前辨識與處置 |
| 下肢即將骨折手術的一般預後門檻 | >3 個月 | 多數完成骨折則不論預後仍固定 |
| denosumab 非典型股骨骨折 | 1.8% | 每月治療者之回溯資料 |
| denosumab 較高風險使用時間 | >3.5 年 | 長期使用者警覺新股骨痛 |
| 骨標靶藥給藥比較 | 12 週不劣於 4 週 | 特定乳癌／去勢抗性攝護腺癌族群 |
| 髖臼籠架加骨水泥全髖翻修 | 4 年 16% | 評估構造耐久與預期存活 |
| 上肢骨轉移占比 | <20% | 雖較少見，仍會破壞輔具與移位能力 |
| 直腿抬高跨髖負荷 | >體重 2 倍 | 無痛對轉子區即將骨折相對放心 |

> **Danger zone**：數字只有在正確情境下才有意義；例如 3 個月門檻來自下肢即將骨折的一般手術選擇，不能拿來拒絕所有短預後病人的疼痛或完成骨折處置。

### 6.4 骨科專科考試核心總結 (Take-Home Points)

1. 40 歲以上成人的破壞性骨病灶，最可能是轉移癌或血液惡性腫瘤，但未確診前仍須排除原發骨腫瘤與感染。
2. 未知原發的標準路徑包括病史與檢查、整根骨雙平面平片、實驗室、胸腹骨盆 CT、全身骨掃描及最易取得病灶切片，正確診斷率為 85%。
3. 曾罹癌病人的新孤立骨病灶有 15% 是與原癌無關的惡性腫瘤；固定前切片是不可省略的安全步驟。
4. Mirels 依影像、大小、部位與疼痛評分；總分 8 以上考慮預防固定，但因特異度僅 35%，須配合臨床判斷。
5. 骨痛可能是即將骨折最重要的單一預測因子；機械性負重痛尤其需要升級評估。
6. 腎、甲狀腺與骨髓瘤病灶可高度血管化，手術前應考慮栓塞；腎細胞癌局部控制不足可持續進展並導致固定失敗。
7. 長骨術後放療應等待傷口癒合，且涵蓋整個植入物區域。
8. 股骨頸廣泛病灶多使用假體；轉子間與轉子下多可用頭髓釘；廣泛破壞、抗放射、完成骨折或固定失敗則考慮近端股骨置換。
9. 進行性神經缺損需手術和／或緊急放療；溶骨、椎弓根及後柱受累增加神經惡化風險。
10. 雙磷酸鹽與 denosumab 可降低骨骼相關事件，但不能取代高風險承重骨的機械穩定。
11. 轉移性骨病手術要提供立即負重與快速功能恢復，同時讓構造耐久度超過預期存活。
12. 所有決策都應整合原發癌別、內臟與多發轉移、病理性骨折、共病、全身治療時序及病人照護目標。

## Summary

骨轉移照護的第一步是正確診斷，而非立即固定。成人破壞性病灶應以整根骨平片、實驗室、胸腹骨盆 CT、全身骨掃描及適當切片完成系統評估；即使病人有既往癌症，孤立病灶仍可能是另一種惡性腫瘤。未確診前擴髓會污染整根骨，是必須避免的災難性錯誤。

治療選擇取決於原發癌生物學、內臟與多發轉移、剩餘存活、疼痛、骨折風險及病人目標。Mirels 可協助長骨風險分層，但須理解其高敏感、低特異；預防固定通常比骨折後固定帶來較少併發症、更短住院與較佳早期功能。手術應一次處理所有弱化區，提供立即功能與足夠耐久性；脊柱進行性神經缺損則必須緊急升級。

放療、疾病專一全身治療、雙磷酸鹽或 denosumab 與局部手術相互補充。長骨固定後放療需待傷口癒合並涵蓋整個植入物；高血管性腎、甲狀腺及骨髓瘤病灶應考慮術前栓塞。最終目標不是單純修補影像上的缺損，而是在病人的剩餘生命中持續減痛、維持活動與避免再次失效。
