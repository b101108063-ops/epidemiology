# Chapter 26: Spinal Trauma — 脊椎創傷

## 章節導讀

脊椎創傷的處置核心是「快速辨識不穩定型態」，再依神經功能與韌帶完整度決定保守或手術。本章依序介紹上頸段（C1-C2）、下頸段與胸腰椎的解剖與生物力學，以及 AO Spine、Subaxial 分級與 TLICS 等決策工具，最後整理手術入路選擇、陷阱與近期文獻。

## 1. 臨床評估與關鍵解剖 (Anatomy & Deforming Forces)

### 1.1 上頸段的穩定性判定（C1-C2）

<span style="color:#22d3ee">寰椎（C1）</span>骨折多為三部分或四部分骨折，同時合併前環與後環損傷。其穩定性主要依據直立X光或CT測量 <span style="color:#e2e8f0">C1 lateral mass overhang on C2</span>，即 **Spence 規則（rule of Spence）**。較少見的型態是孤立性 C1 側塊骨折（isolated C1 lateral mass fracture）；若側塊明顯位移，枕骨髁（occipital condyle）會陷入移位、變寬的側塊骨折處，形成頸部 <span style="color:#f87171">cock-robin deformity（鴛鴦頸畸形）</span>。部分作者主張以 C1 側塊螺絲加 cross connector 進行 C1 骨水泥合（osteosynthesis）以重建環狀結構；但大多數 C1 骨折可用外部矯形器（external orthosis）處理。

<span style="color:#22d3ee">樞椎（C2）</span>是 70 歲以上族群中最常見的骨折椎體。其齒突（odontoid process）具有獨特的血液供應，因此骨折後 <span style="color:#f87171">癒合不良（nonunion）風險較高</span>，在老年人族群中的死亡風險與髖部骨折相當。最常使用的是 <span style="color:#e2e8f0">Grauer 修訂版 Anderson 與 D'Alonzo 分型</span>。

| Grauer 分型 | 骨折部位與特徵 | 生物學特性與治療傾向 |
|---|---|---|
| **Type I** | 齒突尖端撕脫性損傷 | 穩定 |
| **Type II** | 穿越齒突基底部 | 位於椎動脈與內頸動脈系統之間的 <span style="color:#f87171">watershed 血供區</span>，癒合不良風險最高 |
| **Type III** | 向外側延伸進入雙側 C1-2 關節 | 癒合接觸面積大，通常以外部矯形器治療 |

### 1.2 Hangman’s 骨折（C2 峽部骨折）

<span style="color:#e2e8f0">Hangman’s fracture</span> 是發生於 C2 的特殊型態，代表 <span style="color:#22d3ee">pars interarticularis</span>（峽部）骨折。其穩定性主要由是否合併 **C2-3 椎間盤損傷** 以及骨折位移程度決定。若 C2-3 椎間盤受損，或出現非典型型態——骨折延伸進入 C2 椎體後方且成角顯著——即需要手術介入。可接受的手術方式包括 <span style="color:#fbbf24">C2-3 前方融合</span> 與 <span style="color:#fbbf24">C2-3 或 C1-3 後方融合</span>。

### 1.3 下頸段的張力帶概念（Subaxial Tension Band）

下頸段損傷（subaxial cervical trauma）指 C2-3 至 C7-T1 椎間盤之間的損傷，最佳的描述方式包含三個軸向：受傷機轉、骨折形態，以及 <span style="color:#22d3ee">tension band（張力帶）</span>是否受損。張力帶是決定「單純壓迫型」與「不穩定型」的根本。

| 張力帶 | 位置 | 受損後的典型形態 |
|---|---|---|
| **後方張力帶** | 韌帶複合體、關節囊 | 屈曲－分離型損傷（flexion-distraction） |
| **前方張力帶** | 椎體前方、前縱韌帶 | 伸展型損傷（extension） |

### 1.4 胸腰椎解剖分區與生物力學

胸腰椎可分為三個生物力學性質不同的區段：

| 區段 | 範圍 | 特性 | 骨折佔比 |
|---|---|---|---|
| **上胸椎** | T1-T10 | 真正的肋骨與胸骨共同穩定，為 <span style="color:#34d399">僵硬節段</span> | 16% |
| **胸腰交界** | T11-L2 | 過渡區；關節面逐漸變得矢狀且缺乏與胸骨的真肋關節，活動度較僵硬的上胸椎大 | <span style="color:#f87171">52%（最高）</span> |
| **下腰椎** | L3-L5 | 矢狀排列的關節面與缺乏椎體外骨性關節，提供活動彈性 | 32% |

損傷風險與各區段生物力學活動範圍直接相關。此外，胸腰椎區域因為重心位於前方，承受 <span style="color:#fbbf24">屈曲力矩（flexion moment arm）</span>。

<span style="color:#22d3ee">後方韌帶複合體（PLC，posterior ligamentous complex）</span> 是維持胸腰椎穩定與矢狀排列的張力帶，包括：韌帶黃（ligamentum flavum）、棘間韌帶（interspinous ligament）、棘上韌帶（supraspinous ligament）與 facet 關節囊。PLC 的完整性賦予脊柱穩定性，也是胸腰椎骨折分型計分系統的主要構成之一。

### 1.5 骨盆脊柱分離的解剖意義

<span style="color:#e2e8f0">Spinopelvic dissociation（骨盆脊柱分離）</span> 是需要早期診斷與固定的致命性損傷。此傷的最初描述為骶骨橫斷骨折造成與脊柱的脫離（disassociation from the spine），典型成因是高處落下或跳躍後承受極端的軸向負荷（axial load），也可見於高能量多發傷。骨質疏鬆患者亦可能出現 <span style="color:#f87171">insufficiency transverse sacral fracture</span> 並造成骨盆脊柱分離。

## 2. 分型系統與決策矩陣 (Classification & Decision Making)

### 2.1 分型系統演進

胸腰椎分型系統的演進，反映了對骨折理解、溝通與處置的世代進展：每一套新系統都指出前一套的弱點並加以改進。

| 分型系統 | 年份 | 核心貢獻 | 限制 |
|---|---|---|---|
| **兩柱系統** | — | 最早的柱狀觀念 | 無法描述脫位 |
| **三柱系統（Denis）** | 1983 | 改進為壓迫、爆裂、seat belt（屈曲－分離）、骨折－脫位四型，統一形態命名 | 未能涵蓋韌帶損傷與神經狀態 |
| **AO 系統** | 1994 | 27 種獨特骨折型態；A 壓迫、B 分離、C 扭轉 | 描述性，與處置建議脫節 |
| **TLICS** | 2005 | 以形態、PLC 完整性、神經狀態三軸積分直接指導處置 | 複雜度較高 |
| **簡化治療演算法** | 2019 | 依「脊柱不穩定」狀態簡化分級 | 尚未廣泛落實 |

### 2.2 AO Spine 下頸段分類（2016）

<span style="color:#e2e8f0">AO Spine subaxial classification</span> 於 2016 年發表，目標是建立對頸椎損傷的共同描述語言，且具備高度的觀察者間一致性（interobserver reliability）。

| 類型 | 定義 | 典型代表 |
|---|---|---|
| **Type A** | 椎體損傷，<span style="color:#34d399">未破壞脊柱張力帶</span> | 壓迫、爆裂 |
| **Type B** | 破壞前方或後方張力帶之一 | 後方＝屈曲－分離；前方＝伸展型 |
| **Type C** | 任一平面的<span style="color:#f87171">平移（translational）</span>損傷 | 骨折－脫位 |

此外，**facet（關節突）損傷**具獨特性，需以獨立描述項表示，內容包含損傷嚴重度與 facet 參與範圍；並設有 **神經狀態修飾符（neurologic status modifier）**，依神經功能缺損程度評分。

> **Danger zone**：AO Spine 系統建立了共同語言，但**並不直接提供處置建議**。不可將 A/B/C 型別直接等同於手術與否。

### 2.3 Subaxial Cervical Spine Injury Classification and Severity Score（2007）

2007 年發表的 <span style="color:#e2e8f0">Subaxial Cervical Spine Injury Classification System</span> 以一套新的計分系統同時進行分類與手術／保守處置指引。

| 項目 | 細項 | 分數 |
|---|---|---|
| **損傷形態** | 壓迫（Compression） | 1 |
| | 爆裂（Burst） | 2 |
| | 分離（Distraction） | 3 |
| | 旋轉平移（Rotation translation） | 4 |
| **椎間盤－韌帶複合體（DLC）** | 完整（Intact） | 0 |
| | 不確定（Indeterminate） | 1 |
| | 斷裂（Disruption） | 2 |
| **神經狀態** | 完整（Intact） | 0 |
| | 神經根損傷（Nerve root injury） | 2 |
| | 完全脊髓損傷（Complete spinal cord injury） | 2 |
| | 不完全脊髓損傷（Incomplete spinal cord injury） | 3 |
| | 持續脊髓壓迫合併神經缺損 | ＋1 |

| 總分 | 建議處置 |
|---|---|
| **≤ 3** | 保守治療（nonsurgical management） |
| **= 4** | 不確定（indeterminant），由主治外科醫師裁量 |
| **> 5** | 手術穩定固定，必要時合併減壓 |

> **Pearl**：計分者對此治療演算法的一致同意率為 **93.3%**，顯示其作為決策框架的實用性。

一般原則：若存在椎間盤－韌帶斷裂與神經功能缺損，傾向手術治療。

### 2.4 TLICS 與簡化治療演算法

<span style="color:#e2e8f0">Thoracolumbar Injury Classification and Severity Score（TLICS）</span> 由 Spine Study Trauma Group 發表，旨在指導手術決策與預後評估。

| 項目 | 細項 | 分數 |
|---|---|---|
| **損傷形態** | 壓迫（Compression） | 1 |
| | 爆裂（Burst） | 2 |
| | 平移／旋轉（Translation/rotation） | 3 |
| | 分離（Distraction） | 4 |
| **PLC** | 完整（Intact） | 0 |
| | 疑似斷裂（Suspected disruption） | 2 |
| | 斷裂（Disruption） | 3 |
| **神經狀態** | 完整（Intact） | 0 |
| | 神經根損傷（Nerve root injury） | 2 |
| | 完全脊髓損傷（Complete spinal cord injury） | 4 |
| | 不完全脊髓損傷（Incomplete spinal cord injury） | 3 |
| | 馬尾症候群（Cauda equina syndrome） | 3 |

| 總分 | 建議處置 |
|---|---|
| **≤ 3** | 保守治療 |
| **= 4** | 不確定族群；手術決策取決於病人與手術因素 |
| **≥ 5** | 應接受手術介入 |

TLICS 演算法具備外部效度（external validity）與高度的觀察者間一致性。儘管如此，部分 TLICS 個案在處置上仍有爭議，因此 Joaquim 等人提出依「脊柱不穩定」狀態為基礎的簡化、以治療為導向的分類系統。

### 2.5 立即不穩定 vs. 延遲不穩定：形態學決策表

| 分類 | 骨折型態 |
|---|---|
| **立即不穩定（Immediate instability）** | 骨折－脫位（fracture-dislocation） |
| | 爆裂骨折合併後方構造完全斷裂及 kyphosis |
| | 韌帶型 Chance 骨折合併排列不整（malalignment） |
| **延遲不穩定（Delayed instability）** | 壓迫骨折 |
| | 爆裂骨折僅有極少或無後方構造斷裂、無排列不整 |
| | 骨質 Chance 骨折但無排列不整 |

> **Pearl**：延遲不穩定的表現形式為持續疼痛、假關節（pseudarthrosis）或畸形持續惡化。

## 3. 治療指引：手術 vs. 保守 (Treatment Algorithm)

### 3.1 上頸段治療原則

| 情境 | 建議處置 | 依據 |
|---|---|---|
| **C1 骨折（多數）** | 外部矯形器 | 側塊 overhang 未達不穩定門檻時 |
| **C1 孤立側塊骨折合併明顯位移** | 考慮 C1 側塊螺絲 + cross connector 骨水泥合 | 避免 cock-robin 畸形 |
| **齒突 Type I** | 保守／外部矯形器 | 型態穩定 |
| **齒突 Type III** | 外部矯形器 | 癒合接觸面積大 |
| **齒突 Type II** | 手術 vs. 保守仍有爭議 | 見下方說明 |
| **Hangman’s 骨折（C2-3 盤受損或後方椎體延伸成角）** | 手術 | C2-3 前方融合或 C2-3／C1-3 後方融合 |

**齒突 Type II 治療目標**：防止 C1-2 不穩定、減少頸痛、允許早期活動。某些研究顯示手術治療死亡率較低且癒合率較高；但 2021 年一項長期研究（282 例連續治療病人、平均追蹤 39 個月）顯示手術組的骨性融合（bony fusion）率較高，但若將 <span style="color:#60a5fa">纖維性融合與骨性融合合併計算</span>，手術與保守兩組間則無差異；長期追蹤在頸痛方面亦無差異。

> **Danger zone**：不可僅以「骨性融合率較高」作為齒突 Type II 一律手術的理由；老年病人保守治療的安全性已有第三級別證據支持（Rizvi 等，282 例）。

### 3.2 下頸段治療原則

下頸段創傷的治療原則建立在四項風險評估之上：移位風險、進行性 kyphosis、神經受累程度與椎管侵犯程度。過去 5 年手術技術與建議並未大幅改變。

| 類別 | 內容 |
|---|---|
| **保守治療** | 依傷勢嚴重度使用支具固定：halo vest、硬頸圈（hard cervical collar）、軟頸圈（soft collar） |
| **手術治療** | 減壓頸椎構造，並以後方與前方兩種入路合併進行穩定固定 |

2021 年一項比較下頸段前路與後路固定的研究，2 年追蹤時健康相關生活品質（health-related quality of life）**無差異**，但後路方式的 <span style="color:#f87171">感染風險增加</span>；此結果與退化性頸椎病變的相關文獻一致。

**前路適應症**：當前方有病變時可直接減壓脊髓管；在椎體終板完整且無 facet 骨折的情況下，單側或雙側 facet 脫位可執行椎間盤切除與融合。針對前述 facet 損傷，一項研究顯示 **單獨前路固定的失敗率為 13%**，且失敗與同時存在的終板與 facet 骨折相關。

**後路適應症**：使用側塊（lateral mass）與椎弓根（pedicle）螺絲固定，可進行多節段減壓，並藉由 facet 切除（facet resection）復位無法復位的骨折型態。

### 3.3 胸腰椎：保守治療

| 項目 | 內容 |
|---|---|
| **適用對象** | 神經功能完整、骨折型態穩定（TLICS ≤ 3，或 AO Type A 型） |
| **療程** | 10 至 12 週 |
| **內涵** | 症狀處理（止痛藥物）、活動調整，可選擇性使用固定裝具 |
| **器具** | 常用胸腰骶矯形器（TLSO）以期達到外部穩定；其效益具爭議性，須與製作成本一併權衡 |
| **追蹤** | 序列影像與理學檢查，評估外傷後畸形、神經功能與疼痛改善 |

保守治療相較手術治療的優勢：併發症較少、成本較低，且在**神經功能完整的穩定型爆裂骨折**中結果相當。另有研究顯示，使用客製成型（custom-molded）的 TLSO 並未證實能改善保守治療病人的結果。部分保守治療病人最終仍需手術。

**保守治療失敗的特徵**：新出現或惡化的神經學發現、疼痛增加、畸形持續進展。此時應與病人／家屬討論風險效益後再決定手術。文獻中尚未確立明確的保守治療失敗危險因子。

> **Pearl**：TLICS ≤ 3 或 AO Type A 是保守治療的基準門檻；20 週以上仍持續疼痛或畸形進展，應重新評估不穩定性。

### 3.4 胸腰椎：手術治療與重建策略

手術介入的目標是穩定脊柱並減壓神經構造。選擇後路單獨、前路單獨或前後聯合，取決於病人神經狀態與骨折形態。

| 入路／策略 | 適應情境 | 技術要點 |
|---|---|---|
| **後路單獨** | PLC 斷裂、需復原矢狀面畸形與後方張力帶 | 椎弓根螺絲與連桿（rod）；可經完整後縱韌帶以 ligamentotaxis 方式間接復位骨折塊並減壓 |
| **前路減壓** | 需直接減壓脊髓管、脊髓節段病灶合併神經功能缺損 | 經椎弓根（transpedicular）、肋橫突（costotransverse）、外側挖空（lateral extracavitary）、微創 retropleural 或 transpsoas/antepsoas，或前路椎體切除後以 allograft／cage 重建 |
| **前後聯合** | PLC 斷裂 + 背側移位骨折塊造成神經缺損（尤其脊髓節段）；骨質疏鬆避免前路單獨重建 | 恢復穩定與矢狀平衡 |
| **長節段融合** | 骨質不佳（poor bone quality） | 可合併或不合併前柱支撐 |

**節段數的選擇**應依病人因素與骨折形態個別化。短節段後路單獨固定會限制整體剛性，代價是較高的器械失敗率。

**McCormack Load-Sharing Score** 用來評估椎體粉碎程度、位移與所需的矢狀面矯正量，以判斷後路單獨短節段固定的成敗。

**微創與新技術**：隨著術中影像與導引的進展，經皮後路固定（percutaneous posterior fixation）逐漸受歡迎；但病人選擇是關鍵——經皮固定已發現與 <span style="color:#f87171">植入失敗風險增加</span> 相關，尤其在體型較大（increased body habitus）與骨密度不佳者。近期的文獻亦描述過 <span style="color:#fbbf24">kyphoplasty 輔助骨折復位合併經皮固定</span>，但尚未被普遍接受為可行的治療選項。

**特殊型態**：

| 骨折型態 | 機轉與特徵 | 處置重點 |
|---|---|---|
| **骨折－脫位（fracture-dislocation）** | 平移－旋轉力造成，常合併顯著神經損傷 | 多需後路骨折與 facet 復位 + 器械融合 |
| **屈曲－分離（Chance fracture）** | PLC 明顯斷裂並向前延伸至椎間盤與椎體；與爆裂不同，椎體塌陷通常不是後續變化 | 可用經皮短節段固定（骨性或軟組織型屈曲－分離損傷） |

> **Danger zone**：骨質疏鬆病人若選擇前路單獨重建，需留意 <span style="color:#f87171">下沉（subsidence）與進行性 kyphosis</span> 風險，此類病人建議前後聯合重建。

### 3.5 骨盆脊柱分離的處置

| 面向 | 內容 |
|---|---|
| **神經損傷範圍** | 從合併馬尾症候群的完全脊髓損傷，到單一神經根損傷 |
| **預後因子** | 骨折型態位於 **S4 以下**時神經功能恢復可能性較低；**kyphosis > 20°** 與神經缺損風險增加相關 |
| **影像** | CT 應可見雙側垂直骶骨骨折合併橫斷成分，形成 U 形的變異型態，可依骨折線位置呈 H、T、Y 型 |
| **不穩定性** | 高度不穩定，多需手術固定 |
| **無法耐受手術者** | 建議保守治療，但後遺症次佳：皮膚潰瘍形成、靜脈血栓與骨折畸形癒合 |

手術治療可包含直接或間接減壓、骨折復位與器械固定，以恢復穩定性與矢狀平衡。

## 4. 手術入路與危險地雷 (Surgical Approach & Pearls)

### 4.1 前後入路的證據比較

| 研究 | 設計與族群 | 結果 | 證據等級 |
|---|---|---|---|
| Fréjd Révész 等（2021） | 前瞻收集資料之觀察性研究，單節段下頸段損傷 | 前路滿意度較高、感染率較低；但 NDI 與生活品質與後路無差異 | III |
| Wallace 等（2019） | RCT 之 meta-analysis，胸腰爆裂骨折（神經完整） | 有無支具在病人報告結果、失敗率與 kyphosis 角度皆無差異 | I |
| Mulcahy 等（2021） | 支具 vs. 無支具之系統性回顧 | 病人報告結果、影像測量、併發症與失敗率均無差異（低至中等強度證據） | II |
| Tan 等（2019） | 系統性回顧與 meta-analysis，6 篇研究 | 前路手術時間較長、估計失血較多；失敗率、翻修率、住院天數與住院費用無差異 | II |
| Badhiwala 等（2021） | 前瞻性脊髓研究之個體病人資料彙整分析 | 較早手術與較佳神經功能結果相關 | II |

### 4.2 胸腰骶矯形器的使用現況

| 證據 | 內容 |
|---|---|
| Wallace 等 | 短期與長期追蹤皆未顯示支具帶來的差異 |
| Mulcahy 等 | 無證據支持支具使用的效益 |
| Linhares 等（2020） | 5 篇研究、267 位受試者：疼痛、kyphosis 進展、前柱高度喪失與長期 Oswestry Disability Index 均無差異 |
| Linhares 等（2021） | 歐洲與北美問卷調查：超過 90% 脊椎專科醫師仍對急性胸腰椎骨折使用支具 |

> **Pearl**：文獻不建議支具，但臨床習慣仍高度使用；向病人說明時應誠實指出其效益證據不足，而非強調必然需要。

### 4.3 骨盆脊柱分離的固定與減壓技巧

| 面向 | 內容 |
|---|---|
| **直接減壓** | 馬尾症候群情境下，以腰骶椎板切除（laminectomy）與椎間孔切開（foraminotomy）進行 |
| **間接減壓／復位** | 已有數種間接復位技巧可恢復矢狀平衡並使骨折復位 |
| **固定方式** | 腰椎與髂骨聯合固定以重建骨性連結；<span style="color:#fbbf24">雙側三角骨水泥合（bilateral triangular osteosynthesis）</span> 在生物力學上最穩定 |
| **固定挑戰** | 骶骨形態異常（sacral dysmorphism）與骨折移位會使骶骨固定受限 |
| **術後** | 若不需直接減壓，可採用經皮固定；固定後鼓勵早期下床負重 |

> **Danger zone**：若椎管或椎間孔內存在骨塊，<span style="color:#f87171">應避免使用骨牽引與 ligamentotaxis 等間接復位技巧</span>，以免進一步損傷神經。

### 4.4 主要陷阱清單

> **陷阱 1：把 AO 分型當成手術指示**。AO Spine 下頸段分類提供共同語言，但原文明確指出它不適用於處置建議。

> **陷阱 2：只看齒突 Type II 的骨性融合率**。2021 年 282 例長期研究中，纖維性與骨性融合合併後手術與保守無差異，頸痛亦無差異。

> **陷阱 3：忽略 facet 骨折的前路固定失敗率**。文獻報告單獨前路固定失敗率 13%，失敗與合併終板及 facet 骨折相關；2021 年提出的 <span style="color:#e2e8f0">Posterior Ligament-Bone Injury Classification and Severity Score</span> 指出，**分數 > 7 與前路單獨固定失敗相關**。

> **陷阱 4：在骨質疏鬆病人做前路單獨重建**。下沉與進行性 kyphosis 風險高，應採前後聯合。

> **陷阱 5：把經皮固定視為低風險**。體型較大與骨密度不佳者的植入失敗風險反而增加。

> **陷阱 6：低估延遲不穩定**。壓迫骨折、僅有輕微後方構造斷裂的爆裂骨折與無排列不整的骨質 Chance 骨折皆屬延遲不穩定，需長期追蹤疼痛、假關節與畸形進展。

### 5.2 OKU 14 骨科專科考試核心總結（Take-Home Points）

1. **辨識不穩定型態是首要任務**：頸椎與腰椎都應能辨認造成不穩定形態的傷型（fracture-dislocation、後方構造完全斷裂 + kyphosis、韌帶型 Chance 骨折伴排列不整為立即不穩定；壓迫骨折、輕微後方斷裂的爆裂骨折、無排列不整的骨質 Chance 骨折為延遲不穩定）。
2. **必須熟悉常用分類**：AO Spine 下頸段（A 椎體、B 張力帶、C 平移＋facet 描述項＋神經修飾符）、Subaxial 計分（≤3 保守、4 不確定、>5 手術）、Grauer 齒突分型（I／II／III）、TLICS（≤3 保守、4 不確定、≥5 手術）。
3. **分型用來決定手術 vs. 保守**：TLICS ≥5 應手術；TLICS ≤3 或 AO Type A 適合 10–12 週保守治療；延遲不穩定者需長期追蹤。
4. **下頸段前後路比較**：2 年時健康相關生活品質無差異，後路感染風險較高；facet 損傷且終板完整者方可做前路椎間盤切除融合，但單獨前路固定失敗率 13%，PLC-bone 分數 >7 者應避免前路單獨固定。
5. **胸腰椎手術的固定策略**：骨質不佳者用長節段融合；短節段後路單獨會增加器械失敗率，可用 McCormack Load-Sharing Score 評估；經皮固定在體型大與骨密度差者失敗風險增加；骨質疏鬆病人前路單獨重建易下沉並進行性 kyphosis，宜前後聯合。
6. **骨盆脊柱分離**：CT 應見雙側垂直＋橫斷的 U 形（H／T／Y 變異）骨折；S4 以下骨折神經恢復機會較低，kyphosis >20° 神經缺損風險增；最穩定固定為雙側三角骨水泥合；椎管內有骨塊時禁用牽引與 ligamentotaxis 間接復位。
7. **整體原則**：脊椎創傷需要迅速診斷與處置；分類系統的演進反映管理與理解的進步；儘管實務上仍有變異，<span style="color:#fbbf24">及時固定（immobilization）、復甦（resuscitation）與穩定（stabilization）</span> 仍是降低併發症的關鍵。仍需更高等級證據證實各種處置模式的優劣，在此之前外科醫師的臨床判斷不可或缺。

## Summary

- **首要任務是辨識不穩定**：頸椎與腰椎都需辨認造成不穩定形態的傷型；胸腰椎可區分立即不穩定（骨折－脫位、後方構造完全斷裂 + kyphosis、韌帶型 Chance 骨折伴排列不整）與延遲不穩定（壓迫骨折、輕微後方斷裂的爆裂骨折、無排列不整的骨質 Chance 骨折）。
- **分型工具**：AO Spine 下頸段分類（A 椎體／B 張力帶／C 平移，另加 facet 描述與神經修飾符，但無處置建議）；Subaxial 計分 ≤3 保守、4 不確定、>5 手術（一致率 93.3%）；TLICS ≤3 保守、4 不確定、≥5 手術；Grauer 齒突分型 I／II／III。
- **齒突 Type II**：手術與保守之爭在 282 例、平均 39 個月追蹤下，纖維 + 骨性融合合併後無差異，長期頸痛亦無差異；70 歲以上 C2 骨折死亡風險與髖部骨折相當。
- **下頸段入路**：前路與後路 2 年健康相關生活品質無差異，後路感染風險較高；facet 損傷且終板完整時可行前路椎間盤切除融合，但單獨前路固定失敗率 13%，PLC-bone 分數 >7 者應避免前路單獨固定。
- **胸腰椎策略**：TLICS ≤3 或 AO Type A 適合 10–12 週保守；骨質不佳用長節段融合，短節段後路單獨增加器械失敗率（可用 McCormack Load-Sharing Score 評估）；骨質疏鬆者前路單獨重建易下沉並進行性 kyphosis，宜前後聯合；經皮固定在體型大與骨密度差者失敗風險增加。
- **骨盆脊柱分離**：CT 見雙側垂直 + 橫斷的 U 形（H／T／Y 變異）骨折；S4 以下神經恢復機會較低，kyphosis >20° 神經缺損風險增；最穩定固定為雙側三角骨水泥合；椎管內有骨塊時禁用牽引與 ligamentotaxis 間接復位。
- **全章原則**：及時固定、復甦與穩定是降低併發症的關鍵；仍需更高等級證據，在此之前外科醫師的臨床判斷不可或缺。
