# Chapter 17: Muscle and Nerve Disorders — 肌肉與神經疾病

## 章節導讀

本章以「轉譯科學與新興科技」為主軸，串聯肌肉與神經疾病的分子遺傳學發掘、藥物與基因治療、組織工程再生策略。內容自脊髓性肌肉萎縮（SMA）的基因治療臨床試驗延伸至肌萎縮性側索硬化症（ALS）的基因組發現，並涵蓋急性弛緩性脊髓炎、周邊神經損傷、臂叢產傷、腦性癱瘓、壓迫性神經病變與多發性硬化症。核心提醒是：多數新發現仍屬初步結果，臨床轉譯前必須嚴謹驗證。

---

## 1. 核心概念與疾病分類 (Core Concepts & Disease Taxonomy)

本章非解剖學章節，「關鍵結構」係指**致病基因、神經肌肉傳遞單位（neuromuscular junction, NMJ）與再生機制**；骨科醫師須先辨識病變層級是肌肉、神經、神經肌肉接合處還是中樞神經系統。

### 1.1 疾病層級分類表

| 層級 | 本章代表疾病 | 關鍵致病／驅動因素 |
|------|--------------|--------------------|
| **肌肉本身** | 線狀體肌病、發炎性肌病、DMD | 肌節細肌絲基因突變、自體免疫性肌炎、myomaker 表現異常 |
| **運動單位／NMJ** | SMA、重症肌無力、ALS、周邊神經損傷 | SMN1/SMN2 缺失、自體抗體、TDP-43 病理、MEP 退化不可逆 |
| **脊髓／中樞** | 急性弛緩性脊髓炎（AFM）、多發性硬化症（MS） | 腸病毒 D68（EV-D68）、免疫性脫髓鞘與神經退化 |
| **發育性** | 臂叢產傷（BPBI）、腦性癱瘓（CP） | 去神經後蛋白穩態失調、de novo 突變 |
| **創傷性／壓迫性** | 急性周邊神經損傷、腕隧道症候群、尺神經卡壓 | 軸突連續性分級、糖尿病與代謝疾病 |
| **再生醫學** | 肌肉量缺失（volumetric muscle loss, VML） | 衛星細胞與細胞外基質流失、纖維化 |

### 1.2 神經肌肉接合處與肌肉終板（MEP）

<span style="color:#e2e8f0">Motor end plate (MEP)</span> 為運動神經與骨骼肌纖維相接處的特化突觸後膜。兩項關鍵發現構成本章疾病機轉核心：

- **MEP 退化具不可逆性**：周邊神經損傷後的突觸後改變使隨後的 MEP 退化不可逆，可能限制功能恢復上限。
- **MEP 在手術黃金期後仍可存活**：2020 年外傷患者去神經肌肉活檢研究發現，多數患者的 MEP 在損傷 26 個月後仍持續存在並維持結構，2 例甚至超過 3 年。

> **Pearl**：<span style="color:#60a5fa;font-weight:600">MEP 存續時間遠比傳統「6 個月」建議窗口長</span>，不應僅以固定時間點判定神經重建機會已流失。

> **Danger zone**：**MEP 退化不可逆**是限制功能恢復的核心變數；若錯過神經再支配黃金期，即使肌肉健康，功能恢復也可能受限。

### 1.3 Volumetric Muscle Loss 的病理定位

<span style="color:#e2e8f0">VML</span> 指骨骼肌肉組織的嚴重流失，常見於外科切除與四肢創傷。與老化或疾病的進行性萎縮不同：內生性修復／重塑機制**無法**在其他急性創傷模型中完全恢復功能；去神經纖維持續無法再生是功能缺損主因；衛星細胞與細胞外基質大量流失是再生受損的解剖基礎；促炎基因持續上調導致**纖維化**。

> **Pearl**：VML 在平民與軍方環境的發生率皆快速上升，且軍中比例特別高，使其成為骨科手術與再生醫學的新興研究領域。

## 2. 分型系統與決策矩陣 (Classification & Decision Making)

### 2.1 脊髓性肌肉萎縮症（SMA）的治療試驗對照

nusinersen（Spinraza）為改變 <span style="color:#e2e8f0">SMN2 splicing</span> 的反義寡核苷酸；另一條途徑是以腺相關病毒載體（AAV）遞送野生型 SMN 的 onasemnogene abeparvovec（Zolgensma），替代缺失的 SMN1 基因。

| 試驗 | 年齡群組 | 疾病嚴重度 | 結果 |
|------|----------|--------------|------|
| **NURTURE** | <6 週 | 無症狀期 SMA；SMN2 2–3 份拷貝 | 改善獨立坐立與行走 |
| **ENDEAR** | <7 個月 | SMA type 1 | 較對照組延緩死亡、減少呼吸器依賴、改善運動里程碑 |
| **CHERISH** | 4 歲起病 | SMA type 2 | 症狀出現 6 個月後，運動功能優於安慰劑對照 |
| **START（歷史對照）** | <8 個月 | SMA type 1；SMN2 2 份拷貝 | 單次靜脈高劑量 onasemnogene abeparvovec 改善存活、運動功能與里程碑達成 |
| **STRONG（進行中）** | <6 歲 | SMA type 2 | 探索 onasemnogene abeparvovec 的效果 |

> **Pearl**：nusinersen 於**無症狀期**（NURTURE）的療效證據，確立了「早期且主動治療」在神經肌肉疾病中的重要性。

### 2.2 線狀體肌病（Nemaline Myopathy）的分型與自然史

線狀體肌病是最常見的先天性肌病之一，病因為**肌節細肌絲**蛋白基因突變（已知多達 12 個基因），可為體染色體顯性或隱性。2021 年橫斷面研究（57 例）建立的自然史：

| 項目 | 數據 |
|------|------|
| 最常見臨床表現 | 先天性（54%），屬較輕的亞型 |
| 需機械性支持的比率 | 58% |
| 該次亞群中需輪椅、呼吸器與餵食管協助者 | 26% |
| 基因型未解者的疾病進展 | 較已確認突變者更差 |

> **Danger zone**：基因型未解（unresolved genotype）者進展更差，提示**未知基因突變可能調控更嚴重的亞型**；不可因「未找到基因診斷」而低估嚴重度。

- **最嚴重亞型**：呼吸肌無力、肌張力低下、呼吸衰竭，最終早期死亡；**較輕亞型**非進行性，不影響生命。
- **藥物**：快速骨骼肌肌鈣蛋白活化劑 <span style="color:#fb923c">tirasemtiv</span> 放大肌鈣蛋白與鈣的結合、暴露肌球蛋白結合位、增強細肌絲功能與肌力產生。2021 年研究顯示其於帶 <span style="color:#60a5fa">ACTA1</span>（alpha-actin 1）突變的線狀體肌病小鼠模型中改善肌肉功能與力輸出。

### 2.3 發炎性肌病（Inflammatory Myopathy）的五種亞型

特發性發炎性肌病為罕見自體免疫疾病，表現為肌炎，可累及皮膚、肺、關節等多器官系統，常致生活品質下降。雖尚無一致分型共識，最被認可的五種亞型：

| 亞型 | 說明 |
|------|------|
| **Dermatomyositis**（皮肌炎） | 皮膚與肌肉受累 |
| **Inclusion body myositis**（包含體肌炎） | 老年族群常見 |
| **Immune-mediated necrotizing myopathy** | 免疫介導性壞死性肌病，肌肉壞死為主 |
| **Overlap myositis**（重疊性肌炎） | 與其他自體免疫疾病重疊 |
| **Polymyositis**（多發性肌炎） | 典型炎症性肌病 |

### 2.4 急性弛緩性脊髓炎（AFM）的診斷決策

<span style="color:#e2e8f0">AFM</span> 為類小兒麻痺的脊髓發炎，主要侵犯脊髓前角細胞與腦幹運動核。2012 年美國首次報告病例後，十年內成為全球性新興疾病。

| 面向 | 內容 |
|------|------|
| 地理與季節 | 美國呈地理群聚；每兩年一次的雙年型，高峰年為 2014、2016、2018 |
| 推定驅動因子 | 腸病毒 D68（enterovirus D68）；其致 AFM 機轉仍未知 |
| 前驅症狀 | 輕微呼吸道症狀與發燒，超過 90% 患者可見；至神經症狀間隔 1 至 10 天 |
| 弱肌型態 | 通常不對稱，可侵犯多肢，隨後呈低反射或無反射；頸、軀幹、橫膈膜、呼吸肌、延腦與顏面肌、眼外肌亦可受累 |
| 鑑別診斷 | Guillain-Barre 症候群、脊髓中風、脫髓鞘性脊髓炎、小兒麻痺及其他感染性脊髓炎；區別 AFM 者即**肌力不對稱** |
| 脊髓 MRI | T2 高訊號以灰質為主，合併腦幹病變；最有用檢查之一 |
| 腦脊髓液細胞數 | 急性期輕微升高（<100/µL），數週後恢復正常 |
| RT-PCR | 非單獨具診斷性，但可辨識腸病毒 D68 區分其他神經疾病 |
| 神經傳導／肌電圖 | 非直接診斷工具，但症狀出現數日後 compound motor action potential 減低或消失，**早期特別有用** |

> **Pearl**：**肌力不對稱是區分 AFM 與其他急性神經疾病最具辨識力的特徵**——可表現為上肢嚴重無力而下肢肌力正常，或左右肢 MRC 肌力分數相差超過 2 分。

| 預後與治療 | 內容 |
|----------|------|
| 恢復速度 | 前幾個月最快；多數患者肌力改善，但**完全恢復者少於 10%** |
| 肢體恢復 | 谷底時 MRC 肌力 0 的肌群恢復最差；呈**由遠端向近端**模式，高度不對稱 |
| 藥物 | 靜脈免疫球蛋白（含中和抗體），具抗病毒與免疫調節之推定效果；其他選擇為小分子抗病毒藥與抗非小兒麻痺腸病毒單株抗體 |
| 手術 | 某肌群恢復不良持續 3 個月以上者，可考慮神經轉移 |

> **Danger zone**：上肢神經轉移在 AFM 的結果**不一致**——手肘功能恢復較佳，肩關節功能恢復較差；下肢與膈神經轉移的成功證據極少。落差提示 AFM 致病機轉具異質性，可能同時涉及異常肌肉與異常神經／脊髓。

### 2.5 周邊神經損傷的分級系統

外傷性周邊神經損傷依嚴重度遞增分為三級：**Neurapraxia**（神經失用，傳導阻斷但軸突連續性保留）、**Axonotmesis**（軸索断裂，軸突斷裂但支持結構相對保留）、**Neurotmesis**（神經完全斷裂，支持組織完全中斷）。外傷患者中 **3% 至 5%** 出現周邊神經損傷，機動車與機車車禍合計占 **50% 以上**。儘管重建手術持續進步，功能恢復仍高度變異且常伴終身殘障；未解決的損傷雖非立即危及生命，卻對就業與醫療支出影響重大。

### 2.6 壓迫性神經病變的風險因子與鑑別

壓迫／卡壓性神經病變是最常見的周邊神經病變，可造成神經痛、感覺缺失與肌力無力。常見類型依序為腕隧道症候群、肘部尺神經卡壓（cubitál tunnel syndrome）；sciatica 亦常見，但定義不一，患病率報告有出入。

| 研究發現 | 內容 |
|---------|------|
| 瑞典縱斷族群研究 | 糖尿病與腕隧道症候群及肘部尺神經卡壓皆強關聯（HR 2.10 與 2.20）；**高血糖**僅與腕隧道症候群風險增加相關，提示對正中與尺神經的差異作用 |
| 感覺定量測試 | 頸神經根病與腕隧道症候群感覺功能相當，但頸神經根病患者報告**更劇烈且更頻繁的疼痛發作** |
| 2019 GWAS | 辨識 **16 個**易感位點，並在手術切除的腱鞘滑膜中確認 ADAMTS10、ADAMTS17、EFEMP1 之表現 |
| COMP 基因 | 中國兩個大家族之遺傳連鎖分析找出兩個相關突變，將腕隧道症候群區分為有／無多發性骨骺發育不良兩亞型 |
| ADCYAP1／PACAP | 術後皮膚轉錄組中於大量皮膚再神經支配時表現差異最大的基因，為神經再生治療標的 |
| 病理機轉差異 | 感覺測試相當但疼痛強度與發作頻率不同，提示兩者底層病理機轉不同 |

> **Danger zone**：腕隧道症候群與頸神經根病**解剖外觀相似但病理機轉不同**——感覺測試相當卻疼痛強度不同，是重要的鑑別線索。

### 2.7 多發性硬化症（MS）的遺傳風險

MS 是中樞神經系統最常見的慢性發炎性自體免疫脫髓鞘與神經退化疾病，發病率約每 10 萬人 350 例，僅美國即近一百萬例；為年輕成人非創傷性神經功能障礙的首要原因（診斷多在 20–30 歲）。

| 遺傳發現 | 內容 |
|---------|------|
| 2019 GWAS | 47,429 例病例中辨識 **233 個**風險位點，含第一個位於單一性染色體（X）的 MS 位點；可解釋估計遺傳力最高約 **48%** |
| 基因表現分析 | 相關基因與風險變異在主要免疫細胞（尤其小膠細胞 microglia）及周邊免疫細胞高度富集 |
| 低頻／罕見變異 meta 分析 | 辨識 4 個新的 MS 易感基因，與常見變異訊號獨立，涉及適應性與先天性免疫 |
| 環境因子 | 血清維生素 D 偏低、吸菸、兒童期肥胖、環境紫外線輻射、EB 病毒感染（多數遺傳風險仍未知） |

> **Pearl**：MS 的女性：男性比例為 **2.5:1**；第一個 X 染色體變異的發現，可能是破解 MS 性別差異遺傳成分的突破口。

## 3. 治療指引：藥物、手術與再生策略 (Treatment Algorithm)

### 3.1 發炎性肌病的非藥物治療

2019 年系統性回顧：物理治療在疾病**穩定期**安全，且為改善生理與功能結果的有效介入；建議復健計畫每週含 **3 次有氧訓練**。2021 年為期 **24 週**的監督式訓練計畫結合日常生活活動（ADL）、阻力與穩定性訓練，防止進展性惡化，並顯著改善肌力、耐力、穩定性與整體失能程度。

> **Pearl**：對發炎性肌病而言，**肌力訓練本身是治療**而非復健附屬品——24 週監督式阻力訓練相較居家運動可達臨床意義大於 20% 的改善。

### 3.2 COVID-19 疫情下的管理調整

| 議題 | 內容 |
|------|------|
| 疾病表型 | 病例報告顯示 COVID-19 感染加重 dermatomyositis 與 immune-mediated necrotizing myopathy 表型；機轉仍不明 |
| 機轉假說 | (1) 病毒經 <span style="color:#22d3ee">ACE2</span> 受體直接進入肌肉組織；(2) SARS-CoV-2 結合並活化 <span style="color:#22d3ee">Toll-like receptor 4</span>，增加 ACE2 表現而觸發過度發炎反應；(3) dermatomyositis 病人中 SARS-CoV-2 誘發 CD8 T 細胞過度活化，觸發適應性先天反應 |
| 醫療中斷影響 | 需持續追蹤但面對面互動受限，受訪者約 **三分之一**出現不利影響，最常見併發症為藥物相關問題 |
| 建議 | 考慮遠端監測與病人自報結果；自導向評估包括**步行距離測試、坐立測試、手臂上舉測試** |

> **Danger zone**：遠端監測無法取代面對面檢查的敏感度差異（尤其肌力分級與感覺變化）。

### 3.3 Volumetric Muscle Loss 的再生治療

由於手術介入與物理治療均無法改善肌肉再生，重建性療法成為建立新生肌肉組織的有前景選項：探索生物學性細胞外基質與無細胞生物材料，偶與幹／前驅細胞及各種生長因子併用。網絡 meta 分析結論為 **無細胞生物材料 + 幹／前驅細胞**的組合對功能缺損改善幅度最大（Level of evidence: I）。

> **Pearl**：此組合是目前最值得投入臨床轉譯的 VML 再生策略。

### 3.4 臂叢產傷（BPBI）的預防性治療

臂叢產傷是最常見的出生傷害，也是小兒上肢麻痺的首要病因。初始神經損傷造成永久性神經缺陷，並在 **20% 至 40%** 的兒童形成次發性肌肉攣縮；這些無法治療的攣縮嚴重妨礙關節活動範圍，是上肢功能障礙與畸形主因。

- **攣縮的生物學**：源自去神經肌肉的縱向生長受損，特徵為**數目較少但過度延展的串聯肌節**，造成功能上較短的肌肉。
- **肌核增生（myonuclear accretion）**：2020/2021 年小鼠模型顯示，若於**新生兒期**操弄衛星細胞功能，去神經肌肉的衛星細胞數目與肌核增生均未受損；縱向生長缺陷反而與 **20S proteasome 催化活性上升**所介導的蛋白降解增加有關。
- **概念性驗證**：使用 <span style="color:#fb923c">bortezomib</span>（FDA 核准的 proteasome 抑制劑）抑制蛋白降解，可恢復縱向生長並減少 BPBI 後攣縮形成。
- **時效性限制**：bortezomib 必須**貫穿出生後發育全程**才能在骨骼成熟時預防攣縮，超過新生兒期後效力即減弱。
- **毒性限制**：長期使用 proteasome 抑制劑具累積毒性，因非選擇性阻斷降解並對多種器官（如腦）造成傷害，甚至妨礙肌肉骨骼發育。

> **Danger zone**：**bortezomib 的「療效—毒性」兩難**：預防攣縮需長期用藥，而長期 proteasome 抑制會傷害腦與肌肉骨骼發育。未來研究須找出可截短的必要抑制期間，或改為針對骨骼肌特異性的蛋白穩態調節因子。

### 3.5 腦性癱瘓（CP）的分子遺傳學與免疫發現

腦性癱瘓是最常見、嚴重且代價高昂的小兒神經發育障礙之一。

| 研究 | 內容 |
|------|------|
| 全外顯子定序（2020、2021） | 揭露**功能喪失與錯義 de novo 突變**富集；致病變異比率**小兒約 33%、成人約 10%** |
| 基因過度代表分析 | 富集於 **Rho guanosine triphosphatase、細胞外基質、黏著斑與細胞骨架**路徑 |
| 共同基因 | 兩項研究**各自**辨識出帶多個 de novo 突變的兩個共同基因：<span style="color:#60a5fa">TUBA1A</span> 與 <span style="color:#60a5fa">CTNNB1</span> |
| TUBA1A 表型 | 107 例回顧：全面性發育遲緩 98.1%、小腦畸形 76.0%、癲癇 71.2%、痙攣 62.5%；胼胝體異常 96.2%、皮質迴旋異常 99.0%、無腦回 70.0% |
| CTNNB1 表型 | 智能障礙、痙攣、小腦畸形與視覺缺損 |
| 新基因 | <span style="color:#60a5fa">RHOE</span> 與 <span style="color:#60a5fa">FBXO31</span> 為先前未與 CP 相關的單基因變異；FBXO31 編碼廣泛表現的腫瘤抑制蛋白，突變導致 cyclin D 降解；該 de novo 錯義變異已在第三人重複報導 |
| 免疫發現 | 恆定型自然殺手 T 細胞（iNKT）與 Vδ2 T 細胞**數量與比例升高**，黏膜相關恆定型 T 細胞與 Vδ1 T 細胞**耗竭**；基線血清 erythropoietin 升高，體外 LPS 刺激後 IL-1α、IL-1β、IL-2 與 IL-6 分泌**減少**，可能促成廣泛神經發炎 |

> **Danger zone**：解讀 CP 遺傳研究須避免誤讀「**腦性癱瘓的基因擬態（genetic mimics）**」、不符指引的 CP 定義，以及缺少適當對照組的資料；衛星細胞耗竭相關研究皆在攣縮**形成之後**才取樣，其致病角色仍未定論。

### 3.6 ALS 的致病基因與分子機轉

ALS 為上、下運動神經元同時退化的神經退化疾病，是最常見的運動神經元疾病，由肌力無力與肌肉耗損快速進展至呼吸衰竭死亡。雖研究眾多，發病機轉仍不明確，限制治療選項。

| 面向 | 內容 |
|------|------|
| 家族型比例 | 多數為特發性／散發性，**10%** 為家族型且帶有基因突變 |
| 最具特徵的基因 | <span style="color:#60a5fa">C9ORF72</span>、<span style="color:#60a5fa">FUS</span>、<span style="color:#60a5fa">SOD1</span>、<span style="color:#60a5fa">TDP-43</span>（由 TARDBP 編碼） |
| 最常見家族型原因 | C9ORF72 基因內 **G4C2 六核苷酸重複擴增**，造成 sense G4C2 與 antisense G2C4 重複 RNA 累積，並降低 C9ORF72 mRNA 與蛋白表現 |
| C9ORF72 機轉 | 增加 GluA1 AMPA 受體次單元表現 → 增加鈣通透性 AMPAR → 谷胺酸 excitotoxicity 脆弱度上升；另造成活性單倍不足，破壞溶酶體生成、增加谷胺酸受體累積並損害神經毒性二胜肽重複蛋白的清除；**功能增益與功能喪失的協同致病機轉**共同觸發神經退化 |
| SOD1 | 第一個與家族型 ALS 相關的基因，已辨識 >185 種疾病相關變異，多為錯義突變，**D90A 最常見**；錯折野生型 SOD1 包涵體見於 C9ORF72、FUS、KIF5A、NEK1、ALS2、VAPB 突變患者 |
| TDP-43 | 高度保守、普遍表現的核糖核蛋白；突變型及其聚集物連同野生型流失被認為是神經退化的可能原因。聚集的 TDP-43 觸發核孔蛋白與運輸因子的隔離／錯位，破壞核膜與核孔複合體，降低核蛋白輸入與 mRNA 輸出；累積使核糖體與粒線體轉錄本去穩定化，扰乱粒線體與蛋白合成 |
| STMN2 | 編碼運動神經元軸突生長與修復必要蛋白的基因，為 TDP-43 連結神經退化的候選 RNA 底物；TDP-43 敲低後表達降低，ALS 屍體脊髓中亦下降 |
| 新增基因（近十年） | ANXA11、ATXN1、CCNF、CHCHD10、C21ORF2、DNAJC7、GLT8D1、KIF5A、LGALSL、MATR3、NEK1、SS18L1、TBK1、TUBA4A |

> **Pearl**：ALS 基因體研究在近十年辨識出十多個新基因，**找出更多基因並確立其致病機轉**，是破解分子機轉與找出治療標的的關鍵。

### 3.7 多發性硬化症的疾病修飾治療（DMT）

所有 DMT 的共同機轉為**減弱神經發炎**，並在較小程度上減弱神經退化（如腦萎縮）。截至 2020 年 7 月共有 **9 類 DMT** 核准用於復發緩解型與活動性次發進行型 MS（發炎活性較高）：interferons（干擾素）、glatiramer acetate、teriflunomide、sphingosine-1-phosphate 受體調節劑、fumarates、cladribine、natalizumab、ocrelizumab、alemtuzumab。

> **Pearl**：**ocrelizumab 是唯一核准用於原發性進行型 MS 的 DMT**（該型神經發炎較少、神經退化較多），以 B 細胞清除策略減少 B 細胞介導發炎導致的神經退化。

| DMT 以外的探索性治療 | 結果 |
|------------------|------|
| 造血幹細胞移植 | 非清髓性 HSCT 於 110 例 RCT 中較持續 DMT 顯著延長疾病進展時間（HR 0.07，中位追蹤 24 個月） |
| 間充質幹細胞 | 第一期試驗於次發進行型 MS 與可行走病人改善功能結果，副作用極輕微 |
| 卵磷脂（biotin） | 第二期試驗（原發／次發進行型 MS）**無效**，且伴隨不良反應 |
| Opicinumab | 第二期試驗（復發緩解型與有復發的次發進行型 MS）**無效**，且伴隨不良反應 |

> **Danger zone**：**remyelination 療法與細胞療法中，只有部分早期訊號成立**——biotin 與 opicinumab 試驗皆未改善障礙。面對早期生物標記訊號，須嚴格遵守試驗設計與終點判讀，不能過度解讀臨床相關性。

## 4. 陷阱與爭議 (Pitfalls, Controversies & Emerging Technologies)

本章無傳統手術技術章節；以下為**跨疾病共通的判讀陷阱與策略爭議**。

> **陷阱 1：把分子發現直接等同於治療機會**。AFM、ALS、CP、MS 的致病基因發現雖多，但多數仍屬初步發現，臨床轉譯前必須嚴謹驗證。

> **陷阱 2：忽略「時間窗」的决定性角色**。nusinersen 於無症狀期的成功、bortezomib 必須貫穿發育全程才有效、AFM 前幾個月恢復最快——三者共同指出：**介入時機本身就是治療效果的一部分**。

> **陷阱 3：低估 MEP 的存續，但高估其可恢復性**。MEP 可在損傷後 26 個月甚至 3 年後仍存在，但退化一旦發生即不可逆。既不能輕易宣告手術時機已過，也不能假設再生的軸突一定能重新支配殘存終板。

> **陷阱 4：混淆「解剖相似」與「病理機轉相同」**。腕隧道症候群與頸神經根病的感覺定量測試相當，但疼痛強度與發作頻率顯著不同；兩者的細胞激素環境與遺傳背景（COMP、ADAMTS10/17、EFEMP1）不同。

> **陷阱 5：把 VML 當成一般急性創傷修復**。VML 的去神經纖維無法再生、衛星細胞與細胞外基質流失、促炎基因持續上調導致纖維化，「一般創傷的恢復時間表」不適用。

> **陷阱 6：以肌肉端研究直接推論病人結果**。小鼠模型研究（衛星細胞耗竭、myomaker 剔除、proteasome 抑制）與人類結果有落差；CP 的衛星細胞研究皆在攣縮形成後才取樣，因果角色未定。

> **陷阱 7：AFM 上肢神經轉移結果被過度樂觀解讀**。手肘屈曲（87%）與伸展（67%）的恢復率優於肩外旋（50%）與外展（20%）；另一系列 8 例報告中僅接受游離肌轉移或神經轉移者獲得 ≥140° 的手肘屈曲，且僅各半族群達到 ≥70° 與 ≥90° 的肩外展，支持**選擇性**應用而非全面推廣。

> **陷阱 8：把「有訊號」等同於「有效」**。MS 的 biotin 與 opicinumab 試驗、發炎性肌病的居家運動對照，都說明**良好對照組與終點定義**是判讀新治療的必要條件。

> **陷阱 9：遺傳檢測陰性不等於低嚴重度**。線狀體肌病中基因型未解者進展更差；MS 中多數遺傳風險仍未知。陰性報告不可作為疾病風險較低的依據。

### 5.2 骨科專科考試核心總結（Take-Home Points）

1. **SMA**：NURTURE（<6 週、無症狀、SMN2 2–3 份）改善坐立與行走；ENDEAR（<7 個月、type 1）延緩死亡、減少呼吸器依賴；CHERISH（4 歲起病、type 2）改善運動功能；onasemnogene abeparvovec 為單次 AAV 基因替代。
2. **線狀體肌病**：最多 12 個細肌絲基因；先天性 54%、需機械性支持 58%；基因型未解者進展更差；tirasemtiv 為有前景標的；SLONM 合併單株蛋白者化療可能較佳但仍有爭議。
3. **發炎性肌病**：五種主要亞型；每週 3 次有氧訓練；24 週監督式訓練優於居家運動；COVID-19 遠端監測用步行距離、坐立與手臂上舉測試。
4. **AFM**：EV-D68 驅動、每兩年流行（2014／2016／2018）、90% 以上有前驅呼吸道症狀、前驅期 1–10 天；**肌力不對稱**為與 GBS、脊髓中風、脫髓鞘性脊髓炎、小兒麻痺鑑別的關鍵；CSF 細胞數 <100/µL；MRC 0 分肌群恢復最差、遠端優於近端；完全恢復者少於 10%；IVIG 治療，神經轉移手肘功能較佳而肩功能較差。
5. **周邊神經損傷**：外傷患者 3%–5%、車禍占 50% 以上；neurapraxia／axonotmesis／neurotmesis 三級；**MEP 退化不可逆**，但可存續 26 個月至 3 年以上。
6. **ALS 基因**：C9ORF72（最常見家族型）、FUS、SOD1（>185 變異、D90A 最常見）、TDP-43 經 STMN2 連結軸突生長；另新增 ANXA11、ATXN1、CCNF、CHCHD10、DNAJC7、GLT8D1、KIF5A、NEK1、TBK1、TUBA4A 等。
7. **BPBI／CP**：BPBI 攣縮（20%–40%）主因為 20S proteasome 介導蛋白降解增加（非衛星細胞問題），bortezomib 須長期使用且有累積毒性；CP 致病變異率小兒約 33%、成人約 10%，TUBA1A 與 CTNNB1 為共同 de novo 突變基因，另有 RHOE、FBXO31；iNKT／Vδ2 T 升高、Vδ1 T 耗竭。
8. **壓迫性神經病變**：腕隧道症候群最常見，其次為肘部尺神經卡壓；糖尿病兩者皆相關（HR 2.10／2.20），高血糖僅與腕隧道相關；易感位點 16 個；COMP 突變分有／無多發性骨骺發育不良兩亞型；ADCYAP1／PACAP 為再生標的。
9. **MS**：每 10 萬人約 350 例、女：男 2.5:1、診斷多在 20–30 歲；233 個風險位點（含首個 X 染色體位點），可解釋至多 48% 遺傳力；9 類 DMT，**ocrelizumab 為唯一核准用於原發性進行型 MS 者**；HSCT 有效（HR 0.07），biotin 與 opicinumab 失敗。
10. **通則**：新發現多屬初步性質；分子標的雖被找到，**臨床轉譯仍需嚴謹驗證與安全性確認**。

## Summary

- **SMA 與線狀體肌病**：nusinersen 於 NURTURE／ENDEAR／CHERISH 確立早期主動治療，onasemnogene abeparvovec 為單次 AAV 基因替代；線狀體肌病最多 12 個細肌絲基因、先天性 54%、需機械性支持 58%，基因型未解者預後較差，tirasemtiv 為有前景標的。
- **發炎性肌病與 AFM**：五種主要亞型，每週 3 次有氧訓練，24 週監督式訓練優於居家運動；AFM 由 EV-D68 驅動、每兩年流行，肌力不對稱為鑑別關鍵，CSF 細胞數 <100/µL，MRC 0 分肌群恢復最差、遠端優於近端，完全恢復者少於 10%，IVIG 治療、神經轉移對手肘功能較佳而肩功能較差。
- **神經損傷與再生**：外傷者 3%–5%、車禍占 50% 以上，neurapraxia／axonotmesis／neurotmesis 三級；MEP 退化不可逆但可存續 26 個月至 3 年以上；VML 需無細胞生物材料＋幹／前驅細胞再生策略。
- **ALS 與 BPBI／CP**：C9ORF72、FUS、SOD1、TDP-43（經 STMN2 連結軸突生長）為核心基因；BPBI 攣縮（20%–40%）主因為 20S proteasome 介導蛋白降解增加；CP 致病變異率小兒約 33%、成人約 10%，TUBA1A 與 CTNNB1 為共同 de novo 突變基因。
- **壓迫性神經病變與 MS**：糖尿病對腕隧道與尺神經卡壓皆相關（HR 2.10／2.20），腕隧道易感位點 16 個；MS 每 10 萬人約 350 例、女：男 2.5:1，233 個風險位點，9 類 DMT 中 ocrelizumab 為唯一核准用於原發性進行型 MS 者，HSCT 有效（HR 0.07）而 biotin 與 opicinumab 失敗。
- **通則**：<span style="color:#60a5fa">分子發現不等於治療機會</span>；介入時機是療效的一部分；解剖相似不代表病理機轉相同；遺傳檢測陰性不代表預後較好。
