# Chapter 56: Spinal Column Infections — 脊椎感染

## 章節導讀

脊椎柱感染橫跨**發病前（de novo）**與**術後（postoperative）**兩大情境，臨床表現常被延誤。本章依「核心概念與臨床評估、決策矩陣、保守與手術治療指引、預防策略與陷阱、實證重點」五個層次整理：先界定 <span style="color:#e2e8f0">PVO（化膿性脊椎骨隨炎／椎間盤炎）</span>、<span style="color:#e2e8f0">SEA（脊髓硬膜上膿腫）</span> 與 <span style="color:#e2e8f0">術後脊椎感染</span> 的流行病學、影像與治療，再以表格整理決策矩陣與預防策略的所有數據。

## 1. 核心概念與臨床評估 (Core Concepts & Clinical Evaluation)

### 1.1 感染範疇總覽

本章處理四種脊椎柱感染：<span style="color:#e2e8f0">osteomyelitis（骨隨炎）</span>、<span style="color:#e2e8f0">diskitis（椎間盤炎）</span>、<span style="color:#e2e8f0">SEA</span> 與 <span style="color:#e2e8f0">postoperative spinal infection（術後脊椎感染）</span>，彼此可共存或互相轉化。

| 面向 | 原文重點 |
|------|----------|
| **最常見病原體** | <span style="color:#c084fc">S aureus（金黃色葡萄球菌）</span> 為脊椎柱感染、PVO 與 SEA 的最常見病原體 |
| **首選影像** | **MRI 加上與不加上釓（gadolinium）對比**是評估椎管內感染的最佳檢查 |
| **治療主軸** | 合併抗生菌；**有神經學缺損時以手術灌洗與清創（irrigation and débridement）為主軸** |
| **非手術治療** | 靜脈抗生素加上支具（bracing）可考慮用於**神經學完整**的骨隨炎／椎間盤炎 |
| **術後感染處置** | 灌洗清創加上長期抗生素，可合併或不合併**器械更換／移除** |

> **Pearl**：骨隨炎與 SEA 的最常見病原體同為 **S aureus**，故在取得培養結果前的經驗性抗生素選擇邏輯是共通的。

### 1.2 化膿性脊椎骨隨炎／椎間盤炎（PVO）

<!-- FIG: 圖 1 — |llustration shows the Weinstein, Boriani, and Biagini classification -->

> **原文缺漏**：PVO 的臨床定義、流行病學與診斷段落不在來源文字中，以下僅整理來源中可見的治療與檢驗數據。

| 項目 | 原文數據 |
|------|----------|
| **影像** | 對比增強影像可改善病灶視覺化，清楚界定對比劑聚集的感染範圍；感染可同時侵犯**椎體與椎間盤** |
| **無神經缺損時** | 可不手術，以**培養導向靜脈抗生菌**治療；抗生素前取得的**血液培養**有助辨識病原體 |
| **活檢** | 常取得 **CT 引導骨活檢**，但效益受質疑 |
| **靜脈抗生菌療程** | 通常 **6 週**，必要時轉口服抗生素 |
| **監測** | 序列檢驗 **WBC、ESR、CRP** 追蹤改善 |
| **藥物選擇** | <span style="color:#fb923c">cefazolin（頭孢唑林）</span> 為**革蘭陽性非 MRSA** 感染最常用的靜脈抗生素；<span style="color:#fb923c">vancomycin（萬古黴素）</span> 為**多數 MRSA 骨隨炎的治療選擇** |
| **會診** | 應請**感染專科**會診以指引抗生素療程 |

**CT 引導活檢的診斷率（依術前懷疑程度分層；323 例接受影像引導活檢）**

| 術前懷疑程度 | 活檢陽性率 |
|--------------|------------|
| 高度懷疑感染（92 例） | **30.4%** |
| 中度懷疑 | **16.1%** |
| 低度懷疑 | **5%** |

**重覆活檢的價值（136 例疑似 PVO）**：第一次活檢即鑑定出病原體者 **44.1%**；第一次活檢陰性後追加活檢者 **79.6%** 可鑑定出病理。

> **Danger zone**：CT 引導活檢的陽性率高度取決於**術前懷疑程度**——即使高度懷疑感染，陽性率也僅約三成。因此**高度懷疑 PVO 但活檢陰性時應考慮重覆活檢**；盲信第一次陰性結果可能延誤診斷。

### 1.3 脊髓硬膜上膿腫（SEA）：流行病學與臨床四分期

<span style="color:#e2e8f0">Spinal epidural abscess</span> 是脊髓管內**硬膜外腔**的感染。若未治療，伴隨高發病率與高死亡率，並因貼近神經構造可造成毀滅性的神經學併發症。

| 面向 | 原文數據 |
|------|----------|
| **好發族群與發生率** | 以 **50 至 70 歲男性**最多；**兒童極為罕見**；每 **10,000 例住院**約 **2 至 5 例** |
| **位置** | **腰椎**最常見：某研究 **54.7%** 位於腰椎、**39.1%** 位於胸椎 |
| **病原體** | <span style="color:#c084fc">S aureus</span> 最常見，**MSSA 比 MRSA 更常見**；另有凝固酶陰性葡萄球菌屬、鏈球菌屬與革蘭陰性菌 |
| **感染途徑** | **直接接種**或**血源性散播**；某三級醫療中心 10 年回顧顯示**血源性散播最常見**，其次為近期手術／處置 |
| **神經障礙機轉** | **直接壓迫**或**脊髓缺血**（由膿腫**質量效應**或**血管細菌性阻塞**） |
| **位置與關聯** | **腹側 SEA** 多伴隨骨隨炎／椎間盤炎；**背側 SEA** 多為 **de novo** |

**SEA 的危險因子（128 例回顧）**

| 危險因子 | 占比 |
|----------|------|
| **靜脈注射藥物使用（IV drug use）** | **39.1%** |
| **糖尿病（diabetes）** | **21.9%** |

其他危險因子包括**近期創傷**、**酒精使用**、**直接接種的處置**（脊椎硬膜外或 facet 注射），以及**共病**如糖尿病與免疫功能低下。

**臨床四分期（increasing disability）**：第一期**局部背痛** → 第二期**放射痛** → 第三期**運動與感覺缺損，可能伴隨大小便失禁** → 第四期**癱瘓**。

**初次就醫症狀（系統性回顧，1,099 例）**

| 症狀 | 比例 |
|------|------|
| 背痛 | **66.8%** |
| 運動無力 | **52%** |
| 感覺異常 | **40%** |
| 發燒 | **43.7%** |
| 大小便失禁 | **27.1%** |

### 1.4 SEA 的實驗室與影像檢查

<!-- FIG: 圖 2 — Magnetic resonance images from a 62-year-old man with methicillin-susc -->

| 檢查 | 原文重點 |
|------|----------|
| **初始實驗室** | **WBC 計數、ESR、CRP 與血液培養**；發炎指標通常**一項以上明顯升高**，但**未升高並不能排除 SEA** |
| **預測保守治療失敗**（128 例） | **糖尿病、CRP > 115、WBC 計數 > 12.5、血培養陽性** |
| **初始影像** | 疑似區段的 **AP 與側位 X 光**評估骨性變化；**CT** 可更細部評估 |
| **首選影像** | **MRI 加上與不加上對比增強**：**T1 低訊號**、**T2 高訊號**，對比時**膿腫呈環狀強化（rim enhancement）** |
| **掃描範圍** | 2019 年回顧建議確診者應做**全脊椎 MRI**，因**多灶性（multifocal）**侵犯比率高 |


> **Pearl**：診斷 SEA 時，**沒有發燒**並不能作為安撫理由——發燒僅見於 **43.7%**，而腰背痛高達 **66.8%**；發炎指標正常同樣不能排除診斷。

## 2. 分型系統與決策矩陣 (Classification & Decision Making)

### 2.1 三種感染情境的決策矩陣

| 臨床情境 | 建議方向 | 原文依據 |
|----------|----------|----------|
| **PVO／osteodiskitis，無神經缺損** | **保守治療**：培養導向靜脈抗生素（≥6 週）＋序列追蹤發炎指標；可加支具 | 無神經缺損可不予手術 |
| **PVO 合併硬膜上膿腫且有神經缺損** | **手術＋抗生素** | 明列適應症 |
| **PVO 保守治療失敗** | 轉手術 | 明列適應症 |
| **PVO 骨性不穩定或顯著 kyphotic 畸形** | 手術（重建穩定與排列） | 明列適應症 |
| **合併小型硬膜上膿腫但無神經缺損** | **有爭議（controversial）** | 原文明確標示為爭議 |
| **SEA，無神經缺損** | **保守治療**日益成為**第一線**：≥6 週培養導向靜脈抗生素＋嚴密監測 | 非手術管理日益增加 |
| **SEA 合併神經功能惡化** | **手術** | 明列適應症 |
| **SEA 陽性血培養且抗生素下仍全身性不適** | 手術 | 明列適應症 |
| **SEA 內科處理後疼痛持續且顯著** | 手術 | 明列適應症 |
| **SEA 合併骨盤膜炎且節段進行性變形** | 手術 | 明列適應症 |
| **術後感染合併神經學變化或敗血症徵象** | **立即進手術室**灌洗、清創與減壓 | 原文要求立即手術 |
| **術後感染，早期（<3 個月）** | 通常**保留內固定器械**，以避免脊柱失穩 | 原文明確 |
| **術後感染，晚期** | **器械保留或移除有爭議**；長期抗生素與清創無法根除時應**強烈考慮移除或更換** | 原文明確 |

### 2.2 硬膜上膿腫：保守 vs. 手術的結果比較

**系統性回顧（1,099 例）**：**59.7%** 初期手術、**40.3%** 非手術照護，**兩組結果未見差異**。**另一研究（128 例）**：**51 例**初期僅以靜脈抗生素治療，**最終 41% 仍接受手術**；**靜脈抗生素加上立即手術**者運動功能改善幅度最大（以 **ASIA score** 測量）。

> **Danger zone**：非手術治療並非「保守即安全」——接受靜脈抗生素者**有 41% 最終仍需手術**。非手術治療必須配合**嚴密的神經學監測**，並預先設定轉手術門檻。

### 2.3 手術治療的目標與範圍

| 面向 | 原文重點 |
|------|----------|
| **手術三目標** | **清創感染**、**穩定脊柱**、**保留神經功能** |
| **畸形矯正** | 感染後的**冠状或矢狀位畸形**亦可用手術矯正 |
| **SEA 手術內容** | **椎板切除（laminectomy）** 提供硬膜囊空間，並**清撤膿腫與感染性物質**；效益為移除**發炎反應連鎖**、**減少質量效應** |
| **是否融合** | 若存在**不穩定**可一併融合，但見 3.5 的代價 |

## 3. 治療指引：保守與手術適應症 (Treatment Algorithm)

### 3.1 PVO／osteodiskitis 的治療流程

| 情境 | 治療 | 說明 |
|------|------|------|
| 無神經缺損 | 培養導向靜脈抗生素 **≥6 週**→ 必要時轉口服；序列 WBC／ESR／CRP | 抗生素前先取血液培養 |
| 檢體取得 | CT 引導骨活檢（依術前懷疑程度陽性率 5%–30.4%）；陰性但高度懷疑時重覆活檢（可達 79.6% 鑑定率） | 效益受質疑但仍為常規 |
| 支持治療 | 依感染節段使用**腰骶 orthosis**（腰椎）或**胸腰 orthosis／Jewett extension**（胸椎） | **無長期效益研究**，但可支撐被感染削弱的脊椎柱 |
| 感染管制 | 請感染專科會診以指引抗生素療程 | 原文明確建議 |

**手術適應症（PVO／osteodiskitis）**：**保守治療失敗**；**合併硬膜上膿腫且有神經缺損**；**骨性不穩定或顯著 kyphotic 畸形**；感染後出現的**冠状位或矢狀位畸形**可一併手術矯正。

> **Pearl**：「小膿腫、無神經缺損」是原文唯一明確標示為**有爭議**的治療決策點——這類病人不應自動接受手術，也不應自動排除手術。

### 3.2 PVO 的手術重建

| 步驟 | 原文重點 |
|------|----------|
| **椎體切除範圍** | 當**椎體受累比例顯著**導致畸形或內科治療失敗時，常行**次全或全切除 corpectomy**，依受累程度決定 |
| **重建** | 以**自體骨、同種異體骨（allograft）或 cage** 重建；**可行時偏好髂骨自體骨**，但 **allograft 或 cage 療效相當**，且已證實**在局部感染下仍安全** |
| **入路** | 由**受累節段與醫師偏好**決定，可為**前方、側方或後方**入路 |
| **固定** | 典型使用**椎弓根螺釘（pedicle screws）**穩定受累節段；合併硬膜上膿腫可一併 **laminectomy** 清撤膿腫 |

### 3.3 PVO 的發病與死亡負擔

| 研究 | 數據 |
|------|------|
| **近期術後骨隨炎／椎間盤炎（65 例回顧）** | **1 年死亡率 6%**；最終追蹤時 **Oswestry Disability Index（ODI）顯著較低**、**EuroQol 五分量表**生活品質亦較低（相較未受影響者） |
| **骨隨炎／椎間盤炎（1,505 例世代分析）** | **死亡率比（mortality rate ratio）為 1.47** |

> **Danger zone**：即使妥善處理，**PVO 仍帶來顯著發病負擔**——近期手術相關者 1 年死亡率達 **6%**，功能與生活品質明顯低於對照組。治療成功的標準不應只是存活，還應納入 ODI 與生活品質的恢復。

### 3.4 SEA 的治療

**保守治療（無神經缺損）**：**培養導向靜脈抗生素至少 6 週**，並**仔細監測神經功能惡化與序列發炎指標**。

**手術治療**：**椎板切除＋灌洗與膿腫清創**；不穩定時可**加做融合**。

**SEA 的手術適應症（原文列舉）**：**神經功能惡化**；**抗生素下仍全身性不適且血培養陽性**；**內科處理後疼痛持續且顯著**；**合併骨盤膜炎且節段進行性變形**。

### 3.5 術後脊椎感染的治療

| 環節 | 原文重點 |
|------|----------|
| **立即處置** | **神經學檢查改變**或出現**敗血症徵象**者，應**立即送入手術室**灌洗、清創與減壓 |
| **術中探查與清創** | 取得**術中組織培養**，探查傷口判定為**淺層或深層**感染；應**徹底清創受感染與壞死組織**，有時需**多次灌洗清創** |
| **費用負擔** | 一項研究報告**平均 4 次灌洗清創（範圍 1 至 16 次）**，每位病人花費 **$250,000–$1,000,000** |
| **抗生素珠** | 當多次清創導致**局部軟組織血管度與灌流受損**、降低靜脈抗生素到達感染部位時，可用**抗生素珠（antibiotic-impregnated beads）** |
| **閉合方式** | 清創後若組織與術區外觀健康，可行**引流管上的一期縫合**；否則以**填塞或真空輔助閉合**，**2 至 5 天**後再次清創 |
| **抗生素療程** | **長期靜脈抗生素至關重要**；深度感染且**有器械**者常以**至少 4 至 6 週**治療；**無器械者有時選較短療程**；藥物與療程應**依培養結果與發炎指標反應**調整。部分作者主張加用口服 **sulfamethoxazole-trimethoprim 或 doxycycline** 作抑制性抗生素 |

> **Danger zone**：反覆清創的代價極高——**平均 4 次灌洗清創、每位病人 $250,000 至 $1,000,000**。因此第一次手術的清創徹底性與早期器械決策具有直接的財務與預後意義。

### 3.6 器械保留與移除的爭議

| 情境 | 原文觀點 |
|------|----------|
| **早期術後感染（<3 個月）** | 通常**保留器械**，避免脊柱失穩 |
| **晚期感染：移除的論據** | **凝固酶陰性葡萄球菌或 <span style="color:#c084fc">Cutibacterium acnes</span> 等惰性菌容易形成生物膜（biofilm）**；研究發現**保留植入物時反覆清創無法根除感染**，多數病人最終仍須移除 |
| **晚期感染：保留的論據** | 也有作者以**積極清創、微生物導向抗生素與保留植入物**成功根除；一項 **MRSA** 外科部位感染**回顧性病例系列 7 例**，清創＋保留植入物＋抗生素，**不需移除植入物**即獲控制 |
| **實務結論** | 若**長期抗生素與清創無法根除晚期深部感染，應強烈考慮移除或更換植入物** |

> **Pearl**：**早期感染偏向保留器械、晚期偏向移除**，但關鍵在於是否為生物膜形成的惰性菌（如 **C. acnes**），以及清創與抗生素是否真正達到根除。

## 4. 預防策略與危險地雷 (Prevention Strategies & Pitfalls)

### 4.1 術後感染預防：病人選擇與術前最佳化

**成人脊椎畸形手術的外科部位感染（SSI）危險因子**：**既往 SSI 史**（**OR 3.2**）、**肥胖**、**糖尿病**、**吸菸**、**翻修手術**、**年齡**、**尿失禁**、**腫瘤切除**、**三種以上共病**。

| 特定數據 | 原文數值 |
|----------|----------|
| **後方腰椎入路 vs. 前方腰椎手術的感染勝算比** | **0.32**（後方腰椎入路感染風險**高於**前方腰椎手術） |
| **HbA1c 與感染風險** | 風險隨 **HbA1c** 升高而**成比例增加**；elective spine surgery 的確切門檻雖有爭議，但研究已顯示 **HbA1c > 7.5%** 顯著增加術後感染風險 |

> **Danger zone**：**「HbA1c > 7.5%」是原文提供的可操作門檻**；術前最佳化血糖控制的同時，務必檢視**未控制的吸菸、肥胖、營養不良與既往感染**等可修正因子。

### 4.2 術前預防措施與其證據強度

| 措施 | 原文證據 |
|------|----------|
| **兒童脊椎手術預防準則** | 對 **13 項**預防策略，兒童脊椎外科醫師共識度 **> 90%**，但**多數建議主要基於專家意見** |
| **13 項策略** | 術前一晚**氯己定皮膚清洗**、術前**尿液培養／陽性時給藥**、**病人衛教單張**、**營養評估**、**圍手術期 cefazolin**、革蘭陰性桿菌的**靜脈預防**、**限制手術室人員進入**、**剪髮取代剃髮**、**傷口內萬古黴素粉**、術後**防水敷料** |
| **術前無菌沐浴／淋浴** | **Cochrane 檢閱 7 篇研究**，顯示此作法**沒有一致效果，也未證實有效** |
| **不同皮膚消毒溶液** | 可能**降低消毒後陽性培養率**，但**未顯示降低術後感染風險** |
| **MSSA／MRSA 術前篩檢** | **2020 年統合分析**顯示**帶菌者風險增加**，**根除帶菌可降低感染風險**；結論為**建議術前篩檢與根除** |

> **Pearl**：**術前 MRSA／MSSA 鼻腔篩檢與去定殖**是少數「有統合分析支持、且可降低感染率」的預防策略；相對地，術前無菌沐浴與皮膚消毒溶液的效益證據薄弱。

### 4.3 手術室污染源

| 污染源 | 原文污染率 |
|--------|------------|
| **顯微鏡目鏡** | **24%** |
| **顯微鏡上方構造所覆蓋的手術鋪巾** | **44%** |
| **C 型手臂（X-ray）** | 上方部位 **56%**；上前部 **28%** |
| **值班後穿著的刷手服** | **89%** |
| **未穿著的刷手服** | **41%** |

> **Danger zone**：**值班後穿著的刷手服污染率達 89%**，而**未穿著者仍有 41%**——刷手服並非乾淨的物件，應納入污染管理的固定監測項目。

### 4.4 術中因素

| 因素 | 原文數據 |
|------|----------|
| **手術時間 2 至 5 小時**（相較 <2 小時） | 深部術後傷口感染 **OR 2.4** |
| **手術時間 >5 小時**（相較 <2 小時） | 感染 **OR 2.85** |
| **估計失血量 >1 L** | 術後傷口感染的**獨立危險因子，OR 2.2** |
| **稀釋優碘（dilute betadine）沖洗** | 隨機對照試驗顯示可**降低外科部位感染** |
| **閉式負壓引流** | **未發現影響感染風險** |
| **抗生素縫線（antibiotic sutures）** | 隨機對照試驗發現可**降低外科部位感染率** |

### 4.5 抗生素預防

| 面向 | 原文重點 |
|------|----------|
| **給藥時間** | **切皮前 60 分鐘內**給予，並**在手術過程中反覆追加** |
| **首選藥物** | 通常為**頭孢菌素（cephalosporins）**，除非有嚴重過敏 |
| **最常用藥物** | <span style="color:#fb923c">cefazolin</span>；須**每 4 小時**或**失血 1.5 L**後追加，故**與麻醉科溝通至關重要** |
| **嚴重頭孢過敏** | 可改用 <span style="color:#fb923c">vancomycin</span> 或 <span style="color:#fb923c">clindamycin</span> |
| **爭議項目** | 圍手術期**常規使用萬古黴素**預防 MRSA、**gentamicin** 預防革蘭陰性菌，仍有爭議 |

### 4.6 傷口內局部抗生素粉

**萬古黴素粉（intrawound vancomycin powder）**

| 研究 | 數據 |
|------|------|
| **器械融合病人** | 深部感染率：控制組 **2.6%** vs. 萬古黴素粉組 **0.2%** |
| **1,001 例後方頸椎融合** | 治療組接受**萬古黴素粉＋淺層引流管＋酒精泡沫消毒**；控制組感染率 **1.86%**，治療組**無報告感染**，儘管治療組**年齡較大**且**超過四節段比例較高** |
| **兔子體內實驗** | 單獨預防性 **cefazolin** 導致**持續 S aureus 污染**，萬古黴素粉組未見此現象 |
| **成人脊椎畸形手術** | 感染**明顯下降**；**每 100 例胸腰段畸形矯正省 $244,000** |
| **反向證據（隨機對照試驗）** | 單獨全身性預防 vs. 加用傷口內萬古黴素：**感染率較低但未達統計顯著**，作者結論為**當感染率本來就低時可能無效** |

**妥拉黴素粉（intrawound tobramycin）**：文獻主要來自**骨科創傷文獻**。**1,085 例開放性骨折**回顧中治療組感染率 **3.7%**、對照組 **12%**；**兔的體內實驗**中傷口內妥拉黴素在**所有受試動物**均**根除 E. coli** 污染，而**對照組 40 隻中 39 隻持續生長**。臨床特別關注**小兒神經肌肉性脊柱側彎**病人，因其**革蘭陰性菌感染率偏高**。

> **Danger zone**：**傷口內萬古黴素粉並非無條件有效**——隨機對照試驗顯示在**感染率本來就低的族群中無統計顯著差異**；應依中心感染率與成本條件判斷。

### 4.7 負壓傷口治療（NPWT）

| 研究 | 結果 |
|------|------|
| **2020 年單一外科醫師經驗** | 前方器械椎間融合的**術後傷口併發症減少**；後方融合**優先用於**腫瘤性、**感染性病因**、**長節段融合（>7 節）**、**術中硬膜破裂**與**翻修手術**者 |
| **2021 年前瞻性非隨機試驗** | 僅減壓者感染 **4.2% vs. 9.1%**——**未達統計顯著**；器械融合者由 **11.4%** 降至 **3.2%**，**具統計顯著差異** |
| **次族群** | **BMI > 30 kg/m²** 與 **40 至 64 歲**病人亦見**統計顯著下降** |

### 4.8 術後感染的流行病學

| 面向 | 原文數據 |
|------|----------|
| **整體發生率** | 依病人相關危險因子（**肥胖、吸菸、營養不良、免疫抑制**）不同，介於 **0.6% 至 18%** |
| **手術相關危險因子** | **手術時間、進入手術室人數、失血量增加、傷口引流**；**器械融合**高於**僅減壓** |
| **硬膜外類固醇注射** | 2021 年 15,000 例研究：**術前硬膜外類固醇注射可能增加腰椎融合後的感染風險**，但**僅減壓者未見此風險**；**尤其術前 30 天內執行者**風險最高 |
| **微生物組成**（8.5 年、6,727 例融合） | 感染率 **5.2%**；**55.2% 單一微生物**、**43.5% 多微生物**、**1.3% 培養陰性** |
| **單一微生物組成** | **79.4%** 為**皮膚菌叢**如革蘭陽性 **Enterococcus**；**20.6%** 為**腸道與革蘭陰性菌** |
| **菌種趨勢** | 革蘭陰性感染**較可能是多微生物**且**出現較早**；存在**解剖學梯度**：**頸椎**以革蘭陽性皮膚菌叢為主，**腰骶椎**轉為革蘭陰性腸道菌叢 |
| **抗藥性** | 檢出菌種中**超過一半（57.5%）對術時預防性抗生素具抗藥性** |

> **Pearl**：**解剖梯度**是本章最具臨床價值的概念之一——這解釋了為何**腰骶椎手術的預防性抗生素選擇**與頸椎不同，也解釋了革蘭陰性菌在腰骶段較早出現的現象。

### 4.9 術後感染的診斷

| 面向 | 原文重點 |
|------|----------|
| **典型表現** | 切口附近**疼痛與壓痛**；可有**傷口滲液、腫脹、紅斑**；**深部感染可於術後 90 天內**出現 |
| **隱匿性** | 傷口裂開與化膿性引流是明顯徵象，但**受感染傷口外觀常相對 innocuous**；**緊密筋膜縫合可讓深部感染在無淺表徵象下發展** |
| **全身徵象** | **發燒與敗血症徵象較不常見**，但可見於 **MRSA** 等高毒力菌株 |
| **發炎指標** | 無感染時術後 **ESR 與 CRP 也會升高**，分別在 **3 個月**與 **2 至 3 週**內恢復正常；**CRP 於術後 2 至 3 天達高峰**，恢復更快更可預測 |
| **感染判斷** | 若 **CRP 未下降**或出現**第二個高峰**，應考慮術後感染；術後感染時**白血球增多見於不到 50% 的病例** |
| **培養** | **血液培養**應在抗生素前採集，但術後感染病人中**常為陰性**；**淺表傷口培養一般不建議**（污染機率高）；**術中培養（intraoperative cultures）** 為確認感染並分離致病菌的**金標準** |
| **X 光** | **平片常為正常**，但有助排除其他病因（包括**器械失敗**）；**潛伏性感染**可見螺釘周圍**透亮區**；**椎間盤炎**可見**終板侵蝕與椎間盤高度喪失** |
| **CT 與 MRI** | 有助辨識**非典型液體積聚**，但**急性術後期結果常相對非特異**，難與正常術後變化區分 |

> **Danger zone**：**術後 CRP 不下降或出現第二個高峰**，是比發燒與白血球增多更可靠的感染訊號（後者出現率不到一半）。相對地，**急性術後期的 CT／MRI 結果往往非特異**，不可單憑影像排除感染。

## 5. 實證更新與 OKU 14 重點 (Recent Evidence & Take-Home Points)

### 5.1 重要研究與證據等級整理

| 主題 | 來源 | 證據等級與結論 |
|------|------|----------------|
| 化膿性脊椎骨髓炎的微生物病因學 | Kim DY, et al: Open Forum Infect Dis 2020;7(6):ofaa176 | **Level IV**（**S aureus** 常於年輕者；革蘭陰性菌常於**女性、年長者、肝硬化或腫瘤**；**MRSA** 常於**慢性腎病**） |
| SEA 危險因子與醫學 vs. 手術（128 例） | Patel AR, et al: Spine J 2014;14(2):326 | **Level IV**（IVDU **39.1%**、糖尿病 **21.9%**） |
| 頸胸段多灶性脊椎感染 | Balcescu C, et al: Neurospine 2019;16(4):756-763 | **Level IV**（建議術前**全脊椎 MRI**） |

| 鼻腔 S aureus 定殖與脊椎術後 SSI 統合分析 | Ning J, et al: Spine J 2020;20(3):448-456 | **Level III**（帶菌者風險增加，去定殖可降低風險） |

| 術前硬膜外類固醇注射與感染風險 | Kreitz TM, et al: Spine 2021;46(3):197-202 | **Level III**（**30 天內**注射風險最高） |
| 融合 SSI 的微生物解剖梯度與抗藥性 | Long DR, et al: Spine 2021;46(3):143-151 | **Level III**（**57.5%** 菌株抗藥） |
| 術後 SSI 植入物保留或移除（49 篇回顧） | Agarwal A, et al: Global Spine J 2020;10(5):640-646 | **Level III**（支持晚期 SSI 移除／更換） |

### 5.2 OKU 14 Key Study Points（本章重點整理）

- **MRI 加上與不加上釓對比**是評估**椎管內感染**的最佳影像檢查。
- **S aureus** 是造成**骨隨炎／椎間盤炎與 SEA** 最常見的病原體。
- 對**神經學完整**的骨隨炎／椎間盤炎病人可考慮**非手術管理**（靜脈抗生素與支具）；**有神經缺損者需手術並加上靜脈抗生素**。
- **傷口內萬古黴素粉**已證實可**降低 elective spine surgery 的術後感染率**。
- **術後脊椎感染**典型處置為**灌洗與清創加上長期抗生素**，可合併或不合併**器械更換／移除**。

### 5.3 骨科專科考試核心總結（Take-Home Points）

1. **範疇與病原體**：骨隨炎、椎間盤炎、SEA 與術後脊椎感染；**S aureus** 最常見（SEA 中 **MSSA > MRSA**）。
2. **首選影像**：**MRI 加上與不加上釓對比**（T1 低訊號、T2 高訊號、對比**環狀強化**）；確診者應做**全脊椎 MRI**。
3. **診斷陷阱**：SEA 的**發炎指標未升高不能排除診斷**（**發燒僅 43.7%**）；術後感染白血球增多少於 50%，但**CRP 未下降或第二個高峰**更可靠。
4. **活檢**：CT 引導骨活檢陽性率依術前懷疑程度為 **30.4%／16.1%／5%**；高度懷疑但陰性時**追加活檢可達 79.6% 鑑定率**。
5. **SEA 四分期**：背痛 → 放射痛 → 運動／感覺缺損合併大小便失禁 → 癱瘓；手術適應症為**神經功能惡化、陽性血培養下持續全身性不適、持續嚴重疼痛、合併骨盤膜炎的進行性變形**。
6. **保守治療監測**：SEA 非手術治療需**≥6 週靜脈抗生素＋嚴密神經學與發炎指標監測**；接受靜脈抗生素者**最終 41% 仍需手術**。**預測保守失敗**：**糖尿病、CRP > 115、WBC > 12.5、血培養陽性**。
7. **PVO 手術**：**次全或全 corpectomy ＋ 自體骨／cage 重建 ＋ 椎弓根螺釘**；合併硬膜上膿腫加做 **laminectomy**。
8. **負擔**：近期術後骨隨炎**1 年死亡率 6%**、**死亡率比 1.47**；術後感染深度化可需**平均 4 次清創、每人 $250,000–$1,000,000**。
9. **預防危險因子**：**HbA1c > 7.5%**、既往 SSI（**OR 3.2**）、後方腰椎入路（**OR 0.32**）、**手術時間 >5 小時（OR 2.85）**、**失血 >1 L（OR 2.2）**。
10. **抗生素預防**：**切皮前 60 分鐘內**給藥、**每 4 小時或失血 1.5 L 追加**；cefazolin 最常用；**萬古黴素粉**多項研究支持但低感染率族群效益不顯著；**NPWT** 對器械融合有效（**11.4%→3.2%**）。
11. **器械保留 vs. 移除**：**早期（<3 個月）多保留器械**；晚期因**生物膜（惰性菌如 C. acnes）** 偏向移除，長期抗生素與清創無法根除時應**強烈考慮移除或更換**。
12. **微生物梯度**：頸椎多為革蘭陽性皮膚菌叢、腰骶椎多為革蘭陰性腸道菌叢；**57.5%** 菌株抗藥。

## Summary

- **範疇與病原體**：骨隨炎／椎間盤炎、**SEA** 與術後感染；**S aureus** 最常見（SEA 中 **MSSA > MRSA**）；**MRI 加上與不加上釓對比** 為首選影像，確診者應做**全脊椎 MRI**。
- **診斷陷阱**：SEA 的**發炎指標正常不能排除診斷**（發燒僅 **43.7%**）；活檢陽性率依術前懷疑程度為 **30.4%／16.1%／5%**，陰性而高度懷疑時追加活檢可達 **79.6%** 鑑定率；術後感染以 **CRP 未下降或第二個高峰** 較白血球增多（**<50%**）可靠。
- **治療決策**：無神經缺損的 PVO 與 SEA 可採**保守治療**（≥6 週靜脈抗生素＋支具與嚴密監測）；**神經缺損、保守失敗、不穩定、進行性畸形或陽性血培養下的全身性不適**為手術適應症。SEA 保守治療者**最終 41% 仍需手術**。
- **手術策略**：PVO 以**次全／全 corpectomy＋自體骨或 cage 重建＋椎弓根螺釘**為主；SEA 以 **laminectomy＋灌洗清創**為主；術後感染須**徹底清創＋長期靜脈抗生素**，平均 **4 次清創、每人 $250,000–$1,000,000**。
- **器械決策**：**早期（<3 個月）多保留器械**；晚期因**生物膜（惰性菌如 C. acnes）** 偏向移除，但**長期抗生素與清創無法根除時應強烈考慮移除或更換**。
- **預防重點**：**HbA1c > 7.5%**、既往 SSI（**OR 3.2**）、後方腰椎入路、**手術時間 >5 小時（OR 2.85）**、**失血 >1 L（OR 2.2）**；**傷口內萬古黴素粉**多項研究支持（深部感染 **2.6% vs 0.2%**，每 100 例畸形矯正省 **$244,000**），但低感染率族群效益不顯著；**NPWT** 對器械融合有效（**11.4%→3.2%**）。
- **微生物梯度**：頸椎多為革蘭陽性皮膚菌叢、腰骶椎多為革蘭陰性腸道菌叢；**57.5%** 菌株對預防性抗生素抗藥，預防用藥需依部位調整。
