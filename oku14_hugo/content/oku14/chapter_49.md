# Chapter 49: The Diabetic Foot — 糖尿病足

## 章節導讀

糖尿病足包含周邊血管疾病、神經病變、感染與骨骼結構破壞的多重影響。本章依據 OKU 14 指引，全面整理糖尿病足潰瘍的評估與分型（包含經典 Meggitt-Wagner 分期與新推薦之 SINBAD 系統）、多學科團隊照護、非手術清創與減壓裝具應用、經驗性抗生素與血管重建處置、各解剖層級截肢手術的關鍵決策，以及夏科氏神經關節病變（Charcot Arthropathy）的機轉、Eichenholtz 分期、Brodsky 分型與足部重構手術，協助臨床醫師建立精準的診斷與治療方針。

---

## 1. 臨床評估與潰瘍分型 (Clinical Evaluation & Ulcer Grading)

糖尿病足的處理必須同時評估血管通暢度、潰瘍深度、神經病變及感染程度。

### 1.1 血管評估與傷口癒合預測

[原文開頭缺漏] ...比 <span style="color:#e2e8f0">ankle-brachial index（ABI，踝肱指數）</span> 更能預測傷口癒合，因為 ABI 常會因動脈壁的血管鈣化（vessel calcification）而假性升高。此外，<span style="color:#e2e8f0">transcutaneous oxygen pressure（TcPO2，經皮氧分壓）</span> 量測值 <span style="color:#34d399">>40 mm Hg</span> 代表具有可接受的傷口癒合潛力。若存在嚴重血管病變，應照會血管外科醫師評估血管重建手術（revascularization procedures）。

> **Pearl**：ABI 常因糖尿病患者的血管鈣化而假性偏高；測量 TcPO2 > 40 mm Hg 能更可靠地反映潛在的傷口癒合能力。

### 1.2 潰瘍分型系統 (Grading Systems)

#### Meggitt-Wagner 分期系統
<span style="color:#e2e8f0">Meggitt-Wagner classification</span> 是評估糖尿病足潰瘍深度與壞疽範圍的經典分型，具高檢查者間一致性（interrater agreement）且已驗證與截肢風險相關，但未涵蓋血管病變（PAD）及感染細節：

| Wagner 分期 | 臨床特徵與深度定義 |
|-------------|--------------------|
| **Stage 0** | 無開放性潰瘍，可能存在閉合性病變或前兆 |
| **Stage 1** | 淺層潰瘍（表皮/真皮），無膿瘍或骨髓炎 |
| **Stage 2** | 深層潰瘍（延伸至肌腱、關節囊或深層結構），無膿瘍或骨髓炎 |
| **Stage 3** | 深層潰瘍併發 <span style="color:#f87171">abscess（膿瘍）</span> 或 <span style="color:#f87171">osteomyelitis（骨髓炎）</span> |
| **Stage 4** | 局限性足部壞疽（localized foot gangrene，如前足或趾部） |
| **Stage 5** | 廣泛性足部壞疽（extensive foot gangrene，波及全足） |

#### SINBAD 分型系統
國際糖尿病足工作組（IWGDF）強烈推薦使用 **SINBAD** 系統（Site, Ischemia, Neuropathy, Bacterial infection, Area, Depth）進行臨床溝通，此系統不依賴特殊檢查且具有可重複性，最高總分為 6 分：

| 評估項目 (Category) | 定義 (Definition) | 積分 (Score) |
|---------------------|-------------------|--------------|
| **Site（部位）** | 前足（Forefoot） | 0 |
| | 中足與後足（Midfoot and hindfoot） | 1 |
| **Ischemia（缺血）** | 至少摸得到 1 條足背/後脛動脈搏動（At least 1 pedal pulse intact） | 0 |
| | 足部動脈搏動消失（Nonintact pedal pulses） | 1 |
| **Neuropathy（神經病變）** | 保護性感覺存在（Protective sensation intact） | 0 |
| | 保護性感覺喪失（Protective sensation lost） | 1 |
| **Bacterial infection（細菌感染）** | 無感染（None） | 0 |
| | 存在感染（Present） | 1 |
| **Area（面積）** | 潰瘍面積 <1 cm² | 0 |
| | 潰瘍面積 ≥1 cm² | 1 |
| **Depth（深度）** | 局限於皮膚與皮下組織（Skin and subcutaneous tissue） | 0 |
| | 延伸至肌肉、肌腱或更深層（Extending to muscle, tendon or deeper） | 1 |
| **總分上限** | **Maximum possible score** | **6** |

> **Pearl**：SINBAD 系統以 6 項臨床指標快速評估，已獲國際指引驗證可用於預測潰瘍癒合率與下肢截肢機率。

### 1.3 多學科照護與血糖控制門檻

糖尿病足的處置需整合骨科、血管外科、整形外科、新陳代謝科、感染科、營養師及裝具師（orthotist）等多學科團隊。血糖控制以 <span style="color:#e2e8f0">hemoglobin A1c（HbA1c，糖化血色素）</span> 為標準，<span style="color:#f87171">HbA1c ≥6.5%</span> 即定義為糖尿病。

| 臨床生化與生理指標 | 臨床意義與截肢風險 |
|---------------------|--------------------|
| **HbA1c ≥ 8.0% 且空腹血糖 ≥ 126 mg/dL** | 2020 年系統綜述顯示，與糖尿病足潰瘍患者下肢截肢機率增加顯著相關 |
| **高血壓、高血脂、腎衰竭、吸菸** | 需積極調控與戒除，以降低糖尿病相關併發症風險 |

## 2. 非手術處置與多學科處置 (Nonsurgical Management & Medical Optimization)

非手術治療的核心目標為：消除異常機械壓力、改善血管灌流、徹底清除感染，並配合客製化輔具達成無潰瘍且可穿鞋的足部狀態。

### 2.1 傷口照護與減壓輔具 (Wound Care & Offloading)

- **門診銳性清創（Sharp Débridement）**：在無明顯膿瘍或骨髓炎時，應於門診以刀片銳性切除壞死組織與老繭（callus），刺激肉芽組織生長。多數患者因神經病變而耐受良好。
- **敷料選擇**：濕到乾（wet-to-dry）敷料可用於清創並吸收滲液；乾燥病灶可添加保濕劑；持續性潰瘍可使用負壓傷口治療（NPWT）。此外，海藻酸鹽（alginates）、膠體（colloids）、含銀或含碘敷料均可輔助使用。高壓氧治療（HBOT）為 FDA 核准用於難治性潰瘍的療法。
- **減壓裝具（Offloading Devices）**：
  - <span style="color:#60a5fa;font-weight:600">Total Contact Casting (TCC)</span>：為傷口減壓的**金標準（gold standard）**，相較於可拆卸式步行器具有更高的癒合率與更快癒合時間。
  - **鞋具設計**：系統綜述顯示搖椅底鞋底（rocker soles）具強實證可降低蹠側峰值壓力；客製鞋墊（custom insoles）具中等實證。
  - **Medicare 給付**：符合資格者每年可獲得 1 雙額外深度/特寬客製鞋（extra-depth, extra-wide custom shoes）及 3 雙客製鞋墊。

### 2.2 營養評估與血清白蛋白門檻

糖尿病足潰瘍患者常伴隨營養不良。在感染評估中，除白血球（WBC）、紅血球沉降率（ESR）、C-反應蛋白（CRP）外，應定期檢測血清白蛋白：

> **Danger zone**：血清白蛋白（Albumin）必須 <span style="color:#34d399">>3.0 g/dL</span> 才具備較可預期的傷口癒合能力並提升肢體挽救（limb salvage）的成功率。

### 2.3 抗生素治療策略 (Antibiotic Therapy)

糖尿病足感染多為多菌性（polymicrobial）：

| 感染嚴重度分類 | 常見病原體與治療原則 |
|----------------|----------------------|
| **非威脅肢體感染 (Non-limb-threatening)** | 最常見病原體為 <span style="color:#c084fc">Staphylococcus aureus</span>；口服抗生素僅限於輕度感染或長期抑制 |
| **威脅肢體或生命感染 (Limb/Life-threatening)** | 以 <span style="color:#c084fc">Gram-negative bacteria</span> 及 <span style="color:#c084fc">Anaerobes</span> 為主 |
| **經驗性靜脈抗生素 (Empiric IV Antibiotics)** | 若治療 24–48 小時無改善、併發骨髓炎、敗血症或威脅肢體，應立即啟用廣效 IV 抗生素，並涵蓋 <span style="color:#c084fc">MRSA</span> 或 <span style="color:#c084fc">Pseudomonas</span> |

### 2.4 血管重建介入 (Vascular Intervention)

動脈超音波（Duplex arterial ultrasonography）確認 PAD 後，配合 CT 血管攝影（CTA）評估血管重建：

- **效果**：血管重建使糖尿病併發嚴重肢體缺血患者的主要截肢率（major amputation rate）<span style="color:#60a5fa">降低近 30%</span>。
- **血管重建途徑**：血管內處置（Endovascular）與傳統開放式手術（Open revascularization）兩者在傷口癒合率與截肢率上無顯著差異。
- **存活率警告**：雖然血管重建可成功保留肢體，但這類患者 <span style="color:#f87171">5 年死亡率接近 50%</span>。

## 3. 手術清創與各層級截肢 (Surgical Débridement & Amputation Spectrum)

當潰瘍併發深部膿瘍或骨髓炎時，必須執行清創與灌洗手術。

### 3.1 手術清創原則與局部抗生素

- **無菌培養**：必須取得未接觸外在環境的深部無菌組織或骨骼培養，以利精準指導抗生素。
- **腔室清創**：徹底切除所有壞死組織與受感染骨骼，必要時執行多次清創，並在兩次手術間搭配負壓傷口治療（NPWT）。
- **局部抗生素載體**：可填入含抗生素的水泥珠（antibiotic beads）或粉劑，提高局部抗生素濃度。

### 3.2 各解剖層級截肢決策 (Amputation Levels)

截肢應盡可能保留足底長條全層軟組織皮瓣（long, full-thickness, plantar soft-tissue flaps）。

| 截肢層級 | 關鍵解剖 Pearls & 手術決策 |
|----------|----------------------------|
| **1. 大拇趾 (Greater toe)** | 必須保留 <span style="color:#22d3ee">flexor hallucis brevis（FHB，屈拇短肌）</span> 於近節趾骨的附著。若切除近節趾骨，FHB 須執行十道縫合固定術（tenodesis），避免種子骨後縮（sesamoid retraction）導致第一蹠骨頭承受過高壓力與再潰瘍。 |
| **2. 小趾 (Lesser toes)** | 切除第二趾（尤其是 MTP 關節處或近端）易導致拇趾外翻。若能保留部分近節趾骨基底，可防止拇趾向缺損處偏移。 |
| **3. 蹠骨射線 (Ray amputation)** | 最常用於第一與第五蹠骨。<br>• **第一射線**：若切除第一蹠骨，失去 <span style="color:#22d3ee">tibialis anterior（脛前肌腱）</span> 會導致垂足（foot drop），應儘量將肌腱重固定於殘骨。<br>• **第五射線**：切除第五蹠骨基底時，必須將 <span style="color:#22d3ee">peroneus brevis（腓骨短肌腱）</span> 重新附著，以平衡內翻力，避免旋後畸形（supination deformity）與外側柱過載。 |
| **4. 中足 (Midfoot / Transmetatarsal)** | 蹠骨切骨需呈拋物線（parabola shape）。<br>• 為維持 Lisfranc 關節穩定度，應保留 <span style="color:#60a5fa">約 3 cm 之第二蹠骨近端基底</span>。<br>• 骨切面需向蹠側斜削（beveled plantarly）。<br>• Lisfranc 關節或更近端截肢時，需轉移 tibialis anterior 與 peroneus brevis，並常需行跟腱延長術（Achilles tendon lengthening）。 |
| **5. 後足 (Hindfoot / Syme / Boyd)** | Chopart 關節截肢即便延長跟腱仍易產生馬蹄足畸形。<br>• **Syme 截肢**：踝關節脫位截肢（ankle disarticulation），依靠跟骨墊於脛骨穹窿負重，高度依賴 <span style="color:#22d3ee">posterior tibial artery（後脛動脈）</span> 供血，需固定跟墊。<br>• **Boyd 截肢**：保留跟骨並行脛跟關節融合（tibia-calcaneus arthrodesis），截肢端較穩固但技術難度高。 |
| **6. 脛骨下截肢 (Transtibial / Below-knee)** | 適用於嚴重感染、跟部潰瘍、周邊血管病變或無法拯救之肢體。雖然能量消耗與死亡率高於遠端截肢，但能提供更可靠 definitive 的治療成果。 |

> **Danger zone**：切除第一射線若未重固定脛前肌腱會導致垂足；切除第五蹠骨基底若未重固定腓骨短肌腱會引發足旋後畸形與外側柱潰瘍。

## 4. 夏科氏神經關節病變 (Charcot Arthropathy)

<span style="color:#e2e8f0">Charcot neuroarthropathy</span> 為糖尿病引發骨骼關節漸進性破壞的嚴重併發症，在糖尿病患者中的盛行率約為 <span style="color:#60a5fa">0.56%</span>（發生率為每 10,000 人年 7.4）。

### 4.1 病因機轉與臨床診斷

- **病因學說**：包含神經血管學說（Neurovascular theory，神經反射引發充血與骨吸收）與神經創傷學說（Neurotraumatic theory，微創傷引發發炎反應與微骨折）。
- **分子機轉**：促發炎細胞激素（TNF-α, IL-1β）升高，活化 <span style="color:#e2e8f0">RANKL-RANK 結合</span>，上調破骨細胞（osteoclast）活性造成骨溶蝕。
- **鑑別診斷**：患足呈現水腫、紅斑與發熱：
  - <span style="color:#fbbf24">紅斑於抬腳 5 分鐘後消退</span>：可與蜂窩性組織炎（cellulitis）鑑別。
  - **ESR 門檻**：血清 <span style="color:#f87171">ESR > 70 mm/hr</span> 與骨髓炎高度相關。
  - **MRI 表現**：急性 Charcot 與骨髓炎在 T1 皆為低訊號、T2 為高訊號；若骨水腫鄰近竇道（sinus tract）或潰瘍則多提示骨髓炎。

### 4.2 解剖分型與病程分期

#### Eichenholtz 病程分期
| Eichenholtz 分期 | 階段名稱 | 臨床與 X 光特徵 |
|------------------|----------|-----------------|
| **Stage 1** | **碎裂期 (Fragmentation phase)** | 局部發熱、紅斑與水腫（易誤診為感染）；X 光可見骨骼碎裂、骨折與關節半脫位/脫位 |
| **Stage 2** | **融合期 (Coalescence phase)** | 發炎反應消退；X 光顯示骨吸收減緩，出現新骨形成與融合 |
| **Stage 3** | **鞏固期 (Consolidation phase)** | 骨骼與關節結構趨於穩定，但殘留足部畸形 |

#### Brodsky 解剖分型
| Brodsky 分型 | 解剖侵犯部位 | 臨床特性 |
|--------------|--------------|----------|
| **Type 1** | **中足（Tarsometatarsal 及 Naviculocuneiform 關節）** | **最常見** |
| **Type 2** | **後足（Subtalar, Talonavicular, Calcaneocuboid 關節）** | 次常見 |
| **Type 3A** | **踝關節（Ankle joint）** | 罕見，但最不穩定 |
| **Type 3B** | **跟骨結節骨折（Calcaneal tuberosity fracture）** | 跟骨後側結構破壞 |

> **Pearl**：Charcot 足最經典的形態為 **搖椅底畸形（rocker-bottom deformity）**、扁平外翻足（pes planovalgus）及蹠內側骨外贅。負重時需達成第一、第五蹠骨頭與跟骨三點平均著地的 **plantigrade foot**。X 光上距骨頸長軸在 AP 與側位照均應與第一蹠骨長軸對齊。

### 4.3 保守治療與足部重構手術

#### 保守治療流程
- **Stage 1**：嚴禁負重（non-weight bearing），使用 <span style="color:#60a5fa">Total Contact Cast (TCC)</span> 減壓，初始每週換模並追蹤 X 光。
- **Stage 2**：腫脹穩定後，過渡至可拆卸式 <span style="color:#e2e8f0">CROW boot（Charcot Restraint Orthotic Walker）</span> 或雙支柱 AFO。
- **Stage 3**：骨骼結構完全穩定後，穿著客製矯形鞋與鞋墊。

#### 手術重構原則 (Surgical Reconstruction)
- **手術時機**：<span style="color:#f87171"> Stage 1 骨骼脆弱嚴禁執行內固定</span>；理想手術時機為 **Stage 3** 發炎反應鞏固後。
- **手術技術**：常見的搖椅底畸形需於畸形頂點執行 **雙平面楔形切骨術（biplanar wedge osteotomy）**，其切除之骨楔在內側與蹠側較寬，以同時矯正外展與搖椅底畸形。
- **術後照護**：術後需嚴格執行長達 <span style="color:#f87171">12 至 16 週的非負重（12 to 16 weeks non-weight bearing）</span>。

### 4.4 截肢在夏科氏足的定位

截肢為治療難治性感染與嚴重畸形的最後手段（last resort），但對於嚴重軟組織缺損、血管供應不足或缺乏足夠骨量可供重構的患者，可作為首選手術方案。

## 5. 實證更新與 OKU 14 重點 (Recent Evidence & Take-Home Points)

### 5.1 關鍵文獻摘要 (Key Study Points)

- **多學科照護**：糖尿病足受血管、神經、肌肉骨骼、營養與軟組織多重因素影響，必須由多學科團隊共同管理。
- **早期診斷 Charcot 關節病**：Charcot 神經關節病變是嚴重且具挑戰性的併發症，需密切注意臨床與影像表現，避免延誤診斷。
- **非手術與手術重構價值**：TCC 與客製鞋能有效減壓；手術重構（軟組織平衡、切骨與關節融合）能建立無痛、無潰瘍且可穿鞋的 plantigrade foot。雖然血管重建降低了截肢率，但糖尿病足仍持續面臨截肢風險。

### 5.2 骨科專科考試核心總結（Take-Home Points）

1. **TcPO2 與 ABI**：測量 TcPO2 > 40 mm Hg 能可靠反映傷口癒合潛力；ABI 常因血管鈣化假性偏高。
2. **截肢風險預估**：HbA1c ≥ 8.0% 且空腹血糖 ≥ 126 mg/dL，以及血清 Albumin < 3.0 g/dL，顯著增加下肢截肢風險。
3. **Meggitt-Wagner 與 SINBAD**：Wagner Stage 3 為深層潰瘍併發膿瘍或骨髓炎；SINBAD 為 IWGDF 推薦之 6 分制臨床溝通評分。
4. **截肢解剖 Pearls**：大拇趾截肢須保留 FHB 肌腱附著；蹠骨射線截肢中，第一射線需保留/重固定 Tibialis anterior 肌腱，第五射線需重固定 Peroneus brevis 肌腱；Transmetatarsal 截肢需保留約 3 cm 之第二蹠骨近端基底以維護 Lisfranc 穩定。
5. **Charcot 關節病**：Eichenholtz Stage 1 發炎期嚴禁手術內固定；Brodsky Type 1（中足）最常見；抬腳 5 分鐘退紅可與蜂窩性組織炎鑑別；重構手術術後需嚴格非負重 12–16 週。

## Summary

本章全面解析糖尿病足的病理生理機轉、臨床診斷與治療思維。針對糖尿病足潰瘍，應以血管檢查（TcPO2）結合 Meggitt-Wagner 與 SINBAD 系統進行評估，並透過多學科團隊優化血糖（HbA1c < 8.0%）與營養（Albumin > 3.0 g/dL）；非手術端以銳性清創及 Total Contact Casting (TCC) 減壓為核心，必要時輔以廣效靜脈抗生素及血管重建處置（降低主要截肢率近 30%）。在截肢手術方面，必須嚴格遵守解剖細節（如第一射線保留脛前肌腱、第五射線保留腓骨短肌腱、Transmetatarsal 截肢保留 3 cm 第二蹠骨基底）以維持肢體力學平衡。針對夏科氏神經關節病變，臨床醫師應熟悉 Eichenholtz 三期與 Brodsky 解剖分型，於 Stage 1 嚴禁內固定並給予 TCC 負重保護，待 Stage 3 發炎鞏固後再執行雙平面楔形切骨術與關節融合重構，提供患者穩固且無潰瘍的 plantigrade 足部。
