# Chapter 53: Cervical Degenerative Conditions — 頸椎退行性疾病

## 章節導讀

頸椎退行性疾病是一個光譜：從 <span style="color:#e2e8f0">spondylosis（脊椎退化症）</span> 與 <span style="color:#e2e8f0">radiculopathy（神經根病變）</span>，一路延伸到 <span style="color:#e2e8f0">deformity（畸形）</span> 與 <span style="color:#e2e8f0">myelopathy（脊髓病變）</span>，其臨床表徵與手術策略完全不同。本章依「臨床評估與關鍵解剖、分型與決策矩陣、保守與手術治療指引、手術入路與陷阱、實證重點」五個層次整理，並以表格比較前方、后方與合併入路，以及融合與保留活動度手術的差異。

## 1. 臨床評估與關鍵解剖 (Clinical Evaluation & Key Anatomy)

### 1.1 退行性疾病的臨床光譜

頸椎退化可造成一整個疾病光譜，呈現疼痛、功能障礙與畸形。治療的核心是**個別化**：以減輕疼痛、恢復功能與矯正畸形為目標，選擇合適的保守或手術處置。

| 疾病範疇 | 主要表徵 | 治療主軸 |
|----------|----------|----------|
| **Spondylosis（脊椎退化）** | 影像退變，可無症狀 | 保守、衛教、追蹤 |
| **Radiculopathy（神經根病變）** | 沿皮節分布的上肢放射痛、麻木、肌力下降 | 保守優先，失敗後減壓手術 |
| **Myelopathy（頸髓病）** | 手部笨拙、步態不穩、反射改變、括約肌症狀 | 中重度需手術減壓 |
| **Deformity（畸形／駝背）** | 軸性頸痛、鴿胸式 chin-on-chest 姿勢 | 矯正排列與穩定重建 |
| **Axial neck pain（單純軸性頸痛）** | 無神經學症狀之頸痛 | 手術證據薄弱，保守為主 |

> **Pearl**：軸性頸痛若**沒有**放射症狀或脊髓病變症狀，其手術治療的證據薄弱（poor），決策應相當保守。

### 1.2 頸髓病的病理機轉與神經電生理評估

<span style="color:#e2e8f0">Cervical myelopathy（頸髓病）</span> 的病理生理雖被認為來自脊髓壓迫，但以 <span style="color:#e2e8f0">Japanese Orthopaedic Association score（JOA 評分）</span> 衡量的嚴重度與功能障礙程度，可能因**頸動脈與椎動脈的動脈硬化**而進一步惡化，提示症狀可能有**血管性貢獻**。

| 檢查／評估 | 臨床用途 | 原文重點 |
|------------|----------|----------|
| **SSEP（somatosensory-evoked potentials，體感覺誘發電位）** | 預測**輕度頸髓病**的疾病嚴重度進展 | 屬神經生理監測的一種 |
| **SSEP ＋ MEP（motor-evoked potentials，運動誘發電位）** | 辨識表現隱晦的病人；區分**脊髓壓迫**與**神經退化性疾病**；協助判斷術後恢復 | 合併使用可達成上述功能 |
| **經顱電刺激 MEP（transcranial electrical MEP）** | 偵測早期頸髓病 | 相較 SSEP 具有**更佳敏感度** |
| **JOA／modified JOA（mJOA）** | 嚴重度分級與手術決策 | 中重度以 mJOA 判定者**建議手術** |


> **Danger zone**：<span style="color:#f87171;font-weight:600">頸髓病病人不會因頸部硬膜外注射而受益</span>——其效果未被證實能預防或延後手術治療；接受注射者在注射後 1 至 5 年間**接受手術的機率反而較高**（1 個月時手術率則無差異）。

### 1.3 深層椎旁肌、矢狀位排列與脆弱性骨折

- **深層頸椎椎旁肌的脂肪浸潤與萎縮**：頸髓病常合併深層椎旁肌的脂肪浸潤與萎縮，尤其是 <span style="color:#22d3ee">longus capitis（頭長肌）</span>、<span style="color:#22d3ee">longus colli（頸長肌）</span> 與 <span style="color:#22d3ee">multifidus（多裂肌）</span>，發生在**脊髓壓迫節段及其尾端**，並參與頸椎排列的維持。
- **動態 X 光的排列變化**：動態攝影上矢狀位參數的變化程度，與頸髓病人的症狀嚴重度相關。2020 年研究顯示，**屈曲時 C2–C7 lordosis 大於 29°** 的病人，其結果優於屈曲時 lordosis 僅 **29° 以內**的病人，**不論接受手術或非手術治療**。
- **脆弱性骨折（fragility fracture）**：除肌肉萎縮外，脆弱性骨折是頸髓病人**發病率與死亡率的重大貢獻因子**，且其發生率**在手術介入後下降**。

### 1.4 頸椎畸形（駝背）與駝背的臨床評估

頸椎畸形可伴隨軸性頸痛、神經根病變與頸髓病，造成顯著功能受損並降低生活品質。

| 面向 | 內容 |
|------|------|
| **病因** | 可源自脊椎退化症（spondylosis）進展；但**既往頸椎手術後的醫源性畸形（iatrogenic deformity）仍是最常見原因** |
| **機轉** | 頸後肌群去神經化與隨後萎縮，使**後方張力帶（posterior tension band）減弱**，增加前方柱所承受的壓迫力，導致頸椎駝背 |
| **發生率** | 椎板成形術或椎板切除術後**術後駝背發生率為 11%–21%** |
| **理學表現** | 可出現 **chin-on-chest deformity（下巴貼胸畸形）**，以 **head suspension test（頭部懸吊測試）** 評估：僵硬畸形病人仰臥時可將頭部懸空維持；**但表現變異性大，上頸椎畸形在某些病人外觀上並不明顯** |
| **影像評估** | 矢狀位與冠狀位排列以 **PA 與 lateral radiographs** 評估；**穩定性與活動度以屈曲－伸展 X 光** 評估 |
| **重要矢狀位參數** | **C2–C7 lordosis**、**sagittal vertical axis（SVA）**、**T1 slope（T1 斜率）**、**chin-brow vertebral axis（水平凝視用）** |
| **系統性連結** | 頸椎排列**高度依賴胸腰椎排列**；**53% 的胸腰椎畸形成人同時存在頸椎畸形** |

> **Pearl**：評估頸椎畸形時務必**同時看胸腰椎**——53% 的胸腰椎畸形成人合併頸椎畸形，忽略下方畸形會使上方代償失效。

## 2. 分型系統與決策矩陣 (Classification & Decision Making)

### 2.1 治療決策矩陣

| 臨床情境 | 建議方向 | 原文依據 |
|----------|----------|----------|
| 輕度頸髓病 | 可先採**非手術治療** | 輕度可啟動保守治療；但手術是防止脊髓病進展及其造成去神經與肌肉萎縮的建議手段 |
| 中度或重度頸髓病（mJOA 判定） | **建議手術** | 明確建議手術介入 |
| 孤立性頸神經根病變 | 先保守；多數外科醫師偏好**後方椎間孔切開術** | 治療選擇須個別化 |
| 軸性頸痛，無放射症狀或脊髓症狀 | 手術**證據薄弱**，保守優先 | 支援手術的證據 poor |
| 保守治療後仍持續或惡化的症狀 | 轉為手術 | 手術常用於對非手術治療無反應的頸髓病、畸形與頸神經根病變 |
| 頸椎畸形（駝背） | 需**重建穩定與排列**，必要時合併入路 | 圓周固定可改善穩定性、降低假關節（pseudarthrosis）機會 |

### 2.2 手術預後不良的預測因子

| 預後不良因子 | 說明 |
|--------------|------|
| **年齡偏高（advanced patient age）** | 術後結果較差 |
| **無法步行（nonambulatory status）** | 術後結果較差 |
| **症狀期間較長（longer symptom duration）** | 術後結果較差 |
| **抽菸（smoking status）** | 術後結果較差 |
| **工傷補償狀態（workers' compensation status）** | 術後結果較差 |
| **既有失能（disability）** | 術後結果較差 |
| **術前病人自述結果評分（PROMs）不佳** | **最強的預測因子**：頸神經根病變用 **neck disability index（NDI）**；頸髓病用 **modified Japanese Orthopaedic Association score（mJOA）** |

> **Danger zone**：單看影像嚴重度不足以預估結果；**術前 PROM（尤其是 NDI 與 mJOA）** 才是預測術後不良結果最強的指標。

### 2.3 症狀期間與病人共性因素對結果的影響

所有病人在手術後都有改善的可能，但下列族群可能獲得**較差的結果**：年齡增加、**症狀期間超過 1 年**、術前症狀嚴重度較高、有**糖尿病與抽菸**病史，以及合併**精神科共病（psychiatric comorbidities）**者。

> **Pearl**：病人期待值的討論（expectations）是術前必要環節，屬於**醫師與病人之間的共同決策（shared decision-making）**。

## 3. 治療指引：保守治療與手術適應症 (Treatment Algorithm)

### 3.1 非手術治療選項與成本效益

頸椎退行性疾病的非手術管理選項相當多元，2019 年研究顯示相較於手術治療，**非手術管理的成本相對低廉**。

| 治療選項 | 說明 |
|----------|------|
| **Activity modification（活動調整）** | 減少誘發症狀的活動 |
| **NSAIDs（非類固醇消炎藥）** | 口服消炎止痛 |
| **Muscle relaxants（肌肉鬆弛劑）** | 緩解肌肉痙攣 |
| **Analgesics（止痛藥）** | 症狀控制 |
| **Physical therapy（物理治療）** | 核心保守療法 |
| **Cervical traction（頸椎牽引）** | 減壓與症狀緩解 |
| **Injections（注射）** | 含硬膜外注射等（見 3.2） |
| **Acupuncture（針灸）** | 輔助療法 |
| **Bracing（頸托固定）** | 支撐與限制活動 |
| **Cervical manipulation（頸椎手法）** | 手法治療 |
| **Manual treatments（徒手治療）** | 手法治療 |

**成本數據**

| 項目 | 數值 |
|------|------|
| 非手術管理（1 年、每位病人） | **$1,143** |
| ACDF（1 年、每位病人） | **$22,559** |

> **Danger zone**：非手術處置在**術前管理**上仍有顯著變異性，主要因為**非手術治療與診斷方式皆缺乏以證據為基礎的指引**；且比較非手術與手術管理本身就很困難——兩組的**術前診斷、疾病嚴重度與治療適應症本來就不對等**，並且在病人逐步走向手術的過程中**存在大量交叉（crossover）**。

### 3.2 頸部硬膜外注射的定位

理論模型顯示，若接受**頸部硬膜外注射**的病人能避免手術的比例**低於 50%**，則 **ACDF 對頸神經根病變比硬膜外注射更具成本效益**。

| 事實 | 結果 |
|------|------|
| 對頸髓病的效益 | **無**——未被證實能預防或延後手術治療 |
| 注射後 1 至 5 年的手術機率 | **較高**（odds 較高） |
| 注射後 1 個月的手術率 | **兩組無差異** |

### 3.3 手術適應症總整理

| 適應症 | 說明 |
|--------|------|
| **頸髓病（中重度，mJOA）** | 明確建議手術 |
| **頸椎畸形** | 手術常用於畸形處理 |
| **對保守治療無反應的頸神經根病變** | 手術常用 |
| **軸性頸痛（無放射／脊髓症狀）** | **不建議以手術為主要策略**，證據薄弱 |
| **輕度頸髓病** | 可先採非手術治療，但手術是防止進展與去神經、萎縮的建議手段 |

> **Pearl**：輕度病人嘗試非手術選項是合理的；但對中重度頸髓病而言，**延遲手術可能導致不可逆的去神經與肌肉萎縮**。

## 4. 手術入路與危險地雷 (Surgical Approach & Pearls)

### 4.1 前方、後方與合併入路

| 入路 | 特色 | 併發症與注意事項 |
|------|------|--------------|
| **前方（anterior）** | 頸椎最常採用的入路；經**肌肉保留式剝離（muscle-sparing dissection）**；可用 **ACDF 合併或不合併 corpectomy** 處理單節段與多節段病變 | 術後**吞嚥困難（dysphagia）**；**聲音嘶啶**（喉返神經損傷或牽拉）；**椎動脈損傷**；**食道穿孔** |
| **後方（posterior）** | 歷史上有利於**多節段（三節或以上）**病變且排列正常者：可做更寬的椎板切除式減壓，以及**保留活動度的椎板成形術** | 術後疼痛較多、**併發症頻率較高**：持續矢狀位排列不良、進行性駝背、**傷口併發症** |
| **合併（combined）** | 同時暴露頸椎前後柱：前方 diskectomy 與 corpectomy，後方 laminectomy 與固定 | **圓周固定（circumferential instrumentation）**可改善穩定性、降低假關節機會 |

**前方減壓的機轉與證據**：ACDF 過程中**椎間盤間隙的撐開（distraction）**可造成**間接減壓**，增加椎間孔空間並最大化頸椎椎管直徑；證據顯示**增加撐開並不導致不良結果**。

> **Pearl**：多節段 ACDF 的病人也可預期顯著的術後症狀改善——**三節段與四節段 ACDF 的臨床結果沒有差異**。

### 4.2 融合手術（Fusion Procedures）

- **原理**：融合手術以跨節段橋接的方式**限制活動（restrict motion）**。
- **代價**：融合帶來的**鄰節段疾病（adjacent segment disease）**風險——融合形成的槓桿臂將力量傳導至鄰近椎间盘。
- **ACDF（anterior cervical diskectomy and fusion）**：**最常見的脊椎手術**，經常用於處理單節段或多節段頸椎退行性疾病。
- **Posterior cervical fusion（後方頸椎融合）**：較常保留給**年長、有頸髓病且為多節段病變**的病人；但因美國**人口老化**，以及**逐漸遠離單獨後方椎板切除**（因術後駝背風險），後方融合已日趨普遍。

### 4.3 保留活動度手術（Motion-Sparing Procedures）

<!-- FIG: 圖 4 — Lateral preoperative (A) and postoperative (B) radio- graphs of a cerv -->
![圖 4 — Lateral preoperative (A) and postoperative (B) radio- graphs of a cerv](/images/oku14/ch53_p0679_fig4.jpg)

保留活動度手術包括 **foraminotomy（椎間孔切開術）**、**laminectomy（椎板切除術）**、**laminoplasty（椎板成形術）** 與 **cervical disk arthroplasty（頸椎人工椎間盤置換術）**。

| 術式 | 技術要點 | 結果與爭議 |
|------|----------|------------|
| **Foraminotomy** | 屬**減壓手術**，擴大脊神經通過的開口以解除疼痛，適用於**孤立性頸神經根病變** | 多數外科醫師偏好**後方**而非前方入路施行椎間孔切開術 |
| **Laminectomy** | 椎板切除減壓 | 與椎板成形術結果相似，但**併發症較多** |
| **Laminoplasty（椎板成形術）** | 將椎板**鉸狀開啟（hinging open）**以增加椎管內可用空間，達到脊髓減壓；技術包括 **open-door（單開門）** 與 **double-door／French door（雙開門）** | 與**後方頸椎融合**結果相似，但**住院天數、再入院率與併發症較少**；**術前 C2–C7 lordosis 小於 7°** 可預測術後駝背；然而**仍是可行的椎板成形術候選者更常接受椎板切除融合**，即使結果相似但**併發症較多** |

> **Pearl**：椎板成形術與後方融合結果相似，但住院天數、再入院與併發症皆較少——然而臨床上多數適合的病人**仍被施以椎板切除融合**，是一個值得檢視的**underutilized procedure（未充分利用的手術）**。

### 4.4 頸椎人工椎間盤置換（Cervical Disk Arthroplasty）

頸椎人工椎間盤為**前方手術**，核准用於**一節或兩節**頸椎退行性椎间盘疾病。與融合相比，椎间盘置換**保留該節段的 facet joints（小關節）**，並藉由保留術中節段的**生理活動**而可能降低鄰節段變化的風險。

| 考量面向 | 原文重點 |
|----------|----------|
| **植入物設計** | 允許**平移獨立於旋轉**的假體較能恢復生理活動範圍與來自鄰節段的負荷分擔（load-sharing） |
| **活動量過多** | 2020 年研究顯示，**過多的活動可能與異位性骨化（heterotopic ossification）形成有關**，而異位性骨化會**隨時間降低活動範圍** |
| **活動受限型假體** | 對**角度與平移運動具阻力**的假體可提供較佳的脊柱構造穩定性，但代價是**活動減少與鄰節段疾病風險增加** |
| **其他穩定因子** | 假體**高度、植入位置**以及**術後軟組織包覆的完整性**皆對椎间盘置換構造的穩定有重要影響 |
| **病人選擇** | 理想病人：**骨質良好、無不穩定、無駝背**；**後縱韌帶骨化（OPLL）**或**強直性脊椎炎（ankylosing spondylitis）**病人常被排除，因增加的活動可能導致其疾病進展 |
| **成本** | 許多外科醫師認為頸椎椎间盘置換**費用昂貴**；但近期研究顯示其**成本效益與 ACDF 相當（comparably cost-effective）** |
| **臨床結果** | 雙盲隨機對照試驗中 **2 年**結果與 ACDF **相似**，包括 NDI、視覺類比評分（VAS）、上肢與頸部疼痛分數、**SF-36 健康問卷**與 **EuroQol 問卷**等 |
| **其他效益** | 與 ACDF 相比，**鄰節段疾病與再手術率較低**；**術後吞嚥困難比率較低**；在**兩節段疾病**中臨床結果較佳 |

| **其他效益** | 與 ACDF 相比，**鄰節段疾病與再手術率較低**；**術後吞嚥困難比率較低**；在**兩節段疾病**中臨床結果較佳 |

> **Danger zone 1**：**ACDF 與頸椎椎间盘置換之爭議長期存在，且置換術的採用率緩慢**——除了費用考量，關鍵在於病人選擇與假體設計的匹配，而非單純的手術技術。

> **Danger zone 2**：**過度活動與異位性骨化有關**；選擇允許大量平移自由活動的假體時，需權衡骨化造成的活動度喪失。

> **Danger zone 3**：**後方入路的併發症不容忽視**——持續矢狀位排列不良、進行性駝背與傷口問題皆較前方入路常見；多節段病變（≥3 節）且排列正常者，傳統上偏好後方以進行更寬的減壓或椎板成形術，但需仔細評估。

> **Danger zone 4**：**椎板成形術後駝背**與**術前 C2–C7 lordosis < 7°** 相關；而**後方單獨椎板切除**因術後駝背風險，正逐漸被融合取代。

### 4.5 手術策略小結

頸椎退化可造成**神經根病變、脊髓病變與畸形**的疾病光譜，導致疼痛與失能。保守與手術治療皆存在，對**輕度**病人採取非手術選項是合理的；**手術能有效改善結果**，而入路與術式必須**依病人個別化**，目標為**減輕疼痛、恢復功能與矯正畸形**。

### 5.2 OKU 14 Key Study Points（本章重點整理）

- 頸椎退行性疾病可從 **spondylosis 與 radiculopathy** 延伸到 **deformity 與 myelopathy**。
- 頸椎退行性疾病的非手術治療選項包括：activity modification、NSAIDs、肌肉鬆弛劑、止痛藥、物理治療、頸椎牽引、注射、針灸、頸托固定、頸椎手法與徒手治療。
- 手術治療在有適應症時，可採取**前方、後方與合併入路**，並可選擇**保留活動度或融合**的術式。

### 5.3 骨科專科考試核心總結（Take-Home Points）

1. **疾病光譜**：脊椎退化症／頸神經根病變／頸椎畸形／頸髓病，四者的治療門檻完全不同；**軸性頸痛無放射或脊髓症狀者手術證據薄弱**。
2. **頸髓病**：中重度以 mJOA 判定者**建議手術**；輕度可先保守，但手術是防止**去神經與肌肉萎縮**的建議手段。術前 **mJOA** 與 NDI 是**最強的預後預測因子**。
3. **預後不良因子**：高齡、無法步行、症狀期間 > 1 年（尤其神經根病變）、抽菸、工傷、失能、糖尿病與精神科共病。
4. **神經電生理**：**經顱電刺激 MEP 的敏感度優於 SSEP**，可偵測早期頸髓病；SSEP 與 MEP 合用可辨識隱晦表現、區分脊髓壓迫與神經退化，並協助判斷術後恢復。
5. **矢狀位與肌肉**：深層椎旁肌（頭長肌、頸長肌、多裂肌）脂肪浸潤與萎縮參與排列；**屈曲時 C2–C7 lordosis > 29°** 者結果較佳；**53%** 胸腰椎畸形成人合併頸椎畸形；椎板成形術後駝背發生率 **11%–21%**，**術前 C2–C7 lordosis < 7°** 為預測因子。
6. **成本**：非手術管理每人每年 **$1,143**，ACDF 為 **$22,559**；若硬膜外注射的病人避免手術的比例**低於 50%**，ACDF 較具成本效益。
7. **入路**：前方最常用，合併多節段 ACDF（三節 vs. 四節）結果無差異；後方併發症較多（持續矢狀位不良、進行性駝背、傷口問題）；合併入路可改善穩定性、降低假關節機會。
8. **椎板成形術**：與後方融合結果相似，但**住院天數、再入院率與併發症較少**，卻仍常被椎板切除融合取代。
9. **人工椎間盤**：核准用於一至二節段；2 年結果與 ACDF 相似，**鄰節段疾病與再手術率較低、術後吞嚥困難較少**；但**活動過多與異位性骨化相關**，OPLL 與強直性脊椎炎多被排除。

## Summary

- **疾病光譜**：頸椎退行性疾病自 spondylosis、radiculopathy 延伸至 deformity 與 myelopathy；**軸性頸痛（無放射／脊髓症狀）手術證據薄弱**。
- **頸髓病評估**：病理多來自脊髓壓迫，但**頸／椎動脈硬化**可能加重 JOA 評分所示的嚴重度；**經顱電刺激 MEP 的敏感度優於 SSEP**，可偵測早期病變；中重度（mJOA）**建議手術**，輕度可先保守以避免不可逆的去神經與萎縮。
- **排列與肌肉**：深層椎旁肌（頭長肌、頸長肌、多裂肌）脂肪浸潤與萎縮影響排列；屈曲時 C2–C7 lordosis **> 29°** 結果較佳；**53%** 胸腰椎畸形成人合併頸椎畸形；術後駝背發生率 **11%–21%**。
- **成本與注射**：非手術管理 **$1,143** vs. ACDF **$22,559**（每人每年）；**硬膜外注射對頸髓病無益**，且注射後 1–5 年手術機率較高；避免手術比例**低於 50%** 時 ACDF 較具成本效益。
- **術式選擇**：前方最常用（三節 vs. 四節 ACDF 結果無差異）；後方併發症較多（持續矢狀位不良、進行性駝背、傷口問題）；合併入路以圓周固定改善穩定、降低假關節；**椎板成形術**結果與後方融合相似但**住院天數、再入院與併發症較少**，**術前 C2–C7 lordosis < 7°** 預測術後駝背。
- **人工椎間盤**：核准一至二節段；2 年結果與 ACDF 相似（NDI、VAS、SF-36、EuroQol），**鄰節段疾病與再手術率較低、吞嚥困難較少**；活動過多與**異位性骨化**相關，OPLL 與強直性脊椎炎多被排除。
- **預後因子**：術前 **NDI 與 mJOA** 為最強預測因子；高齡、無法步行、症狀 > 1 年、抽菸、工傷、失能、糖尿病與精神科共病者結果較差。
