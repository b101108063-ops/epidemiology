> **Gordis Epidemiology** 第五版 | Chapter 19

## 章節摘要

**公共政策的制定需要扎實的科學證據，而流行病學是提供此類證據的核心工具。** 本章介紹風險評估的 framework、政策制定的流行病學基礎，以及如何將流行病學研究結果轉化為實際政策。同時探討研究中的不確定性來源與風險溝通的挑戰。

---

## 1. 風險評估的 framework

### 四步驟模型

風險評估是公共政策的科學基礎，分為四個步驟：

| 步驟 | 名稱 | 說明 |
|------|------|------|
| 1 | **危害識別（Hazard identification）** | 某物質是否會對健康造成危害？ |
| 2 | **劑量-反應評估（Dose-response assessment）** | 暴露量與危害程度之間的關係為何？ |
| 3 | **暴露評估（Exposure assessment）** | 實際暴露於該危害物質的程度？ |
| 4 | **風險特徵化（Risk characterization）** | 整合前三步，估計特定族群的風險 |

> **臨床重點**
> 風險評估的每一步都涉及不確定性。正確的政策制定需要公開、透明地呈現這些不確定性，而非掩蓋或忽略它們。

### 危害識別

**危害識別**是確認某物質是否可能對健康造成危害的過程。主要證據來源包括：

- **流行病學研究**：族群層級的疾病與暴露關聯
- **毒理學研究**：動物實驗與體外試驗
- **機械研究**：疾病發生機制的科學理解

---

## 2. 劑量-反應關係

### 核心概念

**劑量-反應關係**描述暴露劑量與健康效應發生率之間的數學關係。

| 劑量類型 | 說明 |
|---------|------|
| **閾值劑量** | 低於此劑量不產生可測量效應 |
| **非閾值劑量** | 任何劑量都可能產生風險（線性無閾模型） |
| **參考劑量（RfD）** | EPA 制定的每日暴露參考劑量 |

### 環境污染物範例

| 物質 | 健康效應 | 劑量-反應特徵 |
|------|---------|-------------|
| **石棉** | 間皮瘤、肺癌 | 線性無閾；無安全暴露水平 |
| **鉛** | 神經毒性（兒童） | 閾值效應；血鉛濃度臨界點 |
| **PM2.5** | 心肺疾病死亡 | 接近線性；每增加 10 μg/m³，死亡風險上升約 4-8% |
| **二手菸** | 肺癌 | 被動吸菸風險約為主動吸菸的 20-30% |

> **臨床重點**
> 並非所有污染物都有明顯的閾值。**線性無閾模型**假設任何暴露都存在風險，這對於致癌物的風險評估尤其重要。

## 3. 暴露資料來源

### 主要來源分類

| 類別 | 資料來源 | 優點 | 限制 |
|------|---------|------|------|
| **訪談資料** | 直接訪談本人或替代回答者 | 取得特定暴露資訊 | 回憶偏差；替代者資訊可能不準確 |
| **就業與職業紀錄** | 工廠紀錄、保險紀錄 | 客觀、可驗證 | 可能不完整；暴露分類粗糙 |
| **醫師紀錄** | 门诊、住院紀錄 | 醫療專業記錄 | 僅記錄就醫者的暴露 |
| **醫院紀錄** | 診斷、處置紀錄 | 系統性收集 | 可能有編碼誤差 |
| **疾病登記** | 癌症登記等 | 可追蹤特定疾病 | 僅限特定疾病 |
| **死亡證明** | 死亡原因的標準化分類 | 全國性資料 | 死因判斷可能不準確 |

### 暴露測量的誤差來源

| 誤差類型 | 說明 |
|---------|------|
| **隨機誤差** | 測量值的隨機變異，降低精確度 |
| **系統性誤差（偏差）** | 測量值系統性偏離真實值 |
| **回憶偏差** | 病例組比對照組更傾向回憶暴露 |
| **選擇偏差** | 研究族群的暴露分布不代表目標族群 |

## 4. 環境流行病學

### 定義與範圍

**環境流行病學**研究環境因素（如空氣污染、水質、土壤污染、噪音、辐射）對人群健康的影響。

### 空氣污染與健康

| 污染物 | 主要來源 | 健康效應 | 證據強度 |
|--------|---------|---------|---------|
| **PM2.5** | 車輛、工廠燃燒 | 心肺死亡、肺癌、哮喘惡化 | 強（多國多研究一致） |
| **臭氧（O₃）** | 汽車廢氣光化反應 | 呼吸道症狀、肺功能下降 | 中等 |
| **二氧化硫（SO₂）** | 燃煤電廠 | 哮喘發作、呼吸症狀 | 中等 |
| **二氧化氮（NO₂）** | 交通排放 | 呼吸道症狀、哮喘 | 中等 |
| **一氧化碳（CO）** | 汽車廢氣 | 頭暈、頭痛、心血管效應 | 強（急性暴露） |

### 全球性環境健康問題

| 問題 | 影響 |
|------|------|
| **氣候變遷** | 熱浪死亡、病媒蚊分布改變、空氣品質惡化、食品安全威脅 |
| **空氣污染** | 全球約 700 萬人過早死亡/年（WHO 估計） |
| **水污染** | 腹瀉疾病、霍亂、傷寒等水媒傳播疾病 |
| **土壤污染** | 重金屬（鉛、鎘、砷）累積對食物鏈的影響 |

> **臨床重點**
> 環境流行病學面臨獨特的挑戰：暴露測量困難（空氣污染物暴露差異大）、長期低劑量暴露效應難以偵測、多因素混合暴露的交互作用。

## 5. 職業流行病學

### 定義與目標

**職業流行病學**研究工作場所因素與工人健康之間的關係，是**職場健康與安全（Occupational health）**的科學基礎。

### 經典職業病研究

| 研究 | 職業暴露 | 健康效應 | 發現 |
|------|---------|---------|------|
| **Pott（1775）** | 掃煙囪工人 | 陰囊癌 | 首次識別職業性癌症 |
| **Ramazzini（1700s）** | 各類工人 | 多種職業病 | 職業醫學之父 |
| **Hill（1950s）** | 染料工廠 | 膀胱癌 | 聯苯胺職業暴露 |
| ** Doll & Hill（1950s）** | 醫師 | 肺癌 | 吸菸與肺癌的流行病學證據 |

### 職業癌症的主要暴露

| 致癌物 | 相關癌症 | 主要暴露行業 |
|--------|---------|------------|
| **石棉** | 肺癌、間皮瘤 | 建築、造船、絕緣材料 |
| **苯** | 白血病 | 石油、化工、橡膠 |
| **甲醛** | 鼻咽癌 | 化工、建材、防腐 |
| **游離輻射** | 肺癌、白血病、甲狀腺癌 | 核能、醫療、礦業 |
| **紫外線** | 黑色素瘤、皮膚癌 | 農業、建築戶外工作者 |
| **柴油廢氣** | 肺癌 | 礦業、運輸 |

### 多重風險因子介入試驗（MRFIT）

| 項目 | 內容 |
|------|------|
| **目的** | 測試多重風險因子介入（戒菸、血壓控制、降膽固醇）能否降低冠心病死亡 |
| **設計** | 隨機對照試驗 |
| **族群** | 35-57 歲男性，高風險者 |
| **主要結果** | 介入組與對照組死亡率無顯著差異 |
| **重要發現** | 死亡率下降主要來自整體人群風險因子的改善，而非特定介入計畫 |

## 6. 系統性文獻回顧與統合分析

### 系統性文獻回顧（Systematic Review）

**系統性文獻回顧**是使用明確、系統化方法識別、評價並整合所有相關研究的文獻回顧。

| 步驟 | 說明 |
|------|------|
| 1 | 定義研究問題（PICO 格式） |
| 2 | 制定搜尋策略 |
| 3 | 篩選相關研究 |
| 4 | 評估研究品質 |
| 5 | 提取資料 |
| 6 | 整合與分析結果 |

### 統合分析（Meta-analysis）

**統合分析**是使用統計方法整合多項研究的定量結果，產生單一效應估計值的技術。

| 指標 | 說明 |
|------|------|
| **Pooled RR/OR** | 統合多研究後的加權平均效應估計 |
| **I² 統計量** | 衡量研究間異質性（I² > 50% 表示高度異質） |
| **發表偏差** | 顯著結果較易發表，導致系統性偏差 |
| **漏斗圖** | 視覺化檢測發表偏差 |

### 證據等級金字塔

| 等級 | 研究類型 | 說明 |
|------|---------|------|
| **Level I** | 隨機對照試驗的系統性回顧 | 最高等級證據 |
| **Level II** | 個別隨機對照試驗 | 高品質 RCT |
| **Level III** | 世代研究、病例對照研究 | 觀察性研究 |
| **Level IV** | 病例系列、專家意見 | 較低等級證據 |

> **臨床重點**
> 統合分析可增加統計效力，但**垃圾進、垃圾出（GIGO）**原則依然適用。若統合的研究品質不佳，統合分析的結果也會有問題。

## 7. 政策制定中的流行病學角色

### 政策制定的階段

| 階段 | 流行病學角色 |
|------|------------|
| **問題識別** | 識別健康問題，描述疾病分布 |
| **風險評估** | 危害識別、劑量-反應評估 |
| **選項開發** | 評估不同政策的潛在效益 |
| **決策** | 提供成本效益證據 |
| **實施** | 監測政策效果 |
| **評估** | 評估政策是否達到預期目標 |

### 實證政策的原則

| 原則 | 說明 |
|------|------|
| **透明性** | 政策決策的科學依據必須公開 |
| **可重複性** | 其他研究者可驗證相同證據 |
| **不確定性的溝通** | 明確說明證據的強度與限制 |
| **價值觀納入** | 科學無法完全回答價值判斷問題 |

### 監管機構與科學顧問

| 機構 | 角色 |
|------|------|
| **EPA（美國環保署）** | 制定環境標準，基於風險評估 |
| **FDA（美國食藥署）** | 藥物、醫療器材、食品安全 |
| **OSHA（職業安全衛生署）** | 職場安全標準 |
| **WHO（世界衛生組織）** | 國際衛生規範、指導方針 |
| **IARC（國際癌症研究中心）** | 致癌物分類 |

### 從研究到政策的範例

| 案例 | 科學證據 | 政策結果 |
|------|---------|---------|
| **紙菸與肺癌** | Doll & Hill 1950 年代前瞻研究 | 菸盒警示標語、公共場所禁菸 |
| **石棉與間皮瘤** | 多國流行病學研究確認 | 限制或禁止石棉使用 |
| **PM2.5 空氣污染** | 時間序列研究、世代研究 | 空氣品質標準（EPA 1997, 2006） |
| **反式脂肪** | 族群研究證實心血管風險 | FDA 禁止部分氫化油 |

## 8. 不確定性的來源

### 研究設計相關的不確定性

| 來源 | 說明 |
|------|------|
| **研究設計不當** | 研究可能未針對感興趣問題設計 |
| **偏差** | 選擇偏差、資訊偏差、混雜未適當控制 |
| **測量誤差** | 暴露測量不準確導致錯誤分類 |
| **樣本量不足** | 統計效力不足，無法偵測真實效應 |
| **分析方法不當** | 統計方法選擇錯誤 |
| **未考量混雜因素** | 重要混雜變數未被控制 |
| **外部效度不足** | 研究結果可能無法推論至目標族群 |

### 效應修飾（Effect Modification）

**效應修飾**是指某變數改變了暴露與疾病之間關聯的強度或方向。

| 情境 | 說明 |
|------|------|
| **年齡** | 某暴露對年輕人的效應可能與老年人不同 |
| **性別** | 激素差異可能影響化學物質的毒性 |
| **遺傳變異** | 基因多型性可能影響藥物或毒物代謝 |
| **社會經濟地位** | 營養、醫療可近性等可能修飾環境效應 |

### 不確定性的溝通

> **臨床重點**
> 不確定性不應成為無作為的藉口，但也不應被忽視。政策制定者需要在證據不完整的情況下做出決策，而**預警原則（Precautionary principle）**提供了一個 Framework：在證據不確定但存在嚴重危害可能時，應採取預防措施。

## 9. 風險溝通

### 風險溝通的原則

| 原則 | 說明 |
|------|------|
| **傾聽** | 了解公眾的關切與認知 |
| **誠實** | 公開說明風險與不確定性 |
| **清楚** | 使用易懂語言，避免專業術語 |
| **可信** | 引用可信賴的來源 |
| **持續** | 風險溝通是持續過程 |

### 風險比較

| 風險類型 | 終生死亡機率（美國） | 說明 |
|---------|-------------------|------|
| **汽車事故** | 約 1/107 | 全美主要死因之一 |
| **被閃電击中** | 約 1/21,000 | 極低 |
| **空氣污染（PM2.5）** | 約 1/2,000–1/5,000 | 依地區差異 |
| **二手菸暴露** | 約 1/10,000 | 增加肺癌風險約 20-30% |
| **吃烤肉** | 約 1/50,000 | 多環芳香烴暴露 |

> **臨床重點**
> 風險比較有助於公眾理解，但需謹慎使用：選擇性比較可能誤導。例如，「某物質的風險等於吃一片培根」聽起來很嚇人，但可能忽略劑量差異與可控性差異。

## 10. 案例研究：空氣污染政策

### 美國 EPA 空氣品質標準的演化

| 年份 | 標準 | 科學基礎 |
|------|------|---------|
| **1971** | 初訂 PM 標準 | 總懸浮微粒（TSP） |
| **1987** | 轉向 PM10 | 粒子大小與沉積位置 |
| **1997** | 首訂 PM2.5 標準 | 多項流行病學研究證實細微粒健康危害 |
| **2006** | 加嚴 PM2.5 標準 | 更多世代研究支持 |
| **2012** | 維持並微調標準 | 持續累積的科學證據 |

### 關鍵科學證據

- **時間序列研究**：短期 PM2.5 增加與每日死亡增加相關
- **世代研究**：長期暴露與心肺死亡率上升相關
- **干預研究**：大型活動期間（如北京奧運）空氣改善伴隨健康指標改善

## 章節總結

1. **風險評估是政策基礎**：四步驟 Framework（危害識別→劑量-反應→暴露評估→風險特徵化）提供結構化方法。

2. **流行病學證據需要詮釋**：研究結果受設計、品質、抽樣等因素影響；不確定性是科學過程的正常組成部分。

3. **系統性回顧提升證據品質**：統合分析可整合多研究結果，但研究品質是前提。

4. **環境與職業流行病學的獨特挑戰**：長期低劑量暴露、多因素混合、暴露測量困難。

5. **政策制定需要科學與價值的結合**：科學告訴我們「能夠做什麼」，價值判斷決定「應該做什麼」。

6. **風險溝通是雙向對話**：不僅是傳播資訊，更是傾聽與互動的過程。
